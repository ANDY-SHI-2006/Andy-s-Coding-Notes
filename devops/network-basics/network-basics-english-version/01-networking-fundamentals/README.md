# Networking Fundamentals

A practical networking fundamentals chapter for developers and DevOps engineers.

## Learning Goals

After completing this chapter, you should be able to:

- Explain how IP addresses, ports, protocols, DNS, gateways, and NAT relate.
- Use the TCP/IP layers to locate connection problems.
- Distinguish the responsibilities of TCP, UDP, HTTP, and HTTPS.
- Use common commands to inspect DNS, routes, ports, and HTTP responses.

## Prerequisites

Basic command-line skills are enough. Command examples identify Windows, Linux, or macOS differences.

## Learning Order

1. [Network Architecture and Core Concepts](01-network-architecture-and-core-concepts.md) — C/S, B/S, IP, ports, and protocols
2. [Network Addressing and Name Resolution](02-network-addressing-and-name-resolution.md) — IP, MAC, ARP, subnets, DNS, and NAT
3. [Network Layers and Transport Protocols](03-network-layers-and-transport-protocols.md) — OSI, TCP/IP, TCP, and UDP
4. [HTTP and HTTPS](04-http-and-https.md) — HTTP, status codes, TLS, and DevOps scenarios
5. [Network Troubleshooting](05-network-troubleshooting.md) — connectivity, DNS, ports, HTTP, and packet capture

## Practice After This Chapter

Complete these tasks on your own computer or a test environment:

1. Find the local IP address, default gateway, and DNS server.
2. Resolve a domain and check whether the target TCP port is reachable.
3. Use `curl` to inspect the response headers from an HTTPS request.
4. Write a troubleshooting sequence for “DNS works but the port is unreachable”.
