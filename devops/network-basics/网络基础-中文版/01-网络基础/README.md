# 网络基础

面向开发者和 DevOps 工程师的计算机网络基础教程。

## 学习目标

完成本章后，你应该能够：

- 解释 IP 地址、端口、协议、DNS、网关和 NAT 的关系。
- 使用 TCP/IP 分层模型定位连接问题。
- 区分 TCP、UDP、HTTP 和 HTTPS 的职责。
- 使用常见命令检查 DNS、路由、端口和 HTTP 响应。

## 前置知识

了解基本的命令行操作即可。命令示例会标注 Windows、Linux 或 macOS 的差异。

## 学习顺序

1. [网络架构与核心概念](01-网络架构与核心概念.md) — C/S、B/S、IP、端口与协议
2. [网络寻址与名称解析](02-网络寻址与名称解析.md) — IP、MAC、ARP、子网、DNS 与 NAT
3. [网络分层与传输协议](03-网络分层与传输协议.md) — OSI、TCP/IP、TCP 与 UDP
4. [HTTP 与 HTTPS](04-HTTP与HTTPS.md) — HTTP、状态码、TLS 与 DevOps 场景
5. [网络故障排查](05-网络故障排查.md) — 连通性、DNS、端口、HTTP 与抓包

## 完成本章后的实操

在自己的计算机或测试环境中完成以下任务：

1. 找出本机 IP、默认网关和 DNS 服务器。
2. 解析一个域名，并确认目标服务的 TCP 端口是否可达。
3. 使用 `curl` 查看一次 HTTPS 请求的响应头。
4. 根据“DNS 正常但端口不通”的场景写出排查步骤。
