# 1 Linux 基础

> 本章介绍 Linux 是什么、如何在虚拟机中搭建环境，以及日常最常用的基本指令。

## 1.1 什么是操作系统

常见的操作系统：**Windows、MacOS、安卓、iOS、Linux**。

操作系统是直接运行在计算机硬件上的系统软件，它既能控制硬件，也能支撑运行在其上的软件。

> **操作系统的作用**——承上启下：**向下**控制硬件，**向上**控制应用软件。

### 为什么要学 Linux

| 原因 | 说明 |
| --- | --- |
| 上线自己的项目 | 学完框架后，把项目部署到云服务器（腾讯云、阿里云、华为云……）上，通常是 Linux |
| 便宜且易上手 | 学生云服务器（2 核 2G）一年大约 70~99 元 |
| 随处远程操作 | 通过 SSH 远程连接，任何地方都能操作你的服务器 |

---

## 1.2 虚拟机与 VMware

**虚拟机（VM）** 的作用是模拟一台真实的计算机——在你的物理机里跑一台虚拟电脑。最常见的虚拟机软件是 **VMware**。

### 安装 VMware

1. 安装包鼠标右键，选择**以管理员身份运行**。
2. 一直点“下一步”；确保安装路径有足够空间（尽量避开 C 盘）。
3. 输入许可证密钥（网上很多），然后完成。

---

## 1.3 创建虚拟机

1. 在 VMware 中新建虚拟机，按向导操作。
2. 开机前，给虚拟机挂载一个 **CD/DVD 镜像**（Ubuntu ISO）。
3. 国内快速下载镜像（Ubuntu 22.04）：https://mirrors.tuna.tsinghua.edu.cn/ubuntu-releases/22.04.5/
4. 第一次开机需要一点时间，耐心等待。
5. 安装时：时区选择**上海**，用户名用**英文**（不要用中文）。
6. 装好后把当前状态保存为**快照**，下次可直接恢复。

> **提示**——第一次登录后如果出现更新提示，不要更新。

| --- | --- |
| `Ctrl + +` | 放大 |
| `Ctrl + -` | 缩小 |

### 命令提示符

```bash
bb@computer:~$
```

| 部分 | 含义 |
| --- | --- |
| `bb` | 当前登录的用户名 |
| `@computer` | 当前主机名 |
| `~` | 当前所在目录；`~` 表示用户主目录（`/home/bb`） |
| `$` | 普通用户的提示符（`#` 表示 root 超级管理员） |

每个用户都有自己的主目录：`bb` → `/home/bb`，`root` → `/root`。

```bash
sudo passwd root   # 第一次需要设置管理员密码
su root            # 切换到管理员
su bb              # 回到普通用户
```

## 1.5 命令格式

```text
command [-options] [parameter]
```

| 部分 | 含义 | 示例 |
| --- | --- | --- |
| `command` | 命令名字 | `cd`、`pwd`、`ls` |
| `[-options]` | 选项，0 个或多个（可合并） | `-r`、`-la` |
| `[parameter]` | 参数，0 个或多个 | `cd game` 中的 `game` 就是参数 |

> `[ ]` 表示**可选**，不是实际要输入的内容。

### 相对路径与绝对路径

```bash
cd folder     # 进入下一级目录（相对路径）
cd ..         # 返回上一级目录
cd ~          # 切换到用户主目录
cd /          # 切换到根目录
```

| 类型 | 定义 |
| --- | --- |
| 相对路径 | 以**当前位置**为起点进出 |
| 绝对路径 | 以 `/`（根）开头 |

### `ifconfig` 需要安装 `net-tools`

```bash
sudo apt-get update      # 更新包源
sudo apt install net-tools
```

> `sudo` 以管理员模式运行指令；`apt install net-tools` 可以类比 Python 的 `pip install xxx`。

如果报锁错误（`/var/lib/dpkg/lock-frontend`），找到并杀掉占用锁的进程：

```bash
sudo lsof /var/lib/dpkg/lock-frontend
sudo kill -9 PID
```

## 1.8 目录结构

Windows 从 C 盘、D 盘等磁盘出发；Linux 一切从根目录 `/` 开始。

```bash
ls /
```

```text
bin  boot  dev  etc  home  lib  lib64  media  mnt  opt
proc root  run  sbin  snap  srv  sys  tmp  usr  var
```

| 目录 | 用途 |
| --- | --- |
| `/bin`、`/sbin` | 系统基本可执行程序 |
| `/boot` | 启动文件 |
| `/dev` | 设备文件 |
| `/etc` | 配置文件 |
| `/home` | 用户主目录 |
| `/lib`、`/lib64` | 共享库 |
| `/media`、`/mnt` | 挂载点 |
| `/opt` | 可选/第三方软件 |
| `/proc`、`/sys` | 虚拟文件系统（内核与进程信息） |
| `/root` | root 用户的主目录 |
| `/tmp` | 临时文件 |
| `/usr` | 用户程序 |
| `/var` | 可变数据（日志、缓存） |

## 1.9 常用命令

### 1.9.1 `ls`——列出目录内容

显示目录中的文件和子目录（名称、权限、大小、时间等）。

```bash
ls            # 当前目录
ls /home/bb   # 指定目录
ls .          # 等价于 ls
ls ..         # 上一级目录
ls ~          # 用户主目录
ls /          # 根目录
```

| 选项 | 含义 |
| --- | --- |
| `-l` | 长格式（权限、所有者、大小、时间） |
| `-a` | 显示所有文件（包括 `.` 开头的隐藏文件） |
| `-la` | 两者结合（等价于 `ll`） |

```bash
ls -la
```

### 1.9.2 `cd`——切换目录

```bash
cd ~        # 用户主目录（等价于单独 cd）
cd ..       # 上一级
cd ../..    # 上两级
cd /path    # 绝对路径
cd dir      # 当前目录下的子目录（相对路径）
cd -        # 切换到上一次所在的目录
```

### 1.9.3 `pwd`——显示当前目录

打印当前目录的绝对路径。

### 1.9.4 `touch`——创建文件

```bash
touch filename
```

### 1.9.5 `cat`——读取文件

把文件内容显示到终端。

```bash
cat filename
cat -n filename   # 显示行号（包括空行）
```

### 1.9.6 `mkdir`——创建目录

```bash
mkdir mydir              # 创建一个文件夹
mkdir mydir1 mydir2      # 创建多个文件夹
mkdir -p game/fps        # 递归创建父目录（game 和 fps）
```

### 1.9.7 `rmdir`——删除空目录

```bash
rmdir -p game/fps/   # 删除 game 和 fps（上下级关系）
```

> 只能删除**空**目录——非空目录用 `rm`。

### 1.9.8 `rm`——删除文件/目录

```bash
rm -f file    # 强制删除，不提示
rm -r dir     # 递归删除（用于目录）
rm -rf dir    # 强制 + 递归（危险！）
```

> `sudo rm -rf` 非常危险——删除的数据无法恢复。

### 1.9.9 `cp`——复制

```bash
cp source destination
```

| 选项 | 含义 |
| --- | --- |
| `-r` | 递归复制目录（复制文件夹**必须**加） |
| `-i` | 目标已存在时询问是否覆盖 |
| `-f` | 直接覆盖 |
| `-n` | 不覆盖，跳过 |
| `-s` | 创建符号链接（快捷方式） |

### 1.9.10 `mv`——移动/重命名

```bash
mv dir /        # 把 dir 移动到根目录
mv dir dir2     # 把 dir 重命名为 dir2
```

| 选项 | 含义 |
| --- | --- |
| `-i` | 移动前询问是否覆盖 |
| `-f` | 强制覆盖 |
| `-n` | 不覆盖 |

### 1.9.11 `clear`——清空终端

```bash
clear    # 快捷键：Ctrl + L
```

## 1.10 通配符

| 通配符 | 含义 |
| --- | --- |
| `*` | 匹配任意多个字符（0 个或多个） |
| `?` | 匹配任意 1 个字符 |
| `[abcd]` | 匹配 a、b、c、d 中任意一个 |
| `[0-9]` | 匹配一个数字（范围） |

```bash
rm -rf test[234567]   # 删除 test2 ~ test7
rm -rf file*.json     # 删除匹配 file*.json 的文件
```

| 模式 | 匹配 |
| --- | --- |
| `bb*` | 以 `bb` 开头的文件 |
| `bb*.py` | 以 `bb` 开头、`.py` 结尾的文件 |
| `bb?.txt` | `bb` + 一个字符 + `.txt` |
| `bb????` | `bb` 开头，后面跟四个字符 |
| `[abcd]*` | 以 a/b/c/d 开头的文件 |
| `b[0-9][0-9]*` | `b` + 两个数字 + 任意 |

---

| 推荐做 | 不要做 |
| --- | --- |
| 用 `cd ~` / `cd /` 快速回到主目录/根目录 | 安装时用户名不要用中文 |
| 按 `Tab` 自动补全，避免拼写错误 | 不要执行 `sudo rm -rf /`——会删光系统 |
| 用 `ls -la` 查看隐藏文件与权限 | 不要混淆相对路径和绝对路径 |
| 做危险操作前先拍一个虚拟机快照 | 第一次登录后不要自动更新 |

**记忆口诀**——`cd` 换地方，`ls` 看内容，`pwd` 知位置；`touch` 建文件，`mkdir` 建目录，`rm -rf` 需谨慎。万物始于根目录 `/`。
