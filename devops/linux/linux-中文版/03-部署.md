# 3 部署

> 本章把 Django 项目变成真正的线上服务：Web 服务器、Apache、MySQL，以及生产环境的黄金组合 **uWSGI + Nginx**。

## 3.1 Web 服务器介绍

**Web 服务器** 是网站的后台服务器，Django 在其上搭建 Web 项目。

| 服务器 | 说明 |
| --- | --- |
| **Apache** | 开源老牌 Web 服务器，长期世界第一；操作简单、速度快、性能稳定，几乎能跑在所有平台上 |
| **IIS** | 微软旗下的 Web 服务器 |
| **Nginx** | 开源后起之秀，俄罗斯开发的高并发服务器；静态/下载服务器，支持负载均衡、反向代理 |
| **Tengine** | 淘宝基于 Nginx 修改的版本 |

## 3.2 搭建 Apache 服务器

### 安装

```bash
sudo apt update               # 更新包列表
sudo apt install apache2      # 安装 Apache
```

### 管理服务

```bash
sudo systemctl start apache2     # 启动
sudo systemctl stop apache2      # 停止
sudo systemctl status apache2    # 查看状态
sudo systemctl restart apache2   # 重启
sudo systemctl enable apache2    # 开机自启
```

### 验证是否启动

- `sudo systemctl status apache2` → 看到 `Active: active (running)` 说明已启动。
- 虚拟机浏览器访问：http://127.0.0.1 或 http://localhost/
- 物理机浏览器访问：http://<虚拟机ip>

### 放上自己的网页

把 HTML 文件放到 `/var/www/html/`，例如 `test.html`：

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Apache 测试成功</title>
</head>
<body>
    <h1>Hello, Apache!</h1>
    <h1 style="color: red">这说明你的 Apache 服务器已经正常工作啦～</h1>
</body>
</html>
```

## 3.3 安装 MySQL

```bash
sudo apt install mysql-server
```

### 安全配置（交互式）

```bash
sudo mysql_secure_installation
# 1. root 密码强校验        -> N（学习阶段不需要）
# 2. 删除匿名用户            -> Y
# 3. 禁止 root 远程登录      -> N
# 4. 删除测试数据库          -> Y
# 5. 权限立即生效            -> Y
```

### 修改 root 密码

```bash
sudo mysql
```

```sql
use mysql;
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '123456';
FLUSH PRIVILEGES;  -- 强制重新加载权限表
EXIT;              -- 退出 MySQL 命令行
```

```bash
sudo systemctl restart mysql
mysql -uroot -p
```

### 允许远程访问

```sql
use mysql;                               -- 使用 mysql 数据库
update user set host="%" where user='root';  -- 允许所有主机访问
FLUSH PRIVILEGES;
```

如果客户端（如 Navicat）还是连不上，修改配置文件：

```bash
sudo vim /etc/mysql/mysql.conf.d/mysqld.cnf
# 把这行注释掉（行首加 #）
# bind-address=127.0.0.1
sudo systemctl restart mysql
```

## 3.4 部署 Django 项目

### 准备环境

```bash
sudo apt install python3
sudo apt install python3-pip
```

Linux 上命令有变化：`python` → `python3`，`pip` → `pip3`。

### 同步环境

```bash
pip freeze > requirements.txt          # 导出依赖（开发机上）
pip install -r requirements.txt        # 安装依赖（服务器上）
```

```bash
pip3 config set global.index-url https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple

pip3 install django==4.2.10

sudo apt install pkg-config            # mysql 开发库
sudo apt install libmysqlclient-dev

pip3 install mysqlclient==2.1.1
pip3 install pillow
```

### 建库并迁移

```bash
python3 manage.py makemigrations
python3 manage.py migrate
```

### settings.py

```python
ALLOWED_HOSTS = ["*"]    # 允许所有 IP 访问（生产环境不要用）
```

### 本地运行

```bash
python3 manage.py runserver               # 127.0.0.1:8000（仅本地）
python3 manage.py runserver 0.0.0.0:8000  # 监听所有网卡
```

> `runserver` 仍是**开发模式**——无法满足并发、可靠性、安全性的生产要求。

### 配置静态 IP（Netplan）

编辑 `/etc/netplan/01-network-manager-all.yaml`（`ens33`、IP、网关要按**你的**网络改，不要完全照抄）：

```yaml
network:
  version: 2
  renderer: NetworkManager
  ethernets:
    ens33:
      dhcp4: no
      addresses:
        - 192.168.16.66/24   # 静态 IP + 掩码（24 = 255.255.255.0）
      gateway4: 192.168.16.2  # 网关
      nameservers:
          addresses: [114.114.114.114, 8.8.8.8]  # DNS 服务器
```

应用并测试：

```bash
sudo netplan apply
ifconfig               # 查看 ens33 是否已改变
ping www.baidu.com     # 测试连通性
```

## 3.5 uWSGI + Nginx 配置

### 为什么需要 uWSGI？

```text
开发：   浏览器 -> Django（python manage.py runserver）   # 仅本地
生产：   浏览器 -> Nginx（Web 服务器）-> uWSGI（WSGI 服务器）-> Django
```

浏览器发的是 **HTTP**，Django 只懂 **WSGI**，两者协议不兼容，所以：

- **Nginx** 负责接收和返回 HTTP（它不懂 WSGI）。
- **uWSGI** 夹在中间，完成 **HTTP ↔ WSGI** 的双向转换。

| 要点 | 说明 |
| --- | --- |
| 协议转换 | Nginx 只说 HTTP，Django 只说 WSGI，uWSGI 在中间翻译 |
| 生产需要 | 内置的 `runserver` 只适合本地调试 |
| 性能 | uWSGI 支持多进程、高并发等优化 |

### 请求流程

1. 浏览器向 Nginx 的 80/443 端口发 HTTP 请求。
2. Nginx 分流：**静态**请求（如 `/static/pic.png`）直接从本地文件系统读取返回；**动态**请求（如 `/api/...`）转发给 uWSGI。
3. uWSGI 把 HTTP 转成 WSGI，交给 Django。
4. Django 处理逻辑，返回 WSGI 响应。
5. uWSGI 把 WSGI 响应转成 HTTP，返回给 Nginx。
6. Nginx 把 HTTP 响应最终返回浏览器。

### 安装 uWSGI

```bash
pip3 install uwsgi
sudo apt install uwsgi uwsgi-core uwsgi-plugin-python3
```

在项目里建 `delop/` 文件夹，里面建 `logs/` 文件夹，再建配置文件 `uwsgi_conf.ini`：

```ini
[uwsgi]
# uwsgi 的 ip 和端口（不要用 8000，那是留给 Django 开发服务器的）
socket=192.168.16.99:8001
# 项目根目录（按自己的改）
chdir=/home/bb/code/bbs
# wsgi.py 的相对路径（按自己的改）
wsgi-file=bbs/wsgi.py
# 进程数
processes=4
# 线程数
threads=2
# uwsgi 的角色
master=True
# 存放进程号的文件（自动创建）
pidfile=uwsgi.pid
# 日志文件（需先创建 logs 文件夹）
daemonize=logs/uwsgi.log
# python 环境路径（用 which python3 查看）
pythonpath=/usr/bin/python3
```

启动 / 停止：

```bash
uwsgi --ini uwsgi_conf.ini    # 启动并放入后台
uwsgi --stop uwsgi.pid         # 停止
ps -aux | grep uwsgi           # 查看是否启动
```

### 安装并配置 Nginx

```bash
sudo apt install nginx
```

创建 `/etc/nginx/conf.d/nginx_conf.conf`：

```nginx
server {
    # 监听端口（HTTP 默认端口）
    listen 80;
    # 域名或 IP，外部访问时用它匹配
    server_name 192.168.16.99;
    # 默认编码，防止中文乱码
    charset utf-8;
    # 限制上传大小（默认只有 1MB）
    client_max_body_size 75M;
    # 媒体文件（用户上传）【可选】
    location /media {
        alias /home/bb/code/bbs/media/;
    }
    # 静态文件（CSS、JS、图片）
    location /static {
        alias /home/bb/code/bbs/static/;
    }
    # 其余请求全部转发给 uwsgi
    location / {
        uwsgi_pass 192.168.16.99:8001;
        include /etc/nginx/uwsgi_params;
    }
}
```

再编辑 `/etc/nginx/nginx.conf`，把第一句后面的用户改成你 Linux 的登录用户名：

```bash
sudo vim /etc/nginx/nginx.conf
# user bb
```

测试并启动：

```bash
sudo nginx -t -c /etc/nginx/nginx.conf   # 测试配置是否有问题
sudo systemctl start nginx               # 启动
sudo systemctl status nginx              # 查看状态
```

浏览器访问 http://192.168.203.66/ 验证。

### 总结启动流程

```bash
# 1. 启动 uwsgi（成功标志：uwsgi.pid 存在，用 ps -aux | grep uwsgi 查看）
uwsgi --ini uwsgi_conf.ini
uwsgi --stop uwsgi.pid   # 停止方式

# 2. 启动 nginx
sudo systemctl start nginx
sudo systemctl stop nginx
sudo systemctl status nginx
sudo systemctl restart nginx

# 3. 访问项目——无需输入端口（nginx 默认监听 80）
```

生产环境改了 Python 代码不会立即生效，需重启 uwsgi：

```bash
uwsgi --stop uwsgi.pid
uwsgi --ini uwsgi_conf.ini

# 如果停止提示找不到 pid，用搜索后强制 kill
ps -aux | grep uwsgi
kill -9 PID
```

不重启就重载 Nginx 配置：

```bash
sudo nginx -s reload -c /etc/nginx/nginx.conf
sudo systemctl reload nginx
# 或直接重启
sudo systemctl restart nginx
```

日志在 `delop/logs/uwsgi.log`。

---

| 推荐做 | 不要做 |
| --- | --- |
| 部署前先配置静态 IP（Netplan） | 不要完全照抄 Netplan/YAML 配置——要匹配你的网络 |
| `ALLOWED_HOSTS = ["*"]` 仅学习阶段用 | 生产环境不要留 `ALLOWED_HOSTS = ["*"]` |
| 改了 Python 代码后重启 uWSGI | 不要用 `runserver` 作为生产服务器 |
| 出错先看 `delop/logs/uwsgi.log` | 不要让 Apache 和 Nginx 同时占用 80 端口 |

**记忆口诀**——Nginx 说 HTTP，Django 说 WSGI，uWSGI 当翻译；静态走 Nginx，动态走 uWSGI 再到 Django；装好后 `systemctl start` + 查 `status` + 访问 IP。
