# 6 运算符

## 6.1 算术运算符

### 6.1.1 基本算术运算

| 运算符 | 描述 | 示例 | 结果 |
|----------|-------------|---------|--------|
| `+` | 加法 | `5 + 3` | `8` |
| `-` | 减法 | `5 - 3` | `2` |
| `*` | 乘法 | `5 * 3` | `15` |
| `/` | 除法（浮点） | `5 / 2` | `2.5` |
| `//` | 整除（向下取整除法） | `5 // 2` | `2` |
| `%` | 取模（求余数） | `5 % 2` | `1` |
| `**` | 幂运算 | `2 ** 3` | `8` |

**注意：**

- 所有基本算术运算符（`+`、`-`、`*`、`/`、`//`、`%`、`**`）都同时适用于**整数**和**浮点数**。
- 当两个操作数都是 `int` 时，`+`、`-`、`*`、`//`、`%` 和 `**` 返回 `int`；`/` 总是返回 `float`。
- 如果任一操作数是 `float`，结果通常是 `float`。
- **浮点数的整除（`//`）：** 将结果**向下**取整到最接近的整数，但以 `float` 形式返回。
- **浮点数的取模（`%`）：** 按照相同的向下取整规则返回余数，同样以 `float` 形式返回。

```python
# Division always returns float
print(10 / 2)      # 5.0

# Floor division discards decimal
print(10 // 3)     # 3

# Modulo for cyclical operations
print(17 % 5)      # 2

# Floor division and modulo with floats
print(5.5 // 2.0)  # 2.0  (floor of 2.75)
print(5.5 % 2.0)   # 1.5  (5.5 - 2.0 * 2.0)
```

### 6.1.2 负数取模

当除数为正数时，Python 的 `%` 总是返回非负结果。

```python
print(-5 % 3)    # 1  (not -2)
print(5 % -3)    # -1 (sign follows divisor)
```

### 6.1.3 `divmod()`

一次调用同时返回商和余数。

```python
q, r = divmod(17, 5)   # q=3, r=2
```

## 6.2 比较运算符

### 6.2.1 基本比较

| 运算符 | 描述 | 示例 | 结果 |
|----------|-------------|---------|--------|
| `==` | 等于 | `5 == 5` | `True` |
| `!=` | 不等于 | `5 != 3` | `True` |
| `>` | 大于 | `5 > 3` | `True` |
| `<` | 小于 | `5 < 3` | `False` |
| `>=` | 大于或等于 | `5 >= 5` | `True` |
| `<=` | 小于或等于 | `5 <= 3` | `False` |

```python
age = 20
print(age >= 18)  # True
```

### 6.2.2 链式比较

Python 支持链式比较，可读性更好。中间值只求值一次。

```python
x = 5

# Equivalent to: 1 < x and x < 10
print(1 < x < 10)     # True

# Equivalent to: x == y == z
print(1 < 2 < 3 < 4)  # True
```

## 6.3 逻辑运算符

| 运算符 | 描述 | 示例 | 结果 |
|----------|-------------|---------|--------|
| `and` | 两者都必须为 True | `True and False` | `False` |
| `or` | 至少一个为 True | `True or False` | `True` |
| `not` | 布尔值取反 | `not True` | `False` |

```python
age = 25
income = 50000
print(age >= 18 and income > 30000)  # True
```

### 6.3.1 真值性（Truthiness）

在布尔上下文中求值为 `False` 的值：

| 值 | 类型 |
|-------|------|
| `0` | 整数零 |
| `0.0` | 浮点数零 |
| `''` | 空字符串 |
| `[]` | 空列表 |
| `{}` | 空字典 |
| `()` | 空元组 |
| `None` | NoneType |
| `set()` | 空集合 |

除此之外的一切值都是 `True`。

```python
name = ""
if not name:
    print("Name is empty")  # This prints
```

### 6.3.2 短路求值

`and` 返回它遇到的**第一个假值**，如果全部为真值则返回**最后一个值**。`or` 返回**第一个真值**，如果全部为假值则返回**最后一个值**。两种情况下，结果都是原始操作数之一，而不一定是布尔值 `True` 或 `False`。

```python
# and: stops at first falsy
print(0 and 99)        # 0 (stops at 0)
print(3 and 5 and 0)   # 0
print(3 and 5)         # 5 (all truthy, returns last)

# or: stops at first truthy
print(3 or 0)          # 3 (stops at 3)
print(0 or "" or 7)    # 7
print(0 or "")         # "" (all falsy, returns last)
```

**常见模式：**

- **默认值：** 当 `value` 为空或为假值时，`value or default` 返回 `default`。
  ```python
  name = input("Name: ") or "Anonymous"
  ```
- **访问前的守卫：** `obj and obj.method()` 可以避免对假值或 `None` 值调用方法。
  ```python
  user and user.name
  ```
- **选取第一个可用值：** `first or second or third` 返回第一个为真的选项。
  ```python
  port = env_port or config_port or 8080
  ```

## 6.4 赋值运算符

### 6.4.1 增强赋值

| 运算符 | 示例 | 等价于 |
|----------|---------|---------------|
| `=` | `x = 5` | `x = 5` |
| `+=` | `x += 3` | `x = x + 3` |
| `-=` | `x -= 3` | `x = x - 3` |
| `*=` | `x *= 3` | `x = x * 3` |
| `/=` | `x /= 3` | `x = x / 3` |
| `//=` | `x //= 3` | `x = x // 3` |
| `%=` | `x %= 3` | `x = x % 3` |
| `**=` | `x **= 3` | `x = x ** 3` |

```python
count = 10
count += 5   # count is now 15
```

### 6.4.2 海象运算符 `:=`

海象运算符在**表达式内部**赋值并返回该值。与作为语句的 `=` 不同，`:=` 是一个表达式，可以用在不允许使用语句的地方。

#### 6.4.2.1 `=` 与 `:=` 的对比

| 特性 | `=` | `:=` |
|---------|-----|------|
| 类型 | 语句 | 表达式 |
| 返回值 | 否 | 是 |
| 可用于 `if`/`while` | 否 | 是 |
| Python 版本 | 所有版本 | 3.8+ |

#### 6.4.2.2 常见模式

- **带输入的 while 循环：** 在一个表达式中把输入赋给 `line` 并检查它。
  ```python
  while (line := input()) != "quit":
      print(f"You entered: {line}")
  ```

- **在 `if` 中复用值：** 只计算一次值，同时用于条件和循环体。
  ```python
  if (n := len(data)) > 10:
      print(f"Too long: {n} items")
  ```

- **列表推导式中避免重复计算：** 赋值一个中间结果并对它进行过滤。
  ```python
  results = [y for x in data if (y := f(x)) > 0]
  ```

- **正则匹配并复用：** 捕获匹配对象并立即使用。
  ```python
  if (match := re.search(r"\d+", text)):
      print(match.group())
  ```

#### 6.4.2.3 限制

`:=` 不能作为独立语句使用。它必须出现在表达式上下文中。

```python
x := 1       # SyntaxError
(x := 1)     # OK — parentheses create expression context
```

## 6.5 身份运算符

### 6.5.1 `is` 和 `is not`

身份运算符比较的是内存地址（同一性），而不仅仅是值。

| 运算符 | 描述 | 示例 |
|----------|-------------|---------|
| `is` | 如果两个操作数引用内存中的同一个对象，则返回 `True` | `x is y` |
| `is not` | 如果两个操作数引用不同的对象，则返回 `True` | `x is not y` |

```python
a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a == b)   # True - same values
print(a is b)   # False - different objects in memory
print(a is c)   # True - same object (c references a)
```

**注意：** 关于驻留机制（小整数缓存、字符串驻留），参见 [5.3 内存驻留](05-数据类型总结.md#53-内存驻留interning基础)。

### 6.5.2 `id()` 函数

`id()` 函数返回对象的内存地址（同一性标识）。`id(x) == id(y)` 等价于 `x is y`。

`==` 通过调用 `__eq__` 比较**值**（相等性）。`is` 和 `id()` 比较**内存地址**（同一性），而不是值。

```python
a = [1, 2, 3]
print(id(a))    # Memory address of a
```

## 6.6 成员运算符

| 运算符 | 描述 | 示例 |
|----------|-------------|---------|
| `in` | 如果在序列中找到该值，则返回 `True` | `'a' in 'abc'` |
| `not in` | 如果未找到该值，则返回 `True` | `'x' not in 'abc'` |

```python
fruits = ["apple", "banana", "cherry"]
print("apple" in fruits)      # True
print("grape" not in fruits)  # True

# Dict membership checks keys
print("name" in {"name": "Alice", "age": 20})  # True

# String substring check
print("he" in "hello")  # True
```

## 6.7 位运算符

位运算符在二进制层面操作整数。不要把 `&` 和 `|` 与逻辑运算符 `and`/`or` 混淆。

| 运算符 | 名称        | 示例  | 结果                  |
| -------- | ----------- | -------- | ----------------------- |
| `&`      | 按位与（AND） | `5 & 3`  | `1`（`101 & 011 = 001`） |
| \|       | 按位或（OR）  | 5 \| 3   | 7（101 \| 011 = 111）    |
| `^`      | 按位异或（XOR） | `5 ^ 3`  | `6`（`101 ^ 011 = 110`） |
| `~`      | 按位取反（NOT） | `~5`     | `-6`（反转所有位） |
| `<<`     | 左移  | `5 << 1` | `10`（`1010`）           |
| `>>`     | 右移 | `5 >> 1` | `2`（`10`）              |

```python
flags = 0b1010
mask = 0b1100

print(flags & mask)   # 0b1000 (8) - keep bits set in both
print(flags | mask)   # 0b1110 (14) - set bits in either
print(flags ^ mask)   # 0b0110 (6)  - set bits different
print(flags << 1)     # 0b10100 (20) - multiply by 2
print(flags >> 1)     # 0b0101 (5)   - divide by 2
```

**位掩码（Bitmask）示例：**

```python
READ = 4    # 0b100
WRITE = 2   # 0b010
EXECUTE = 1 # 0b001

# Grant read + write
permissions = READ | WRITE   # 0b110 (6)

# Check if write is granted
print(bool(permissions & WRITE))  # True

# Revoke write
permissions &= ~WRITE
```

## 6.8 运算符优先级

按优先级从高到低排列：

| 优先级 | 运算符 | 描述 |
|------------|-----------|-------------|
| 1 | `()` | 括号（分组） |
| 2 | `**` | 幂运算 |
| 3 | `+x`、`-x`、`~x` | 一元正号、负号、按位取反 |
| 4 | `*`、`/`、`//`、`%` | 乘法、除法、整除、取模 |
| 5 | `+`、`-` | 加法、减法 |
| 6 | `<<`、`>>` | 位移动 |
| 7 | `&` | 按位与 |
| 8 | `^` | 按位异或 |
| 9 | \| | 按位或 |
| 10 | `==`、`!=`、`>`、`<`、`>=`、`<=`、`is`、`is not`、`in`、`not in` | 比较、身份、成员运算 |
| 11 | `not` | 逻辑非 |
| 12 | `and` | 逻辑与 |
| 13 | `or` | 逻辑或 |
| 14 | `if ... else` | 条件表达式 |
| 15 | `=`、`+=`、`-=` 等 | 赋值 |

> **最佳实践：** 使用括号让优先级明确。不要依赖记忆整张优先级表。

## 6.9 三元运算符

用一行代码写出简洁的条件表达式。

```python
# Syntax
value_if_true if condition else value_if_false

# Example
status = "adult" if age >= 18 else "minor"

# Equivalent to
if age >= 18:
    status = "adult"
else:
    status = "minor"
```

**注意：** 嵌套三元表达式是合法的，但会损害可读性。

```python
# Avoid
result = "A" if score >= 90 else "B" if score >= 80 else "C"

# Prefer
if score >= 90:
    result = "A"
elif score >= 80:
    result = "B"
else:
    result = "C"
```

## 6.10 运算符重载

使用特殊（魔术）方法为用户自定义类的运算符定义自定义行为。

> **注意：** 本节使用类和 `self`，这些内容在[第 12 章：面向对象编程](12-面向对象编程.md)中讲解。读完那一章后再回到这里，会有更深入的理解。

| 运算符 | 魔术方法 | 触发示例 |
|----------|--------------|-----------------|
| `+` | `__add__(self, other)` | `a + b` |
| `-` | `__sub__(self, other)` | `a - b` |
| `*` | `__mul__(self, other)` | `a * b` |
| `/` | `__truediv__(self, other)` | `a / b` |
| `==` | `__eq__(self, other)` | `a == b` |
| `!=` | `__ne__(self, other)` | `a != b` |
| `<` | `__lt__(self, other)` | `a < b` |
| `>` | `__gt__(self, other)` | `a > b` |
| `<=` | `__le__(self, other)` | `a <= b` |
| `>=` | `__ge__(self, other)` | `a >= b` |
| `str()` | `__str__(self)` | `print(a)` |
| `len()` | `__len__(self)` | `len(a)` |
| `[]` | `__getitem__(self, key)` | `a[key]` |

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

    def __eq__(self, other):
        return self.x == other.x and self.y == other.y

    def __str__(self):
        return f"Vector({self.x}, {self.y})"

v1 = Vector(1, 2)
v2 = Vector(3, 4)
print(v1 + v2)   # Vector(4, 6)
```
