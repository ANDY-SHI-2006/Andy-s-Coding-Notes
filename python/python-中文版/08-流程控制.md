# 8 流程控制

程序按照特定的顺序执行语句。默认情况下，Python 从上到下依次运行代码（顺序执行）。流程控制结构可以让你根据条件改变执行顺序，或者重复执行某段代码块。

## 8.1 分支结构

### 8.1.1 `if` / `elif` / `else`

按条件执行代码块。Python 使用缩进来定义代码块的作用域。

```python
age = 20

if age >= 18:
    print("Adult")
elif age >= 13:
    print("Teenager")
else:
    print("Child")
```

**要点：**
- `elif` 是 "else if" 的缩写——可以串联多个条件
- `else` 是可选的
- 只有第一个匹配的分支会被执行

```python
# Multiple conditions with elif
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"
```

**短路求值：**

`and` / `or` 从左向右求值，一旦结果可以确定就立即停止。

```python
# Safe: obj.name is only evaluated if obj is not None
if obj is not None and obj.name == "Alice":
    print(obj.name)
```

**用 `or` 提供默认值：**

`or` 在左操作数为真值（truthy）时返回左操作数，否则返回右操作数。这是提供备用值的常见惯用法。

```python
# If value is falsy (None, "", 0, []), use fallback instead
result = value or fallback_value

# Practical example
timeout = user_config or 30        # 30 if user_config is None/0/""
name = input("Name: ") or "Guest"  # "Guest" if user presses Enter
```

> 另请参阅：[7.2.3](07-用户交互.md#723-空输入的默认值) 中 `input()` 与 `or` 的用法。

### 8.1.2 三元运算符

一种用一行代码写出简单 if-else 语句的简洁方式。

**语法：**
```python
value_if_true if condition else value_if_false
```

**示例：**
```python
# Standard if-else
if age >= 18:
    status = "adult"
else:
    status = "minor"

# Ternary operator - equivalent in one line
status = "adult" if age >= 18 else "minor"
```

**使用场景：** 最适合简单的条件赋值。对于复杂逻辑，为了可读性应使用标准的 if-else。

### 8.1.3 单行 `if` 语句

Python 允许将简单的 `if` 语句写在同一行上。

**语法：**
```python
if condition: statement
```

**限制条件：**
- 该语句必须是**简单的、非复合语句**
- 允许：赋值、函数调用、单个表达式
- 不允许：嵌套的 `if`、循环或其他复合语句

**示例：**
```python
# Valid: simple statement on one line
if x > 0: print("positive")

# Invalid: compound statements not allowed on single line
# if x > 0: if y > 0: print("both positive")  # SyntaxError
```

**注意：** 单行 `if` 与三元运算符不同。单行 `if` 只处理"为真"的情况，没有 else 分支。

### 8.1.4 `match` / `case`（结构化模式匹配）

Python 3.10+ 引入的特性，用于将数据结构按模式进行匹配。

**何时使用 `match`、何时使用 `if`：**

| 场景 | 推荐 | 原因 |
|----------|-----------|--------|
| 多个精确值分支 | `match` | 比串联 `elif` 更清晰 |
| 复杂的布尔逻辑（`and`/`or`） | `if` | 表达能力更强 |
| 解构数据（元组、列表） | `match` | 模式绑定更简洁 |
| 范围比较（`>`、`<`） | `if` | `match` 中的守卫可读性较差 |
| Python < 3.10 | `if` | `match` 不可用 |

#### 8.1.4.1 基本值匹配

##### 8.1.4.1.1 基本语法

```python
status = 200

match status:
    case 200:
        print("OK")
    case 404:
        print("Not Found")
    case 500:
        print("Server Error")
    case _:
        print("Unknown status")
```

##### 8.1.4.1.2 执行顺序

各个 case 从上到下依次检查。第一个匹配的 `case` 会被执行，其余分支被跳过。`_`（通配符）应放在最后，否则它会遮蔽其下方的所有分支。

##### 8.1.4.1.3 无匹配

如果没有任何 `case` 匹配且没有 `_`，`match` 语句什么也不做——不报错，也不警告。

##### 8.1.4.1.4 OR 模式

用 `|` 匹配多个值。

```python
match status:
    case 200 | 201:
        print("Success")
    case 404 | 403 | 401:
        print("Client Error")
    case _:
        print("Other")
```

##### 8.1.4.1.5 枚举匹配

匹配 `Enum` 成员可以让代码更安全、更可读。

从概念上讲，这等价于用 `if` / `elif` 检查 `status == Status.OK`、`status == Status.NOT_FOUND` 等，但 `match` 能让分支结构更加清晰。

```python
from enum import Enum

class Status(Enum):
    OK = 200
    NOT_FOUND = 404
    ERROR = 500

match status:
    case Status.OK:
        print("Success")
    case Status.NOT_FOUND:
        print("Missing")
    case Status.ERROR:
        print("Failed")
```

##### 8.1.4.1.6 变量名陷阱

`case` 中的裸名称总是被当作**捕获变量**（绑定匹配到的值），而不是值比较。

写 `case HTTP_OK:` 实际上相当于 `HTTP_OK = status`——它会把匹配到的值赋给 `HTTP_OK`。

要进行比较，请使用字面量或带点号的名称。

```python
HTTP_OK = 200
match status:
    case HTTP_OK:       # ❌ Binds 'HTTP_OK', does NOT compare to 200
        print("OK")
    case 200:           # ✅ Literal comparison
        print("OK")
    case Status.OK:     # ✅ Dotted name comparison
        print("OK")
```

#### 8.1.4.2 序列匹配（列表 / 元组）

按结构匹配并绑定变量。

##### 8.1.4.2.1 元组匹配

```python
point = (3, 0)

match point:
    case (0, 0):
        print("Origin")
    case (x, 0):
        print(f"On x-axis at {x}")
    case (0, y):
        print(f"On y-axis at {y}")
    case (x, y):
        print(f"Point at ({x}, {y})")
```

##### 8.1.4.2.2 列表匹配

```python
items = [1, 2, 3]

match items:
    case []:
        print("Empty")
    case [single]:
        print(f"One item: {single}")
    case [first, second]:
        print(f"Two items: {first}, {second}")
    case [first, *rest]:
        print(f"First: {first}, Rest: {rest}")
```

##### 8.1.4.2.3 变量作用域

在 `case` 模式中绑定的变量，在 `match` 语句**之后**仍然可以访问。

```python
match point:
    case (x, y):
        pass
print(x, y)   # x and y are accessible here
```

##### 8.1.4.2.4 `as` 模式

在匹配各个组成部分的同时，捕获整个匹配到的值。

```python
match point:
    case (x, y) as pt:
        print(f"Matched {pt} with x={x}, y={y}")
```

#### 8.1.4.3 守卫子句

守卫（guard）在 `case` 之后添加一个 `if` 条件，对匹配到的值做进一步筛选。

**语法：** `case variable if condition:`

- `variable` 捕获匹配到的值
- `if condition` 决定该分支是否执行

```python
# Range classification
match age:
    case n if n < 13:      print("Child")
    case n if n < 20:      print("Teenager")
    case n if n < 65:      print("Adult")
    case _:                print("Senior")

# Structure match + guard
match nums:
    case [a, b, c] if a + b + c > 10:
        print(f"Sum {a+b+c} > 10")
    case [a, b, c]:
        print(f"Sum {a+b+c} <= 10")
```

**注意：** 每个 `case` 分支体可以在多行中包含多条语句。上面的示例把 `print` 写在同一行，只是为了在笔记中节省空间。

```python
# Equivalent multi-line version
match age:
    case n if n < 13:
        print("Child")
    case n if n < 20:
        print("Teenager")
    case n if n < 65:
        print("Adult")
    case _:
        print("Senior")
```

#### 8.1.4.4 字典匹配

按键的结构匹配字典。

```python
user = {"name": "Alice", "age": 20}

match user:
    case {"name": str(name), "age": int(age)}:
        print(f"{name} is {age} years old")
    case {"name": str(name)}:
        print(f"Name only: {name}")
    case {}:
        print("Empty dict")
```

#### 8.1.4.5 匹配数据类

按属性结构匹配类的实例。

```python
from dataclasses import dataclass

@dataclass
class Point:
    x: int
    y: int

p = Point(3, 4)

match p:
    case Point(x=0, y=0):
        print("Origin")
    case Point(x=0, y=y):
        print(f"On y-axis at {y}")
    case Point(x=x, y=y):
        print(f"Point ({x}, {y})")
```

> **注意：** `@dataclass` 中的 `x: int` 语法是**类型注解**（type hint）。它告诉 `@dataclass` 要生成哪些字段，并帮助 IDE 提供自动补全。参见 [16 类型注解](16-类型注解.md#16-类型注解)。

#### 8.1.4.6 通配符 `_`

`_` 匹配任意值但不绑定它。当不需要使用该值时很有用。

```python
match point:
    case (0, 0):
        print("Origin")
    case (_, 0):      # Any x, y is 0
        print("On x-axis")
    case (0, _):      # x is 0, any y
        print("On y-axis")
    case _:
        print("Somewhere else")
```

**类实例模式（`case ClassName()`）**

匹配某个类的任意实例，而不提取属性。

```python
match p:
    case Point():           # Any Point instance
        print("It's a point")
    case _:
        print("Not a point")
```

## 8.2 循环结构

### 8.2.1 `for` 循环

#### 8.2.1.1 基本迭代

遍历可迭代对象中的元素。

```python
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

for char in "hello":
    print(char)
```

#### 8.2.1.2 `range()`

生成一个数字序列。

##### 8.2.1.2.1 语法

```python
range(stop)
range(start, stop)
range(start, stop, step)
```

| 参数 | 说明 | 默认值 |
|-----------|-------------|---------|
| `start` | 起始值（包含） | `0` |
| `stop` | 结束值（**不包含**） | 必填 |
| `step` | 步长（增量或减量） | `1` |

##### 8.2.1.2.2 基本示例

```python
for i in range(5):           # 0, 1, 2, 3, 4
    print(i)

for i in range(1, 10, 2):    # 1, 3, 5, 7, 9
    print(i)

for i in range(10, 0, -1):   # 10, 9, ..., 1
    print(i)
```

> **注意：** `range()` 返回的是惰性迭代器，而不是列表。`range(10**9)` 在被迭代之前几乎不占用内存。

##### 8.2.1.2.3 `reversed()`

以逆序遍历序列，且不修改原序列。

```python
for i in reversed(range(5)):     # 4, 3, 2, 1, 0
    print(i)

for char in reversed("hello"):   # 'o', 'l', 'l', 'e', 'h'
    print(char)
```

#### 8.2.1.3 `enumerate()`

在遍历时同时获取索引和值。

##### 8.2.1.3.1 基本用法

```python
fruits = ["apple", "banana", "cherry"]

for i, fruit in enumerate(fruits):
    print(f"{i}: {fruit}")
# Output:
# 0: apple
# 1: banana
# 2: cherry
```

##### 8.2.1.3.2 自定义起始索引

```python
for i, fruit in enumerate(fruits, start=1):
    print(f"{i}. {fruit}")
# Output:
# 1. apple
# 2. banana
# 3. cherry
```

##### 8.2.1.3.3 要点

- `enumerate()` 产生 `(index, value)` 元组。`list(enumerate(["a", "b"]))` 的结果是 `[(0, "a"), (1, "b")]`。
- `start` 参数改变起始索引。常用 `1` 来实现符合人类习惯的编号方式。
- 从概念上讲，它类似于 `zip(range(len(iterable)), iterable)`，但 `enumerate()` 可读性更好、更符合 Python 风格（Pythonic）。
- 与 `range()` 一样，它返回惰性迭代器，而不是列表。

#### 8.2.1.4 `zip()`

并行遍历多个序列。在最短的序列处停止。

##### 8.2.1.4.1 基本用法

```python
names = ["Alice", "Bob", "Charlie"]
scores = [85, 92, 78]

for name, score in zip(names, scores):
    print(f"{name}: {score}")
# Output:
# Alice: 85
# Bob: 92
# Charlie: 78
```

##### 8.2.1.4.2 长度不等

当各个序列长度不同时，`zip()` 在最短的那个序列处停止。

```python
a = [1, 2, 3]
b = ['a', 'b']
list(zip(a, b))  # [(1, 'a'), (2, 'b')]
```

##### 8.2.1.4.3 用 `zip_longest` 填充

使用 `itertools.zip_longest` 可以一直迭代到最长的序列耗尽为止。缺失的值默认用 `None` 填充，也可以用 `fillvalue` 指定填充值。

```python
from itertools import zip_longest

list(zip_longest([1, 2, 3], ['a', 'b']))
# [(1, 'a'), (2, 'b'), (3, None)]

list(zip_longest([1, 2, 3], ['a', 'b'], fillvalue='?'))
# [(1, 'a'), (2, 'b'), (3, '?')]
```

##### 8.2.1.4.4 用 `zip(*matrix)` 转置

结合解包运算符 `*` 与 `zip`，可以将行和列转置。

```python
matrix = [[1, 2, 3], [4, 5, 6]]
cols = list(zip(*matrix))   # [(1, 4), (2, 5), (3, 6)]
```

##### 8.2.1.4.5 一次性迭代器

`zip()` 返回一次性迭代器。一旦耗尽，就不能再次迭代。

```python
z = zip([1, 2], ['a', 'b'])
list(z)  # [(1, 'a'), (2, 'b')]
list(z)  # [] — already exhausted
```

#### 8.2.1.5 字典迭代

```python
data = {"a": 1, "b": 2, "c": 3}

# Keys (default)
for key in data:
    print(key)

# Values
for value in data.values():
    print(value)

# Key-value pairs
for key, value in data.items():
    print(f"{key} = {value}")
```

#### 8.2.1.6 遍历时修改序列

不要在遍历序列的同时向其中添加或删除元素。由于索引会发生偏移，迭代器会跳过某些元素。

```python
# WRONG: skips elements
for item in items:
    if item < 0:
        items.remove(item)

# CORRECT: iterate over a copy
for item in items[:]:
    if item < 0:
        items.remove(item)
```

#### 8.2.1.7 循环变量的作用域

循环变量在循环**结束**之后仍然可以访问，其值为最后一次赋的值。如果循环从未执行，该变量则是未定义的。

```python
for i in range(3):
    pass
print(i)   # 2 — still accessible

for target in ["a", "b", "c"]:
    pass
print(target)   # 'c' — last value remains
```

### 8.2.2 `while` 循环

只要条件保持为 `True`，就重复执行代码块。

#### 8.2.2.1 基本语法

```python
count = 0
while count < 5:
    print(count)
    count += 1

# User input validation
password = ""
while password != "secret":
    password = input("Enter password: ")
print("Access granted")
```

**注意：** 要确保条件最终会变为 `False`，否则循环将永远运行下去。

#### 8.2.2.2 `while True` + `break` 模式

当退出条件需要在循环体内部确定时，使用 `while True`。

```python
# Menu loop
while True:
    choice = input("Enter command (q to quit): ")
    if choice == "q":
        break
    print(f"Processing: {choice}")

# Search loop with unknown end condition
while True:
    data = fetch_data()
    if data is None:
        break
    process(data)
```

### 8.2.3 `break` 语句

立即退出最内层循环。

```python
# Search for a value and stop when found
for i in range(100):
    if i == 42:
        print("Found it!")
        break
    print(i)  # Prints 0 to 41
```

**嵌套循环：** `break` 只退出**最内层**的循环。

```python
for i in range(3):
    for j in range(3):
        if i == j == 1:
            break          # Exits inner loop only
        print(f"({i}, {j})")
# Output: (0,0) (0,1) (0,2) (1,0) (2,0) (2,1) (2,2)
```

### 8.2.4 `continue` 语句

跳过当前迭代的剩余部分，直接进入下一次迭代。

```python
# Print only odd numbers
for i in range(10):
    if i % 2 == 0:
        continue
    print(i)  # Prints 1, 3, 5, 7, 9
```

> **注意：** 与 `break` 一样，在嵌套结构中 `continue` 也只作用于**最内层**循环。

### 8.2.5 循环的 `else` 子句

`else` 代码块**仅在循环正常结束时**（没有遇到 `break`）才会执行。

```python
# Example: Search for a value
for i in range(5):
    if i == 10:  # Condition not met
        print("Found!")
        break
else:
    # Executes because loop finished without break
    print("Not found - loop completed normally")
```

**使用场景：** 适用于搜索操作——你想知道是否没有找到目标项。

**`while...else`**

同样的逻辑也适用于 `while` 循环。

```python
# User input with retry limit
tries = 0
while tries < 3:
    password = input("Password: ")
    if password == "secret":
        print("Access granted")
        break
    tries += 1
else:
    print("Too many failed attempts")
```

### 8.2.6 `pass` 语句

一个什么也不做的占位符。当语法上必须有一条语句、但实际不需要任何操作时使用。

```python
# Placeholder for future implementation
if condition:
    pass  # Placeholder — does nothing, but satisfies syntax requirement

# Empty class or function body
class MyClass:
    pass

def my_function():
    pass
```
