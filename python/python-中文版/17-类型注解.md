# 17 类型注解

Python 是**动态类型**语言——变量的类型在运行时确定，并且随时可以将其重新赋值为另一种类型。这很灵活，但会让大型代码库变得难以理解。

**类型注解**（type annotation，也叫*类型提示*，type hint）用于说明一个值*应该*是什么类型。解释器并不会强制执行它们；它们的作用是：

1. **提升代码可读性**——其他开发者（以及未来的你）能明确知道预期的类型
2. **获得 IDE 支持**——自动补全、在运行前发现错误
3. **支持静态分析**——像 `mypy` 这样的工具可以在部署前捕获类型不匹配问题

可以把类型注解理解为**机器可读取的高质量注释**。

## 17.1 基本语法

用冒号 `:` 为名称附加类型。

```python
age: int = 25
name: str = "Alice"
pi: float = 3.14
enabled: bool = True
```

对于函数，为每个参数和返回值添加注解：

```python
def greet(name: str, times: int) -> str:
    return name * times

def log(message: str) -> None:
    print(message)
```

**语法小结：**

| 语法 | 位置 | 含义 |
|--------|-------|---------|
| `x: int` | 变量 / 参数 | 该值应当是 `int` |
| `-> str` | 函数返回值 | 该函数返回 `str` |
| `-> None` | 函数返回值 | 该函数不返回任何内容 |

## 17.2 常见类型

**基本类型：** `int`、`float`、`str`、`bool`、`None`

**集合类型**（Python 3.9+）：

```python
scores: list[int] = [90, 85, 88]
profile: dict[str, int] = {"age": 25, "score": 90}
point: tuple[int, int] = (3, 4)
flags: set[str] = {"a", "b"}
```

> **注意：** 在 Python 3.8 及更早版本中，需要从 `typing` 导入：`from typing import List, Dict, Tuple, Set`。

**联合类型**——当一个值可能是几种类型之一时：

```python
# Parameter can be int OR str
def find(user_id: int | str) -> dict | None:
    ...

# Most common case: parameter is optional (may be None)
def greet(name: str | None = None) -> str:
    if name is None:
        return "Hello, Guest"
    return f"Hello, {name}"
```

**⚠️ 常见陷阱：** 一个 `str | None` 类型的值并不确定是 `str`。必须先检查：

```python
def greet(name: str | None = None) -> str:
    # ❌ Wrong: None has no upper() method
    # return name.upper()

    # ✅ Correct: narrow the type before using it
    if name is None:
        return "Hello"
    return name.upper()
```

这种「先检查再使用」的模式称为**类型窄化**（type narrowing）。

**旧版语法**（Python ≤3.9）：

```python
from typing import Union, Optional

# Same meaning as int | str
def find(user_id: Union[int, str]) -> Union[dict, None]:
    ...

# Optional[X] is shorthand for Union[X, None]
def greet(name: Optional[str] = None) -> str:
    ...
```

**语法对比：**

| 含义     | Python 3.10+ | Python ≤3.9       |
| ----------- | ------------ | ----------------- |
| int 或 str  | int \| str   | `Union[int, str]` |
| str 或 None | str \| None  | `Optional[str]`   |
| int 组成的列表 | `list[int]`  | `List[int]`       |

**@dataclass 示例**——类型注解的实际应用：

```python
from dataclasses import dataclass

@dataclass
class Point:
    x: int
    y: int

p = Point(3, 4)  # __init__ generated automatically from annotations
```

## 17.3 运行时行为

类型提示在运行时**不会被强制执行**，解释器会完全忽略它们。

```python
def add(a: int, b: int) -> int:
    return "surprise"   # Runs fine; no runtime error

add(1, 2)   # Returns "surprise" without complaint
```

如需真正的检查，请使用静态类型检查器，例如 `mypy`：

```bash
mypy script.py
# error: Incompatible return value type (got "str", expected "int")
```

你也可以在运行时读取类型提示：

```python
import typing

def add(a: int, b: int) -> int:
    return a + b

print(typing.get_type_hints(add))
# {'a': <class 'int'>, 'b': <class 'int'>, 'return': <class 'int'>}
```

**何时使用类型注解：**
- ✅ 函数签名（尤其是公开 API）
- ✅ 从值上看不出明显类型的变量
- ✅ 复杂的数据结构
- ❌ 不要为显而易见的简单情形过度注解，例如 `i: int = 0`
