# 10 文件操作

## 10.1 打开与关闭文件

### 10.1.1 `open()` 函数

`open()` 是一个内置函数，用于返回一个文件对象（file object）。

```python
open(file, mode='r', encoding=None, ...)
```

| 参数 | 含义 |
|-----------|---------|
| `file` | 文件路径（字符串或 `Path`） |
| `mode` | 打开文件的方式；默认为 `"r"` |
| `encoding` | 文本编码；文本文件请使用 `"utf-8"` |

如果手动打开文件，必须调用 `close()` 来释放系统资源：

```python
f = open("data.txt", "r", encoding="utf-8")
content = f.read()
f.close()
```

忘记关闭文件会泄漏系统资源，在长时间运行的程序中尤其如此。

### 10.1.2 `with` 语句

`with` 语句创建一个上下文，文件对象会在代码块结束时自动关闭，即使发生错误也不例外。

```python
with open("data.txt", encoding="utf-8") as f:
    content = f.read()
# File is closed here
```

语法：

```python
with open(file, mode, encoding) as variable:
    # work with the file object
```

由于 `with` 能保证资源清理，它是打开文件的推荐方式。本章所有示例都使用 `with`。

### 10.1.3 路径类型

**相对路径**相对于当前工作目录解析。

```python
"./file.txt"       # In the current directory
"../data/file.txt" # One level up, then into data/
```

**绝对路径**从文件系统的根目录开始。

```python
"C:/Users/name/file.txt"   # Forward slashes work on Windows too
"/home/name/file.txt"      # Linux / macOS
```

为了跨平台兼容，建议在路径中使用 `/`。

**Windows 反斜杠与原始字符串。** Windows 路径传统上使用 `\`。在 Python 字符串中，`\` 是转义字符，因此 Windows 路径要么进行转义，要么写成原始字符串（raw string）。

```python
"C:\\Users\\name\\file.txt"  # Escaped backslashes
r"C:\Users\name\file.txt"    # Raw string: backslash is literal
```

**当前工作目录。** 所有相对路径的起点都是**当前工作目录**。如果程序从另一个目录运行，同一个相对路径可能指向不同的文件。

关于如何查看或更改当前工作目录，详见 [10.6 路径与文件元数据](#106-路径与文件元数据)。

### 10.1.4 文件打开模式

**读模式**

| 模式 | 说明 |
|------|-------------|
| `"r"` | 读（默认）。文件必须存在。 |

```python
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()
```

**写模式**

| 模式 | 说明 |
|------|-------------|
| `"w"` | 写（覆盖，文件不存在则创建） |
| `"a"` | 追加（文件不存在则创建） |
| `"x"` | 创建并写入；文件已存在则失败 |

```python
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Hello\n")

with open("log.txt", "a", encoding="utf-8") as f:
    f.write("New entry\n")
```

**读写模式**

| 模式 | 说明 |
|------|-------------|
| `"r+"` | 读写；**不截断**；文件必须存在 |
| `"w+"` | 读写；**先截断**；文件不存在则创建 |
| `"a+"` | 读并追加；文件不存在则创建；写入总是落在文件末尾 |

**关键区别：** `"r+"` 保留已有内容且要求文件存在；`"w+"` 会先清空文件，文件不存在时则创建。使用 `"a+"` 时，无论 `seek()` 如何定位，写入总是落在文件末尾，因此它主要用于日志式的追加写入。

```python
with open("data.txt", "r+", encoding="utf-8") as f:
    f.seek(0)
    f.write("NEW")     # Overwrites first 3 chars, keeps the rest

with open("fresh.txt", "w+", encoding="utf-8") as f:
    f.write("Hello")   # Creates or clears the file
    f.seek(0)
    print(f.read())    # "Hello"
```

**二进制模式**

在任意模式后加上 `b` 即以二进制模式打开文件（`"rb"`、`"wb"`、`"ab"`、`"r+b"`……），此时操作的是原始 `bytes` 而非 `str`。完整的模式表、读写方法以及文本模式与二进制模式的区别，见 [10.3 二进制文件](#103-二进制文件)。

### 10.1.5 编码

文本文件存储的是字节；`encoding` 告诉 Python 如何把这些字节转换成字符。打开文本文件时务必指定 `encoding="utf-8"`，避免依赖系统默认编码。

```python
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()
```

关于编码、字节及常见陷阱的更多细节，见 [10.5 字符编码](#105-字符编码)。

## 10.2 文件对象的方法

### 10.2.1 读取方法

这些方法从文本文件中读取数据。它们都作用于以文本模式打开的文件对象。

除非另有说明，本节的示例假设 `data.txt` 的内容为：

```text
Line 1
Line 2
Line 3
```

**`read()`**

| 方法 | 返回值 | 参数 |
|--------|---------|------------|
| `read()` | 整个文件内容，以字符串返回 | — |
| `read(n)` | 最多 `n` 个字符，以字符串返回 | `n`：字符数量 |

```python
with open("data.txt", encoding="utf-8") as f:
    content = f.read()

print(repr(content))
# 'Line 1\nLine 2\nLine 3\n'
```

**字符与字节的区别：** `read(n)` 读取的是 **n 个字符**，而不是 n 个字节。使用 UTF-8 时，一个汉字在磁盘上占 3 个字节，但 `read(1)` 仍返回一个字符。完整示例见 [10.5.5 字节位置与多字节字符](#1055-字节位置与多字节字符)。

**`readline()`**

| 方法 | 返回值 |
|--------|---------|
| `readline()` | 文件中的一行，包括末尾的换行符 |

```python
with open("data.txt", encoding="utf-8") as f:
    first = f.readline()
    second = f.readline()

print(repr(first))   # 'Line 1\n'
print(repr(second))  # 'Line 2\n'
```

**`readlines()`**

| 方法 | 返回值 |
|--------|---------|
| `readlines()` | 所有行组成的字符串列表 |

```python
with open("data.txt", encoding="utf-8") as f:
    lines = f.readlines()

print(lines)
# ['Line 1\n', 'Line 2\n', 'Line 3\n']
```

### 10.2.2 写入方法

这些方法向文件写入数据。它们要求文件以写模式（`"w"`、`"x"`）或追加模式（`"a"`）打开。

**`write()`**

| 方法 | 返回值 | 参数 |
|--------|---------|------------|
| `write(string)` | 写入的字符数 | `string`：要写入的文本 |

```python
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Hello World\n")
```

**`writelines()`**

| 方法 | 返回值 | 参数 |
|--------|---------|------------|
| `writelines(lines)` | `None` | `lines`：字符串可迭代对象 |

```python
with open("output.txt", "w", encoding="utf-8") as f:
    f.writelines(["Line 1\n", "Line 2\n"])
```

**不会自动添加换行符**

`write()` 和 `writelines()` 都不会自动添加换行符。如果省略 `\n`，连续的写入会拼接在同一行。

```python
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Hello")
    f.write("World")

# File content: HelloWorld
```

```python
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Hello\n")
    f.write("World\n")

# File content:
# Hello
# World
```

`writelines()` 同样如此：

```python
with open("output.txt", "w", encoding="utf-8") as f:
    f.writelines(["Line 1", "Line 2"])

# File content: Line 1Line 2
```

### 10.2.3 文件指针控制

这些方法控制文件指针（cursor）的位置。

**`tell()`**

| 方法 | 返回值 |
|--------|---------|
| `tell()` | 当前指针位置（以字节计） |

```python
with open("data.txt", encoding="utf-8") as f:
    f.read(5)
    print(f.tell())   # 5
```

**注意：** 位置以**字节**计数，而不是字符。使用 UTF-8 时，一个汉字占 3 个字节，因此读取一个汉字后 `tell()` 返回 `3`——完整示例见 [10.5.5 字节位置与多字节字符](#1055-字节位置与多字节字符)。

**`seek()`**

| 方法 | 参数 |
|--------|------------|
| `seek(offset, whence=0)` | `offset`：移动的字节数；`whence`：参照点 |

**参数：**

| 参数 | 含义 | 取值 |
|-----------|---------|--------|
| `offset` | 移动的字节数。正值向前移动，负值向后移动。 | 整数 |
| `whence` | 移动的参照点。 | `0` = 文件开头（默认），`1` = 当前位置，`2` = 文件末尾 |

**各 `whence` 取值的示例：**

```python
with open("data.txt", "rb") as f:
    f.read(5)

    f.seek(0)       # whence=0: back to the start
    f.seek(3, 0)    # whence=0: 3 bytes from the start
    f.seek(-2, 1)   # whence=1: 2 bytes backward from current position
    f.seek(0, 2)    # whence=2: move to the end of the file
```

**常见用法：**

```python
# Rewind to the beginning and re-read
with open("data.txt", encoding="utf-8") as f:
    first = f.read(5)
    f.seek(0)
    second = f.read(5)

# Jump to the end of the file
with open("data.txt", "rb") as f:
    f.seek(0, 2)
    print(f.tell())   # File size in bytes
```

**文本模式的限制：**

在文本模式下，`seek()` 按字节移动，但必须落在字符边界上。文本模式中 `whence=1` 和 `whence=2` 通常只允许 `offset=0`。如需任意字节偏移，请以二进制模式（`"rb"`）打开文件。

关于多字节字符（如 UTF-8 中文）的特殊情况，见 [10.5.5 字节位置与多字节字符](#1055-字节位置与多字节字符)。

### 10.2.4 逐行迭代

逐行处理文件最常用的方式是 `for` 循环。

```python
with open("data.txt", encoding="utf-8") as f:
    for line in f:
        print(line.strip())   # strip() removes trailing newline
```

**为什么这样可以？**

`open()` 返回的文件对象是一个**迭代器**（iterator）。在 `for` 循环中使用它时，Python 会反复调用等效于 `readline()` 的操作，直到到达文件末尾：

```python
# What for line in f: does internally
while True:
    line = f.readline()
    if not line:        # Empty string means end of file
        break
    # process line
```

这种方式内存效率高，因为每次只加载一行，而不像 `read()` 那样加载整个文件。

关于底层的迭代器机制，见 [11.5 迭代器](11-高级函数.md#115-迭代器)。

## 10.3 二进制文件

二进制模式读写原始字节。适用于图片、音频或序列化二进制数据等非文本文件。

### 10.3.1 二进制文件模式

| 模式 | 说明 |
|------|-------------|
| `"rb"` | 二进制读。文件必须存在。 |
| `"wb"` | 二进制写。覆盖或创建。 |
| `"ab"` | 二进制追加。文件不存在则创建。 |
| `"r+b"` | 二进制读写。不截断。 |
| `"w+b"` | 二进制读写。先截断。 |

```python
with open("photo.jpg", "rb") as f:
    data = f.read()
```

### 10.3.2 二进制读取方法

| 方法 | 说明 |
|--------|-------------|
| `read()` | 读取全部字节 |
| `read(n)` | 最多读取 `n` 个字节 |

```python
with open("data.bin", "rb") as f:
    data = f.read()
```

### 10.3.3 二进制写入方法

| 方法 | 说明 |
|--------|-------------|
| `write(bytes)` | 写入一个 `bytes` 对象 |

```python
with open("data.bin", "wb") as f:
    f.write(b"\x00\x01\x02")
```

### 10.3.4 文本模式与二进制模式对比

| 方面 | 文本模式 | 二进制模式 |
|--------|-----------|-------------|
| 模式示例 | `"r"`、`"w"`、`"a"` | `"rb"`、`"wb"`、`"ab"` |
| 数据类型 | `str` | `bytes` |
| 编码 | 自动进行编码/解码 | 不做编码解释 |
| 适用场景 | 纯文本文件 | 图片、音频、序列化二进制数据 |

```python
# Copy an image file byte by byte
with open("photo.jpg", "rb") as src:
    with open("copy.jpg", "wb") as dst:
        dst.write(src.read())
```

## 10.4 常见文件格式

### 10.4.1 JSON

**`json.dumps()`**

| 函数 | 用途 |
|----------|---------|
| `json.dumps(obj, ...)` | Python 对象 → JSON 字符串 |

```python
import json

data = {"name": "Alice", "age": 25}
json_str = json.dumps(data, ensure_ascii=False)
# '{"name": "Alice", "age": 25}'
```

**`ensure_ascii` 参数：**

- `True`（默认）：非 ASCII 字符会被转义为 `\uXXXX` 序列，输出为纯 ASCII。
- `False`：非 ASCII 字符按原样输出，对中文及其他 Unicode 文本更具可读性。

```python
data = {"name": "中文"}

json.dumps(data)                      # '{"name": "\\u4e2d\\u6587"}'
json.dumps(data, ensure_ascii=False)  # '{"name": "中文"}'
```

**`json.loads()`**

| 函数 | 用途 |
|----------|---------|
| `json.loads(string, ...)` | JSON 字符串 → Python 对象 |

```python
import json

json_str = '{"name": "Alice", "age": 25}'
data = json.loads(json_str)
```

**`json.dump()`**

| 函数 | 用途 |
|----------|---------|
| `json.dump(obj, f, ...)` | Python 对象 → 文件 |

```python
import json

data = {"name": "Alice", "age": 25}

with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False)
```

**`json.load()`**

| 函数 | 用途 |
|----------|---------|
| `json.load(f, ...)` | 文件 → Python 对象 |

```python
import json

with open("data.json", encoding="utf-8") as f:
    loaded = json.load(f)
```

### 10.4.2 CSV

**为什么要用 `newline=""`？**

打开 CSV 文件时，务必传入 `newline=""`。在 Windows 上，默认的文本模式会在写入时把 `\n` 转换为 `\r\n`。而 `csv` 模块本身就会写入 `\r\n` 行尾，转换之后会变成 `\r\r\n`，导致每行数据之间多出一个空行。

```python
# Without newline="" on Windows, you may get:
# name,age
#
# Alice,20
#
# Bob,25

# Correct:
with open("output.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerows([["name", "age"], ["Alice", 20], ["Bob", 25]])
```

使用 `newline=""` 会禁用这种自动转换，让 `csv` 模块自行控制行尾。这在 Linux 和 macOS 上同样安全，因此所有 CSV 文件操作都应使用它。

**用 Excel 打开 CSV：使用 `utf-8-sig`。** Windows 上的 Excel 依赖 BOM（字节顺序标记）来识别 UTF-8。包含中文的纯 UTF-8 CSV 在 Excel 中打开时可能出现乱码。写入时使用 `encoding="utf-8-sig"` 可添加 BOM：

```python
with open("output.csv", "w", encoding="utf-8-sig", newline="") as f:
    writer = csv.writer(f)
    writer.writerows([["name", "city"], ["Alice", "北京"]])
```

`utf-8-sig` 也可用于读取：有 BOM 时会自动去除，没有时则与纯 UTF-8 行为一致，因此对于要与 Excel 用户共享的 CSV 文件，它是安全的默认选择。

下面的读写示例假设 CSV 文件内容如下：

```text
name,age
Alice,20
Bob,25
Carol,30
```

**以列表形式读取 CSV：`csv.reader()`**

| 函数 | 用途 |
|----------|---------|
| `csv.reader(f)` | 将每行读取为字符串列表 |

```python
import csv

with open("data.csv", encoding="utf-8", newline="") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)

# ['name', 'age']
# ['Alice', '20']
# ['Bob', '25']
# ['Carol', '30']
```

**从列表写入 CSV**

`csv.writer(f)` 返回一个 writer 对象。实际的写入由其 `.writerow()` 和 `.writerows()` 方法完成。

| 函数 / 方法 | 用途 |
|-------------------|---------|
| `csv.writer(f)` | 创建 writer 对象 |
| `writer.writerow(row)` | 从一个列表写入一行 |
| `writer.writerows(rows)` | 从列表的列表写入多行 |

```python
import csv

with open("output.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["name", "age"])
    writer.writerow(["Alice", 20])
    writer.writerows([["Bob", 25], ["Carol", 30]])
```

**以字典形式读取 CSV：`csv.DictReader()`**

| 函数 | 用途 |
|----------|---------|
| `csv.DictReader(f)` | 以第一行为字段名，将每行读取为字典 |

```python
import csv

with open("data.csv", encoding="utf-8", newline="") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row)

# {'name': 'Alice', 'age': '20'}
# {'name': 'Bob', 'age': '25'}
# {'name': 'Carol', 'age': '30'}
```

**从字典写入 CSV**

`csv.DictWriter(f, fieldnames)` 返回一个 DictWriter 对象。必须先调用 `.writeheader()`，然后再调用 `.writerow()` 或 `.writerows()`。

| 函数 / 方法 | 用途 |
|-------------------|---------|
| `csv.DictWriter(f, fieldnames)` | 创建 DictWriter 对象 |
| `writer.writeheader()` | 写入表头行 |
| `writer.writerow(row)` | 从一个字典写入一行 |
| `writer.writerows(rows)` | 从字典列表写入多行 |

```python
import csv

with open("output.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=["name", "age"])
    writer.writeheader()
    writer.writerow({"name": "Alice", "age": 20})
    writer.writerows([
        {"name": "Bob", "age": 25},
        {"name": "Carol", "age": 30},
    ])
```

## 10.5 字符编码

### 10.5.1 字符串与字节

在 Python 中，文本以 `str` 对象存储——即 Unicode 字符序列。而文件存储的是原始**字节**。编码（encoding）就是在字符与字节之间相互转换的规则。

```python
text = "中文"

# Encode: str → bytes
b = text.encode("utf-8")
print(b)   # b'\xe4\xb8\xad\xe6\x96\x87'

# Decode: bytes → str
print(b.decode("utf-8"))   # 中文
```

同样的字符在不同编码下会产生不同的字节：

```python
"中文".encode("utf-8")   # b'\xe4\xb8\xad\xe6\x96\x87'  (6 bytes)
"中文".encode("gbk")     # b'\xd6\xd0\xce\xc4'          (4 bytes)
```

**存储单位：**
- 1 Byte（字节）= 8 bit（位）
- 1 KB = 1024 Byte
- 1 MB = 1024 KB

### 10.5.2 为什么编码很重要

打开文本文件时，Python 必须使用某种编码把字节解码为 `str`。如果编码与磁盘上的字节不匹配，结果就是乱码或 `UnicodeDecodeError`。

```python
# Write with GBK encoding
with open("gbk.txt", "w", encoding="gbk") as f:
    f.write("中文")

# Read with UTF-8 encoding — mismatch!
with open("gbk.txt", encoding="utf-8") as f:
    content = f.read()   # UnicodeDecodeError
```

**经验法则：** 打开文本文件时始终指定 `encoding="utf-8"`。Python 默认使用系统的区域编码，它因操作系统而异，可能引发错误。

### 10.5.3 常见编码

| 编码 | 说明 | 每字符字节数 |
|----------|-------------|----------------|
| ASCII | 128 个英文字符 | 1 |
| UTF-8 | Unicode，变长 | 1-4（中文：3） |
| GBK | 中文标准 | 1（英文），2（中文） |

UTF-8 是现代标准。它向后兼容 ASCII，并支持所有 Unicode 字符，是大多数文本文件最安全的选择。

### 10.5.4 用 `ord()` 和 `chr()` 处理码点

每个 Unicode 字符都有一个数值码点（code point）。`ord()` 返回字符的码点；`chr()` 把码点转换回字符。

```python
print(ord('A'))     # 65
print(chr(65))      # 'A'
print(ord('中'))    # 20013
print(chr(20013))   # '中'
```

### 10.5.5 字节位置与多字节字符

`seek()` 按**字节**移动文件指针，而不是按字符。对于任何多字节编码——不仅仅是 UTF-8 中文——都必须定位到与字符边界对齐的字节位置。

```python
with open("chinese.txt", "w", encoding="utf-8") as f:
    f.write("中文")         # 2 characters, 6 bytes on disk

with open("chinese.txt", "r", encoding="utf-8") as f:
    print(repr(f.read(1)))  # '中' — read() counts characters
    print(f.tell())         # 3 — but the cursor position is in bytes

    f.seek(3)               # Move to byte 3 (start of second char)
    print(f.read(1))        # "文"

    # f.seek(1)             # ❌ Bad — lands in middle of a 3-byte character
    # f.read(1)             # UnicodeDecodeError
```

## 10.6 路径与文件元数据

本节使用一个共同的场景：一个具有以下结构的项目：

```text
project/
├── scripts/
│   └── demo.py
└── data/
    ├── records.json
    └── records_backup.json
```

`data/records.json` 的内容为：

```json
{"name": "Alice", "age": 25}
```

所有示例假设脚本在 `project/` 或 `project/scripts/` 内运行。当需要构建指向数据文件的可靠路径时，脚本文件本身所在的位置就很重要。

### 10.6.1 工作目录

**两种"位置"。** 处理文件时，需要了解两个不同的目录概念：

- **当前工作目录**（`cwd`）：启动脚本时所在的目录。
- **脚本目录**：脚本文件（`demo.py`）所在的目录。

两者通常相同，但取决于你在哪里运行脚本，也可能不同。

**API 对比。** 下面的示例假设采用上文介绍的项目结构，并且脚本从 `project/` 目录启动：

```shell
python scripts/demo.py
```

因此，当前工作目录是 `project/`，而脚本本身位于 `project/scripts/`。

| 操作 | `os` 风格 | `pathlib` 风格 |
|-----------|-----------|-----------------|
| 获取当前工作目录 | `os.getcwd()` | `Path.cwd()` |
| 更改当前工作目录 | `os.chdir(path)` | 无直接对应 |
| 获取脚本目录 | `os.path.dirname(os.path.abspath(__file__))` | `Path(__file__).resolve().parent` |

**使用 `os`：**

```python
import os

# Where the script was launched from
print(os.getcwd())        # C:\Users\Andy\project

# Change the current working directory
os.chdir("data")
print(os.getcwd())        # C:\Users\Andy\project\data
```

**使用 `pathlib`：**

```python
from pathlib import Path

# Where the script was launched from
print(Path.cwd())         # C:\Users\Andy\project

# Where the script file itself is located
script_dir = Path(__file__).resolve().parent
print(script_dir)         # C:\Users\Andy\project\scripts
```

**为什么工作目录很重要。** 如果脚本使用相对路径打开文件，路径将相对于当前工作目录解析，而不是相对于脚本所在位置。这会导致同一个脚本因运行位置不同而表现不同。

使用上文介绍的项目结构，`demo.py` 的内容为：

```python
with open("data/records.json", encoding="utf-8") as f:
    content = f.read()
```

从 `project/` 运行：

```bash
python scripts/demo.py
```

- `cwd` 是 `project/`。
- `data/records.json` 存在。✅

从 `project/scripts/` 运行：

```bash
python demo.py
```

- `cwd` 是 `project/scripts/`。
- 脚本会查找 `project/scripts/data/records.json`，而该文件不存在。❌

这就是为什么生产代码应该相对于**脚本目录**而不是当前工作目录来定位资源文件。

**关于 `__file__` 的说明。** `__file__` 只在运行已保存的脚本时可用。它在交互式 shell 或 REPL 中不起作用，因为那些环境中没有脚本文件。

### 10.6.2 路径构建

从 `project/scripts/demo.py` 构建指向 `data/records.json` 的路径。`data` 目录在上一层。

| 操作 | `os` 风格 | `pathlib` 风格 |
|-----------|-----------|-----------------|
| 拼接路径 | `os.path.join(a, b, ...)` | `Path(a) / b / ...` |
| 规范化路径 | `os.path.normpath(p)` | `Path(p).resolve()` |

**使用 `os`：**

```python
import os

script_dir = os.path.dirname(os.path.abspath(__file__))
records = os.path.normpath(os.path.join(script_dir, "..", "data", "records.json"))

print(records)        # C:\Users\Andy\project\data\records.json (Windows)
                      # /home/andy/project/data/records.json (Linux/macOS)

with open(records, encoding="utf-8") as f:
    content = f.read()
```

**使用 `pathlib`：**

```python
from pathlib import Path

script_dir = Path(__file__).resolve().parent
records = script_dir.parent / "data" / "records.json"

print(records)        # C:\Users\Andy\project\data\records.json (Windows)
                      # /home/andy/project/data/records.json (Linux/macOS)

with open(records, encoding="utf-8") as f:
    content = f.read()
```

现代代码推荐使用 `Path` 配合 `/` 运算符，因为它在 Windows、Linux 和 macOS 上的行为完全一致。

### 10.6.3 路径信息

检查路径是否存在，以及它是什么类型的对象。

| 操作 | `os` 风格 | `pathlib` 风格 |
|-----------|-----------|-----------------|
| 检查是否存在 | `os.path.exists(p)` | `Path(p).exists()` |
| 是否为文件？ | `os.path.isfile(p)` | `Path(p).is_file()` |
| 是否为目录？ | `os.path.isdir(p)` | `Path(p).is_dir()` |

**使用 `os`：**

```python
import os

script_dir = os.path.dirname(os.path.abspath(__file__))
records = os.path.normpath(os.path.join(script_dir, "..", "data", "records.json"))
data_dir = os.path.dirname(records)

print(os.path.exists(records))    # True
print(os.path.isfile(records))    # True
print(os.path.isdir(data_dir))    # True
```

**使用 `pathlib`：**

```python
from pathlib import Path

records = Path(__file__).resolve().parent.parent / "data" / "records.json"
data_dir = records.parent

print(records.exists())           # True
print(records.is_file())          # True
print(data_dir.is_dir())          # True
```

### 10.6.4 文件元数据

获取 `records.json` 的大小和最后修改时间。

| 操作 | `os` 风格 | `pathlib` 风格 |
|-----------|-----------|-----------------|
| 获取大小 | `os.path.getsize(p)` | `Path(p).stat().st_size` |
| 获取修改时间 | `os.path.getmtime(p)` | `Path(p).stat().st_mtime` |
| 完整元数据 | `os.stat(p)` | `Path(p).stat()` |

**使用 `os`：**

```python
import os

script_dir = os.path.dirname(os.path.abspath(__file__))
records = os.path.normpath(os.path.join(script_dir, "..", "data", "records.json"))

print(os.path.getsize(records))      # 28
print(os.path.getmtime(records))     # 1712345678.0

stat = os.stat(records)
print(stat.st_size)                  # 28 (size in bytes)
print(stat.st_mtime)                 # 1712345678.0 (last modification)
```

**使用 `pathlib`：**

```python
from pathlib import Path

records = Path(__file__).resolve().parent.parent / "data" / "records.json"

print(records.stat().st_size)        # 28
print(records.stat().st_mtime)       # 1712345678.0
```

### 10.6.5 创建和删除文件/目录

使用任一模块创建和删除目录与文件。

| 操作 | `os` 风格 | `pathlib` 风格 |
|-----------|-----------|-----------------|
| 创建目录 | `os.mkdir(path)` | `Path(path).mkdir()` |
| 创建嵌套目录 | `os.makedirs(path)` | `Path(path).mkdir(parents=True)` |
| 删除文件 | `os.remove(path)` | `Path(path).unlink()` |
| 删除空目录 | `os.rmdir(path)` | `Path(path).rmdir()` |

**使用 `os`：**

```python
import os

# Create a directory and nested directories
os.mkdir("reports")
os.makedirs("reports/2024/sales", exist_ok=True)

# Remove a file and an empty directory
os.remove("temp.txt")
os.rmdir("reports/2024/sales")  # directory must be empty
```

**使用 `pathlib`：**

```python
from pathlib import Path

# Create a directory and nested directories
Path("reports").mkdir()
Path("reports/2024/sales").mkdir(parents=True, exist_ok=True)

# Remove a file and an empty directory
Path("temp.txt").unlink()
Path("reports/2024/sales").rmdir()  # directory must be empty
```

**注意事项：**

- `os.makedirs()` 和 `Path.mkdir(parents=True)` 会创建所有缺失的父目录。
- 传入 `exist_ok=True` 可以在目录已存在时跳过报错——对于可能运行多次的代码来说必不可少。
- `os.remove()` / `Path.unlink()` 是永久删除文件，而不是移入回收站。

### 10.6.6 读写快捷方式

读取和写入 records 文件。

| 操作 | 使用 `open()` | `pathlib` 风格 |
|-----------|-----------|-----------------|
| 读取文本 | `open(p).read()` | `Path(p).read_text()` |
| 写入文本 | `open(p, 'w').write(s)` | `Path(p).write_text(s)` |
| 读取字节 | `open(p, 'rb').read()` | `Path(p).read_bytes()` |
| 写入字节 | `open(p, 'wb').write(b)` | `Path(p).write_bytes(b)` |

**使用 `open()`：**

```python
import os

script_dir = os.path.dirname(os.path.abspath(__file__))
records = os.path.normpath(os.path.join(script_dir, "..", "data", "records.json"))

with open(records, encoding="utf-8") as f:
    content = f.read()
print(content)        # {"name": "Alice", "age": 25}

# Write updated content
with open(records, "w", encoding="utf-8") as f:
    f.write('{"name": "Bob", "age": 30}')
```

**使用 `pathlib`：**

```python
from pathlib import Path

records = Path(__file__).resolve().parent.parent / "data" / "records.json"

content = records.read_text(encoding="utf-8")
print(content)        # {"name": "Alice", "age": 25}

# Write updated content
records.write_text('{"name": "Bob", "age": 30}', encoding="utf-8")
```

### 10.6.7 目录遍历

列出 `data` 目录中的所有文件，并匹配 JSON 文件。

| 操作 | `os` 风格 | `pathlib` 风格 |
|-----------|-----------|-----------------|
| 列出目录 | `os.listdir(dir)` | `Path(dir).iterdir()` |
| 模式匹配 | `glob.glob(pattern)` | `Path(dir).glob("*.json")` |

**使用 `os` 和 `glob`：**

```python
import os
import glob

script_dir = os.path.dirname(os.path.abspath(__file__))
data_dir = os.path.normpath(os.path.join(script_dir, "..", "data"))

# List all entries
for entry in os.listdir(data_dir):
    print(entry)
# records.json
# records_backup.json

# Match JSON files only
for json_file in glob.glob(os.path.join(data_dir, "*.json")):
    print(os.path.basename(json_file))
# records.json
# records_backup.json
```

**使用 `pathlib`：**

```python
from pathlib import Path

data_dir = Path(__file__).resolve().parent.parent / "data"

# List all entries
for entry in data_dir.iterdir():
    print(entry.name)
# records.json
# records_backup.json

# Match JSON files only
for json_file in data_dir.glob("*.json"):
    print(json_file.name)
# records.json
# records_backup.json
```

**返回类型的关键区别：**

- `os.listdir()` 返回**字符串**列表（条目名称）。
- `Path.iterdir()` 产出 **Path 对象**，因此示例中使用 `.name` 来获取条目名称。

类似地，`glob.glob()` 返回字符串，而 `Path.glob()` 产出 Path 对象。

### 10.6.8 `os.path` 与 `pathlib` 对比

上述所有操作都可以用任一模块完成，但它们代表两种不同的风格：

| 方面 | `os` / `os.path` | `pathlib` |
|--------|------------------|-----------|
| 风格 | 基于字符串的函数调用 | 面向对象的 `Path` 对象 |
| 路径拼接 | `os.path.join(a, b)` | `Path(a) / b` |
| 跨平台 | 正确，但需手动处理 | 内置 `/` 运算符自动处理分隔符 |
| 推荐程度 | 适合简单脚本 | 新代码首选 |

一般推荐现代 Python 代码使用 `pathlib`，因为路径是带有 `.exists()`、`.read_text()`、`.glob()` 等方法的对象，而不是在多个函数调用之间传递的字符串。

## 10.7 实用文件处理

### 10.7.1 临时文件

对于生命周期短、需要自动清理的文件和目录，使用 `tempfile` 模块。

| 函数 | 用途 |
|----------|---------|
| `TemporaryFile(...)` | 创建匿名临时文件（无可见路径） |
| `NamedTemporaryFile(...)` | 创建带有可见路径的临时文件 |
| `TemporaryDirectory()` | 创建临时目录 |

常用参数：

| 参数 | 含义 |
|-----------|---------|
| `mode` | 文件模式，如 `"w"`、`"wb"` |
| `suffix` | 文件名后缀，如 `".txt"` |
| `prefix` | 文件名前缀 |
| `dir` | 临时文件创建的目录 |
| `delete` | 对于 `NamedTemporaryFile`，关闭时删除（默认为 `True`） |

```python
import tempfile

# Unnamed temporary file (no file path, auto-deleted when closed)
with tempfile.TemporaryFile(mode="w+") as f:
    f.write("temporary data")
    f.seek(0)
    print(f.read())     # temporary data

# Named temporary file (has a path, auto-deleted by default)
with tempfile.NamedTemporaryFile(mode="w", delete=True, suffix=".txt") as f:
    f.write("temporary data")
    print(f.name)       # C:\Users\Andy\AppData\Local\Temp\tmp<random>.txt

# Temporary directory
with tempfile.TemporaryDirectory() as tmpdir:
    print(tmpdir)       # C:\Users\Andy\AppData\Local\Temp\tmp<random>
```

**注意：** 当你只需要一个类文件对象时，`TemporaryFile` 更安全，因为它在大多数系统上没有可见路径。只有当其他程序或 API 需要通过路径访问该文件时，才使用 `NamedTemporaryFile`。

### 10.7.2 常见文件错误

文件操作常因可预见的原因失败。应当显式处理这些错误，而不是让程序崩溃。

| 错误 | 原因 | 典型解决办法 |
|-------|-------|-------------|
| `FileNotFoundError` | 路径不存在 | 检查路径，或先使用 `Path.exists()` |
| `PermissionError` | 权限不足 | 以适当权限运行，或修改文件权限 |
| `UnicodeDecodeError` | 编码错误 | 指定 `encoding="utf-8"`；编码未知时用 `charset-normalizer` 检测 |
| `IsADirectoryError` | 试图把目录当文件打开 | 改用 `os.listdir()` 或 `Path.iterdir()` |

以上异常都继承自 `OSError`，因此当不需要区分具体类型时，可以一并捕获：

```python
try:
    with open("data.txt", encoding="utf-8") as f:
        content = f.read()
except OSError:
    print("Failed to read the file.")
```

通常捕获具体的异常更好，因为这样能给出精确的错误信息或恢复措施。

```python
try:
    with open("missing.txt", encoding="utf-8") as f:
        content = f.read()
except FileNotFoundError:
    print("File does not exist.")
except PermissionError:
    print("No permission to read the file.")
except UnicodeDecodeError:
    print("Encoding mismatch — try a different encoding.")
```

**防御性检查：** 如果不确定文件是否存在，先检查，或者使用 `Path`：

```python
from pathlib import Path

p = Path("data.txt")
if p.exists():
    content = p.read_text(encoding="utf-8")
else:
    print("File does not exist.")
```

关于 `try/except` 语句本身，见 [14.3 异常处理语法](14-异常处理.md#143-异常处理语法)。

### 10.7.3 用 `shutil` 复制和移动文件

`shutil` 模块提供复制、移动和删除整个文件树的高级操作，比自己写循环更方便。

| 函数 | 用途 |
|----------|---------|
| `shutil.copy(src, dst)` | 复制文件。保留基本权限。 |
| `shutil.copy2(src, dst)` | 复制文件。保留修改时间等元数据。 |
| `shutil.copytree(src, dst)` | 复制整个目录树。 |
| `shutil.move(src, dst)` | 移动文件或目录。 |
| `shutil.rmtree(path)` | 删除整个目录树。 |

```python
import shutil
from pathlib import Path

# Copy a file
shutil.copy("data/records.json", "data/records_copy.json")

# Copy a file and preserve metadata
shutil.copy2("data/records.json", "data/records_copy2.json")

# Copy an entire directory tree
shutil.copytree("data", "data_backup")

# Move a file or directory
shutil.move("data/records_copy.json", "archive/records_copy.json")

# Delete a directory and everything inside it
shutil.rmtree("data_backup")
```

**注意：** `shutil.rmtree()` 会永久删除目录，无法撤销，请谨慎使用。如需更安全的删除，可以使用 `send2trash` 等第三方库将文件移入回收站。

## 10.8 速查表

**文件模式**

| 模式 | 含义 |
|------|---------|
| `"r"` | 读；文件必须存在 |
| `"w"` | 写；截断或创建 |
| `"a"` | 追加；文件不存在则创建 |
| `"x"` | 创建；文件已存在则失败 |
| `"+"` | 附加到 `r`/`w`/`a` 上以支持读写（`"r+"`、`"w+"`、`"a+"`） |
| `"b"` | 附加到任意模式以使用二进制（`"rb"`、`"wb"`……） |

**读写（文本模式）**

| 方法 | 用途 |
|--------|---------|
| `f.read()` / `f.read(n)` | 整个文件 / 最多 `n` 个字符 |
| `f.readline()` | 一行（包括 `\n`） |
| `f.readlines()` | 所有行组成的列表 |
| `for line in f:` | 逐行迭代（内存高效） |
| `f.write(s)` | 写入字符串 |
| `f.writelines(lines)` | 写入字符串可迭代对象 |
| `f.tell()` / `f.seek(offset, whence)` | 文件指针位置 / 移动指针（以字节计） |

**路径：`os` 与 `pathlib` 对比**

| 任务 | `os` 风格 | `pathlib` 风格 |
|------|-----------|-----------------|
| 拼接路径 | `os.path.join(a, b)` | `Path(a) / b` |
| 脚本目录 | `os.path.dirname(os.path.abspath(__file__))` | `Path(__file__).resolve().parent` |
| 存在 / 是文件 / 是目录 | `os.path.exists/isfile/isdir(p)` | `p.exists()` / `p.is_file()` / `p.is_dir()` |
| 读 / 写文本 | `open(p).read()` / `open(p, "w").write(s)` | `p.read_text()` / `p.write_text(s)` |
| 列出 / 匹配目录 | `os.listdir(d)` / `glob.glob(pattern)` | `p.iterdir()` / `p.glob("*.json")` |
| 大小 / 修改时间 | `os.path.getsize(p)` / `os.path.getmtime(p)` | `p.stat().st_size` / `p.stat().st_mtime` |

**JSON 和 CSV**

| 任务 | 代码 |
|------|------|
| 对象 → JSON 字符串 | `json.dumps(obj, ensure_ascii=False)` |
| JSON 字符串 → 对象 | `json.loads(s)` |
| 对象 → 文件 | `json.dump(obj, f, ensure_ascii=False)` |
| 文件 → 对象 | `json.load(f)` |
| 读取 CSV 行 | `csv.reader(f)` / `csv.DictReader(f)` |
| 写入 CSV 行 | `csv.writer(f).writerows(rows)` / `csv.DictWriter(f, fieldnames)` |

**黄金法则**

- 文本文件始终使用 `with open(...)` 并指定 `encoding="utf-8"`。
- CSV 文件始终传入 `newline=""`；如果 CSV 会用 Excel 打开，使用 `encoding="utf-8-sig"`。
- 相对于脚本目录而不是当前工作目录来定位资源文件。
- 捕获具体的异常（`FileNotFoundError`、`PermissionError` 等），而不是裸 `except`。
