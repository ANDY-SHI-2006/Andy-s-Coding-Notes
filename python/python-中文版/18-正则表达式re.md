# 18 正则表达式（re 模块）

正则表达式（regular expression，简称 regex）是一种用来描述字符串模式的小型语言。借助 Python 标准库的 `re` 模块，你可以用一段模式（pattern）完成查找、校验、提取、替换和切分等文本处理任务，而无需手写繁琐的循环与判断。

```python
import re
```

## 18.1 快速上手

### 18.1.1 第一个例子

假设要从一段文本中找出所有数字。不用正则时你需要逐字符判断；用正则只需要一个模式 `\d+`（一个或多个数字）：

```python
import re

text = "Order 42 costs 199 yuan, placed on 2024-05-01."
numbers = re.findall(r"\d+", text)
print(numbers)   # ['42', '199', '2024', '05', '01']
```

整个过程分两步：先用模式描述「要找什么」，再调用 `re` 模块的函数执行匹配。

再看一个提取邮箱的例子：

```python
import re

text = "Contact alice@example.com or bob_2024@test.org for details."
emails = re.findall(r"[\w.+-]+@[\w-]+\.[\w.]+", text)
print(emails)   # ['alice@example.com', 'bob_2024@test.org']
```

这个模式的含义会在 18.2 节逐一拆解，现在只需建立直觉：正则就是用一套紧凑的符号描述字符串的形状。

### 18.1.2 为什么模式要用原始字符串

正则表达式大量使用反斜杠 `\`（如 `\d`、`\b`、`\w`），而 Python 字符串本身也把 `\` 当作转义符。同一个反斜杠有两层含义，容易互相干扰。

Python 中 `\b` 是转义序列，表示退格符；而正则中 `\b` 表示单词边界（word boundary）。对比：

```python
import re

text = "a word boundary"

# Wrong: "\b" becomes the backspace character before regex sees it
print(re.findall("\bword\b", text))     # []

# Right: r"..." keeps backslashes intact
print(re.findall(r"\bword\b", text))    # ['word']
```

虽然 `"\d"` 恰好能工作（`\d` 不是 Python 的合法转义序列，会被原样保留，但会触发语法警告），依赖这种「恰好」非常危险。**惯例：正则模式一律写成原始字符串（raw string）`r"..."`。**

```python
print("\d")    # \d (works by accident, but raises SyntaxWarning)
print("\\d")   # \d (explicit escaping, correct but noisy)
print(r"\d")   # \d (raw string, the recommended way)
```

## 18.2 元字符与字符类

正则模式由普通字符和元字符（metacharacter）组成。普通字符匹配自身，元字符有特殊含义。

### 18.2.1 元字符速查表

| 元字符 | 含义 | 示例模式 | 匹配 |
|--------|------|----------|------|
| `.` | 任意单个字符（默认不含换行） | `a.c` | `abc`、`a1c` |
| `^` | 字符串（或行）开头 | `^abc` | 开头的 `abc` |
| `$` | 字符串（或行）结尾 | `abc$` | 结尾的 `abc` |
| `*` | 前一个元素出现 0 次或多次 | `ab*c` | `ac`、`abc`、`abbc` |
| `+` | 前一个元素出现 1 次或多次 | `ab+c` | `abc`、`abbc` |
| `?` | 前一个元素出现 0 次或 1 次 | `ab?c` | `ac`、`abc` |
| `{n}` | 恰好出现 n 次 | `a{3}` | `aaa` |
| `{m,}` | 至少出现 m 次 | `a{2,}` | `aa`、`aaa`…… |
| `{m,n}` | 出现 m 到 n 次 | `a{2,4}` | `aa`、`aaa`、`aaaa` |
| `[]` | 字符类，匹配其中任意一个字符 | `[aeiou]` | 任意元音字母 |
| `[^]` | 否定字符类，匹配不在其中的字符 | `[^0-9]` | 任意非数字字符 |
| `|` | 或，匹配左右任一分支 | `cat|dog` | `cat` 或 `dog` |
| `()` | 分组，并捕获内容 | `(ab)+` | `ab`、`abab`…… |

字符类内可以用连字符表示范围：`[0-9]`、`[a-z]`、`[A-Za-z]`。

### 18.2.2 转义序列

| 序列 | 含义 | 等价字符类 |
|------|------|-----------|
| `\d` | 数字 | `[0-9]` |
| `\D` | 非数字 | `[^0-9]` |
| `\w` | 单词字符（字母、数字、下划线） | `[a-zA-Z0-9_]` |
| `\W` | 非单词字符 | `[^a-zA-Z0-9_]` |
| `\s` | 空白字符（空格、制表符、换行等） | — |
| `\S` | 非空白字符 | — |
| `\b` | 单词边界 | — |
| `\B` | 非单词边界 | — |
| `\A` | 仅匹配整个字符串的开头 | — |
| `\Z` | 仅匹配整个字符串的结尾 | — |

最小示例：

```python
import re

re.findall(r"\d+", "a1b22c333")        # ['1', '22', '333']
re.findall(r"\w+", "hi, there!")       # ['hi', 'there']
re.findall(r"\s", "a b\tc")            # [' ', '\t']
re.findall(r"\bcat\b", "cat category scatter cat")
# ['cat', 'cat'] — only the standalone word matches
re.findall(r"a.c", "abc axc a c")      # ['abc', 'axc', 'a c']
re.findall(r"^ab", "ab cd ab")         # ['ab'] — only at the start
re.findall(r"ab$", "cd ab cd ab")      # ['ab'] — only at the end
re.findall(r"colou?r", "color colour") # ['color', 'colour']
re.findall(r"\d{2,4}", "1 22 333 4444 55555")
# ['22', '333', '4444', '5555'] — 2 to 4 digits
re.findall(r"cat|dog", "cat bird dog") # ['cat', 'dog']
```

注意 `^` 在字符类内表示否定（`[^0-9]`），在字符类外表示开头，二者含义不同。

## 18.3 核心函数

### 18.3.1 `re.match()` —— 只从开头匹配

`re.match(pattern, string)` 只检查字符串的**开头**是否匹配，匹配成功返回 Match 对象，否则返回 `None`：

```python
import re

re.match(r"\d+", "123abc")   # <re.Match object; span=(0, 3), match='123'>
re.match(r"\d+", "abc123")   # None — digits are not at the start
```

### 18.3.2 `re.search()` —— 全文查找第一个匹配

`re.search(pattern, string)` 扫描整个字符串，返回**第一个**匹配：

```python
import re

re.search(r"\d+", "abc123def456")   # <re.Match object; span=(3, 6), match='123'>
```

### 18.3.3 `re.fullmatch()` —— 整体匹配

`re.fullmatch(pattern, string)` 要求**整个字符串**都符合模式，常用于格式校验：

```python
import re

re.fullmatch(r"\d{4}-\d{2}-\d{2}", "2024-05-01")      # Match
re.fullmatch(r"\d{4}-\d{2}-\d{2}", "2024-05-01xyz")   # None
```

等价于在模式两端加上 `\A` 和 `\Z`，但更清晰。

### 18.3.4 `re.findall()` —— 所有匹配

`re.findall(pattern, string)` 返回所有不重叠匹配组成的列表：

```python
import re

re.findall(r"\d+", "12 and 345 and 6789")   # ['12', '345', '6789']
```

若模式中包含分组，返回的是各组的内容（详见 18.5 节）。

### 18.3.5 `re.finditer()` —— 返回迭代器

`re.finditer(pattern, string)` 返回一个产生 Match 对象的迭代器，适合处理大量匹配或需要匹配位置的场景：

```python
import re

for m in re.finditer(r"\d+", "12 and 345"):
    print(m.group(), m.span())
# 12 (0, 2)
# 345 (7, 10)
```

### 18.3.6 `re.sub()` —— 替换

`re.sub(pattern, repl, string)` 把所有匹配替换为 `repl`：

```python
import re

re.sub(r"\d+", "#", "a1b22c333")        # 'a#b#c#'
re.sub(r"\s+", " ", "too   many\tspaces")   # 'too many spaces'
```

替换串中可以用 `\1`、`\2` 等反向引用（backreference）引用捕获组：

```python
import re

# Swap date format from YYYY-MM-DD to MM/DD/YYYY
re.sub(r"(\d{4})-(\d{2})-(\d{2})", r"\2/\3/\1", "2024-05-01")
# '05/01/2024'
```

`repl` 也可以是一个函数，接收 Match 对象并返回替换串：

```python
import re

re.sub(r"\d+", lambda m: str(int(m.group()) * 2), "a1b22")
# 'a2b44'
```

### 18.3.7 `re.split()` —— 按模式切分

`re.split(pattern, string)` 在每个匹配处切开字符串，比 `str.split()` 灵活：

```python
import re

re.split(r"[,;]\s*", "a, b;c,  d;e")   # ['a', 'b', 'c', 'd', 'e']
re.split(r"\d+", "a1b22c")             # ['a', 'b', 'c']
```

### 18.3.8 函数对比表

| 函数 | 功能 | 返回值 | 典型场景 |
|------|------|--------|----------|
| `re.match()` | 从开头匹配 | Match 或 `None` | 判断前缀格式 |
| `re.search()` | 找第一个匹配 | Match 或 `None` | 查找单个目标 |
| `re.fullmatch()` | 整体匹配 | Match 或 `None` | 校验整个字符串 |
| `re.findall()` | 所有匹配 | 字符串列表 | 批量提取内容 |
| `re.finditer()` | 所有匹配 | Match 迭代器 | 大文本、需要位置 |
| `re.sub()` | 替换匹配 | 新字符串 | 清洗、格式转换 |
| `re.split()` | 按模式切分 | 字符串列表 | 多分隔符切分 |

`re` 模块的速查亦可参见 16.7.5 节。

## 18.4 Match 对象

### 18.4.1 匹配失败返回 `None`

`match()`、`search()`、`fullmatch()` 失败时返回 `None`。**必须先判空，再使用结果**，否则会抛出 `AttributeError`：

```python
import re

m = re.search(r"\d+", "no digits here")
if m:
    print(m.group())
else:
    print("No match found")   # No match found
```

### 18.4.2 常用方法

```python
import re

m = re.search(r"(\w+)@(\w+\.com)", "mail: alice@example.com")

m.group()        # 'alice@example.com' — the entire match
m.group(1)       # 'alice' — capture group 1
m.group(2)       # 'example.com' — capture group 2
m.groups()       # ('alice', 'example.com') — all groups as a tuple
m.start()        # 6 — start index of the match
m.end()          # 23 — end index (exclusive)
m.span()         # (6, 23) — (start, end)
```

- `group(0)` 与 `group()` 相同，都是整个匹配；`group(1)`、`group(2)`……对应各捕获组（capture group）。
- `groupdict()` 返回命名组组成的字典（见 18.5 节）。
- `start()`、`end()`、`span()` 也可以传入组号，如 `m.span(1)` 获取第一组的位置。

## 18.5 分组

### 18.5.1 捕获组与编号

圆括号 `(...)` 创建捕获组，组按左括号出现的顺序从 1 开始编号：

```python
import re

m = re.search(r"(\d{4})-(\d{2})-(\d{2})", "Date: 2024-05-01")
m.group(0)   # '2024-05-01'
m.group(1)   # '2024'
m.group(2)   # '05'
m.group(3)   # '01'
m.groups()   # ('2024', '05', '01')
```

分组还可以配合量词使用：`(ab)+` 匹配 `abab` 这样的重复单元。

### 18.5.2 非捕获组

有时分组只为限定量词或 `|` 的作用范围，并不需要捕获内容。用 `(?:...)` 创建非捕获组（non-capturing group），它不占用组号：

```python
import re

m = re.search(r"(?:Mr|Ms)\. (\w+)", "Mr. Smith")
m.group(1)      # 'Smith' — only one capture group
m.groups()      # ('Smith',)
```

### 18.5.3 命名组

组一多，数字编号就难以阅读。命名组（named group）用 `(?P<name>...)` 定义，用名字访问：

```python
import re

m = re.search(r"(?P<year>\d{4})-(?P<month>\d{2})-(?P<day>\d{2})",
              "Date: 2024-05-01")
m.group("year")    # '2024'
m.groupdict()      # {'year': '2024', 'month': '05', 'day': '01'}
```

模式内部可以用 `(?P=name)` 反向引用命名组，要求匹配与之前相同的内容。例如匹配连续重复的单词：

```python
import re

re.findall(r"\b(?P<word>\w+) (?P=word)\b", "the the cat and and dog")
# ['the', 'and']
```

### 18.5.4 替换中的 `\g<name>`

在 `re.sub()` 的替换串中，命名组用 `\g<name>` 引用（`\1`、`\2` 这样的编号写法也仍然有效）：

```python
import re

re.sub(r"(?P<first>\w+) (?P<last>\w+)", r"\g<last> \g<first>", "John Smith")
# 'Smith John'
```

## 18.6 标志位

`re` 函数都接受可选的 `flags` 参数，用于改变匹配行为。多个标志位用 `|` 组合。

### 18.6.1 `re.IGNORECASE` —— 忽略大小写

```python
import re

re.findall(r"python", "Python python PYTHON")                      # ['python']
re.findall(r"python", "Python python PYTHON", re.IGNORECASE)       # 3 matches
# ['Python', 'python', 'PYTHON']
```

可简写为 `re.I`。

### 18.6.2 `re.MULTILINE` —— `^` 和 `$` 匹配每行

默认情况下 `^` 和 `$` 只匹配整个字符串的开头与结尾。加上 `re.MULTILINE`（简写 `re.M`）后，它们匹配每一行的开头与结尾：

```python
import re

text = "first line\nsecond line\nthird line"

re.findall(r"^\w+", text)                # ['first']
re.findall(r"^\w+", text, re.MULTILINE)  # ['first', 'second', 'third']
```

### 18.6.3 `re.DOTALL` —— `.` 匹配换行

默认 `.` 不匹配换行符 `\n`。加上 `re.DOTALL`（简写 `re.S`）后 `.` 匹配包括换行在内的任意字符：

```python
import re

text = "start\nmiddle\nend"

re.search(r"start.*end", text)              # None — . stops at newlines
re.search(r"start.*end", text, re.DOTALL)   # Match — spans all three lines
```

### 18.6.4 `re.VERBOSE` —— 可写注释的多行模式

复杂模式写在单行里难以阅读。`re.VERBOSE`（简写 `re.X`）允许把模式拆成多行并加注释，模式中的空白会被忽略（需要匹配空白时写成 `\ ` 或 `[ ]`）：

```python
import re

pattern = re.compile(r"""
    (?P<year>\d{4})   # Four-digit year
    -                 # Separator
    (?P<month>\d{2})  # Two-digit month
    -                 # Separator
    (?P<day>\d{2})    # Two-digit day
""", re.VERBOSE)

m = pattern.search("Date: 2024-05-01")
print(m.groupdict())   # {'year': '2024', 'month': '05', 'day': '01'}
```

## 18.7 `re.compile()` 与模式复用

`re.compile(pattern, flags)` 把模式预编译成 Pattern 对象。当同一模式要被反复使用时，预编译可以避免重复解析，也让代码更清晰：

```python
import re

date_pattern = re.compile(r"\d{4}-\d{2}-\d{2}")

lines = ["2024-05-01 ok", "no date", "2024-12-31 ok"]
for line in lines:
    m = date_pattern.search(line)
    if m:
        print(m.group())
# 2024-05-01
# 2024-12-31
```

编译后的 Pattern 对象拥有与模块级函数同名的方法——`search()`、`match()`、`fullmatch()`、`findall()`、`finditer()`、`sub()`、`split()`——参数中不再需要模式本身：

```python
import re

pattern = re.compile(r"\d+", re.ASCII)

pattern.findall("a1b22")          # ['1', '22']
pattern.sub("#", "a1b22")         # 'a#b#'
```

事实上，模块级函数 `re.findall(pattern, text)` 内部就是先编译再调用；`re` 还会缓存最近使用的编译结果，因此偶尔使用的简单场景直接用模块级函数即可，循环或高频调用时推荐显式 `re.compile()`。

## 18.8 贪婪与非贪婪

量词 `*`、`+`、`?`、`{m,n}` 默认是贪婪（greedy）的：在能匹配的前提下，尽可能多地匹配字符。在量词后加 `?` 就变成非贪婪（non-greedy，也称懒惰 lazy）匹配：尽可能少地匹配。

经典例子：提取 HTML 标签。

```python
import re

html = "<b>bold</b> and <i>italic</i>"

re.findall(r"<.*>", html)
# ['<b>bold</b> and <i>italic</i>'] — greedy: first < to last >

re.findall(r"<.*?>", html)
# ['<b>', '</b>', '<i>', '</i>'] — non-greedy: stops at the first >
```

贪婪版从第一个 `<` 一路吃到字符串里最后一个 `>`；非贪婪版每遇到一个 `>` 就结束一次匹配。

四种非贪婪量词：`*?`、`+?`、`??`、`{m,n}?`。

```python
import re

re.findall(r"\d+?", "12345")       # ['1', '2', '3', '4', '5'] — minimal
re.findall(r"\d{2,4}?", "12345")   # ['12', '34'] — as few as allowed
```

注意：非贪婪不等于「最短匹配优先」，正则引擎仍然从左向右扫描，只是在每个起点尽量少匹配。

## 18.9 实战示例

### 18.9.1 校验邮箱格式

```python
import re

def is_valid_email(s):
    # Local part: word chars, dots, plus, hyphen
    # Domain: labels separated by dots, ending with a TLD
    pattern = r"[\w.+-]+@[\w-]+(\.[\w-]+)+"
    return re.fullmatch(pattern, s) is not None

is_valid_email("alice@example.com")    # True
is_valid_email("bob@mail.example.org") # True
is_valid_email("no-at-sign.com")       # False
is_valid_email("a@b")                  # False — no dot in domain
```

构成思路：`[\w.+-]+` 匹配 `@` 前的本地部分；`[\w-]+(\.[\w-]+)+` 匹配域名，要求至少出现一个 `.标签`，从而保证有顶级域。注意这是实用主义的简化版，完整的邮箱规范（RFC 5322）远比这复杂。

### 18.9.2 校验中国大陆手机号

```python
import re

def is_valid_phone(s):
    # Starts with 1, second digit 3-9, then 9 more digits
    return re.fullmatch(r"1[3-9]\d{9}", s) is not None

is_valid_phone("13812345678")   # True
is_valid_phone("12345678901")   # False — second digit must be 3-9
is_valid_phone("1381234567")    # False — only 10 digits
```

构成思路：`1` 固定开头；`[3-9]` 限定第二位；`\d{9}` 补足剩余 9 位，合计 11 位。用 `fullmatch()` 确保没有多余字符。

### 18.9.3 从文本提取 URL

```python
import re

text = "See https://example.com/a?x=1 and http://test.org, or ftp://skip.me"
urls = re.findall(r"https?://[^\s,]+", text)
print(urls)   # ['https://example.com/a?x=1', 'http://test.org']
```

构成思路：`https?` 匹配 `http` 或 `https`（`s?` 表示 `s` 可选）；`://` 是字面量；`[^\s,]+` 匹配除空白和逗号外的一切字符，直到 URL 结束。

### 18.9.4 解析日志行

用命名组把一行日志拆解成结构化字段：

```python
import re

log_pattern = re.compile(
    r"(?P<date>\d{4}-\d{2}-\d{2}) "
    r"(?P<time>\d{2}:\d{2}:\d{2}) "
    r"\[(?P<level>\w+)\] "
    r"(?P<message>.*)"
)

line = "2024-05-01 12:30:45 [ERROR] Database connection failed"
m = log_pattern.fullmatch(line)
print(m.groupdict())
# {'date': '2024-05-01', 'time': '12:30:45',
#  'level': 'ERROR', 'message': 'Database connection failed'}
```

构成思路：每个字段一个命名组，字段之间用字面空格和 `[]` 分隔；`.*` 兜底匹配剩余的消息内容。多个相邻的原始字符串会在语法层面自动拼接成一个模式。

## 18.10 常见坑与最佳实践

### 18.10.1 忘记用原始字符串

`"\b"` 是退格符而不是单词边界，见 18.1.2 节。模式一律写 `r"..."`。

### 18.10.2 混淆 `match()` 和 `search()`

`re.match()` 只从开头匹配，是新手最常见的错误来源：

```python
import re

re.match(r"\d+", "abc123")    # None — misleading!
re.search(r"\d+", "abc123")   # Match — finds 123
```

想匹配整个字符串时用 `re.fullmatch()`，比给模式手动加 `^...$` 更明确。

### 18.10.3 贪婪导致的过度匹配

默认量词会吞下比预期更多的内容（见 18.8 节）。结果不符合预期时，先检查是否需要把 `*`、`+` 改成 `*?`、`+?`，或者用更精确的字符类（如 `[^>]*` 代替 `.*?`）——后者往往既清晰又高效：

```python
import re

re.findall(r"<[^>]*>", "<b>bold</b>")   # ['<b>', '</b>'] — no backtracking
```

### 18.10.4 灾难性回溯

正则引擎默认通过回溯（backtracking）试探匹配路径。当嵌套量词出现歧义时，路径数量会指数级膨胀，造成灾难性回溯（catastrophic backtracking），程序看似「卡死」：

```python
import re

# DANGER: each "a" can be split between the inner and outer quantifiers
# re.fullmatch(r"(a+)+$", "a" * 30 + "b")   # Takes an extremely long time!
```

对 `"aaa...ab"` 这样的输入，每个 `a` 都有多种在内外两层量词之间分配的方式，引擎要尝试 `2^n` 种组合才能确认失败。

规避方法：

- 改写模式，消除歧义。`(a+)+$` 等价于 `a+$`。
- 让相邻量词匹配的字符集互不相交，如 `(\w+\s?)+` 比 `(\w+\s*)+` 安全。
- Python 3.11 起支持占有量词（possessive quantifier）`*+`、`++` 和原子组（atomic group）`(?>...)`，它们禁止回溯，例如 `re.fullmatch(r"(?>a+)+$", s)` 或更直接的 `r"a++$"`。
- 对不可信输入，可考虑第三方库 `regex`，它支持给匹配设置超时。

### 18.10.5 什么时候不该用正则

正则擅长「形状简单、规则稳定」的文本，不适合解析具有嵌套结构的格式：

- **不要**用正则解析 HTML——标签可嵌套、属性可乱序、还有容错写法，正则无法可靠处理。请用标准库 `html.parser` 或第三方库（如 Beautiful Soup、lxml）。
- **不要**用正则解析 JSON——直接用 `json` 模块。
- 复杂的逐字符状态判断（如带括号配对的表达式求值），写一个小的解析器往往比维护一条巨型正则更可靠。

判断标准很简单：如果一条正则长到你需要 `re.VERBOSE` 加十几行注释才能看懂，多半已经用错了工具。
