# 9 函数

## 9.1 函数剖析（三要素）

Python 中的每个函数都有三个核心组成部分：

### 9.1.1 三个核心要素

| 要素 | 作用 | 示例 |
|---------|------|---------|
| **名称** | 标识符 + 内存中的地址 | `def greet():` → `greet` 就是名称 |
| **参数** | 输入变量（形参）/ 传入的值（实参） | `(name, age)` |
| **返回值** | 发送回调用者的输出 | `return result` |

### 9.1.2 函数名是引用

函数名只是对内存中函数对象的一个引用。你可以把它赋值给另一个变量，两个名字都指向同一个函数。

```python
def add(a, b):          # name = "add", parameters = (a, b)
    result = a + b      # function body
    return result       # return value

# The function name is a reference to the function object
print(add)              # <function add at 0x...>

# You can assign the function to another variable
my_add = add            # Both names point to the same function
print(my_add(2, 3))     # 5
```

### 9.1.3 返回值规则

1. `return` 后面跟什么，返回值就是什么
2. `return` 会立即结束函数执行——其后的代码不会运行
3. 如果没有 `return`，函数会隐式返回 `None`
4. 不带值的 `return` 同样返回 `None`

## 9.2 函数参数

### 9.2.1 形参与实参

两个相关术语很容易混淆：

- **形参（Parameters）** 是函数**定义**中列出的变量。
- **实参（Arguments）** 是函数**调用**时传入的实际值。

```python
def greet(name):          # `name` is a parameter
    print(f"Hello, {name}!")

greet("Alice")          # "Alice" is an argument
```

### 9.2.2 必需参数与默认参数

定义函数时，你可以把参数设为必需或可选。

| 参数类型 | 语法 | 说明 |
|---------------|--------|-------------|
| 必需参数 | `def fn(a, b)` | 调用时必须提供 |
| 默认参数 | `def fn(a=10)` | 可选，省略时使用默认值 |
| 混合 | `def fn(a, b=10)` | 必需参数必须位于默认参数之前 |

```python
def greet(name, greeting="Hello"):  # name: required, greeting: optional
    print(f"{greeting}, {name}!")

greet("Alice")           # Hello, Alice!
greet("Bob", "Hi")       # Hi, Bob!
```

### 9.2.3 位置实参与关键字实参

调用函数时，可以按位置或按名称传递实参。

| 传递方式 | 语法 | 说明 |
|-------------|--------|-------------|
| 位置传递 | `fn(1, 2)` | 按位置传递，顺序重要 |
| 关键字传递 | `fn(a=1, b=2)` | 按名称传递，顺序不重要 |
| 混合 | `fn(1, b=2)` | 位置实参必须位于关键字实参之前 |

```python
def info(name, age, gender):
    print(name, age, gender)

info("Alice", 20, "F")                    # Positional
info(name="Bob", age=25, gender="M")      # Keyword
info("Charlie", gender="F", age=30)       # Mixed
```

### 9.2.4 仅限位置参数：`/`

位于 `/` 之前的参数必须按位置传递。

```python
def divide(a, b, /):
    return a / b

divide(10, 2)       # OK
# divide(a=10, b=2) # TypeError: positional-only argument passed as keyword
```

### 9.2.5 仅限关键字参数：`*`

位于单独的 `*` 之后的参数必须按关键字传递。

```python
def greet(name, *, greeting="Hello"):
    print(f"{greeting}, {name}!")

greet("Alice")              # OK
greet("Alice", greeting="Hi")  # OK
# greet("Alice", "Hi")      # TypeError: positional argument after *
```

### 9.2.6 可变默认参数陷阱

默认参数值在函数**定义时**只求值**一次**，而不是每次调用函数时都重新求值。使用可变对象（如 `list` 或 `dict`）作为默认值，可能导致多次调用之间发生意外共享。

```python
# WRONG: mutable default shared across calls
def append_item(value, items=[]):
    items.append(value)
    return items

print(append_item(1))  # [1]
print(append_item(2))  # [1, 2]  ← unexpectedly keeps previous value
```

安全的写法是以 `None` 作为默认值，并在函数内部创建新的可变对象。

```python
# CORRECT: create a new list each call
def append_item(value, items=None):
    if items is None:
        items = []
    items.append(value)
    return items

print(append_item(1))  # [1]
print(append_item(2))  # [2]
```

## 9.3 可变参数

### 9.3.1 可变位置参数 `*args`

| 特性 | 说明 |
|---------|-------------|
| 语法 | `def fn(*args)` |
| 类型 | 包含所有多余位置实参的元组 |
| 命名 | 按惯例命名为 `args` |

```python
def total(*args):           # args is a tuple
    return sum(args)

total()                     # 0
total(1, 2, 3)              # 6
total(1, 2, 3, 4, 5)        # 15

# Mixed with regular params
def info(a, b, *args):      # a, b required; args collects the rest
    print(f"a={a}, b={b}, rest={args}")

info(1, 2)                  # a=1, b=2, rest=()
info(1, 2, 3, 4, 5)         # a=1, b=2, rest=(3, 4, 5)
```

### 9.3.2 可变关键字参数 `**kwargs`

| 特性 | 说明 |
|---------|-------------|
| 语法 | `def fn(**kwargs)` |
| 类型 | 包含所有多余关键字实参的字典 |
| 命名 | 按惯例命名为 `kwargs` |

```python
def info(**kwargs):         # kwargs is a dict
    for key, value in kwargs.items():
        print(f"{key}: {value}")

info(name="Alice", age=20)  # name: Alice, age: 20

# Universal template (accepts any arguments)
def universal(*args, **kwargs):
    print(f"Positional: {args}")
    print(f"Keyword: {kwargs}")

universal(1, 2, 3, name="Alice", age=20)
# Positional: (1, 2, 3)
# Keyword: {'name': 'Alice', 'age': 20}
```

## 9.4 参数顺序速查表

Python 3 的函数按以下顺序组合所有参数形式：

```python
# With variable positional collection
def fn(pos_only, /, pos_or_kwd, default="value", *args, kwd_only, **kwargs):
    pass

# With bare * (keyword-only, but no *args collection)
def fn2(pos_only, /, pos_or_kwd, *, kwd_only, **kwargs):
    pass
```

**注意：** `*args` 与单独的 `*` 互斥——它们占据相同的语法位置。你可以使用其中之一，但不能在同一个函数签名中同时使用两者。

```python
# Invalid: cannot have both *args and bare *
def fn(*args, *, b):   # SyntaxError
    pass
```

| 部分                                          | 语法                               | 传递方式                       |
| --------------------------------------------- | ---------------------------------- | ------------------------------ |
| 仅限位置                                      | `a, b, /`                          | 只能按位置                     |
| 位置或关键字（可选默认值）                    | `c`、`d="value"`                   | 按位置或按关键字               |
| 可变位置                                      | `*args`                            | 收集多余的位置实参             |
| 仅限关键字（可选默认值）                      | `*, name` 或 `*args, name="value"` | 只能按关键字                   |
| 可变关键字                                    | `**kwargs`                         | 收集多余的关键字实参           |

```python
def demo(a, b, /, c, d="default", *, e, f="kw_only"):
    print(f"a={a}, b={b}, c={c}, d={d}, e={e}, f={f}")

# a, b: positional-only
# c: positional or keyword
# d: default, positional or keyword
# e, f: keyword-only
demo(1, 2, 3, e="required")
# a=1, b=2, c=3, d=default, e=required, f=kw_only
```

## 9.5 参数解包

| 操作                 | 语法         | 说明                             |
| -------------------- | ------------ | -------------------------------- |
| 列表/元组解包        | `fn(*list)`  | 将序列解包为位置实参             |
| 字典解包             | `fn(**dict)` | 将字典解包为关键字实参           |

```python
def add(a, b, c):
    return a + b + c

nums = [1, 2, 3]
print(add(*nums))           # Equivalent to add(1, 2, 3)

data = {"a": 1, "b": 2, "c": 3}
print(add(**data))          # Equivalent to add(a=1, b=2, c=3)
```

## 9.6 函数返回值

| 特性 | 说明 |
|---------|-------------|
| `return` | 结束函数执行，将值返回给调用者 |
| 单个值 | `return x` |
| 多个值 | `return a, b`（返回元组） |
| 无 return | 隐式返回 `None` |
| 空 return | `return` 返回 `None` |

```python
def square(x):
    return x * x              # Returns single value

def stats(x, y):
    return x + y, x - y       # Returns tuple (can unpack)

sum_val, diff = stats(10, 3)  # Unpacking
```

## 9.7 作用域

### 9.7.1 LEGB 规则

Python 按 **LEGB** 顺序解析名称，从内到外依次为：

| 作用域 | 说明 | 示例 |
|-------|-------------|---------|
| **L**ocal（局部） | 当前函数内部 | 函数内定义的变量 |
| **E**nclosing（闭包） | 最近的外层嵌套函数中 | 嵌套外层函数中的变量 |
| **G**lobal（全局） | 模块级别 | 模块中定义的变量 |
| **B**uilt-in（内置） | Python 的内置名称 | `print`、`len`、`str` 等 |

```python
x = "global"

def outer():
    x = "enclosing"

    def inner():
        x = "local"
        print(x)  # local

    inner()
    print(x)      # enclosing

outer()
print(x)          # global
```

赋值会改变该名称存在的最内层作用域，除非你使用 `global` 或 `nonlocal` 指定其他作用域。

### 9.7.2 `global` 与 `nonlocal`

当需要给位于当前函数局部作用域之外的变量赋值时，使用这两个关键字。

#### 9.7.2.1 `global`

在函数内部修改模块级变量。

```python
count = 0                   # Global variable

def increment():
    global count            # Declare using global
    count += 1

increment()
print(count)                # 1
```

#### 9.7.2.2 `nonlocal`

修改外层（非全局）闭包变量，通常用于嵌套函数中。

```python
def outer():
    x = 10                  # Enclosing variable
    def inner():
        nonlocal x          # Modify outer variable
        x += 1
    inner()
    return x

print(outer())              # 11
```

**`nonlocal` 查找规则：**
1. 从最内层的闭包作用域开始**向外**搜索
2. 在找到的**第一个**匹配变量名处停止
3. 如果在任何闭包（非全局）作用域中都找不到匹配 → `SyntaxError`

```python
def level_1():
    x = "level_1"
    def level_2():
        x = "level_2"       # New local variable in level_2
        def level_3():
            nonlocal x      # Binds to the NEAREST enclosing x → level_2's x
            x = "modified by level_3"
        level_3()
        print(x)            # "modified by level_3" (level_2's x was changed)
    level_2()
    print(x)                # "level_1" (level_1's x was NOT changed)

level_1()
```

需要修改模块级变量时使用 `global`；需要修改外层函数作用域中的变量时使用 `nonlocal`。

#### 9.7.2.3 对比

| 关键字 | 所修改的作用域 | 典型使用场景 | 示例 |
|---------|-------------------|------------------|---------|
| `global` | 模块级（全局）变量 | 计数器、配置标志、共享状态 | `global count` |
| `nonlocal` | 最近的外层（非全局）变量 | 需要修改外层局部变量的嵌套函数 | `nonlocal x` |

## 9.8 函数文档与类型提示

### 9.8.1 文档字符串（Docstrings）

在函数定义之后紧跟三引号字符串来为函数编写文档。

```python
def calculate_area(length, width):
    """
    Calculate the area of a rectangle.

    Parameters:
        length (float): The length of the rectangle.
        width (float): The width of the rectangle.

    Returns:
        float: The calculated area.
    """
    return length * width

# Access docstring
print(calculate_area.__doc__)
```

### 9.8.2 类型提示

可选的注解，用于提升代码可读性和 IDE 支持。

```python
def greet(name: str, age: int) -> str:
    return f"Hello {name}, you are {age} years old."

# Type hints have no runtime effect
greet("Alice", 20)  # Works normally

# Variable annotations
score: int = 95
names: list[str] = ["Alice", "Bob"]
user: dict[str, int] = {"age": 20}
```

**注意：** Python 仍然是动态类型语言。类型提示由外部工具（如 `mypy`）检查，而不是在运行时检查。

**另请参阅：** [17 类型注解](17-类型注解.md)，其中有更详细的讨论。

从 `typing` 模块导入以进行复杂类型声明。

```python
from typing import Optional, Union, Callable, List

# Optional: value or None
def greet(name: Optional[str] = None) -> str:
    return f"Hello, {name or 'Guest'}"

# Union: multiple accepted types
def add(a: Union[int, float], b: Union[int, float]) -> float:
    return a + b

# Callable: function as parameter
def apply(func: Callable[[int], int], value: int) -> int:
    return func(value)
```


## 9.9 递归

调用自身的函数。必须有一个**基线条件（base case）**来终止递归。

```python
def factorial(n):
    if n <= 1:           # Base case
        return 1
    return n * factorial(n - 1)  # Recursive case

factorial(5)  # 120
```

**注意：** Python 有递归深度限制（默认约为 1000）。深度较大的递归请改用迭代。

```python
import sys
sys.getrecursionlimit()   # 1000 (default)
```
