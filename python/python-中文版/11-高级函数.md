# 11 高级函数

## 11.1 Lambda 匿名函数

`lambda` 是一个小型的匿名函数，以单个表达式的形式书写。

### 11.1.1 语法与基本用法

```python
# lambda parameters: expression
square = lambda x: x ** 2
square(5)                   # 25

# Equivalent to:
def square(x):
    return x ** 2
```

### 11.1.2 常见使用场景

lambda 表达式最有用的场景是作为高阶函数的简短参数。

```python
# Sort with custom key
pairs = [(1, 'one'), (2, 'two'), (3, 'three')]
pairs.sort(key=lambda x: x[1])  # Sort by second element

# With map/filter
list(map(lambda x: x * 2, [1, 2, 3]))      # [2, 4, 6]
list(filter(lambda x: x > 0, [-1, 2, 3]))  # [2, 3]
```

### 11.1.3 局限性

- **只能是单个表达式**——不能包含语句、赋值或循环
- **不支持类型注解和文档字符串**
- **难以调试**——lambda 在回溯信息（traceback）中没有有意义的名称

短小、用完即弃的函数用 `lambda`；任何复杂的逻辑都用 `def`。

## 11.2 高阶函数

### 11.2.1 什么是高阶函数？

**高阶函数**（higher-order function）是指至少满足下列条件之一的函数：

- **接受另一个函数作为参数**
- **返回一个函数作为结果**

Python 中最常见的内置高阶函数：

| 内置高阶函数 | 用途 |
|-------------|---------|
| `map()` | 将函数应用于每个元素 |
| `filter()` | 筛选满足条件的元素 |
| `sorted()` | 使用自定义键排序 |

### 11.2.2 `map()`

| 特性 | 说明 |
|---------|-------------|
| 语法 | `map(func, iterable)` |
| 返回值 | 包含转换后元素的迭代器 |
| 输出 | 用 `list()` 转换为列表 |

**执行流程：**
1. 创建一个 `map` 迭代器对象，它记住 `func` 和 `iterable`
2. 每次迭代时，从 `iterable` 中取出一个元素，传给 `func`，产出结果
3. 持续进行，直到 `iterable` 耗尽

```python
# Convert strings to integers
nums = ["1", "2", "3"]
list(map(int, nums))        # [1, 2, 3]

# Transform with lambda
list(map(lambda x: x ** 2, [1, 2, 3]))  # [1, 4, 9]

# map() returns an iterator — lazy evaluation
mapped = map(int, nums)
print(mapped)               # <map object at 0x...>  (not a list yet)
```

### 11.2.3 `filter()`

| 特性 | 说明 |
|---------|-------------|
| 语法 | `filter(func, iterable)` |
| 返回值 | 包含 func 返回 True 的元素的迭代器 |
| 输出 | 用 `list()` 转换为列表 |

**执行流程：**
1. 创建一个 `filter` 迭代器对象，它记住 `func` 和 `iterable`
2. 每次迭代时，取出一个元素，调用 `func(element)`
3. 如果结果为**真值（truthy）**，产出该元素；如果为**假值（falsy）**，跳过它
4. 持续进行，直到 `iterable` 耗尽

```python
# Filter even numbers
nums = [1, 2, 3, 4, 5, 6]
list(filter(lambda x: x % 2 == 0, nums))  # [2, 4, 6]

# Filter with condition
users = [{"name": "Alice", "age": 25}, {"name": "Bob", "age": 17}]
list(filter(lambda u: u["age"] >= 18, users))
```

### 11.2.4 带 `key` 参数的 `sorted()`

| 特性 | 说明 |
|---------|-------------|
| 语法 | `sorted(iterable, key=None, reverse=False)` |
| 返回值 | 新的已排序列表（原列表不变） |
| `key` | 用于提取比较键的函数 |

```python
nums = [3, 1, 4, 1, 5]
sorted(nums)                        # [1, 1, 3, 4, 5]
sorted(nums, reverse=True)          # [5, 4, 3, 1, 1]

# Sort by key function
words = ["banana", "pie", "Washington"]
sorted(words, key=len)              # ['pie', 'banana', 'Washington']

# Sort by object attribute
users = [{"name": "Bob", "age": 30}, {"name": "Alice", "age": 25}]
sorted(users, key=lambda x: x["age"])  # Alice first

# Sort by absolute value
nums = [-3, 1, -2, 4]
sorted(nums, key=lambda x: abs(x))   # [1, -2, -3, 4]

# Sort by parsed numeric value from string
products = ["iPhone_8000", "Mi_4000", "Huawei_10000"]
sorted(products, key=lambda x: int(x.split("_")[1]))  # ['Mi_4000', 'iPhone_8000', 'Huawei_10000']
```

**注意：** 关于基本的排序语法以及与 `.sort()` 的对比，参见 [3.5.2 排序](03-序列类型.md#352-排序)。

## 11.3 `any()` 和 `all()`

### 11.3.1 基本用法

只要至少有一个元素为真值，`any(iterable)` 就返回 `True`；只有当所有元素都为真值时，`all(iterable)` 才返回 `True`。

```python
any([False, 0, "hello"])   # True
any([False, 0, ""])        # False

all([1, 2, 3])             # True
all([1, 0, 3])             # False (0 is falsy)
```

一个值如果能通过 `if` 检查，就称为**真值（truthy）**。常见的假值有 `0`、`0.0`、`""`、`[]`、`{}`、`None` 和 `False`。

### 11.3.2 配合条件使用

大多数情况下，你会传入一个生成器表达式来对每个元素进行条件检查。

```python
nums = [-1, -5, 3, -8]
any(n > 0 for n in nums)          # True
all(n < 0 for n in nums)          # False

# Check if any user is an admin
users = [{"name": "Alice", "role": "user"}, {"name": "Bob", "role": "admin"}]
any(u["role"] == "admin" for u in users)   # True

# Check if all users are adults
users = [{"name": "Alice", "age": 25}, {"name": "Bob", "age": 30}]
all(u["age"] >= 18 for u in users)   # True
```

### 11.3.3 短路行为与空输入

这两个函数都会提前停止。`any()` 在遇到第一个真值元素时停止，`all()` 在遇到第一个假值元素时停止。

```python
nums = [-1, -5, 3, -8]
any(n > 0 for n in nums)     # True (stops at 3)

nums = [2, 4, 6, 7, 8]
all(n % 2 == 0 for n in nums)   # False (stops at 7)

# Empty inputs
any([])     # False
all([])     # True
```

### 11.3.4 常见陷阱

`all()` 会把 `0`、`""`、`None` 和空容器视为假值，因此在检查非布尔值时要显式写出条件。

```python
nums = [0, 1, 2]
all(nums)                    # False (0 is falsy)
all(n >= 0 for n in nums)    # True
```

## 11.5 迭代器

### 11.5.1 迭代器协议

Python 的迭代协议依赖两个方法：

| 方法 | 作用 |
|--------|------|
| `__iter__()` | 调用它从可迭代对象获取迭代器。对迭代器自身调用时，返回 `self`。 |
| `__next__()` | 返回下一项。没有更多项时抛出 `StopIteration`。 |

内置函数 `iter()` 和 `next()` 会为你调用这些魔法方法（双下划线方法）。

```python
lst = [1, 2, 3]
it = iter(lst)              # Calls lst.__iter__()

next(it)                    # 1  (calls it.__next__())
next(it)                    # 2
next(it)                    # 3
# next(it)                  # StopIteration exception
```

**可迭代对象与迭代器：**

- **可迭代对象（Iterable）：** 拥有 `__iter__()`，可以被多次循环遍历。列表、元组、字符串、字典和集合都是可迭代对象。
- **迭代器（Iterator）：** 同时拥有 `__iter__()` 和 `__next__()`。迭代器是一次性的——一旦耗尽就不会重置。

```python
# for loop uses iterator internally
for item in lst:            # Calls iter(lst), then next() repeatedly
    print(item)
```

### 11.5.2 `for` 循环的底层工作原理

`for` 循环是迭代器协议模式的语法糖：

```python
lst = ["Alice", "Bob", "Charlie"]

# What "for item in lst" actually does internally:
_iterator = iter(lst)           # 1. Get iterator from iterable
while True:
    try:
        item = next(_iterator)  # 2. Get next element
        print(item)             # 3. Execute loop body
    except StopIteration:       # 4. No more elements → exit
        break
```

`for` 循环会自动处理 `StopIteration`，这就是为什么你在正常循环中永远不会看到这个异常。当你用 `next()` 手动耗尽一个迭代器时，必须自己捕获（或放任）`StopIteration`。

```python
it = iter([1, 2, 3])

# Manual iteration (must handle StopIteration)
try:
    while True:
        print(next(it))
except StopIteration:
    print("Done")
```

### 11.5.3 `itertools` 概览

用于高效迭代模式的内置模块。

| 函数 | 用途 | 示例 |
|----------|---------|---------|
| `count(start, step)` | 无限计数器 | `count(10, 2)` → 10, 12, 14... |
| `cycle(iterable)` | 无限重复 | `cycle("AB")` → A, B, A, B... |
| `repeat(value, times)` | 重复某个值 | `repeat(5, 3)` → 5, 5, 5 |
| `chain(a, b)` | 拼接可迭代对象 | `chain([1,2], [3,4])` → 1, 2, 3, 4 |
| `groupby(iterable, key)` | 对连续的相等项分组 | 见下方示例 |

```python
import itertools

# chain: flatten lists
list(itertools.chain([1, 2], [3, 4]))   # [1, 2, 3, 4]

# groupby: group consecutive items
data = [("A", 1), ("A", 2), ("B", 3), ("B", 4)]
for key, group in itertools.groupby(data, key=lambda x: x[0]):
    print(key, list(group))   # A [(A,1), (A,2)]  B [(B,3), (B,4)]
```

## 11.6 生成器

### 11.6.1 生成器函数与生成器表达式

生成器（generator）是一种按需产出值、而不是把所有值都存进内存的迭代器。

| 特性 | 说明 |
|---------|-------------|
| 定义 | 含有 `yield` 的函数，或生成器表达式 |
| 行为 | 惰性求值，一次产出一个值 |
| 内存 | 对大型或无限序列非常高效 |

#### 11.6.1.1 生成器函数

在函数内部使用 `yield` 即可创建生成器。每个 `yield` 会暂停执行并返回一个值。

```python
def countdown(n):
    while n > 0:
        yield n             # Pause and return value
        n -= 1

for num in countdown(5):    # 5, 4, 3, 2, 1
    print(num)
```

#### 11.6.1.2 生成器表达式

生成器表达式看起来与列表推导式相似，但使用圆括号。它惰性地产出值，而不是构建一个完整的列表。

```python
# Does NOT create a list in memory
gen = (x ** 2 for x in range(1000000))

# Values are produced one at a time when iterated
for value in gen:
    pass
```

#### 11.6.1.3 无限序列

生成器可以无限运行，因为它是按需计算值的。

```python
def fibonacci():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b

fib = fibonacci()
[next(fib) for _ in range(10)]  # First 10 Fibonacci numbers
```

### 11.6.2 生成器执行流程

调用生成器函数时，函数体**并不会**立即执行，而是返回一个生成器对象。函数体只有在调用 `next()` 时才会执行，并在每个 `yield` 处**暂停**，下次调用 `next()` 时从那个确切的位置继续执行。

```python
def step_generator():
    print("Step 1: start")
    yield 10
    print("Step 2: resumed")
    yield 20
    print("Step 3: resumed again")
    yield 30
    print("Step 4: finished")

g = step_generator()        # Nothing printed yet — returns generator object
print(next(g))              # Step 1: start → 10  (pauses at first yield)
print(next(g))              # Step 2: resumed → 20  (resumes, pauses at second yield)
print(next(g))              # Step 3: resumed again → 30
# next(g)                   # Step 4: finished → StopIteration
```

**关键要点：** `yield` 既是输出点，也是检查点。生成器在两次调用之间会记住自己的局部变量和执行位置。

### 11.6.3 生成器表达式与列表推导式对比

语法上只差一个字符，但行为截然不同：

| 特性 | 列表推导式 `[]` | 生成器表达式 `()` |
|---------|------------------------|---------------------------|
| 结果 | 内存中的完整列表 | 惰性迭代器对象 |
| 内存占用 | 高（存储所有值） | 低（按需产出） |
| 可复用性 | 可多次迭代 | 一次性使用 |
| 语法 | `[x**2 for x in range(n)]` | `(x**2 for x in range(n))` |

```python
# List comprehension — creates entire list immediately
squares_list = [x ** 2 for x in range(5)]
print(squares_list)       # [0, 1, 4, 9, 16]
print(type(squares_list)) # <class 'list'>

# Generator expression — creates iterator, values generated on demand
squares_gen = (x ** 2 for x in range(5))
print(squares_gen)        # <generator object <genexpr> at 0x...>
print(type(squares_gen))  # <class 'generator'>

# Must consume with list() or iterate
print(list(squares_gen))  # [0, 1, 4, 9, 16]
```

**何时使用哪一个：**
- 需要随机访问或多次遍历时，使用**列表推导式**
- 处理大型/无限序列或单次遍历的流水线时，使用**生成器表达式**

### 11.6.4 生成器方法

生成器支持与调用者进行通信。

| 方法 | 用途 |
|--------|---------|
| `send(value)` | 向生成器发送值，恢复其执行 |
| `throw(exc)` | 在生成器内部抛出异常 |
| `close()` | 提前终止生成器 |

```python
def accumulator():
    total = 0
    while True:
        value = yield total   # Receive value via send()
        if value is None:
            break
        total += value

acc = accumulator()
next(acc)           # Start generator
acc.send(10)        # total = 10
acc.send(5)         # total = 15
acc.close()         # Clean shutdown
```

### 11.6.5 `yield from`

将迭代委托给子生成器。

```python
def sub_generator():
    yield 1
    yield 2

def main_generator():
    yield "start"
    yield from sub_generator()
    yield "end"

list(main_generator())   # ['start', 1, 2, 'end']
```
