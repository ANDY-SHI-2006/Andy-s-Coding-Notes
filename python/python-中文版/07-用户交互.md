# 7 用户交互

## 7.1 `print()` 函数

### 7.1.1 语法

```python
print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False)
```

| 参数 | 说明 | 默认值 |
|-----------|-------------|---------|
| `*objects` | 要打印的值（数量可变） | — |
| `sep` | 各值之间的分隔符 | `' '`（空格） |
| `end` | 最后一个值之后追加的字符串 | `'\n'`（换行符） |
| `file` | 输出流 | `sys.stdout` |
| `flush` | 强制刷新输出流 | `False` |

### 7.1.2 `sep` 参数

指定多个值之间的分隔符。默认为空格 `' '`。

```python
print(1, 2, 3)           # 输出：1 2 3
print(1, 2, 3, sep='+')  # 输出：1+2+3
print(1, 2, 3, sep='\n') # 输出：每个占一行
```

### 7.1.3 `end` 参数

指定在末尾打印什么。默认为换行符 `'\n'`。

```python
print(1, end='')         # 输出后不换行
print(2, end=' ')        # 用空格代替换行
print(3)                 # 输出：1 2 3
```

### 7.1.4 `file` 和 `flush` 参数

- `file`：将输出从屏幕重定向到文件或流，适用于**日志记录**。
- `flush`：强制立即输出，而不是等待缓冲区填满，适用于**进度指示**和**实时监控**。

| 参数 | 说明 | 默认值 |
|-----------|-------------|---------|
| `file` | 输出目标 | `sys.stdout` |
| `flush` | 强制立即输出 | `False` |

```python
# 将输出重定向到文件
with open("output.txt", "w") as f:
    print("Hello, file!", file=f)

# 强制立即输出（适用于进度显示）
print("Loading...", end="", flush=True)
```

### 7.1.5 返回值

`print()` 总是返回 `None`，不能作为表达式的一部分使用。

```python
result = print("hello")   # 打印 "hello"
print(result)             # None
```

### 7.1.6 `sep` 与 `end` 的组合用法

同时使用两个参数的实用单行写法。

```python
# CSV 风格输出
print("Alice", 20, "NY", sep=",", end="\n")

# 进度条风格
for i in range(5):
    print(i, end=" ", flush=True)   # 0 1 2 3 4
```

## 7.2 `input()` 函数

### 7.2.1 基本输入

从用户读取一行输入，结果为**字符串**。末尾的换行符会被去除。可以传入可选的提示信息。若需数值类型，必须手动转换。

```python
# 基本输入
name = input("Enter your name: ")
print(f"Hello, {name}!")

# 转换为 int
age = int(input("Enter your age: "))
print(f"Next year you will be {age + 1}")

# 转换为 float
height = float(input("Enter your height (m): "))
```

### 7.2.2 输入验证

`input()` 总是返回字符串。转换之前务必先验证，避免程序崩溃。

```python
# 安全的整数输入（一次性）
try:
    num = int(input("Enter a number: "))
except ValueError:
    print("Invalid input. Please enter a valid integer.")
    num = 0

# 循环直到输入有效（最常用的模式）
while True:
    try:
        num = int(input("Enter a number: "))
        break
    except ValueError:
        print("Invalid input. Try again.")

# 链式转换（常见，但不校验时不安全）
num = int(input("Enter a number: "))  # 输入 "abc" 会崩溃
```

### 7.2.3 空输入的默认值

当用户未输入任何内容直接按回车时，`input()` 返回空字符串 `""`（其布尔值为假）。可以用 `or` 在一行内提供默认值。

```python
# 用户什么都不输入时，"" 为假值，因此使用 "Anonymous"
name = input("Name: ") or "Anonymous"
print(f"Hello, {name}!")

# .strip() 防止空格被当作输入
command = input("> ").strip() or "help"
```

**此处 `or` 的工作原理：** `or` 是短路运算符。如果左操作数为真值（truthy），则返回左操作数；否则返回右操作数。其结果是原始值之一，而不只是 `True` 或 `False`。

- `"Alice" or "Anonymous"` → `"Alice"`（左侧为真值）
- `"" or "Anonymous"` → `"Anonymous"`（左侧为假值，因此使用默认值）

这意味着 `input("Name: ") or "Anonymous"` 等价于写一个 `if` 语句：检查输入是否为空，然后赋默认值。

### 7.2.4 使用 `getpass` 进行安全输入

输入密码或其他敏感信息时使用 `getpass.getpass()`。输入的字符不会回显到终端。

```python
from getpass import getpass, getuser

password = getpass("Enter password: ")
# 输入的字符会被隐藏

username = getuser()  # 获取当前登录名（取决于操作系统）
```

> **注意：** `getpass()` 在某些 IDE（如 VS Code 终端）中可能无法正常工作。请改用真实的终端或命令行。

### 7.2.5 使用 `ast.literal_eval` 安全解析

> **绝不要对不可信的输入使用 `eval()`。** `eval()` 会执行任意代码，存在严重的安全风险。

`eval()` 把输入字符串当作 Python 代码并执行。

- 恶意用户可以输入 `__import__('os').system('rm -rf /')`，而 `eval()` 会真的执行该命令。

`ast.literal_eval()` 只把字符串转换为基本数据类型（列表、字典、数字、字符串）。

- 它从不执行代码——只解析字面量。
- 如果输入不是字面量，它会抛出异常。

```python
# 危险 — 请勿使用
result = eval(input())  # 用户可以输入恶意代码

# 更安全的替代方案
import ast
value = ast.literal_eval(input())  # 只解析字面量
```

**对比：**

| 输入字符串 | `eval()` | `ast.literal_eval()` |
|-------------|----------|---------------------|
| `"[1, 2, 3]"` | ✅ 列表 `[1, 2, 3]` | ✅ 列表 `[1, 2, 3]` |
| `"{1: 'a'}"` | ✅ 字典 `{1: 'a'}` | ✅ 字典 `{1: 'a'}` |
| `"1 + 1"` | ✅ 执行运算 → `2` | ❌ 抛出 `ValueError` |
| `"__import__('os').system('rm -rf /')"` | ❌ 执行命令 | ❌ 抛出 `ValueError` |

**为什么不直接用 `int()`？**

- `int()` 只能转换单个数值字符串。当输入保证是一个整数时使用它。
- `eval()` 可以解析任何字面量并执行表达式，但它会执行任意代码，因此对用户输入不安全。
- `ast.literal_eval()` 能识别与 `eval()` 相同的基本数据类型（列表、字典、数字、字符串、布尔值、`None`），但它从不执行代码，因此可以安全地用于不可信输入。

```python
int("42")                     # 42，但只适用于单个整数
ast.literal_eval("[1, 2, 3]") # [1, 2, 3]，适用于更丰富的结构，安全
```

### 7.2.6 多行输入

持续读取多行，直到遇到 EOF 或空行。

**EOF**（文件结束符）：当输入被关闭时，`input()` 会抛出 `EOFError`（Unix：Ctrl+D，Windows：Ctrl+Z）。

```python
try:
    line = input()
except EOFError:
    print("Input closed")
```

```python
# 读到 EOF 为止（Unix：Ctrl+D，Windows：Ctrl+Z）
import sys
lines = sys.stdin.read()

# 读到空行为止
lines = []
while (line := input()):
    lines.append(line)
```

## 7.3 字符串格式化

### 7.3.1 f-string（推荐）

在字符串前加前缀 `f` 或 `F`，在 `{}` 中嵌入表达式。Python 3.6+ 可用。

```python
name = "Alice"
age = 20
print(f"My name is {name} and I am {age} years old.")
print(f"Next year I will be {age + 1}")

# 格式化数字
pi = 3.14159265
print(f"Pi = {pi:.2f}")  # Pi = 3.14
```

### 7.3.2 格式说明符

格式说明符在 `{}` 内遵循统一的语法：

```
{value:[fill][align][sign][#][0][width][grouping][.precision][type]}
```

每个组成部分都是可选的。顺序中只有一点必须遵守：`fill` 必须位于 `align` 之前。

#### 7.3.2.1 填充（fill）

放在 `align` 之前的任意单个字符，用于填充空白位置。必须与对齐说明符搭配使用。

```python
f"{'hi':0>5}"     # '000hi'   (用 0 填充空位)
f"{'hi':#^6}"     # '#hi###'  (用 # 填充空位)

# 数字补零的简写形式
f"{42:05d}"       # '00042'
f"{42:0=5d}"      # '00042'   (等价的显式写法)
```

#### 7.3.2.2 对齐（align）

控制在字段宽度内的位置。对齐符前面总是有宽度值。

| 符号 | 含义 |
|--------|---------|
| `<` | 左对齐 |
| `>` | 右对齐 |
| `^` | 居中 |
| `=` | 在符号与数字之间填充（仅限数字） |

**指定宽度时的默认对齐方式：**

- 字符串默认**左对齐**（`<`）
- 数字默认**右对齐**（`>`）

```python
f"{'hi':10}"      # 'hi        '   (字符串默认左对齐)
f"{42:10}"        # '        42'   (数字默认右对齐)

# 显式对齐
f"{'hi':>10}"     # '        hi'   (右对齐，宽度 10)
f"{'hi':<10}"     # 'hi        '   (左对齐，宽度 10)
f"{'hi':^10}"     # '    hi    '   (居中，宽度 10)
f"{-42:0=10}"     # '-000000042'   (在符号和数字之间填充)
```

#### 7.3.2.3 符号（sign）

控制正数和负数的显示方式。

| 符号 | 含义 |
|--------|---------|
| `+` | 总是显示符号（`+3`、`-3`） |
| `-` | 仅对负数显示符号（默认） |
| ` ` | 正数显示空格，负数显示负号 |

```python
f"{3:+d}"         # '+3'
f"{3: d}"         # ' 3'
f"{-3:d}"         # '-3'
```

#### 7.3.2.4 替代形式（`#`）

将默认输出格式改为替代表示形式。

| 搭配使用 | 效果 | 示例 |
|-----------|--------|---------|
| `b` | 前缀 `0b` | `f"{255:#b}"` → `'0b11111111'` |
| `o` | 前缀 `0o` | `f"{255:#o}"` → `'0o377'` |
| `x` | 前缀 `0x` | `f"{255:#x}"` → `'0xff'` |
| `X` | 前缀 `0X` | `f"{255:#X}"` → `'0XFF'` |
| `f` / `F` | 总是显示小数点 | `f"{1.0:#f}"` → `'1.000000'` |
| `e` / `E` | 总是显示小数点 | `f"{1.0:#e}"` → `'1.000000e+00'` |
| `g` / `G` | 保留尾随零 | `f"{1.0:#g}"` → `'1.00000'` |

```python
# 整数前缀
f"{255:#b}"       # '0b11111111'
f"{255:#o}"       # '0o377'
f"{255:#x}"       # '0xff'

# 浮点数：强制显示小数点
f"{1.0:f}"         # '1.000000'  (默认也会显示)
f"{1.0:g}"         # '1'         (默认会去掉)
f"{1.0:#g}"        # '1.00000'   (# 会保留末尾的零)
```

#### 7.3.2.5 宽度（width）

设置字段的最小宽度。如果值更短，则按对齐方式进行填充。

```python
f"{'hi':10}"      # 'hi        '   (宽度 10，字符串默认左对齐)
f"{42:10d}"       # '        42'   (数字默认右对齐)
```

#### 7.3.2.6 分组（grouping）

在数字之间插入分隔符以提高可读性。

| 符号 | 含义 |
|--------|---------|
| `,` | 逗号作为千位分隔符 |
| `_` | 下划线作为千位分隔符 |

```python
f"{1000000:,}"    # '1,000,000'
f"{1000000:_}"    # '1_000_000'
```

#### 7.3.2.7 精度（precision）

`.n` 对数字设置小数位数，对字符串设置最大长度。

**对于数字：** 精度会对值进行四舍五入（采用 round-half-to-even，又称银行家舍入法），而不是截断。

**对于字符串：** 精度会将其截断到给定的最大长度。

```python
# 数字：四舍五入，而非截断
f"{3.14159:.2f}"  # '3.14'
f"{2.5:.0f}"       # '2'   (银行家舍入)
f"{3.5:.0f}"       # '4'   (银行家舍入)

# 字符串：截断
f"{'hello':.3}"   # 'hel'
```

> **浮点数陷阱：** 某些小数无法用二进制精确表示。例如，`f"{2.675:.2f}"` 得到的是 `'2.67'` 而不是 `'2.68'`，因为 `2.675` 实际存储的值略小于其真值。

#### 7.3.2.8 类型（type）

声明输出格式。

| 符号 | 含义 |
|--------|---------|
| `f` | 定点浮点数 |
| `e` / `E` | 科学计数法 |
| `%` | 百分比（乘以 100） |
| `d` | 整数（十进制） |
| `b` | 二进制 |
| `o` | 八进制 |
| `x` / `X` | 十六进制 |
| `s` | 字符串（默认） |

```python
f"{3.14159:.2f}"  # '3.14'
f"{3.14159:.2e}"  # '3.14e+00'
f"{0.25:.1%}"     # '25.0%'
f"{255:b}"        # '11111111'
f"{255:x}"        # 'ff'
```

#### 7.3.2.9 组合各组成部分

按照语法模板的顺序拼接各组成部分，即可构建复杂的格式。

```python
# [fill][align][width][.precision][type]
f"{3.14159:0>10.2f}"   # '0000003.14'

# [sign][#][width][grouping][.precision][type]
f"{1234.5:+#12,.2f}"   # '   +1,234.50'

# [fill][align][sign][width][type]
f"{-42:*<+8x}"         # '-2a****'
```

### 7.3.3 `str.format()`

适用于旧版本 Python 或复杂格式化的替代方案。同样的格式说明符在 `{}` 中均可使用。

```python
template = "My name is {} and I am {} years old."
print(template.format("Alice", 20))

# 命名占位符
print("Name: {name}, Age: {age}".format(name="Bob", age=25))

# 带索引的位置占位符
print("{0} {1} {0}".format("A", "B"))  # A B A

# 带格式说明符
print("{:.2f}".format(3.14159))        # 3.14
print("{:>10}".format("hi"))           # "        hi"
```

### 7.3.4 `format()` 内置函数

`format()` 函数对单个值应用格式说明符。当值和格式字符串分开存放时很有用。

```python
value = 3.14159
spec = ".2f"
print(format(value, spec))   # 3.14

# 等价于 f-string
print(f"{value:.2f}")        # 3.14
```

### 7.3.5 `%` 格式化（旧式）

`%` 运算符是源自 C 语言 `printf` 的 Python 初代格式化风格。在旧代码中仍能见到，但**不推荐**用于新项目。

| 说明符 | 类型 | 示例 |
|-----------|------|---------|
| `%s` | 字符串 | `"%s" % "hello"` → `'hello'` |
| `%d` | 整数 | `"%d" % 42` → `'42'` |
| `%f` | 浮点数 | `"%f" % 3.14` → `'3.140000'` |
| `%.2f` | 带精度的浮点数 | `"%.2f" % 3.14` → `'3.14'` |
| `%10s` | 宽度 | `"%10s" % "hi"` → `'        hi'` |
| `%%` | 字面量 `%` | `"100%%"` → `'100%'` |

```python
name = "Alice"
age = 20
print("My name is %s and I am %d years old." % (name, age))

# 字典风格
print("Name: %(name)s, Age: %(age)d" % {"name": "Bob", "age": 25})
```

> **不推荐用于新代码。** 请改用 f-string。

### 7.3.6 对比

| 方法 | 示例 | 适用场景 |
|--------|---------|-------------|
| f-string | `f"{name}"` | 现代 Python（3.6+），可读性最好 |
| `.format()` | `"{}".format(name)` | 兼容性需求、复杂格式化 |
| `format()` | `format(x, ".2f")` | 动态格式字符串 |
| `%` 运算符 | `"%s" % name` | 仅限旧代码（不推荐） |
