# 5 数据类型总结

## 5.1 可变类型与不可变类型

### 5.1.1 定义

**可变**（mutable）对象在创建之后可以被修改。其内部值会改变，但内存地址保持不变。

**不可变**（immutable）对象在创建之后不能被修改。任何看似修改它们的操作实际上都会创建一个具有不同内存地址的新对象。

### 5.1.2 示例

```python
# Mutable: list, dict, set
list1 = [1, 2, 3]
print(id(list1))
list1.append(4)
print(id(list1))      # Same address

dict1 = {"a": 1}
dict1["b"] = 2        # Same dict object, just updated

# Immutable: tuple, string, int
tuple1 = (1, 2, 3)
# tuple1[0] = 10      # TypeError

str1 = "hello"
# str1[0] = "H"       # TypeError

a = 1000
print(id(a))
a = 2000              # Reassignment creates a new integer object
print(id(a))          # Different address
```

### 5.1.3 同一性与相等性

```python
# Lists with same values are different objects
list1 = [1, 2, 3]
list2 = [1, 2, 3]
print(list1 is list2)   # False (different memory addresses)
print(list1 == list2)   # True (same values)

# Tuples with same values are equal, but may or may not be the same object
# This depends on the Python implementation; do not rely on it.
t1 = (1, 2, 1000)
t2 = (1, 2, 1000)
print(t1 == t2)         # True (same values)
print(t1 is t2)         # Not guaranteed; often False for larger values
```

### 5.1.4 总结

| 类型       | 示例                                                                            | 能否修改？ | 内存地址           |
| --------- | ------------------------------------------------------------------------------- | --------- | ------------------ |
| 可变      | `list`、`dict`、`set`、`bytearray`、自定义对象                                    | 能        | 保持不变           |
| 不可变    | `int`、`str`、`tuple`、`bool`、`float`、`frozenset`、`bytes`、`complex`、`None`   | 不能      | 会改变（新对象）   |


## 5.2 赋值、浅拷贝与深拷贝

浅拷贝与深拷贝适用于任何可变容器：列表、字典、集合、bytearray，以及带有可变属性的自定义对象。不可变类型（`int`、`str`、`tuple`、`frozenset`、`bytes`）不需要拷贝，因为它们不能被修改。

### 5.2.1 赋值 vs 浅拷贝 vs 深拷贝

| 操作 | 会发生什么 | 嵌套对象 | 常见方式 |
|-----------|--------------|----------------|-------------|
| `b = a` | 创建指向**同一个**对象的新引用 | 共享 | 直接赋值 |
| `b = copy.copy(a)` | 创建一个**新容器** | 共享 | `list[:]`、`list.copy()`、`dict.copy()`、`set.copy()` |
| `b = copy.deepcopy(a)` | 创建一个**新容器**，并递归拷贝所有内容 | 相互独立 | `copy.deepcopy()` |

### 5.2.2 列表示例

```python
import copy

original = [1, [2, 3]]

# Assignment: just another name for the same object
ref = original
ref[0] = 99
print(original)              # [99, [2, 3]] — affected

# Shallow copy: new list, but nested list is shared
shallow = copy.copy(original)
shallow[1][0] = 88
print(original)              # [99, [88, 3]] — nested object affected

# Deep copy: completely independent
deep = copy.deepcopy(original)
deep[1][0] = 77
print(original)              # [99, [88, 3]] — unaffected
```

### 5.2.3 字典示例

```python
import copy

original = {"a": [1, 2], "b": [3, 4]}

# Assignment
ref = original
ref["a"] = [9, 9]
print(original)  # {'a': [9, 9], 'b': [3, 4]} — affected

# Shallow copy: new dict, but nested lists are shared
shallow = original.copy()
shallow["a"][0] = 99
print(original)  # {'a': [99, 2], 'b': [3, 4]} — nested object affected

# Deep copy: completely independent
deep = copy.deepcopy(original)
deep["a"][0] = 77
print(original)  # {'a': [99, 2], 'b': [3, 4]} — unaffected
```

### 5.2.4 集合示例

集合只能包含可哈希（hashable）的元素，因此不允许嵌套对象。`.copy()` 方法执行的是浅拷贝。

```python
s1 = {1, 2, 3}
s2 = s1.copy()
s2.add(4)

print(s1)  # {1, 2, 3}
print(s2)  # {1, 2, 3, 4}
```

## 5.3 内存驻留（Interning）基础

对于较小的常用值，Python 有时会复用同一个不可变对象。这被称为**驻留**（interning）。

### 5.3.1 小整数缓存

介于 -5 到 256 之间的整数在启动时会被缓存。该范围内值相同的变量通常引用同一个对象。

```python
a = 100
b = 100
print(a is b)   # True (cached)

x = 1000
y = 1000
print(x is y)   # False (not guaranteed; may be True in some REPLs)
```

### 5.3.2 字符串驻留

某些字符串会被自动驻留，尤其是那些看起来像标识符的字符串。

```python
a = "hello"
b = "hello"
print(a is b)   # often True

x = "hello world"
y = "hello world"
print(x is y)   # usually False (not interned)
```

**重要：** 不要用 `is` 来比较值。请使用 `==`。

## 5.4 垃圾回收简介

Python 通过**引用计数**和**循环垃圾回收器**自动管理内存。

### 5.4.1 引用计数

每个对象都会记录有多少个名称或容器引用它。当计数降为零时，内存就会被释放。

```python
x = [1, 2, 3]
y = x       # reference count increases
x = None    # one reference removed
y = None    # reference count drops to 0; list is freed
```

### 5.4.2 `del` 与引用

```python
x = [1, 2, 3]
del x       # Removes the name x, not the object itself
```

### 5.4.3 循环引用

如果两个对象互相引用，它们的引用计数永远不会降到零。Python 的循环垃圾回收器会定期检测并清理这些对象。

```python
a = []
b = []
a.append(b)
b.append(a)

# Without cyclic GC, a and b would never be freed.
```

**注意：** 你几乎不需要直接与垃圾回收器打交道。只需知道：只要有东西引用某个对象，它就会一直存活。
