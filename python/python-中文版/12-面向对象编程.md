# 12 面向对象编程

面向对象编程（OOP）是一种组织代码的方式，它把相关的数据和行为组合到**类**（class）中。类是蓝图；通过它你可以创建**对象**（也称为**实例**，instance）。

OOP 的核心思想是：

- **封装（Encapsulation）：** 将数据（属性）和行为（方法）捆绑在一起，并控制对内部状态的访问。
- **继承（Inheritance）：** 基于已有类创建新类，复用并扩展其行为。
- **多态（Polymorphism）：** 通过统一的接口使用不同的对象，使同一段代码可以处理不同的类型。

Python 中使用 `class` 关键字定义类。方法是定义在类内部的函数；第一个参数通常是 `self`，它指向当前操作的实例。

## 12.1 类属性、实例属性与方法

### 12.1.1 类属性

| 特性 | 说明 |
|---------|-------------|
| 定义 | 在类的所有实例之间共享 |
| 访问方式 | `ClassName.attr` 或 `instance.attr` |
| 使用场景 | 常量或所有实例共享的数据 |

```python
class Student:
    school = "XYZ High"     # 类属性（共享）

print(Student.school)       # 通过类访问
s = Student()
print(s.school)             # 通过实例访问
```

### 12.1.2 实例属性

| 特性 | 说明 |
|---------|-------------|
| 定义 | 每个实例独有 |
| 创建位置 | 通常在 `__init__` 方法中 |
| 访问方式 | `instance.attr` |

```python
class Student:
    def __init__(self, name, age):
        self.name = name    # 实例属性
        self.age = age      # 实例属性

s1 = Student("Alice", 20)
s2 = Student("Bob", 21)     # 各自拥有独立的 name/age
```

### 12.1.3 实例方法

| 特性 | 说明 |
|---------|-------------|
| 第一个参数 | `self`（实例引用） |
| 访问能力 | 可以访问实例属性和类属性 |
| 调用方式 | `instance.method()` |

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def get_grade(self):        # 实例方法
        if self.score >= 90:
            return "A"
        return "B"

s = Student("Alice", 95)
print(s.get_grade())            # "A"
```

### 12.1.4 小结：类成员与实例成员对比

| 方面 | 类属性 | 实例属性 | 实例方法 |
|--------|-----------------|--------------------|-----------------|
| 定义位置 | 直接写在类体中 | 通常在 `__init__` 中通过 `self` 定义 | 在类体中定义，第一个参数为 `self` |
| 是否共享？ | ✅ 所有实例共享 | ❌ 每个实例独有 | ❌ 绑定到各个实例 |
| 访问方式 | `ClassName.attr` 或 `instance.attr` | `instance.attr` | `instance.method()` |
| 典型用途 | 常量、计数器、共享配置 | 对象特有的数据（姓名、年龄、分数） | 使用实例数据的对象行为 |
| 示例 | `school = "XYZ High"` | `self.name = name` | `def get_grade(self): ...` |

### 12.1.5 `__slots__`

限制允许使用的属性，以节省内存并防止拼写错误。

```python
class Point:
    __slots__ = ["x", "y"]

    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(1, 2)
# p.z = 3             # AttributeError: 'Point' object has no attribute 'z'
```

**权衡：** `__slots__` 会移除 `__dict__`，从而节省内存，但也因此无法动态添加属性。

## 12.2 类方法与静态方法

### 12.2.1 类方法

| 特性 | 说明 |
|---------|-------------|
| 装饰器 | `@classmethod` |
| 第一个参数 | `cls`（类引用） |
| 使用场景 | 工厂方法、替代构造器 |

```python
class Student:
    count = 0

    def __init__(self, name):
        self.name = name
        self.__class__.count += 1    # 通过实例修改类属性

    @classmethod
    def get_count(cls):         # 类方法
        return cls.count

print(Student.get_count())      # 0
s1 = Student("Alice")
s2 = Student("Bob")
print(Student.get_count())      # 2 — 每次 __init__ 都让计数器加一
```

**局限性：** 类方法只能访问**类属性**、调用其他**类方法**。它们**不能**访问实例属性或调用实例方法——因为没有可用的 `self`。

```python
class Demo:
    class_attr = "shared"

    def __init__(self):
        self.instance_attr = "mine"

    @classmethod
    def class_method(cls):
        print(cls.class_attr)       # ✅ 正确 — 类属性
        # print(self.instance_attr) # ❌ Error — no self in class method
```

### 12.2.2 静态方法

| 特性 | 说明 |
|---------|-------------|
| 装饰器 | `@staticmethod` |
| 无隐式参数 | 没有 `self` 或 `cls` |
| 使用场景 | 与类相关的工具函数 |

```python
class MathUtils:
    @staticmethod
    def add(a, b):              # 静态方法
        return a + b

print(MathUtils.add(3, 5))      # 8 (无需实例)
```

**关键理解：** 静态方法本质上只是一个恰好放在类命名空间里的普通函数。它无法访问 `self`（实例）或 `cls`（类）。当逻辑在概念上与类相关、但不需要任何类数据或实例数据时，就使用静态方法。

### 12.2.3 实例方法、类方法与静态方法对比

| 方面 | 实例方法 | 类方法 | 静态方法 |
|--------|----------------|--------------|---------------|
| 装饰器 | 无 | `@classmethod` | `@staticmethod` |
| 第一个参数 | `self`（实例） | `cls`（类） | 无 |
| 能访问实例属性？ | ✅ 能 | ❌ 不能 | ❌ 不能 |
| 能访问类属性？ | ✅ 能 | ✅ 能 | ❌ 不能 |
| 能调用实例方法？ | ✅ 能 | ❌ 不能 | ❌ 不能 |
| 能调用类方法？ | ✅ 能 | ✅ 能 | ❌ 不能 |
| 典型用途 | 对象行为 | 工厂方法 / 计数器 | 工具函数 |

## 12.3 继承与 `super()`

### 12.3.1 基本继承

继承让一个类获得另一个类的属性和方法。

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        raise NotImplementedError("Subclass must implement")

class Dog(Animal):              # Dog 继承自 Animal
    def speak(self):
        return f"{self.name} says woof!"

class Cat(Animal):
    def speak(self):
        return f"{self.name} says meow!"

d = Dog("Buddy")
print(d.speak())                # Buddy says woof!
```

抛出 `NotImplementedError` 只会在**调用时**失败。如需更严格、更正式地强制子类实现某个方法——在**实例化时**就失败——请参见 [12.9 抽象基类](#129-抽象基类)。

### 12.3.2 `super()`

调用父类的方法。

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

class Student(Person):
    def __init__(self, name, age, student_id):
        super().__init__(name, age)     # 调用父类的 __init__
        self.student_id = student_id

s = Student("Alice", 20, "S001")
print(s.name)                       # Alice (来自 Person)
```

### 12.3.3 配合 `super()` 重写方法

当子类重新定义父类的方法时，`super()` 让你可以先复用父类的实现，再添加自定义行为。

```python
class Chef:
    def cook(self):
        print("Heat pan")
        print("Add ingredients")
        print("Simmer")

class SichuanChef(Chef):
    def cook(self):
        super().cook()              # 复用父类的步骤
        print("Add chili oil")      # 添加自定义步骤
        print("Plate")

s = SichuanChef()
s.cook()
# Heat pan
# Add ingredients
# Simmer
# Add chili oil
# Plate
```

**经验法则：** 想要*扩展*父类行为时，调用 `super().method()`；想要*完全替换*父类行为时，则不调用它。

**完全替换的示例：**

```python
class Chef:
    def cook(self):
        print("Heat pan")
        print("Add ingredients")
        print("Simmer")

class MicrowaveChef(Chef):
    def cook(self):
        # 不调用 super().cook() — 完全替换整个流程
        print("Pierce film lid")
        print("Microwave on high for 3 minutes")
        print("Let stand for 1 minute")

m = MicrowaveChef()
m.cook()
# Pierce film lid
# Microwave on high for 3 minutes
# Let stand for 1 minute
```

## 12.4 特殊方法（魔法方法）

| 方法 | 用途 | 触发方式 |
|--------|---------|--------------|
| `__init__` | 构造器 | `Class()` |
| `__str__` | 字符串表示 | `str()`、`print()` |
| `__repr__` | 官方表示 | `repr()` |
| `__eq__` | 相等比较 | `==` |
| `__lt__` | 小于比较 | `<` |
| `__len__` | 长度 | `len()` |
| `__getitem__` | 索引访问 | `obj[key]` |

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):          # 用于友好的输出
        return f"Vector({self.x}, {self.y})"

    def __eq__(self, other):    # 用于 == 比较
        return self.x == other.x and self.y == other.y

v = Vector(1, 2)
print(v)                        # Vector(1, 2)
```

### 12.4.1 `__repr__` 与 `__str__` 的区别

| 方法 | 用途 | 调用者 | 回退方案 |
|--------|---------|-----------|----------|
| `__str__` | 面向用户、非正式 | `str()`、`print()` | `__repr__` |
| `__repr__` | 无歧义、面向开发者 | `repr()`、交互式解释器 | 默认的对象地址 |

**最佳实践：** `__repr__` 理想情况下应返回一段有效的 Python 代码，可以据此重建该对象。

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        return f"Point({self.x}, {self.y})"

    def __str__(self):
        return f"({self.x}, {self.y})"

p = Point(1, 2)
print(p)           # (1, 2)     — __str__
print(repr(p))     # Point(1, 2) — __repr__
```

### 12.4.2 比较方法

实现富比较运算符（`__eq__`、`__lt__`、`__le__`、`__gt__`、`__ge__`）。

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __eq__(self, other):
        if not isinstance(other, Point):
            return NotImplemented
        return self.x == other.x and self.y == other.y

    def __lt__(self, other):
        if not isinstance(other, Point):
            return NotImplemented
        return (self.x, self.y) < (other.x, other.y)

p1 = Point(1, 2)
p2 = Point(1, 2)
p3 = Point(3, 4)

print(p1 == p2)   # True
print(p1 < p3)    # True
# print(p1 >= p3)   # ❌ TypeError — __ge__ not defined
```

**陷阱：`__eq__` 会禁用 `__hash__`。** 一旦你定义了 `__eq__`，Python 会把 `__hash__` 设为 `None`，使实例变为不可哈希——它们不能再放入 `set`，也不能用作 `dict` 的键：

```python
p = Point(1, 2)
# {p}                 # ❌ TypeError: unhashable type: 'Point'
```

有两种解决办法：

- 如果实例是不可变的且应当可哈希，就显式定义 `__hash__`，例如 `return hash((self.x, self.y))`。
- 如果实例是可变的，保持其不可哈希通常才是正确的设计——把可变对象用作键是滋生 bug 的温床。

**自动生成其余方法：** 如果你只定义了 `__eq__` 和另一个比较运算符，可以使用 `@functools.total_ordering` 自动生成其余的比较方法。

详情请参见 [17.6 `@functools.total_ordering`](17-functools.md#176-使用-functoolstotal_ordering-自动生成比较方法)。

### 12.4.3 可调用对象

通过定义 `__call__`，可以让实例像函数一样被调用。

```python
class Multiplier:
    def __init__(self, factor):
        self.factor = factor

    def __call__(self, value):
        return value * self.factor

triple = Multiplier(3)
print(triple(5))   # 15
```

**常见使用场景：**
- **有状态的函数：** 可调用对象可以在多次调用之间记住状态，而不借助闭包的普通 `def` 函数做不到这一点。
- **自定义函数对象：** 包装行为，使对象本身可以传给任何期望函数的地方（例如回调、事件处理器）。
- **计数器 / 日志器：** 跟踪某物被调用了多少次。

```python
class Counter:
    def __init__(self):
        self.count = 0

    def __call__(self):
        self.count += 1
        return self.count

c = Counter()
print(c())   # 1
print(c())   # 2
print(c())   # 3
```

### 12.4.4 算术运算符重载

通过实现相应的特殊方法，可以让对象支持 `+`、`-`、`*`、`/` 等运算符。

| 运算符 | 特殊方法 |
|----------|----------------|
| `+` | `__add__` |
| `-` | `__sub__` |
| `*` | `__mul__` |
| `/` | `__truediv__` |
| `//` | `__floordiv__` |
| `%` | `__mod__` |
| `**` | `__pow__` |

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, other):
        if not isinstance(other, Vector):
            return NotImplemented
        return Vector(self.x + other.x, self.y + other.y)

    def __sub__(self, other):
        if not isinstance(other, Vector):
            return NotImplemented
        return Vector(self.x - other.x, self.y - other.y)

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

v1 = Vector(1, 2)
v2 = Vector(3, 4)
print(v1 + v2)   # Vector(4, 6)
print(v1 - v2)   # Vector(-2, -2)
```

**返回 `NotImplemented`：** 当另一个操作数不受支持时，返回 `NotImplemented`，这样 Python 可以尝试反向运算，或抛出正确的 `TypeError`。

### 12.4.5 容器协议

实现容器协议，可以让你自己的对象表现得像列表、字典或集合。

| 特殊方法 | 触发方式 | 用途 |
|----------------|--------------|---------|
| `__len__` | `len(obj)` | 返回元素个数 |
| `__getitem__` | `obj[key]` | 按索引或键获取元素 |
| `__setitem__` | `obj[key] = value` | 按索引或键设置元素 |
| `__delitem__` | `del obj[key]` | 删除元素 |
| `__iter__` | `for x in obj` | 返回一个迭代器 |
| `__contains__` | `item in obj` | 成员测试 |

```python
class Deck:
    def __init__(self):
        self._cards = ["A", "2", "3", "4", "5"]

    def __len__(self):
        return len(self._cards)

    def __getitem__(self, index):
        return self._cards[index]

    def __iter__(self):
        return iter(self._cards)

deck = Deck()
print(len(deck))       # 5
print(deck[0])         # A
print("3" in deck)     # True
for card in deck:
    print(card)
# A 2 3 4 5
```

**注意：** 如果类没有定义 `__contains__`，`in` 运算符会回退为通过 `__iter__` 进行迭代并逐项比较。这就是为什么上面的 `Deck` 从未定义 `__contains__`，`"3" in deck` 仍然有效。只有当你需要更快或自定义的成员测试时，才显式定义 `__contains__`。

**厌倦了手写特殊方法的样板代码？** 对于主要用于存储数据的类，`@dataclass` 可以自动生成 `__init__`、`__repr__`、`__eq__` 等方法——参见 [13.5.4 `@dataclass`](13-闭包与装饰器.md#1354-dataclass)。

## 12.5 封装

Python 使用命名约定来表示预期的可见性。

| 约定 | 含义 | 访问范围 |
|------------|---------|--------|
| `name` | 公开 | 任何地方 |
| `_name` | 受保护 | 内部使用；可以访问但不建议 |
| `__name` | 私有 | 名称改写为：`_ClassName__name` |

```python
class BankAccount:
    def __init__(self, balance):
        self._balance = balance         # 受保护
        self.__pin = "1234"             # 私有（名称改写）

    def get_balance(self):
        return self._balance

acct = BankAccount(1000)
print(acct._balance)                # 能用但不推荐
# print(acct.__pin)                 # AttributeError
print(acct._BankAccount__pin)       # 技术上仍可访问（名称改写）
```

**Python 的哲学：约定优于强制。**

与 Java 或 C++ 不同，Python 无法真正隐藏属性。`_name` 和 `__name` 都仍然可以被访问：
- `_name` 只是一种**君子协定**——解释器不会做任何阻止访问的事
- `__name` 使用**名称改写**（name mangling，`_ClassName__name`），让意外访问变得更困难，但有心的开发者仍然可以访问到它

这有时被形容为"防君子不防小人"。其目的是向其他程序员传达意图，而不是强制安全。如果你需要真正的访问控制，请使用 property 的 getter/setter，或者认真设计你的 API。

## 12.6 property 装饰器

把一个方法暴露为属性。

```python
class Circle:
    def __init__(self, radius):
        self._radius = radius

    @property
    def radius(self):
        return self._radius

    @radius.setter
    def radius(self, value):
        if value < 0:
            raise ValueError("Radius cannot be negative")
        self._radius = value

    @property
    def area(self):
        return 3.14159 * self._radius ** 2

c = Circle(5)
print(c.radius)         # 5 (看起来像普通属性)
c.radius = 10           # 使用 setter
print(c.area)           # 314.159
```

**只读 property 示例：**

没有 setter 的 property 是只读的。这对于依赖其他属性的计算值很有用。

```python
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height

    @property
    def area(self):
        return self.width * self.height

r = Rectangle(4, 5)
print(r.area)   # 20

# r.area = 100  # AttributeError: can't set attribute
```

**重要：** `@<name>.setter` 要求先定义一个与之匹配的 `@property` getter。关于原因和具体的报错示例，参见 [13.5.1.5 为什么 setter 需要先定义 getter](13-闭包与装饰器.md#13515-为什么-setter-需要先定义-getter)。

**最佳实践：** `@property` getter 和 `@<name>.setter` 使用相同的方法名，这样 property 的行为就像一个真正的属性。

## 12.7 鸭子类型与多态

Python 使用**鸭子类型**（duck typing）：一个对象是否适用，取决于它是否具有所需的方法/属性，而不是取决于它的类型。

```python
class Dog:
    def speak(self):
        return "Woof!"

class Cat:
    def speak(self):
        return "Meow!"

def animal_sound(animal):
    # 无需类型检查 — 任何有 .speak() 的对象都可以
    print(animal.speak())

animal_sound(Dog())   # Woof!
animal_sound(Cat())   # Meow!
```

### 12.7.1 类型内省

| 函数 | 用途 |
|----------|---------|
| `isinstance(obj, type)` | 检查对象是否是某个类型的实例（支持继承） |
| `issubclass(cls, type)` | 检查一个类是否是另一个类的子类 |
| `type(obj)` | 返回对象的确切类型 |

```python
d = Dog()
isinstance(d, Dog)      # True
isinstance(d, object)   # True (Dog 继承自 object)
issubclass(Dog, object) # True
```

**继承链示例：**

```python
class Animal:
    pass

class Mammal(Animal):
    pass

class Dog(Mammal):
    pass

dog = Dog()

# isinstance 检查整条继承链
isinstance(dog, Dog)      # True  — 精确匹配
isinstance(dog, Mammal)   # True  — 父类
isinstance(dog, Animal)   # True  — 祖父类
isinstance(dog, object)   # True  — 所有类都继承自 object

# type() 只检查精确类型
type(dog) is Dog          # True
type(dog) is Mammal       # False  ← type() 不检查继承
```

**关键区别：**
- `isinstance(obj, Class)` → 检查整个继承链（通常更推荐）
- `type(obj) is Class` → 只检查确切类型（忽略继承）

## 12.8 多重继承与 MRO

一个类可以继承自多个父类。Python 使用**方法解析顺序（Method Resolution Order，C3 线性化算法）**来确定实际运行哪个方法。

```python
class Flyer:
    def move(self):
        print("Flying")

class Swimmer:
    def move(self):
        print("Swimming")

class Duck(Flyer, Swimmer):
    pass

d = Duck()
d.move()            # Flying — Flyer 在 MRO 中靠前
print(Duck.__mro__) # (<class 'Duck'>, <class 'Flyer'>, <class 'Swimmer'>, <class 'object'>)
```

**`super()` 遵循的是 MRO，而不是"父类"。** 在单继承中两者是一致的，但在多重继承中，`super()` 会委托给 *MRO 链中的下一个类*。这正是 mixin 能够协同工作的原因：链上的每个类都可以调用 `super()` 把工作传递下去，从而保证每个类的方法恰好运行一次。12.8.2 中的 mixin 示例就依赖这一点——`Employee` 中的 `super().__init__(name, age)` 通过 MRO 到达 `Person.__init__`。

### 12.8.1 用 `__bases__` 和 `__base__` 查看继承关系

Python 在类上提供了用于内省继承关系的特殊属性：

| 属性 | 返回值 | 使用场景 |
|-----------|---------|----------|
| `Class.__bases__` | 所有直接父类组成的元组 | 查看所有直接父类 |
| `Class.__base__` | 第一个（最左边的）直接父类 | 快速查看主要父类 |

```python
class Animal:
    pass

class Mammal(Animal):
    pass

class Dog(Mammal):
    pass

# __base__ — 第一个（最左）直接父类
print(Dog.__base__)      # <class '__main__.Mammal'>

# __bases__ — 所有直接父类的元组
print(Dog.__bases__)     # (<class '__main__.Mammal'>,)

# 多继承
class CanFly:
    pass

class FlyingDog(Dog, CanFly):
    pass

print(FlyingDog.__base__)   # <class '__main__.Dog'> (第一个父类)
print(FlyingDog.__bases__)  # (<class '__main__.Dog'>, <class '__main__.CanFly'>)
```

**注意：** `__base__` 只显示*第一个*父类。要查看完整的继承层次，请使用 `__mro__` 或 `__bases__`。

### 12.8.2 Mixin

**mixin** 是一种小型的类，专门用来为其他类添加某种特定行为。它不应该被单独实例化，通常也不会作为主要父类出现。

```python
class JSONSerializableMixin:
    def to_json(self):
        import json
        return json.dumps(self.__dict__)

class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

class Employee(Person, JSONSerializableMixin):
    def __init__(self, name, age, role):
        super().__init__(name, age)
        self.role = role

e = Employee("Alice", 30, "Engineer")
print(e.to_json())   # {"name": "Alice", "age": 30, "role": "Engineer"}
```

**Mixin 命名约定：** 许多 Python mixin 使用 `Mixin` 后缀，以表明它们提供的是一种可复用的行为，而不是一个现实世界中的概念。

## 12.9 抽象基类

抽象基类（ABC）让你可以定义一个子类必须实现的公共接口。继承自 ABC 的类必须重写每一个抽象方法，否则它无法被实例化。

### 12.9.1 定义抽象类

使用 `ABC` 作为基类，并用 `@abstractmethod` 标记方法。

```python
from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self):
        pass

    @abstractmethod
    def perimeter(self):
        pass
```

### 12.9.2 具体子类

具体子类必须实现从 ABC 继承来的每一个抽象方法。

```python
class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

    def perimeter(self):
        return 2 * (self.width + self.height)

r = Rectangle(3, 4)
print(r.area())        # 12
print(r.perimeter())   # 14
```

如果子类遗漏了某个抽象方法，实例化时会抛出错误：

```python
class BadRectangle(Shape):
    pass

# b = BadRectangle()   # TypeError: Can't instantiate abstract class
```

### 12.9.3 何时使用 ABC

在以下情况下使用抽象基类：

- 你想在多个子类之间强制推行统一的接口。
- 你在设计插件系统或框架，要求用户必须实现特定的钩子（hook）。
- 你想明确地记录一个类层次结构中必须实现的方法。

### 12.9.4 抽象 property

你也可以通过堆叠 `@property` 和 `@abstractmethod` 把 property 标记为抽象的。这样子类就必须提供该 property 自己的实现。

```python
from abc import ABC, abstractmethod

class Vehicle(ABC):
    @property
    @abstractmethod
    def wheels(self):
        pass

class Bicycle(Vehicle):
    @property
    def wheels(self):
        return 2

class Car(Vehicle):
    @property
    def wheels(self):
        return 4

print(Bicycle().wheels)   # 2
print(Car().wheels)       # 4
```

关于为什么 `@property` 必须写在 `@abstractmethod` 上面，以及颠倒顺序会发生什么，参见 [13.4.1 装饰器叠加](13-闭包与装饰器.md#1341-装饰器叠加)。

## 12.10 组合与继承

继承适用于"是一个"（is-a）的关系：`Dog` *是一个* `Animal`。组合更适合"有一个"（has-a）的关系：`Car` *有一个* `Engine`。

在组合中，一个对象把其他对象作为自己的属性，并将工作委托给它们。与深层的继承层次相比，这通常能产生更灵活的代码。

**继承方式：**

```python
class ElectricVehicle:
    def move(self):
        print("Moving on electric power")

class ElectricCar(ElectricVehicle):
    pass
```

**组合方式：**

```python
class ElectricEngine:
    def move(self):
        print("Moving on electric power")

class Car:
    def __init__(self):
        self.engine = ElectricEngine()

    def move(self):
        self.engine.move()

c = Car()
c.move()   # Moving on electric power
```

**何时优先选择组合：**

- 关系是"有一个"而不是"是一个"。
- 你希望通过更换组件在运行时改变行为。
- 你希望避免脆弱的基类和紧耦合。

**何时使用继承：**

- 关系确实是"是一个"。
- 子类需要复用并特化父类的大部分行为。
- 继承层次浅且稳定。

一个常见的指导原则：拿不准时，**优先使用组合而非继承**。

## 12.11 速查表

**类成员与实例成员**

| 方面 | 类属性 | 实例属性 | 实例方法 |
|--------|-----------------|--------------------|-----------------|
| 定义位置 | 类体中 | `__init__` 中通过 `self` | 类体中，第一个参数为 `self` |
| 是否共享？ | 所有实例共享 | 每个实例独有 | 绑定到各个实例 |
| 访问方式 | `Class.attr` 或 `obj.attr` | `obj.attr` | `obj.method()` |

**三种方法**

| 种类 | 装饰器 | 第一个参数 | 可访问内容 |
|------|-----------|-------------|----------|
| 实例方法 | — | `self` | 实例属性 + 类属性 |
| 类方法 | `@classmethod` | `cls` | 仅类属性 |
| 静态方法 | `@staticmethod` | — | 都不可（工具函数） |

**常用特殊方法**

| 方法 | 触发方式 | 方法 | 触发方式 |
|--------|--------------|--------|--------------|
| `__init__` | `Class(...)` | `__len__` | `len(obj)` |
| `__str__` | `print()`、`str()` | `__getitem__` | `obj[key]` |
| `__repr__` | `repr()`、交互式解释器 | `__iter__` | `for x in obj` |
| `__eq__` | `==` | `__contains__` | `x in obj` |
| `__lt__` | `<`（其余的用 `@total_ordering` 生成） | `__call__` | `obj(...)` |
| `__add__` 等 | `+`、`-`、`*`、`/`、... | | |

**可见性约定**

| 名称 | 含义 |
|------|---------|
| `name` | 公开 |
| `_name` | 内部使用（仅为约定） |
| `__name` | 名称改写为 `_ClassName__name` |
| `@property` | 把方法暴露为属性；添加 `@x.setter` 以支持写入 |

**黄金法则**

- 调用 `super().method()` 来*扩展*父类行为；不调用则*替换*父类行为。在多重继承中，`super()` 遵循 MRO。
- 定义 `__eq__` 会禁用 `__hash__`——要么同时定义 `__hash__`，要么有意保持类不可哈希。
- 在不支持的比较和运算中返回 `NotImplemented`（而不是抛出异常）。
- 使用 ABC（`class Shape(ABC)` + `@abstractmethod`）强制子类实现接口。
- 拿不准时，优先使用组合（"有一个"）而非继承（"是一个"）。
- 纯数据类：使用 `@dataclass`，而不是手写特殊方法。
