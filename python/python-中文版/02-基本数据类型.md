# 2 基本数据类型

## 2.1 整数类型

Python 整数具有无限精度，不会发生溢出。

### 2.1.1 进制

| 前缀 | 进制 | 有效数字 | 示例 | 值 | 为什么重要 |
|--------|------|-------------|---------|-------|----------------|
| `0b` | 2 | `0-1` | `0b1010` | `10` | 位运算、标志位掩码 |
| `0o` | 8 | `0-7` | `0o755` | `493` | Unix 文件权限 |
| `0x` | 16 | `0-9`、`a-f`/`A-F` | `0xFF` | `255` | 颜色、内存地址、字节 |

**转换为字符串（带前缀）：**

```python
bin(10)    # '0b1010'
oct(493)   # '0o755'
hex(255)   # '0xff'   ← always lowercase
```

**从字符串转换为整数：**

```python
int('1010', 2)       # 10
int('0o755', 8)      # 493
int('0xff', 16)      # 255
int('FF', 16)        # 255  (prefix optional)

hex(255)[2:].upper() # 'FF'
```

### 2.1.2 常见陷阱

- `hex()` 总是返回小写字母，且不会补零。
- `int(x, base)` 期望的是一个**字符串**。`int(0xff, 16)` 会抛出 `TypeError`，因为 `0xff` 已经是一个 `int`。
- 不带前缀的字符串必须显式传入 `base`；否则会按十进制解析：
  ```python
  int('10', 2)   # 2
  int('10')      # 10
  ```

### 2.1.3 格式化输出

```python
x = 5

bin(x)[2:]       # '101'          (strip prefix)
f'{x:08b}'       # '00000101'     (8-bit binary)
f'{x:02x}'       # '05'           (2-digit hex, lowercase)
f'{255:02X}'     # 'FF'           (2-digit hex, uppercase)
```

### 2.1.4 下划线分隔符

可以使用下划线分隔符 `_` 提高可读性（Python 3.6+）。

```python
million = 1_000_000  # Same as 1000000
```


## 2.2 浮点数类型

### 2.2.1 科学计数法

浮点数可以用科学计数法表示非常大或非常小的数。指数标记 `e` 或 `E` 不区分大小写。

```python
x = 9.9e2      # 9.9 × 10² = 990.0
y = 3.14E-2    # 3.14 × 10⁻² = 0.0314
```

### 2.2.2 特殊值

浮点数支持无穷大（infinity）和非数（not-a-number）。

```python
import math

positive_inf = float('inf')
negative_inf = float('-inf')
not_a_number = float('nan')

math.isinf(float('inf'))   # True
math.isnan(float('nan'))   # True
```

### 2.2.3 精度陷阱

由于二进制表示的局限，浮点运算可能产生意想不到的结果。

```python
0.1 + 0.2 == 0.3    # False (0.30000000000000004)
```

**`round()` 使用银行家舍入法**（round half to even，向偶数舍入）：当一个数恰好位于两个整数的正中间时，会向最近的偶数舍入。这可以避免大数据集中的偏差，并符合 IEEE 754 浮点数标准。

```python
round(2.5)   # 2  (nearest even integer)
round(3.5)   # 4  (nearest even integer)
```

**注意：** 浮点数以二进制存储，所以像 `2.05` 这样的值并不恰好等于 `2.05`。这可能导致 `round(2.05, 1)` 返回 `2.0` 而不是 `2.1`。

如需精确的十进制运算，请使用 `decimal.Decimal`：

```python
from decimal import Decimal

Decimal('0.1') + Decimal('0.2') == Decimal('0.3')  # True
```

### 2.2.4 `float` 与 `int` 之间的转换

`int()` 将浮点数向零截断（而不是四舍五入）。`float()` 通过添加 `.0` 将整数转换为浮点数。

```python
print(int(3.14))    # 3
print(int(-3.14))   # -3 (truncates toward zero)
print(int(3.99))    # 3

print(float(5))     # 5.0
print(float(0))     # 0.0
```

**注意：** 如果需要四舍五入到最接近的整数而不是截断，请使用 `round()`。

```python
print(round(3.6))   # 4
print(round(2.5))   # 2 (banker's rounding)
```

## 2.3 字符串类型

字符串是不可变的字符序列。单引号 `' '` 和双引号 `" "` 可以互换使用。

### 2.3.1 转义序列

| 序列 | 含义 |
|----------|---------|
| `\n` | 换行 |
| `\t` | 制表符 |
| `\\` | 反斜杠 |
| `\'` | 单引号 |
| `\"` | 双引号 |

```python
print("Line 1\nLine 2")   # Two lines
print("Tab\there")        # Tab separation
```

### 2.3.2 原始字符串

在字符串前加上 `r` 前缀即可创建原始字符串（raw string）。反斜杠会被视为字面字符，这在处理 Windows 文件路径和正则表达式时非常有用。

```python
# Without raw string
path = "C:\\Users\\EDY\\Desktop\\demo.py"

# With raw string
path = r"C:\Users\EDY\Desktop\demo.py"
```

### 2.3.3 多行字符串

三引号 `'''` 或 `"""` 会保留换行和格式。它们通常用于文档字符串（docstring）和长文本块。

```python
text = """This is a
multi-line string
that spans several lines"""
```

### 2.3.4 字符串运算

```python
# Concatenation
full = "Hello" + " " + "World"   # 'Hello World'

# Repetition
line = "-" * 20                   # '--------------------'

# Length
count = len("hello")              # 5

# Membership
found = "he" in "hello"           # True
```

### 2.3.5 字符串表示：`str()` 与 `repr()`

这两个函数都会返回对象的字符串版本，但它们面向的受众不同。

| 函数 | 用途 | 适用场景 |
|----------|---------|----------|
| `str()` | 人类可读的表示形式 | 向用户展示输出 |
| `repr()` | 无歧义、面向开发者的表示形式 | 调试和日志记录 |

`repr()` 会显式显示转义字符和引号，使换行符等隐藏字符可见：

```python
text = "Line 1\nLine 2"

print(str(text))
# Line 1
# Line 2

print(repr(text))
# 'Line 1\nLine 2'
```

**提示：** 当你想精确查看字符串的内容（包括空白字符和特殊字符）时，请使用 `repr()`。

### 2.3.6 不可变性

字符串不能被原地修改。任何看似修改字符串的操作实际上都会创建一个新字符串。

```python
s = "hello"
# s[0] = "H"     # TypeError: 'str' object does not support item assignment

s = "H" + s[1:]   # Creates a new string: 'Hello'
```

关于字符串的更多细节（索引、切片、方法和比较），请参阅 [3.1 字符串](03-序列类型.md#31-字符串)。


## 2.4 布尔类型

### 2.4.1 布尔值

布尔类型只有两个值：`True` 和 `False`。大小写很重要，`true` 和 `false` 是无效的。布尔值是比较运算和逻辑运算的结果。

```python
flag = True
result = 5 > 3   # True
```

### 2.4.2 真值与假值（Truthy 和 Falsy）

在布尔上下文中，以下值会被判定为 `False`，其余所有值都会被判定为 `True`。

| 值 | 类型 |
|-------|------|
| `0` | 整数零 |
| `0.0` | 浮点数零 |
| `""` | 空字符串 |
| `[]` | 空列表 |
| `{}` | 空字典 |
| `()` | 空元组 |
| `None` | NoneType |
| `set()` | 空集合 |

### 2.4.3 `bool()` 构造函数

将任意值显式转换为布尔值。

```python
bool(0)         # False
bool(1)         # True
bool("")        # False
bool("hello")   # True
bool([])        # False
bool([1, 2])    # True
```


## 2.5 None 类型

### 2.5.1 None 值

`None` 表示值的缺失，类似于其他语言中的 `null`。没有显式 `return` 语句的函数会返回 `None`。

```python
def do_nothing():
    pass

result = do_nothing()  # result is None
```

### 2.5.2 使用 `is` 进行比较

与 `None` 比较时应始终使用 `is` 或 `is not`。使用 `==` 虽然可行，但不符合惯例。

```python
value = None

# Correct
if value is None:
    pass

# Incorrect (not Pythonic)
if value == None:
    pass
```


## 2.6 类型转换

### 2.6.1 转换函数

| 函数 | 转换为 | 失败情形 |
|----------|-------------|--------------|
| `int(x)` | 整数 | 无法解析时抛出 `ValueError` |
| `float(x)` | 浮点数 | 无法解析时抛出 `ValueError` |
| `complex(x)` | 复数 | 无法解析时抛出 `ValueError` |
| `str(x)` | 字符串 | 极少失败 |
| `bool(x)` | 布尔值 | 永不失败（依据真值判定） |
| `list(x)` | 列表 | 不可迭代时抛出 `TypeError` |
| `tuple(x)` | 元组 | 不可迭代时抛出 `TypeError` |

### 2.6.2 转换示例

```python
int("42")       # 42
int(3.14)       # 3 (truncates toward zero)
int("abc")      # ValueError

float("3.14")   # 3.14
complex("3+4j") # (3+4j)

str(100)        # "100"
bool(0)         # False
bool("hello")   # True

# Common pattern: convert user input
age = int(input("Enter age: "))
```

### 2.6.3 处理转换错误

转换前务必校验用户输入。使用 `try/except` 优雅地处理无效数据。

```python
user_input = input("Enter a number: ")

try:
    value = int(user_input)
    print(f"Converted: {value}")
except ValueError:
    print(f"'{user_input}' is not a valid integer")
```

## 2.7 数值比较

### 2.7.1 数值比较

数字按其数值进行比较。整数和浮点数可以直接比较。

```python
print(3 < 5.5)   # True
print(2 == 2.0)  # True
```

### 2.7.2 混合类型限制

- 不能直接比较数字与字符串
- `max(1, "a")` 会抛出 `TypeError`

### 2.7.3 链式比较

Python 支持类似数学记法的链式比较。`a < b < c` 等价于 `a < b and b < c`。

```python
print(1 < 2 < 3)   # True  (1 < 2 and 2 < 3)
print(1 < 5 < 2)   # False (5 < 2 is False)
print(1 < 3 > 2)   # True  (1 < 3 and 3 > 2)
```

**注意：** 中间的值只会被求值一次，因此链式比较比写两个单独的比较略微高效一些。
