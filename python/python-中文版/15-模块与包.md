# 15 模块与包

**模块**（module）是一个包含 Python 代码（变量、函数、类）的单个 `.py` 文件。**包**（package）是一个把相关模块组织在一起的目录，通常带有一个 `__init__.py` 文件。模块与包让你能够把代码组织成可复用、易管理的部分。

## 15.1 导入模块

### 15.1.1 基本导入

使用 `import` 加载整个模块，使用 `from ... import` 加载指定的名称。

```python
import math
print(math.sqrt(16))      # 4.0

from math import sqrt, pi
print(sqrt(16))           # 4.0
print(pi)                 # 3.14159...

# Alias
import numpy as np
from datetime import datetime as dt
```

### 15.1.2 导入规则

| 语法 | 效果 | 建议 |
|--------|--------|----------------|
| `import module` | 导入整个模块 | 推荐 —— 避免命名冲突 |
| `from module import name` | 导入指定名称 | 适用于少数广为人知的名称 |
| `from module import *` | 导入所有公开名称 | **避免** —— 会污染命名空间 |

```python
# Preferred
import os
import json

# OK for specific, well-known names
from pathlib import Path
from typing import Optional

# Avoid
from math import *   # sqrt, pi, sin, cos... all dumped into global namespace
```

## 15.2 包

### 15.2.1 什么是包？

**包**是一个捆绑相关模块的目录，通常包含一个 `__init__.py` 文件（往往为空），以便 Python 将其识别为包而不是普通目录。可以把包看作一个命名空间：`graphics.shapes` 将与图形相关的代码组织在 `graphics` 包之下，使名称井然有序并避免冲突。

### 15.2.2 包结构

```text
my_project/
    main.py
    graphics/
        __init__.py
        shapes.py
        colors.py
```

- `graphics/` 是一个包。
- `__init__.py` 告诉 Python 这是一个包。
- `shapes.py` 和 `colors.py` 是子模块。

**提示：** 从 Python 3.3 起，`__init__.py` 可以省略（称为命名空间包，namespace package），但显式写出 `__init__.py` 仍是推荐做法。

### 15.2.3 从包中导入

使用点号表示法访问子模块。

```python
# Import a submodule
import graphics.shapes
graphics.shapes.draw_circle()

# Import a specific name from a submodule
from graphics.shapes import draw_circle
draw_circle()

# Import a submodule with an alias
from graphics import shapes as gshapes
gshapes.draw_circle()
```

### 15.2.4 相对导入

在包内部，可以使用相对点号导入同级模块。一个点表示当前包，两个点表示父包。

```python
# graphics/colors.py wants shapes.py from the same package
from . import shapes

# graphics/colors.py wants something from the parent package
from .. import config
```

**注意：** 相对导入只有在模块作为包被导入时才有效，直接运行单个模块时无效。

### 15.2.5 用 `__all__` 控制 `from package import *`

对于模块，如果没有 `__all__`，`from module import *` 会导入所有不以下划线开头的名称。但对于包，`from package import *` 只会导入 `__init__.py` 中已经绑定的名称，并不会自动导入子模块——这正是需要在 `__init__.py` 中用 `__all__` 显式定义公开 API 的原因。

```python
# graphics/__init__.py
__all__ = ["shapes", "colors"]
```

```python
from graphics import *   # Only brings in shapes and colors
```

## 15.3 模块搜索路径

Python 按以下顺序搜索模块：

1. 当前目录
2. `PYTHONPATH` 中的目录
3. 标准库目录
4. 第三方包目录（`site-packages`）

```python
import sys
print(sys.path)   # List of search directories
```

## 15.4 `__name__ == "__main__"`

位于这个判断中的代码只会在文件被直接执行时运行，而在作为模块被导入时不会运行。

```python
# utils.py
def helper():
    return "I am a helper"

if __name__ == "__main__":
    # This only runs when executing: python utils.py
    print("Direct execution test:")
    print(helper())
```

**最佳实践：** 始终将可执行代码包裹在 `if __name__ == "__main__":` 中，使模块可以被复用。

## 15.5 pip 与 PyPI

`pip` 是 Python 的包安装工具，PyPI（Python Package Index，Python 包索引）是公共包仓库。推荐用 `python -m pip` 的形式调用 pip，它可以确保包安装到你想要的那个 Python 解释器上，避免多版本环境下装错位置。

```bash
# Install a package (recommended form)
python -m pip install requests

# Shorthand
pip install requests

# Install specific version
pip install requests==2.28.1

# Upgrade
pip install --upgrade requests

# Uninstall
pip uninstall requests

# List installed packages
pip list

# Freeze requirements
pip freeze > requirements.txt

# Install from requirements
pip install -r requirements.txt
```

## 15.6 虚拟环境

虚拟环境（virtual environment）是为每个项目创建的相互隔离的 Python 环境。

```bash
# Create venv
python -m venv .venv

# Activate (Windows)
.venv\Scripts\activate

# Activate (macOS/Linux)
source .venv/bin/activate

# Deactivate
deactivate
```

**为什么要用 venv？** 不同项目可能需要同一个包的不同版本，venv 可以防止版本冲突。

**常见工作流：** 为每个项目创建并激活 venv，然后用 `pip install -r requirements.txt` 安装依赖。`.venv` 目录不要提交到版本库，记得在 `.gitignore` 中排除它。

## 15.7 标准库速查

Python 的标准库（standard library）非常丰富，下面列出最常用的模块。

### 15.7.1 `os` —— 操作系统接口

```python
import os

os.getcwd()              # Current working directory
os.listdir(".")          # List files in directory
os.path.exists("file.txt")  # Check if file exists
os.path.join("dir", "file") # Cross-platform path joining
os.path.basename("/home/user/file.txt")  # "file.txt"
os.path.dirname("/home/user/file.txt")   # "/home/user"
os.mkdir("new_folder")   # Create directory
os.remove("file.txt")    # Delete file

# Execute a shell command (platform-dependent)
os.system("python --version")   # Runs command in subshell
```

### 15.7.3 `datetime` —— 日期与时间

```python
from datetime import datetime, timedelta

now = datetime.now()
print(now.strftime("%Y-%m-%d %H:%M:%S"))  # datetime → string

# Parse string to datetime
birthday = datetime.strptime("2000-05-15", "%Y-%m-%d")
print(birthday.year)          # 2000

print(future)
```

### 15.7.4 `random` —— 随机数

```python
import random

random.randint(1, 10)     # Random integer [1, 10]
random.random()           # Random float [0.0, 1.0)
random.choice(["a", "b"]) # Random single element
random.shuffle(list)      # Shuffle list in-place

# choices() — sampling WITH replacement (can pick same item multiple times)
# Supports weights for biased sampling
elements = ["A", "B", "C", "D"]
weights = [10, 1, 1, 1]   # A is 10x more likely
random.choices(elements, weights=weights, k=3)
# Example: ['A', 'A', 'B'] — A appears more frequently

# sample() — sampling WITHOUT replacement (no duplicates)
random.sample(elements, k=2)   # Example: ['C', 'A']
```

| 方法 | 放回 | 重复 | 权重 | 使用场景 |
|--------|-------------|------------|---------|----------|
| `choice()` | — | — | 不支持 | 随机选取一个元素 |
| `choices()` | 有放回 | 允许 | 支持 | 抽奖、加权选取 |
| `sample()` | 无放回 | 不允许 | 不支持 | 无放回抽取 |

更深入的内容见 [25 random 随机数](25-random随机数.md)。

### 15.7.5 `re` —— 正则表达式

```python
import re

# Match pattern
re.match(r"\d+", "123abc")     # Match at start
re.search(r"\d+", "abc123")    # Search anywhere
```

### 15.7.6 `pprint` —— 美化打印

`pprint` 模块通过自动缩进和换行来格式化复杂的数据结构（尤其是嵌套的字典和列表），使其比普通的 `print()` 输出更易读。

```python
import pprint

data = {
    1: {"name": "Alice", "age": 25, "scores": [90, 85, 88]},
    2: {"name": "Bob", "age": 30, "scores": [78, 82, 91]},
    3: {"name": "Charlie", "age": 22, "scores": [95, 92, 89]},
}

# Standard print — hard to read
print(data)
# {1: {'name': 'Alice', 'age': 25, 'scores': [90, 85, 88]}, 2: ...}

# Pretty print — structured and readable
pprint.pprint(data)
# {1: {'age': 25, 'name': 'Alice', 'scores': [90, 85, 88]},
#  2: {'age': 30, 'name': 'Bob', 'scores': [78, 82, 91]},
#  3: {'age': 22, 'name': 'Charlie', 'scores': [95, 92, 89]}}
```

**控制输出宽度：**

```python
# Limit line width (default is 80)
pprint.pprint(data, width=40)

# Use a PrettyPrinter instance for repeated use
printer = pprint.PrettyPrinter(indent=4, width=50)
printer.pprint(data)
```

**适用场景：** 调试过程中需要查看嵌套数据结构时。

## 15.8 循环导入

当两个模块互相导入对方时，就会发生**循环导入**（circular import）。Python 会先部分加载第一个模块，然后尝试加载第二个模块，而第二个模块又请求第一个模块。此时第一个模块可能尚未完全初始化，因此第二个模块可能看到不完整或为 `None` 的名称。

### 15.8.1 问题示例

```python
# a.py
from b import func_b

def func_a():
    return "A"

# b.py
from a import func_a

def func_b():
    return func_a()
```

运行 `a.py` 可能会失败或出现异常行为，因为当 `b` 从 `a` 导入时，`a` 还没有加载完毕。

### 15.8.2 如何避免循环导入

- **重构代码：** 把共享代码移到第三个模块中，让两个模块都去导入它。
- **延迟导入：** 如果依赖只在运行时才需要，就在函数内部导入，而不是在模块顶层导入。
- **使用 `if TYPE_CHECKING`：** 仅用于类型提示时，把导入放在 `typing.TYPE_CHECKING` 判断之下，使其不会在导入时执行。

```python
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from other_module import SomeClass

def process(obj: "SomeClass") -> None:
    ...
```

## 15.9 使用 `importlib` 重新加载模块

模块一旦被导入，Python 就会将其缓存在 `sys.modules` 中。编辑源文件后再次导入**并不会**重新加载修改后的代码。可以使用 `importlib.reload()` 强制重新加载。

```python
import importlib
import my_module

# After editing my_module.py
importlib.reload(my_module)
```

**使用场景：**
- 长时间运行的程序（例如 Web 服务器、游戏循环、数据科学 notebook）。
- 热插拔插件模块。

**注意事项：**
- `reload()` 只会更新模块对象；已经基于旧代码创建的对象不会自动更新。
- 其他地方持有的引用可能仍然指向旧的函数或类。

```python
import importlib
import math

# Force reload of a standard library module (rarely needed)
importlib.reload(math)
```
