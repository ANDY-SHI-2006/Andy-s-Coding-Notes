# 8 数据交互

现代 Web 应用会与服务器通信，在不刷新页面的情况下收发数据。

## 8.1 XMLHttpRequest（遗留方案）

在 JavaScript 中发起 HTTP 请求的原始方式。每个 XHR 都会经历五个 `readyState` 值：

| readyState | 常量 | 含义 |
|------------|------|------|
| `0` | `UNSENT` | 对象已创建，尚未调用 `open()` |
| `1` | `OPENED` | 已调用 `open()` |
| `2` | `HEADERS_RECEIVED` | 已调用 `send()`，已接收响应头 |
| `3` | `LOADING` | 响应体正在下载 |
| `4` | `DONE` | 请求完成，响应已完全可用 |

使用 `onreadystatechange` 等待状态 `4`，然后在使用响应之前验证 HTTP `status`。

```javascript
let xhr = new XMLHttpRequest();
xhr.open("GET", "https://api.example.com/users", true);

xhr.onreadystatechange = function() {
    if (xhr.readyState === 4) {
        if (xhr.status >= 200 && xhr.status < 400) {
            let data = JSON.parse(xhr.responseText);
            console.log(data);
        } else {
            console.error("HTTP error:", xhr.status, xhr.statusText);
        }
    }
};

xhr.onerror = function() {
    console.error("Network error");
};

xhr.send();
```

> **注意：** `xhr.onload` 在请求成功完成时触发（大致等价于 `readyState === 4` 加上 2xx/3xx 状态码）。当你需要观察每一个状态时，使用 `onreadystatechange`，并且始终检查 `status`，而不是假设请求一定成功。

> **勘误：** 课程课件有时会说 GET 限制在“约 2 KB”，POST“无限制”。实际上 GET 长度取决于浏览器和服务器（通常为 8 KB–64 KB 或更大），POST 请求体也会受到服务器配置（`max_body_size`、框架默认值等）的限制。

### 8.1.1 带 URL 参数的 GET 请求

GET 数据通过 URL 查询字符串传输。使用 `encodeURIComponent` 对值进行编码，以避免特殊字符问题。

```javascript
let name = "Li Ming";
let age = 19;
let url = `https://api.example.com/users?name=${encodeURIComponent(name)}&age=${age}`;

let xhr = new XMLHttpRequest();
xhr.open("GET", url, true);
xhr.send();
```

> URL 不适合承载大载荷。保持 GET 请求简短；具体限制因浏览器和服务器而异。

### 8.1.2 POST 请求与 Content-Type 请求头

POST 将数据放在请求体中发送。选择与你的载荷格式匹配的 `Content-Type`。

| Content-Type | 使用场景 | 发送方式 |
|--------------|----------|----------|
| `application/json` | JSON 载荷 | `xhr.send(JSON.stringify(data))` |
| `application/x-www-form-urlencoded` | 普通表单字段（键=值对） | `xhr.send("name=Alice&age=20")` |
| `multipart/form-data` | 文件上传或混合内容 | 让 `FormData` 自动设置 |

```javascript
// JSON POST
let xhr = new XMLHttpRequest();
xhr.open("POST", "https://api.example.com/users", true);
xhr.setRequestHeader("Content-Type", "application/json;charset=UTF-8");
xhr.send(JSON.stringify({ name: "Alice", age: 20 }));

// URL-encoded POST
let xhr2 = new XMLHttpRequest();
xhr2.open("POST", "https://api.example.com/users", true);
xhr2.setRequestHeader("Content-Type", "application/x-www-form-urlencoded");
xhr2.send("name=Alice&age=20");
```

> 使用 `FormData` 时，不要手动设置 `Content-Type: multipart/form-data` —— 浏览器必须自己添加 boundary 参数。

### 8.1.3 常见 HTTP 状态码

| 状态码 | 含义 | 常见原因 |
|--------|------|----------|
| `200` | OK | GET/PUT/PATCH 成功 |
| `201` | Created | POST 成功并创建资源 |
| `204` | No Content | DELETE 成功或响应为空 |
| `400` | Bad Request | 请求格式错误 or 校验失败 |
| `401` | Unauthorized | 缺少或无效的身份认证 |
| `403` | Forbidden | 已通过认证，但没有权限 |
| `404` | Not Found | 资源不存在 |
| `500` | Internal Server Error | 服务器端异常 |

将 `2xx` 视为成功，`4xx` 视为客户端问题，`5xx` 视为服务器端问题。

### 8.1.4 将 XHR 包装为 Promise

`XMLHttpRequest` 基于事件，但你可以把它包装起来，使其能与 `async/await` 配合使用。

```javascript
function request(method, url, data = null, headers = {}) {
    return new Promise((resolve, reject) => {
        let xhr = new XMLHttpRequest();
        xhr.open(method, url, true);

        Object.entries(headers).forEach(([key, value]) => {
            xhr.setRequestHeader(key, value);
        });

        xhr.onreadystatechange = function() {
            if (xhr.readyState === 4) {
                if (xhr.status >= 200 && xhr.status < 400) {
                    resolve(xhr.response);
                } else {
                    reject(new Error(`HTTP ${xhr.status}: ${xhr.statusText}`));
                }
            }
        };

        xhr.onerror = () => reject(new Error("Network error"));
        xhr.send(data);
    });
}

// 用法
(async () => {
    let users = await request("GET", "/api/users");
    console.log(JSON.parse(users));
})();
```

### 8.1.5 学生信息 CRUD 小项目

一个根据后端列表渲染的小表格。通过 POST 新增学生，每次请求成功后重新渲染表格。

```javascript
const API = "https://api.example.com/students";

async function loadStudents() {
    let list = JSON.parse(await request("GET", API));
    tbody.innerHTML = list.map(s =>
        `<tr><td>${s.id}</td><td>${s.name}</td><td>${s.age}</td></tr>`
    ).join("");
}

form.addEventListener("submit", async (e) => {
    e.preventDefault();
    let body = JSON.stringify({ name: nameInput.value, age: +ageInput.value });
    await request("POST", API, body, { "Content-Type": "application/json" });
    form.reset();
    loadStudents();
});
```

要点：
- 先获取列表，然后将每一项映射为表格行。
- 对 GET 和 POST 使用同一个辅助函数，以便复用 `readyState`/`status` 检查。
- POST 后重新渲染，而不是手动插入一行。

## 8.2 Fetch API

一个现代的、基于 Promise 的 HTTP 请求 API。

### 8.2.1 GET 请求

```javascript
fetch("https://api.example.com/users")
    .then(response => {
        if (!response.ok) {
            throw new Error("HTTP " + response.status);
        }
        return response.json();   // 解析 JSON 响应体
    })
    .then(data => {
        console.log(data);
    })
    .catch(error => {
        console.error("Fetch error:", error);
    });
```

### 8.2.2 POST 请求

```javascript
fetch("https://api.example.com/users", {
    method: "POST",
    headers: {
        "Content-Type": "application/json"
    },
    body: JSON.stringify({
        name: "Alice",
        email: "alice@example.com"
    })
})
    .then(response => response.json())
    .then(data => console.log("Created:", data))
    .catch(error => console.error("Error:", error));
```

### 8.2.3 Fetch 选项

| 选项 | 说明 |
|------|------|
| `method` | HTTP 方法：`GET`、`POST`、`PUT`、`DELETE`、`PATCH` |
| `headers` | 请求头对象 |
| `body` | 请求体（字符串、FormData、Blob 等） |
| `mode` | `cors`、`no-cors`、`same-origin` |
| `credentials` | `omit`、`same-origin`、`include`（发送 cookie） |

### 8.2.4 Response 对象

```javascript
fetch("/api/data")
    .then(response => {
        response.ok;           // 状态为 200-299 时为 true
        response.status;       // HTTP 状态码（200、404、500）
        response.statusText;   // 状态消息（"OK"、"Not Found"）
        response.headers;      // 响应头

        // 读取响应体（只能读取一次）
        return response.json();     // 解析为 JSON
        // return response.text();  // 解析为纯文本
        // return response.blob();  // 解析为二进制 blob
    });
```

## 8.3 async / await

一种更简洁的 Promise 写法。

### 8.3.1 async/await 基础

```javascript
async function getUsers() {
    try {
        let response = await fetch("https://api.example.com/users");
        if (!response.ok) {
            throw new Error("HTTP " + response.status);
        }
        let users = await response.json();
        console.log(users);
        return users;
    } catch (error) {
        console.error("Failed to fetch users:", error);
    }
}

getUsers();
```

### 8.3.2 并行请求

```javascript
async function loadDashboard() {
    try {
        let [users, posts] = await Promise.all([
            fetch("/api/users").then(r => r.json()),
            fetch("/api/posts").then(r => r.json())
        ]);

        console.log("Users:", users);
        console.log("Posts:", posts);
    } catch (error) {
        console.error("Failed to load dashboard:", error);
    }
}
```

### 8.3.3 错误类型与 throw

JavaScript 有几种内置错误类型。你也可以用 `throw new Error()` 创建自己的错误。

| 错误类型 | 含义 | 示例 |
|----------|------|------|
| `ReferenceError` | 变量未声明 | `console.log(notDefined);` |
| `TypeError` | 值不是预期类型 | `null.something;` |
| `SyntaxError` | 无效语法（通常在解析阶段抛出） | `let x = ;` |
| `RangeError` | 值超出允许范围 | `(1).toFixed(101)` |

```javascript
function divide(a, b) {
    if (b === 0) {
        throw new Error("Cannot divide by zero");
    }
    return a / b;
}

try {
    divide(10, 0);
} catch (err) {
    console.log(err.name);    // "Error"
    console.log(err.message); // "Cannot divide by zero"
}
```

## 8.4 FormData

用于发送包含文件上传或多部分数据的表单。

```javascript
let form = document.getElementById("uploadForm");
let formData = new FormData(form);

// 或手动构建
let formData = new FormData();
formData.append("name", "Alice");
formData.append("avatar", fileInput.files[0]);

fetch("/api/upload", {
    method: "POST",
    body: formData   // 无需设置 Content-Type 请求头 —— 浏览器会自动设置
})
    .then(response => response.json())
    .then(data => console.log(data));
```

### 8.4.1 使用 FormData 的 XHR 文件上传

`FormData` 也可以与 `XMLHttpRequest` 配合使用。浏览器会自动设置 `multipart/form-data` 及正确的 boundary。

```javascript
let input = document.getElementById("fileInput");
let file = input.files[0];

let fd = new FormData();
fd.append("img", file);

let xhr = new XMLHttpRequest();
xhr.open("POST", "/api/upload", true);

xhr.upload.addEventListener("progress", (e) => {
    if (e.lengthComputable) {
        let percent = Math.round((e.loaded / e.total) * 100);
        console.log(`Upload progress: ${percent}%`);
    }
});

xhr.onreadystatechange = function() {
    if (xhr.readyState === 4 && xhr.status >= 200 && xhr.status < 400) {
        console.log("Uploaded:", xhr.responseText);
    }
};

xhr.send(fd);
```

上传多个文件时，循环追加每一项：

```javascript
let fd = new FormData();
for (let file of input.files) {
    fd.append("img", file);   // 同一名称，多个值
}
xhr.send(fd);
```

## 8.5 JSON Server 通信模式

针对 REST API 的典型 CRUD 操作：

```javascript
const API_URL = "https://api.example.com/items";

// 创建
async function createItem(data) {
    let response = await fetch(API_URL, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify(data)
    });
    return response.json();
}

// 读取
async function getItem(id) {
    let response = await fetch(`${API_URL}/${id}`);
    return response.json();
}

// 更新
async function updateItem(id, data) {
    let response = await fetch(`${API_URL}/${id}`, {
        method: "PUT",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify(data)
    });
    return response.json();
}

// 删除
async function deleteItem(id) {
    let response = await fetch(`${API_URL}/${id}`, {
        method: "DELETE"
    });
    return response.ok;
}
```

## 8.6 最佳实践

| 应该做 | 不应该做 |
|--------|----------|
| 解析前始终检查 `response.ok` | 因为 Promise 已解决就假设 fetch 一定成功 |
| 使用 `async/await` 提高可读性 | 嵌套过深的 `.then()` 链 |
| 对独立的并行请求使用 `Promise.all` | 请求互不依赖时还按顺序逐个 await |
| 使用 `try/catch` 处理错误 | 让未处理的 Promise 拒绝静默崩溃 |
| 设置合适的 `Content-Type` 请求头 | 发送 JSON 却不带 `application/json` 请求头 |
| 用 `AbortController` 中止长时间运行的请求 | 让请求无限期挂起 |

### 8.6.1 常见 HTTP 请求头 / 响应头

| 请求头 | 用途 |
|--------|------|
| `Accept` | 客户端可处理的媒体类型，例如 `application/json` |
| `Content-Type` | 请求体的媒体类型 |
| `User-Agent` | 客户端应用标识 |
| `Authorization` | 凭证，通常为 `Bearer <token>` |
| `Origin` | 请求页面的协议 + 主机 + 端口（由浏览器设置） |
| `Cookie` | 服务器之前设置的 cookie |

| 响应头 | 用途 |
|--------|------|
| `Access-Control-Allow-Origin` | CORS：哪些源可以读取响应 |
| `Content-Type` | 响应体的媒体类型 |
| `Content-Encoding` | 压缩方法，例如 `gzip` |
| `Cache-Control` | 缓存指令 |
| `Set-Cookie` | 指示浏览器存储 cookie |
| `Location` | 重定向目标（与 3xx 状态码一起使用） |

你可以在浏览器的 Network 面板中查看请求/响应头。

## 8.7 Axios

Axios 是一个基于 `XMLHttpRequest` 构建的流行 HTTP 库。它会自动解析 JSON、拒绝非 2xx 响应，并兼容旧版浏览器。

通过 CDN 引入：

```html
<script src="https://cdn.jsdelivr.net/npm/axios/dist/axios.min.js"></script>
```

```javascript
// GET
axios.get("https://api.example.com/users")
    .then(response => console.log(response.data));

// 带查询参数的 GET
axios.get("https://api.example.com/users", { params: { age: 20 } })
    .then(response => console.log(response.data));

// POST JSON
axios.post("https://api.example.com/users", { name: "Alice", age: 20 })
    .then(response => console.log(response.data));

// 完整配置对象
axios({
    method: "POST",
    url: "/users",
    data: { name: "Alice" },
    headers: { "X-Requested-With": "XMLHttpRequest" }
});

// 设置默认值
axios.defaults.baseURL = "https://api.example.com";
axios.defaults.headers.common["Authorization"] = "Bearer token";
```

> **提示：** Axios 响应对象暴露 `data`、`status`、`statusText`、`headers` 和 `config`。大多数时候你只需要 `response.data`。

## 8.8 同源策略与 CORS

浏览器执行**同源策略**：页面只能读取来自同一来源的响应，除非服务器明确允许。

两个 URL 共享同一来源，当且仅当它们具有相同的：

- 协议（`http:` 与 `https:`）
- 主机 / 域名
- 端口（`:80`、`:3000` 等）

跨域限制是一种**浏览器安全行为**。命令行工具、服务器和非浏览器环境不受 CORS 限制。

解决方案：

1. **CORS 请求头（服务端）** —— 服务器发送如下请求头：
   ```http
   Access-Control-Allow-Origin: https://your-site.com
   Access-Control-Allow-Methods: GET, POST, OPTIONS
   Access-Control-Allow-Headers: Content-Type
   ```
2. **开发代理** —— 开发期间将 API 调用通过同一来源转发（例如 Vite 或 webpack devServer proxy）。
3. **服务端转发** —— 你自己的后端调用外部 API，再把数据返回给前端。

> 对于非简单请求（自定义请求头、GET/HEAD/POST 以外的 HTTP 方法，或特定内容类型），浏览器会自动发送预检 `OPTIONS` 请求。
