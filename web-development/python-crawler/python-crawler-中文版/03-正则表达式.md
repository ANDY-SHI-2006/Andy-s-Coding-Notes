# 3 正则表达式

正则表达式（Regular Expression）是爬虫"取"数据阶段的利器：当我们用 Requests 把整页 HTML 下载下来后，需要用一种"规则"从海量文本里过滤出真正有用的字段。正则就是一种用字符串描述过滤逻辑的语言，它不依赖 Python，几乎所有编程语言都有对应实现，Python 通过内置的 `re` 模块提供支持。

## 3.1 爬虫四步流程与正则的定位

一个完整的爬虫通常可以拆成四步：

| 步骤 | 动作 | 说明 |
|------|------|------|
| 1 | 明确目标 | 确定要爬哪个网站、提取哪些字段 |
| 2 | 爬 | 发送请求，下载页面的全部内容（HTML/JSON 等） |
| 3 | 取 | 从下载的内容中过滤、提取出有用的数据 |
| 4 | 处理数据 | 清洗、保存（写文件 / 入库） |

正则表达式主要服务于第 3 步"取"。它适合在**结构简单、规律明显**的文本里做精确抽取；当页面结构复杂、标签嵌套很深时，第 4、7 章介绍的 BeautifulSoup 和 XPath 会更合适。

## 3.2 什么是正则表达式

正则表达式是一串"规则字符串"，用来表达文本的匹配逻辑。例如 `\d+` 表示"一个或多个数字"，`chuanzhiboke\t\.\tpython` 表示"chuanzhiboke、制表符、点号、制表符、python"这样一个字面串。

> **核心要点：** 正则不是 Python 独有的语法。它诞生于理论计算机科学，被 Perl、Java、JavaScript、Python 等广泛实现。Python 用它内置的 `re` 模块来支持正则。

## 3.3 原始字符串 r''

正则里反斜杠 `\` 有转义含义，例如 `\d` 表示数字。但如果用普通字符串写正则，Python 解释器会先把 `\` 当作字符串转义处理，导致"双重转义"：

```python
# 普通字符串：Python 先把 \t 解释成制表符，\d 也会触发警告
pat1 = 'chuanzhiboke\t\.\tpython'

# 原始字符串：r 前缀让 Python 原样保留反斜杠
pat2 = r'chuanzhiboke\t\.\tpython'
```

> **注意：** 用 `r''` 前缀书写正则几乎是强制性的习惯。它避免了 `\d`、`\s`、`\t` 等被 Python 提前转义，也让正则可读性更好。建议所有正则都写成原始字符串。

## 3.4 常见匹配模式

正则语法由一组元字符构成。下表是爬虫中最常用的匹配模式：

| 模式 | 含义 |
|------|------|
| `\w` | 字母、数字、下划线（word） |
| `\W` | 非 word 字符 |
| `\s` | 空白字符（空格、制表符、换行等） |
| `\S` | 非空白字符 |
| `\d` | 数字（digit） |
| `\D` | 非数字 |
| `\A` | 字符串开头 |
| `\Z` / `\z` | 字符串结尾 |
| `\G` | 上一次匹配结束的位置 |
| `\n` | 换行符 |
| `\t` | 制表符 |
| `^` | 行首 |
| `$` | 行尾 |
| `.` | 任意字符（默认不含换行，`re.S` 后含换行） |
| `[...]` | 字符集，匹配括号内任意一个字符 |
| `[^...]` | 反向字符集，匹配不在括号内的任意字符 |
| `*` | 前一个元素出现 0 次或多次 |
| `+` | 前一个元素出现 1 次或多次 |
| `?` | 前一个元素出现 0 次或 1 次 |
| `{n}` | 前一个元素恰好出现 n 次 |
| `{n,m}` | 前一个元素出现 n 到 m 次 |
| `|` | 或运算 |
| `()` | 分组，同时用于提取 |

## 3.5 compile() 编译正则

`re.compile(pattern)` 会把一个正则字符串编译成 `Pattern` 对象。后续的 `match`、`search`、`findall` 等方法既可以作为 `re` 模块的顶层函数直接调用，也可以作为 `Pattern` 对象的方法调用。

```python
import re

# 编译成 Pattern 对象
pat = re.compile(r'\d+')

# 两种调用方式等价
m1 = pat.search('one12two34')        # Pattern 对象的方法
m2 = re.search(r'\d+', 'one12two34') # 顶层函数
```

> **核心要点：** 当一个正则要被**反复使用**（比如在循环里匹配成千上万条数据）时，先 `compile` 一次再复用，比每次都把字符串重新编译更高效。

## 3.6 re.match() 从头匹配

`re.match(pattern, string)` 只从字符串的**起始位置**开始尝试匹配，如果开头不匹配就返回 `None`：

```python
import re

m = re.match(r'\d+', '12abc')
print(m)          # <re.Match object; span=(0, 2), match='12'>

m = re.match(r'\d+', 'abc12')
print(m)          # None（开头不是数字）
```

> **勘误：** 旧课件中打印结果是 `<_sre.SRE_Match object ...>`，这是 Python 2 时代的类名；Python 3 中应显示为 `<re.Match object ...>`。

`match` 还支持 `pos` 和 `endpos` 参数指定匹配的起止范围：

```python
m = re.match(r'\d+', 'xxx12yyy', 3, 6)   # 从索引 3 开始匹配
print(m.group())                          # 12
```

### 3.6.1 Match 对象的方法

匹配成功后返回的 `Match` 对象提供了提取结果的方法：

| 方法 | 说明 |
|------|------|
| `group([g])` | 返回匹配到的（分组）子串；省略参数等价于 `group(0)`，即整体 |
| `start([g])` | 返回（分组）子串的起始索引 |
| `end([g])` | 返回（分组）子串的结束索引（不包含） |
| `span([g])` | 返回 `(start, end)` 元组 |

```python
m = re.search(r'(\d+)-(\d+)', '电话：010-12345')
print(m.group())      # 010-12345（整体）
print(m.group(1))     # 010
print(m.group(2))     # 12345
print(m.start(1))     # 3
print(m.end(1))       # 6
print(m.span(1))      # (3, 6)
```

## 3.7 re.search() 任意位置匹配

`re.search()` 会扫描**整个字符串**，返回第一个成功匹配的结果（而 `match` 只看开头）：

```python
import re

m = re.search(r'\d+', 'abc12def34')
print(m.group())       # 12（第一个数字串）
print(m.span())        # (3, 5)
```

> **核心要点：** 能不用 `match` 就尽量用 `search`。爬虫场景中数据往往埋在文本中间，`match` 从开头匹配的语义太严格，`search` 更符合直觉。

## 3.8 re.findall() 查找全部

`re.findall()` 返回字符串中**所有**匹配的结果，返回类型是一个列表：

```python
import re

re.findall(r'\d+', 'abc12def34')      # ['12', '34']
```

当正则里有**分组**时，`findall` 返回的是元组列表，每个元组对应一组捕获：

```python
html = '<li data-view="4"><a href="/3.mp3" singer="齐秦">往事随风</a></li>'
items = re.findall(r'singer="(.*?)">(.*?)</a>', html, re.S)
print(items)   # [('齐秦', '往事随风')]
```

## 3.9 re.finditer() 返回迭代器

`re.finditer()` 与 `findall` 一样查找全部匹配，但返回的是一个**迭代器**，逐个产出 `Match` 对象。数据量很大时用迭代器更省内存，也能拿到每个匹配的位置信息：

```python
import re

for m in re.finditer(r'\d+', 'one12two34three56'):
    print(m.group(), m.span())
# 12 (3, 5)
# 34 (9, 11)
# 56 (16, 18)
```

## 3.10 re.split() 分割字符串

`re.split()` 按正则匹配到的位置把字符串切开，返回列表：

```python
import re

# 按任意空白或逗号、分号分割
re.split(r'[\s,;]+', 'a, b;c  d')
# ['a', 'b', 'c', 'd']
```

> **核心要点：** `str.split()` 只能按一个固定字面量分割，`re.split()` 能用任意复杂规则（如多种分隔符、连续分隔符）分割。

## 3.11 re.sub() 替换

`re.sub(pattern, repl, string[, count])` 把匹配到的内容替换成 `repl`：

| 参数 | 说明 |
|------|------|
| `repl` | 替换目标，可以是字符串，也可以是**函数**（接收一个 `Match` 对象并返回字符串） |
| `count` | 最多替换次数，省略时替换全部 |

```python
import re

re.sub(r'\d+', '#', 'a1b22c333')          # 'a#b#c#'
re.sub(r'\d+', '#', 'a1b22c333', count=1) # 'a#b22c333'
```

`repl` 传入函数时，可以对每次匹配做动态处理：

```python
import re

def double(m):
    return str(int(m.group()) * 2)

re.sub(r'\d+', double, 'a1b22')   # 'a2b44'
```

### 3.11.1 引用分组

在替换串里可以用 `\1`、`\2` 引用前面的分组，实现"交换顺序"等操作：

```python
import re

# 交换两个单词的顺序
re.sub(r'(\w+)\s+(\w+)', r'\2 \1', 'hello world')   # 'world hello'
```

当分组号后面紧跟数字时，`\1xxx` 会被误读为第 `1xxx` 组，需要用 `\g<1>` 明确界定分组边界：

```python
import re

# 错误写法：\133 会被解析成八进制字符
re.sub(r'(\d+)', r'\133', '123')   # 得到 'S'（八进制 0o133 = 'S'）

# 正确写法：用 \g<1> 引用第 1 组
re.sub(r'(\d+)', r'\g<1>3333', '123')   # '1233333'
```

> **勘误：** 课件中 `re.sub(r'(\d+)', r'\133', ...)` 的 `\133` 会被 Python 解析为八进制字符，导致替换结果错误；正确做法是改用 `\g<1>` 引用分组。旧课件把"引用分组"写成"repl 还可以使用 id 的形式来引用分组"，应为"使用 `\1`、`\2` 的形式引用分组"。

## 3.12 贪婪与非贪婪

Python 的数量词（`*`、`+`、`?`、`{m,n}`）默认是**贪婪**的：尽量多匹配。在数量词后加一个 `?` 就变成**非贪婪**（惰性）：尽量少匹配。

```python
html = '<div>第一个</div><div>第二个</div>'

# 贪婪：.* 尽可能多吃，一直匹配到最后一个 </div>
re.findall(r'<div>.*</div>', html)
# ['<div>第一个</div><div>第二个</div>']

# 非贪婪：.*? 尽可能少吃，遇到第一个 </div> 就停
re.findall(r'<div>.*?</div>', html)
# ['<div>第一个</div>', '<div>第二个</div>']
```

> **核心要点：** 爬虫提取字段时几乎总是用非贪婪 `.*?`。贪婪的 `.*` 会跨过多个标签边界，把多个目标一起吞掉。

## 3.13 分组匹配 ()

分组 `()` 有两个作用：一是**改变优先级**，二是**捕获内容**。提取数据时，把目标值放进括号，前后的特征字符原样保留即可：

```python
import re

html = '<a href="/3.mp3" singer="齐秦">往事随风</a>'

m = re.search(r'singer="(.*?)">(.*?)</a>', html, re.S)
print(m.group(1))   # 齐秦
print(m.group(2))   # 往事随风
```

> **核心要点：** 规律是"把要提取的字段用 `(.*?)` 圈起来，字段前后的固定文本原样照抄"。分组越多，`group(n)` 的 n 就越大。

## 3.14 匹配模式 re.S

`re.S`（即 `re.DOTALL`）让 `.` 也能匹配换行符。HTML 源码里标签往往跨多行，此时 `.*?` 默认匹配不到换行，必须加 `re.S`：

```python
import re

html = '''<div>
    第一个
</div>'''

# 不加 re.S：. 匹配不到换行，结果为空
re.findall(r'<div>(.*?)</div>', html)         # []

# 加 re.S：. 可以跨行匹配
re.findall(r'<div>(.*?)</div>', html, re.S)   # ['\n    第一个\n']
```

> **核心要点：** 只要被匹配的文本里可能出现换行，就加上 `re.S`。`re.I`（忽略大小写）是另一个常用标志，与 `re.S` 可用 `|` 组合，如 `re.S | re.I`。

## 3.15 转义特殊字符

`$`、`.`、`\` 等字符在正则里有特殊含义。如果要把它们当作**普通文本**匹配，需要加反斜杠转义：

```python
import re

# 错误：. 和 $ 是元字符，price 后面任意字符都能匹配
re.search(r'price\sis\s$5.00', 'price is $5X00')   # 仍然能匹配

# 正确：\$ 和 \. 让它们退化为字面量
re.search(r'price\sis\s\$5\.00', 'price is $5.00')  # 精确匹配
```

## 3.16 或运算 |

`|` 表示"或"，让正则一次匹配多个备选项。典型的应用是用一次 `sub` 同时清理一个标签的开、闭标记：

```python
import re

html = '<a href="/1.mp3">沧海一声笑</a>'

# 同时去掉 <a ...> 和 </a>
text = re.sub(r'<a.*?>|</a>', '', html)
print(text)   # 沧海一声笑
```

> **核心要点：** `|` 的分支范围是"它左右两侧各自到括号边界为止"，必要时用括号分组，例如 `(cat|dog)` 只匹配两个单词之一。

## 3.17 实战一：提取歌曲列表

把前面讲过的"分组 + 非贪婪 + re.S"组合起来，从一段歌曲列表 HTML 中提取歌手和歌名：

```python
import re

html = """
<div id="song-list">
<li data-view="2"><a href="/1.mp3" singer="任贤齐">沧海一声笑</a></li>
<li data-view="3"><a href="/2.mp3" singer="邓丽君">甜蜜蜜</a></li>
<li data-view="4"><a href="/3.mp3" singer="齐秦">往事随风</a></li>
</div>
"""

items = re.findall(r'singer="(.*?)">(.*?)</a>', html, re.S)
for singer, song in items:
    print(f'歌手：{singer}，歌名：{song}')
# 歌手：任贤齐，歌名：沧海一声笑
# 歌手：邓丽君，歌名：甜蜜蜜
# 歌手：齐秦，歌名：往事随风
```

## 3.18 实战二：豆瓣新书速递

完整的爬虫示例通常把逻辑拆成"下载 / 解析 / 保存"三个函数，用正则完成中间解析，循环翻页抓取多页数据：

```python
import re
import requests

headers = {
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36'
}

def get_data(page):
    """下载第 page 页的 HTML"""
    url = f'https://book.douban.com/latest?subcat=all&p={page}'
    resp = requests.get(url, headers=headers)
    return resp.text

def parse_data(html):
    """用正则提取书名、链接、封面图"""
    pattern = re.compile(
        r'<a href="(.*?)".*?title="(.*?)".*?<img src="(.*?)"',
        re.S
    )
    return pattern.findall(html)

def save_data(items):
    """追加写入 txt"""
    with open('douban_books.txt', 'a', encoding='utf-8') as f:
        for link, title, img in items:
            f.write(f'{title}\t{link}\t{img}\n')

if __name__ == '__main__':
    for page in range(1, 11):
        html = get_data(page)
        items = parse_data(html)
        save_data(items)
        print(f'第 {page} 页完成，共 {len(items)} 条')
```

> **注意：** 豆瓣页面结构会随改版变化，上面的正则只是教学骨架；实际抓取前先在测试工具里核对真实 HTML。写文件部分属于第 6 章"数据持久化"的内容，这里简单引用即可。

## 3.19 在线测试工具

写正则时建议先用在线工具验证，再粘贴进代码：

- **tool.oschina.net/regex**：输入测试文本和正则，实时高亮所有匹配结果。

> **核心要点：** 先在线调试、确认匹配无误，再写进代码，可以避免大量"猜正则—跑代码—再猜"的来回。

**记忆口诀**

- 四步流程：目标 → 爬 → 取 → 处理，正则在"取"。
- 正则习惯：一律用 `r''` 原始字符串，避免双重转义。
- 常用元字符：`\d` 数字、`\w` 词、`\s` 空白、`.` 任意、`*+?{}` 数量、`[]` 集合、`()` 分组、`|` 或。
- 六方法：`compile` 先编译，`match` 看开头，`search` 找第一处，`findall` 全列表，`finditer` 迭代器，`split` 分割，`sub` 替换。
- 提取套路：`(.*?)` 圈目标 + 前后照抄 + `re.S` 跨行。
- 引用分组：`\1 \2` 交换序，`\g<1>` 隔边界（别用会变八进制的 `\133`）。
