# 0 环境搭建与工具

在动手写第一个爬虫之前，先把开发环境准备好。本课程使用 Python 3 作为主语言，并用 Jupyter Notebook 作为交互式学习工具——它适合边学边跑代码、逐格验证结果。

## 0.1 Python 环境准备

爬虫课程离不开 Python。先确认本机已经安装了 Python，并注意版本号。

| 项目 | 要求 |
|------|------|
| 语言 | Python |
| 最低版本 | Python 3.8+ |
| 验证命令 | `python --version` |

> **注意：** requests 等现代库早已停止支持 Python 2，请务必使用 Python 3.8 及以上版本。旧课件里写的「支持 Python 2.6–3.5」是过时信息。

验证安装是否成功：

```bash
python --version
# 例如输出：Python 3.11.4
```

如果提示找不到 `python`，请先到 [python.org](https://www.python.org/downloads/) 下载安装包，安装时勾选「Add Python to PATH」。

## 0.2 pip 与镜像源

`pip` 是 Python 的包管理器，用来安装第三方库（本课程后面会用到 `requests`、`bs4`、`selenium` 等）。

常用命令：

| 命令 | 作用 |
|------|------|
| `pip install 包名` | 安装第三方库 |
| `pip install 包名 -i 镜像地址` | 指定镜像源安装 |
| `pip list` | 查看已安装的包 |
| `pip uninstall 包名` | 卸载包 |
| `pip show 包名` | 查看某个包的详细信息 |

默认情况下 `pip` 从国外官方源下载，速度可能很慢。国内可以换成镜像源加速：

```bash
# 使用清华镜像源（推荐）
pip install 包名 -i https://pypi.tuna.tsinghua.edu.cn/simple --trusted-host pypi.tuna.tsinghua.edu.cn
```

| 镜像源 | 地址 |
|--------|------|
| 清华大学 | `https://pypi.tuna.tsinghua.edu.cn/simple` |
| 阿里云 | `https://mirrors.aliyun.com/pypi/simple` |

> **核心要点：** `-i` 指定镜像地址，`--trusted-host` 让 pip 信任该域名（避免 SSL 证书校验报错）。

## 0.3 认识 Jupyter Notebook

### 0.3.1 什么是 Jupyter Notebook

Jupyter Notebook 是一个**交互式笔记本**：你可以在网页里写代码，一格一格地运行，并即时看到输出结果。它非常适合学习爬虫——因为爬虫经常需要「发请求 → 看响应 → 改参数」反复试探，交互式环境能让你快速迭代。

| 特点 | 说明 |
|------|------|
| 交互式 | 代码分单元格（cell）运行，结果内嵌显示 |
| 多语言 | 支持 40+ 种语言（Python、R、Julia 等） |
| 混合内容 | 代码、Markdown 文档、图片可以混排在同一文档里 |
| 教学友好 | 适合边讲边演示，也适合做笔记 |

### 0.3.2 `.ipynb` 不是 `.py`

Jupyter 笔记本的文件后缀是 **`.ipynb`**，而不是 `.py`。它内部是一个 JSON 结构，既保存代码，也保存运行结果和 Markdown 文本。

| 文件类型 | 后缀 | 内容 |
|----------|------|------|
| 普通 Python 脚本 | `.py` | 纯代码文本 |
| Jupyter 笔记本 | `.ipynb` | JSON，含代码 + 输出 + 文档 |

所以不要用「新建 `.py` 文件」的方式打开它，而应该通过 Jupyter 环境打开。

### 0.3.3 标题与 Markdown

在 Jupyter 的 Markdown 单元格里，`#` 开头的写法与 Markdown 完全一致：

```markdown
# 一级标题
## 二级标题
### 三级标题
```

运行 Markdown 单元格后，`#` 会被渲染成标题样式。

### 0.3.4 Raw NBConvert

Raw NBConvert 是一种「原生」单元格类型，内容不会被渲染、不会被执行，通常用于导出时保留原始格式（例如 LaTeX 片段）。日常记笔记基本用不到，了解即可。

## 0.4 安装 Jupyter Notebook

使用 pip 安装：

```bash
# 常规安装
pip install jupyter notebook

# 国内加速安装
pip install jupyter notebook -i https://pypi.tuna.tsinghua.edu.cn/simple --trusted-host pypi.tuna.tsinghua.edu.cn
```

安装时可能遇到两类问题：

> **注意：** Windows 上若安装 `pywinpty` 报错（编译失败或找不到对应版本），需要根据本机 **Python 版本和位数**（如 3.11 / 64 位）到 [PyPI](https://pypi.org/project/pywinpty/) 下载对应的 `.whl` 文件，再用 `pip install 文件名.whl` 安装。

macOS / Linux 上推荐用用户级安装：

```bash
pip3 install --user jupyter
```

安装完成后启动：

```bash
python3 -m IPython notebook
```

## 0.5 启动 Jupyter 与主面板

### 0.5.1 启动命令

在终端里输入：

```bash
jupyter notebook
```

启动成功后浏览器会自动打开控制面板，地址通常是：

```
http://localhost:8888/tree
```

### 0.5.2 主面板三大页签

主面板顶部有三个页签：

| 页签 | 作用 |
|------|------|
| **Files** | 浏览、创建、打开文件（最常用） |
| **Running** | 查看正在运行的笔记本和终端 |
| **Clusters** | 并行计算集群（一般用不到） |

### 0.5.3 New 的四个选项

在 Files 页签点击右上角 **New**，可以看到四个选项：

| 选项 | 作用 |
|------|------|
| **Python 3** | 新建 Python 笔记本（`.ipynb`） |
| **Text File** | 新建纯文本文件 |
| **Folder** | 新建文件夹 |
| **Terminal** | 打开网页版终端 |

学习本课程时，每次都选 **Python 3** 即可。

## 0.6 单元格操作与类型

### 0.6.1 单元格操作

笔记本由一个个单元格（cell）组成。常用操作如下：

| 操作 | 说明 |
|------|------|
| 编辑 | 点击单元格即可编辑内容 |
| 运行 | `Shift + Enter` 运行当前格并跳到下一格 |
| 插入 | 上方插入 `A`，下方插入 `B`（编辑模式下 `Esc` 进入命令模式后按） |
| 剪切 / 复制 / 粘贴 | `X` / `C` / `V`（命令模式下） |
| 移动 | 选中后拖动，或用快捷键上下移动 |
| 中断 | 停止长时间运行的代码 |
| 保存 | `Ctrl + S` 或工具栏 Save 按钮 |
| 重启内核 | Kernel → Restart，清空变量重新开始 |

> **核心要点：** 记住两个模式——绿色边框是**编辑模式**（输入文字），蓝色边框是**命令模式**（用快捷键操作单元格）。`Esc` 切换回命令模式，`Enter` 进入编辑模式。

### 0.6.2 四种单元格类型

| 类型 | 用途 |
|------|------|
| **Code** | 写 Python 代码，可运行 |
| **Markdown** | 写文档、标题、笔记 |
| **Raw NBConvert** | 原生内容，不做渲染 |
| **Heading** | 旧版标题类型，现已并入 Markdown，用 `#` 即可 |

- **启动** = "`jupyter notebook` → `localhost:8888/tree`。"
- **单元格** = "`Shift + Enter` 运行，`Esc` 回命令模式，`A` 上插 `B` 下插。"
