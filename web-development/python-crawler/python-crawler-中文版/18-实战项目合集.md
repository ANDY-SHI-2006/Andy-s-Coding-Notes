# 18 实战项目合集

前面的章节拆解了爬虫的各个零件，这一章把它们组装成完整的实战项目。这里收录 8 个 Scrapy / 多任务爬虫项目，以及一个「Django + Elasticsearch」搜索引擎项目，覆盖从单机爬虫到分布式、再到检索展示的完整链路。

## 18.1 项目总览

| 项目 | 技术栈 | 数据存储 |
|------|--------|----------|
| 链家租房 | Scrapy + XPath | JSON |
| 豆瓣新书速递 | Scrapy + meta 传参 | MySQL |
| 网易新闻 | Scrapy + Selenium | 自定义 item |
| 腾讯新闻（多进程） | multiprocessing + jsonpath | Excel(openpyxl) |
| 腾讯新闻（多线程） | threading + jsonpath | Excel(openpyxl) |
| 携程景点 | Scrapy POST + jsonpath | 分类存储 |
| 比亚迪经销商 | Scrapy POST + jsonpath | 自定义 item |
| books.toscrape | CrawlSpider + scrapy-redis | Redis |
| Django+ES 搜索引擎 | Scrapy + ES + Django | Elasticsearch |

> **核心要点：** 前 8 个项目属于「Scrapy + 多任务」实战，最后一个是「Django + ES」检索展示项目。每个项目按「说明 + 技术栈 + 关键流程」展开。

## 18.2 链家租房爬虫

**说明：** Scrapy 基础入门项目，抓取链家租房列表页的标题、价格与链接。

**技术栈：** Scrapy、XPath、item 建模、pipeline 存 JSON。

**关键流程：**

```python
import scrapy

class LianjiaSpider(scrapy.Spider):
    name = "lianjia"
    allowed_domains = ["lianjia.com"]
    start_urls = ["https://cs.lianjia.com/zufang/"]

    def parse(self, response):
        titles = response.xpath('//div[@class="content__list--item"]/a/@title').getall()
        prices = response.xpath('//span[@class="content__list--item-price"]/em/text()').getall()
        links = response.xpath('//div[@class="content__list--item"]/a/@href').getall()
        for t, p, l in zip(titles, prices, links):
            yield {"title": t, "price": p, "link": response.urljoin(l)}
```

> **核心要点：** 用 `response.xpath(...).getall()` 提取列表，再用 `zip()` 把标题、价格、链接打包成一条条记录；item 建模后交给 pipeline 存 JSON。

## 18.3 豆瓣新书速递爬虫

**说明：** 列表页提取概要，翻页进详情页回填内容，跨页传参用 `meta`。

**技术栈：** Scrapy、翻页、`meta` 传参、pymysql 存 MySQL。

**关键流程：**

```python
import scrapy

class DoubanSpider(scrapy.Spider):
    name = "douban"
    allowed_domains = ["douban.com"]
    start_urls = ["https://book.douban.com/latest"]

    def parse(self, response):
        items = []
        for one in response.xpath('//li[@class="media clearfix"]'):
            item = {
                "title": one.xpath('.//h2/a/text()').get(),
                "url": one.xpath('.//h2/a/@href').get(),
            }
            items.append(item)
            yield scrapy.Request(
                url=response.urljoin(item["url"]),
                callback=self.parse_detail,
                meta={"items": item},   # meta 跨解析函数传数据
            )

    def parse_detail(self, response):
        item = response.meta["items"]
        item["content"] = "".join(response.xpath('//div[@class="intro"]/p/text()').getall())
        yield item
```

> **勘误：** 课件里 `item['content'] = contents.strip()` 中 `contents` 是 `.extract()` 返回的**列表**，直接 `.strip()` 会抛 `AttributeError`。应写成 `contents[0].strip()` 或 `''.join(contents).strip()`（如上例）。另外 `meta={'items': items}` 复用已 yield 的同一 item 对象，可用但需留意引用共享。

**pipeline 存 MySQL：**

```python
import pymysql

class MySQLPipeline:
    def open_spider(self, spider):
        self.db = pymysql.connect(user="root", password="<密码>",
                                  database="<库名>", charset="utf8mb4")
        self.cursor = self.db.cursor()
    def process_item(self, item, spider):
        d = dict(item)
        self.cursor.execute(
            "insert into book(title,content) values(%s,%s)",
            [d.get("title"), d.get("content")],
        )
        self.db.commit()
        return item
    def close_spider(self, spider):
        self.cursor.close()
        self.db.close()
```

> **注意：** 建议用 `charset='utf8mb4'` 以完整支持 Unicode（含 emoji）；`close_spider` 里除了 `db.close()`，还应 `cursor.close()`。

## 18.4 网易新闻 scrapy+selenium 项目

**说明：** 抓取网易新闻四大板块（国内/国际/军事/航空）的新闻，用 Selenium 处理动态加载。

**技术栈：** Scrapy、Selenium、下载中间件拦截、两类 item（板块 Item + 详情 Item）。

**关键流程：**

- items 定义「板块 Item」「详情 Item」两类；
- 按 index 提取四大板块的新闻链接；
- 下载中间件 `process_response` 拦截目标 URL，用无头浏览器渲染动态数据，再篡改成 `HtmlResponse` 返回。

```python
# middlewares.py
from scrapy.http import HtmlResponse

class NewsSpiderDownloaderMiddleware:
    def process_response(self, request, response, spider):
        if request.url in spider.module_urls:      # 只拦截动态页面
            browse = spider.browse
            browse.get(request.url)
            browse.execute_script("window.scrollTo(0, document.body.scrollHeight)")
            page_text = browse.page_source         # 渲染后的 HTML
            return HtmlResponse(url=request.url, body=page_text,
                                encoding="utf-8", request=request)
        return response                            # 其他请求原样返回
```

> **勘误：** 课件中 `for one_url in self.url: yield scrapy.Request(...)` 写在 `for index in index_list` **内部**，导致每轮都重复 yield 之前已积累的 url，应把第二个 for 移到外层循环之后。另外 `detail_Item['title'] = titles`（titles 是列表）存的是 list，应取 `titles[0]` 或 join。

## 18.5 腾讯新闻（多进程版）

**说明：** 用多进程采集腾讯新闻热榜，`jsonpath` 解析 `$..title` / `$..url`，存 Excel。

**技术栈：** `multiprocessing.Pool`、`Manager.Queue`、jsonpath、openpyxl。

**关键流程：**

```python
import json
import requests
from jsonpath import jsonpath
from openpyxl import Workbook
from multiprocessing import Pool, Manager

def down(page, q):
    url = f"https://r.inews.qq.com/gw/event/hot_ranking_list?page_num={page}"
    data = requests.get(url, headers={"User-Agent": "<UA>"}).json()
    titles = jsonpath(data, "$..title") or []
    urls = jsonpath(data, "$..url") or []
    for t, u in zip(titles, urls):
        q.put([t, u])

if __name__ == "__main__":
    m = Manager()
    q = m.Queue()                        # 跨进程共享队列
    pool = Pool(4)
    for page in range(1, 6):
        pool.apply_async(down, args=(page, q))
    pool.close()
    pool.join()

    wb = Workbook(); ws = wb.active
    ws.append(["标题", "链接"])
    while not q.empty():
        ws.append(q.get())
    wb.save("tencent.xlsx")
```

> **勘误：** ① 课件 `from openpyxl import workbook` 是非标准写法，标准写法是 `from openpyxl import Workbook`。② 课件定义了整段随机 UA 列表却从未使用，实际 `headers` 用固定 UA，应删除或真正 `random.choice` 使用。③ `for ... else: print('翻页结束')` 的 `else` 在 for 正常结束（无 break）时必执行，属对 for-else 语义误用。④ `while not q.empty()` 在多进程队列下不可靠，建议用哨兵值或 `q.get(timeout=...)`。

## 18.6 腾讯新闻（多线程版）

**说明：** 同一热榜数据改用多线程分页段并发抓取，逻辑与多进程版类似。

**技术栈：** `threading.Thread`、jsonpath、openpyxl。

**关键流程：**

```python
import threading
import requests
from jsonpath import jsonpath
from openpyxl import Workbook

rows = []
lock = threading.Lock()

def down(page):
    url = f"https://r.inews.qq.com/gw/event/hot_ranking_list?page_num={page}"
    data = requests.get(url, headers={"User-Agent": "<UA>"}).json()
    titles = jsonpath(data, "$..title") or []
    urls = jsonpath(data, "$..url") or []
    with lock:
        rows.extend(zip(titles, urls))

threads = [threading.Thread(target=down, args=(p,)) for p in range(1, 6)]
for t in threads: t.start()
for t in threads: t.join()

wb = Workbook(); ws = wb.active
ws.append(["标题", "链接"])
for r in rows:
    ws.append(r)
wb.save("tencent_thread.xlsx")
```

> **勘误：** 课件多线程版里多个线程并发往同一个 `ws`/`wb`（openpyxl 对象）`append` 并 `save`，存在数据竞争/覆盖风险。应像多进程版那样先收集到共享结构（如上例的 `rows` + 锁），再由单线程主进程统一写 Excel。

## 18.7 携程景点 POST 爬虫

**说明：** 携程景点接口是 POST + JSON，需重写 `start_requests` 发 POST，`jsonpath` 解析城市/景区，两个 item 类 + 两条管道分类存储，`cb_kwargs` 传参翻页。

**技术栈：** Scrapy POST、重写 `start_requests`、jsonpath、`cb_kwargs`、分类管道。

**关键流程：**

```python
import json
import scrapy
from jsonpath import jsonpath

class XcSpider(scrapy.Spider):
    name = "xc_spider"
    url = "https://m.ctrip.com/restapi/soa2/<接口路径>"

    def start_requests(self):              # 覆盖：自定义 POST 起始请求
        yield scrapy.Request(
            url=self.url,
            method="POST",
            body=json.dumps({"cityId": "<城市ID>", "pageIndex": 1}),
            headers={"User-Agent": "<移动端UA>"},
            callback=self.parse_jq_data,
            dont_filter=True,
        )

    def parse_jq_data(self, response):
        data = response.json()
        names = jsonpath(data, "$.attractionList[*].cardStr") or []
        for name in names:
            poi_name = jsonpath(name, "$..poiName")  # 从每个 cardStr 里解析
            if poi_name:
                yield {"name": poi_name[0]}
```

> **勘误：** ① 课件 `name_list.append(poiName)` 应追加解析出的 `poi_name`，而非整个 cardStr 循环变量。② 注释「`start_requests` 方法名是默认的不能修改」表述不准：`start_requests` 是 Scrapy 约定的**可覆盖**方法，覆盖它正是为了自定义起始请求。

**分类存储：** 定义两个 item 类（如城市 Item、景点 Item），pipeline 里用 `isinstance(item, XxxItem)` 判断走不同文件/不同管道。

```python
class XcPipeline:
    def process_item(self, item, spider):
        if isinstance(item, CityItem):
            # 存城市文件
            ...
        elif isinstance(item, ViewpointItem):
            # 存景点文件
            ...
        return item
```

## 18.8 比亚迪经销商 POST 爬虫

**说明：** 比亚迪经销商查询接口为 POST，`scrapy.Request(method='POST', body=json.dumps(payload))` 发请求，jsonpath 解析地址/电话。

**技术栈：** Scrapy POST、jsonpath。

**关键流程：**

```python
import json
import scrapy
from jsonpath import jsonpath

class BydSpider(scrapy.Spider):
    name = "byd_spider"
    allowed_domains = ["bydauto.com.cn"]
    url = "https://www.bydauto.com.cn/api/comom/search_join_shop"
    payload = {"type": 2, "province": 430000, "city": 430100}

    def start_requests(self):
        yield scrapy.Request(
            url=self.url,
            method="POST",
            body=json.dumps(self.payload),
            callback=self.parse,
        )

    def parse(self, response):
        data = response.json()
        addrs = jsonpath(data, "$..address") or []
        tels = jsonpath(data, "$..tel") or []
        for a, t in zip(addrs, tels):
            yield {"address": a, "tel": t}
```

## 18.9 books.toscrape 分布式爬虫

**说明：** 用 CrawlSpider + Rule + LinkExtractor 做分页跟随与详情解析，再配 scrapy-redis 实现分布式，管道存 Redis。

**技术栈：** CrawlSpider、Rule、LinkExtractor、scrapy-redis。

**关键流程：**

```python
from scrapy.linkextractors import LinkExtractor
from scrapy.spiders import CrawlSpider, Rule

class BookSpider(CrawlSpider):
    name = "book"
    allowed_domains = ["toscrape.com"]
    start_urls = ["https://books.toscrape.com/"]
    rules = [
        Rule(LinkExtractor(restrict_xpaths=('//li[@class="next"]/a')), follow=True),
        Rule(LinkExtractor(restrict_css=('.product_pod')), callback="parse_book"),
    ]

    def parse_book(self, response):
        yield {
            "name": response.css("h1::text").get(),
            "price": response.css(".price_color::text").get(),
        }
```

**分布式改造：** 把 `start_urls` 换成 `redis_key`，settings 启用 scrapy-redis 组件（详见第 14 章）。

```python
# settings.py
DUPEFILTER_CLASS = "scrapy_redis.dupefilter.RFPDupeFilter"
SCHEDULER = "scrapy_redis.scheduler.Scheduler"
SCHEDULER_PERSIST = True
ITEM_PIPELINES = {"scrapy_redis.pipelines.RedisPipeline": 400}
REDIS_URL = "redis://127.0.0.1:6379"

# 爬虫中：去掉 start_urls，改用 redis_key
redis_key = "book:start_urls"
```

> **勘误：** 课件里 `example.py` 的类名 `DmozSpider` 是 Scrapy 官方 tutorial 的残留名，与项目（book_spider）不符，应改名为 `BookSpider`（统一为 `dmoz` 也应写成 `Dmoz`）。

## 18.10 Django + Elasticsearch 搜索引擎项目

**说明：** 这是把「爬虫抓取 → ES 索引 → Web 搜索」串起来的完整项目：Scrapy 爬携程景点 → pipeline 调 ES 工具类写索引 → Kibana 查看 → Django 提供搜索页面。

### 18.10.1 整体数据流程

```
Scrapy 爬取携程景点 → pipeline 调用 Estools 写 ES → Kibana 查看数据 → Django 搜索引擎展示
```

### 18.10.2 es_tools 封装类

```python
from elasticsearch import Elasticsearch

class Estools:
    def __init__(self):
        self.es = Elasticsearch("http://127.0.0.1:9200")
        print("ok" if self.es.ping() else "fail")

    def creat_es_index(self, body):
        # 建索引 + mappings（含 ik_max_word 分词）
        return self.es.indices.create(index="es_data", body=body)

    def save_data(self, body):
        return self.es.index(index="es_data", body=body)

    def close(self):
        self.es.close()
```

> **勘误：** `insert_data(self, body, index='xcxc', id=None)` 声明了 `id` 参数但内部 `es.index(index=index, body=body)` 未使用 `id`，属冗余参数。另注意这里 ES 客户端是 7.x 语法（`body=`），8.x 需改 `document=`。

### 18.10.3 Scrapy pipeline 接入 ES

```python
from es_tools.esTools import Estools
from xcc.items import ViewpointItem

class ViewpointPipeline:
    def __init__(self):
        self.es = Estools()

    def process_item(self, item, spider):
        if isinstance(item, ViewpointItem):   # 只处理景点 Item
            self.es.save_data(dict(item))
        return item

    def close_spider(self, spider):
        self.es.close()
```

> **注意：** 需在 settings 中开启该 pipeline，才会在抓取时写 ES。另外 `xc/items.py` 里 `XcItem` 是空的（仅 `pass`），携程案例实际用的是 `xcc/items.py` 的 `ViewpointItem`，勿混淆 `xc` 与 `xcc` 两个项目。

### 18.10.4 分布式启动脚本 start_host.py

```python
import redis
import json

r = redis.Redis()
# 推送 JSON 起始任务；key 必须与爬虫 redis_key 一致
r.lpush("<redis_key>", json.dumps({"url": "https://m.ctrip.com/restapi/..."}))
```

> **勘误：** `r.lpush('ct:start_url', ...)` 的 key 名 `ct:start_url`（单数）与 RedisSpider 默认 `redis_key = "<name>:start_urls"`（复数）不一致，需在爬虫里显式设置 `redis_key = 'ct:start_url'`。
