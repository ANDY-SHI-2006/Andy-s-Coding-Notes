# 19 面试与求职

学完技术只是第一步，把能力"卖"给面试官才是关键。本章从四个维度收尾：怎么写一份能过 HR 初筛的简历，Python 与爬虫方向的高频面试题该怎么答，三类笔试编程真题（微博指数 / Shopee / 京东联盟）怎么做，以及正则 / XPath / BeautifulSoup 的速查对照表。

## 19.1 简历撰写

### 19.1.1 HR 筛选视角与简历构成

HR 每份简历只看几十秒，简历本质是"请面试官给我一次面试机会"的广告。技术岗简历通常包含：

| 模块 | 内容 |
|---|---|
| 基本信息 | 姓名、联系方式、求职意向、学历 |
| 教育背景 | 学校、专业、时间、主修课程 |
| 技能清单 | 编程语言、框架、工具，按熟练度分级 |
| 项目经历 | 项目名、职责、技术栈、量化成果 |
| 实习/竞赛 | 相关经历、奖项 |
| 自我评价 | 简洁的定位一句话 |

> **核心要点：** 邮箱投递时标题要自报家门——"岗位 + 姓名 + 学历/经验"，例如 `Python 爬虫工程师-张三-本科-3年`，让 HR 一眼判断是否匹配。

### 19.1.2 撰写原则

- **简洁明了**：一页为主，关键词突出。
- **准确可信**：不夸大，写得出就要经得起追问。
- **目标明确**：针对岗位定制，把最相关的经历放最前。
- **优势前置**：把亮点（项目、成果、技术栈）放在显眼位置。

投递分纸质与网络：纸质用于现场招聘会，排版规整；网络投递（招聘网站、内推、邮箱）注意格式与标题。

## 19.2 面试理论题：Python 基础

### 19.2.1 高频概念

| 问题 | 答题要点 |
|---|---|
| 垃圾回收（GC） | 以**引用计数**为主，`del` 或引用归零即回收；**标记-清除**处理循环引用；**分代回收**提升效率 |
| 深拷贝 vs 浅拷贝 | `copy()` 浅拷贝只复制外层对象；`deepcopy()` 递归复制所有层级 |
| `==` vs `is` | `==` 比较**值**是否相等；`is` 比较**身份**（是否同一对象，即 id 相同） |
| 迭代器 vs 生成器 | 迭代器实现 `__iter__`/`__next__`；生成器是含 `yield` 的函数，惰性取值、省内存 |
| 多线程 vs 多进程 | 线程共享内存、受 GIL 限制；进程隔离、可利用多核 |

### 19.2.2 高频代码题

单例模式（保证全局只有一个实例）：

```python
class Singleton:
    _instance = None
    def __new__(cls, *args, **kwargs):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance
```

装饰器与闭包：

```python
def log(func):                       # 装饰器：闭包包裹原函数
    def wrapper(*args, **kwargs):
        print(f"call {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@log
def add(a, b):
    return a + b
```

生成器：

```python
def gen(n):
    for i in range(n):
        yield i * i                # yield 使函数成为生成器
```

> **核心要点：** GIL 是 CPython 解释器锁，导致同一进程内多线程无法真正并行执行 CPU 密集任务，但 IO 密集（如爬虫网络等待）仍可用多线程提速；多进程或协程是绕开 GIL 的常见选择。

## 19.3 面试理论题：爬虫方向

| 问题 | 答题要点 |
|---|---|
| 常用请求方式 | GET / POST / PUT / DELETE / HEAD / OPTIONS |
| GET 与 POST 区别 | GET 参数在 URL、有长度限制、可缓存、幂等；POST 参数在请求体、无长度限制、用于写操作 |
| TCP 三次握手 | SYN → SYN+ACK → ACK，确认双方收发能力 |
| TCP 四次挥手 | FIN → ACK → FIN → ACK，全双工关闭 |
| 完整 HTTP 请求 | 请求行（方法+路径+版本）+ 请求头 + 空行 + 请求体 |
| 常见反爬 | UA 检测、IP 频率、验证码、字体反爬、JS 加密、登录态 |
| Scrapy 运行流程 | 引擎 → 调度器 → 下载器 → 爬虫 → 管道，中间件贯穿 |
| 数据去重 | `set`、布隆过滤器、Scrapy 的 `request_fingerprint` |
| 大数据量分布式 | Scrapy-Redis：共享请求队列与去重集合 |
| 状态码 | 200 成功、301/302 重定向、403 拒绝、404 不存在、500 服务器错误 |

> **核心要点：** 面试官要的不是背诵，而是"你做过什么 → 遇到什么坑 → 怎么解决"。把每个知识点关联到第 09、16、17 章讲过的反爬与逆向手段，答案会立体很多。

## 19.4 笔试真题一：微博指数

题目：POST 请求某指数接口，用 jsonpath 提取 `x`（日期）与 `s`（指数值），输出三列 CSV。

```python
import csv, requests
from jsonpath import jsonpath

url = '<指数接口>'                 # 脱敏
headers = {'User-Agent': '<UA>', 'Referer': '<来源>'}
data = {'keyword': '病毒'}         # 查询关键词

resp = requests.post(url, headers=headers, data=data).json()
dates = jsonpath(resp, '$..x')    # 日期列表
exps  = jsonpath(resp, '$..s')    # 指数列表

with open('weibo.csv', 'w', encoding='gbk', newline='') as f:
    w = csv.writer(f)
    w.writerow(["关键字", "日期", "指数值"])
    for d, e in zip(dates[0], exps[0]):
        w.writerow(["病毒", d, e])
```

> **勘误：** 源课件 `open(..., newline='' "")` 多了个 `""` 导致语法错误，正确写法是 `open(..., newline='')`。
>
> **核心要点：** `jsonpath(..., '$..x')` 返回列表，取 `[0]` 才是数据行；`newline=''` 避免 Windows 下 CSV 出现多余空行。

## 19.5 笔试真题二：Shopee 店铺商品

题目：用 jsonpath 提取 `name` / `itemid` / `price` / `sold` / `historical_sold`，`newest` 参数 0/30/60 翻页，输出五列 CSV。

```python
import csv, requests
from jsonpath import jsonpath

def fetch(newest=0):
    url = '<店铺接口>'
    params = {'newest': newest, '<其他参数>': '<值>'}
    resp = requests.get(url, params=params, headers=headers).json()
    names = jsonpath(resp, '$..name')
    itemids = jsonpath(resp, '$..itemid')
    prices = jsonpath(resp, '$..price')
    solds = jsonpath(resp, '$..sold')
    hist = jsonpath(resp, '$..historical_sold')
    return zip(names[0], itemids[0], prices[0], solds[0], hist[0])

with open('shopee.csv', 'w', encoding='utf-8-sig', newline='') as f:
    w = csv.writer(f)
    w.writerow(['商品名称', 'itemid', '价格', '销量', '历史销量'])   # 表头只写一次
    for newest in (0, 30, 60):
        for row in fetch(newest):
            w.writerow(row)
```

> **勘误：** 源课件 `save_data()` 每次调用都 `writerow` 写表头，翻页时表头重复，表头应只在初始化时写一次；`newline='' ""` 同理应为 `newline=''`。

## 19.6 笔试真题三：京东联盟

题目：用 Selenium 渲染页面，`etree.HTML` + XPath 取商品链接，再用正则提取商品 id。

```python
from selenium import webdriver
from lxml import etree
import re

driver = webdriver.Chrome()
driver.get('<页面地址>')

tree = etree.HTML(driver.page_source)          # 把渲染后的 HTML 交给 etree
links = tree.xpath('//div[@class="item"]/a/@href')   # 商品链接

ids = []
for link in links:
    m = re.search(r'(\d+)', link)              # 从链接里提取商品 id
    if m:
        ids.append(m.group(1))

driver.quit()
print(ids)
```

> **核心要点：** 京东等站商品数据由 JS 渲染，`requests` 拿不到完整 DOM，需要 Selenium 渲染后再 `etree.HTML` 解析；商品 id 藏在链接里，用正则提取。

## 19.7 高频题型速查：正则 / XPath / BeautifulSoup

笔试常考"给你一段 HTML，用三种方式各取一次"，下面的对照表覆盖最常见操作。

| 目的 | 正则（re） | XPath（lxml） | BeautifulSoup |
|---|---|---|---|
| 取所有标签 | `re.findall(r'<div.*?>', html)` | `//div` | `soup.find_all('div')` |
| 按 class 定位 | `re.search(r'class="item"')` | `//div[@class="item"]` | `soup.select('div.item')` |
| 取属性 | `re.search(r'href="(.*?)"', s)` | `//a/@href` | `a.get('href')` |
| 取文本 | `re.search(r'>(.*?)<', s)` | `//div/text()` | `a.get_text()` |
| 按条件过滤 | `re.search(r'item.*', s)` | `//div[contains(@class,"item")]` | `soup.select('div[class*="item"]')` |
| 取第 N 个 | `re.findall(...)[n]` | `(//div)[n]` 或 `//div[n]` | `soup.find_all('div')[n]` |

常用语法速记：

| 工具 | 常用写法 |
|---|---|
| 正则 | `.` 任意字符、`* + ?` 重复、`\d \w \s` 数字/单词/空白、`^ $` 起止、`( )` 分组、`(?P<name>...)` 命名分组 |
| XPath | `//` 任意层级、`@attr` 属性、`text()` 文本、`contains()` 包含、`[n]` 位置、`..` 父节点、`ancestor::`/`following-sibling::` 轴 |
| BeautifulSoup | `find` / `find_all` / `select`、`.text`、`.get('attr')`、CSS 选择器 `.class` `#id` `div > a` |

**记忆口诀**

- **简历四原则：** 简洁、可信、目标明确、优势前置。
- **Python 高频：** GC 引用计数、深浅拷贝、迭代器/生成器、`==` vs `is`、单例、GIL。
- **爬虫高频：** 三次握手四次挥手、get/post、反爬手段、Scrapy 流程、去重、状态码。
- **笔试套路：** requests + jsonpath 提字段 + csv 三/五列，Selenium + etree + re 提链接。
- **三语法对照：** 正则 `re.search/findall`、XPath `//div[@class]`、bs4 `select/find_all`。
