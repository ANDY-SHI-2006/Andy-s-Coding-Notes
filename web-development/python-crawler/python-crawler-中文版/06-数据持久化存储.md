# 6 数据持久化存储

爬虫抓到的数据如果只打印在控制台，程序一退出就全部丢失。本章讲解如何把数据持久化保存下来：先是最简单的文件与 CSV 写入，再进入关系型数据库 MySQL（通过 `pymysql` 操作），最后用 `DBUtils` 连接池封装成可复用的 `SQLHelper`，并以 `loguru` 日志作为"运行信息持久化"的收尾。

## 6.1 文件读写基础

Python 内置的 `open()` 函数负责打开文件，返回一个文件对象，之后可以读、写、追加，用完要 `close()` 或使用 `with` 语句自动关闭。

### 6.1.1 `open()` 与打开模式

```python
# 完整签名（常用参数）
open(file, mode='r', buffering=-1, encoding=None, newline=None)
```

- `file`：文件路径。
- `mode`：打开模式，见下表。
- `encoding`：字符编码，如 `utf-8`、`gbk`。读取网页抓到的内容时常见 `gbk` 或 `utf-8`。
- `buffering`：缓冲策略，`0` 不缓冲、`1` 行缓冲、大于 `1` 为缓冲区字节数、默认 `-1` 由系统决定。

| 模式 | 含义 | 指针位置 |
|---|---|---|
| `r` | 只读（文件必须存在） | 开头 |
| `w` | 只写，覆盖已有内容 | 开头 |
| `a` | 追加，内容写到末尾 | 末尾 |
| `x` | 新建并只写，文件已存在则报错 | 开头 |
| `b` | 二进制模式（如 `rb`、`wb`） | 同主模式 |
| `t` | 文本模式（默认） | 同主模式 |
| `r+` | 读写，指针在开头 | 开头 |
| `w+` | 读写，先清空再写 | 开头 |
| `a+` | 读写，指针在末尾 | 末尾 |

> **核心要点：** 记法：`r` 读、`w` 写（覆盖）、`a` 追加，加 `+` 变"可读写"。`r`/`w` 的指针在文件开头，`a` 的指针在末尾。

```python
# with 语句自动关闭文件，无需手动 close()
with open('data.txt', 'w', encoding='utf-8') as f:
    f.write('hello\n')
```

### 6.1.2 文件读取

```python
with open('data.txt', 'r', encoding='utf-8') as f:
    content = f.read()          # 读整个文件，可传 size 限制字节数
    line = f.readline()         # 读一行（含换行符），EOF 返回空串
    lines = f.readlines()       # 读所有行，返回每行组成的列表
```

> **注意：** 文件指针会随读取向后移动。`read()` 读完后指针已在末尾，紧接着 `readlines()` 只会得到空列表。要重复读取可用 `f.seek(0)` 把指针移回开头。

### 6.1.3 文件写入

```python
lines = ['第一行\n', '第二行\n']

with open('out.txt', 'w', encoding='utf-8') as f:
    f.write('单条字符串\n')      # write(str)：写一个字符串
    f.writelines(lines)         # writelines(iterable)：写多行，参数为列表/元组
```

> **注意：** `writelines()` 不会自动加换行符，需要你自己在每行末尾带上 `\n`。

## 6.2 CSV 文件持久化

CSV 是表格数据的纯文本格式，可用 `csv` 标准库写入：

```python
import csv

# newline='' 防止 Windows 下每行之间多出空行
with open('data.csv', 'w', newline='', encoding='utf-8') as f:
    w = csv.writer(f)
    w.writerow(['name', 'age'])            # 写单行（列表）
    w.writerows([('tom', 18), ('jerry', 20)])  # 写多行（列表套元组）
```

- `csv.writer(f)` 创建写入器。
- `writer.writerow(list)` 写一行。
- `writer.writerows(list_of_tuples)` 写多行。

> **核心要点：** `newline=''` 是关键参数，否则生成的 CSV 每两行之间会空一行。

## 6.3 用 pymysql 操作 MySQL

CSV 适合小批量简单数据；数据量一大、要查询更新，就需要关系型数据库。`pymysql` 是纯 Python 的 MySQL 驱动。

### 6.3.1 连接数据库与游标

```python
import pymysql
from pymysql import cursors

conn = pymysql.connect(
    host='127.0.0.1',
    port=3306,
    user='root',
    password='<你的数据库密码>',
    database='spider',
    charset='utf8mb4',          # 不能写 'utf-8'（带连字符）
)
```

> **勘误：** pymysql 的 `charset` 参数不能写成 `utf-8`（带连字符），会报错。正确写法是 `utf8`；推荐 `utf8mb4`，可完整支持 emoji 等四字节字符。

游标（cursor）用于执行 SQL 并取结果：

```python
cur = conn.cursor()                              # 默认：结果以元组返回
cur = conn.cursor(cursor=cursors.DictCursor)     # 结果以字典返回，key 为列名
```

### 6.3.2 建表（DDL）

```python
with conn.cursor() as cur:
    sql = """
    CREATE TABLE IF NOT EXISTS userinfo (
        id INT AUTO_INCREMENT PRIMARY KEY,
        user VARCHAR(32) NOT NULL,
        pwd  VARCHAR(64) NOT NULL
    ) ENGINE=innodb DEFAULT CHARSET=utf8mb4;
    """
    cur.execute(sql)
    conn.commit()
```

- `cursor.execute(sql)` 执行一条 SQL。
- DDL（建表）也是写操作，通常需要 `conn.commit()` 提交。
- `ENGINE=innodb` 指定存储引擎，`DEFAULT CHARSET` 指定表字符集。

### 6.3.3 增：插入数据

单条插入用 `execute(sql, params)`，参数用 `%s` 占位（注意不是 `%d` 也不是 `?`）：

```python
name, pwd = 'tom', '123456'
with conn.cursor() as cur:
    cur.execute('insert into userinfo(user, pwd) values (%s, %s)', [name, pwd])
    conn.commit()
    last_id = cur.lastrowid    # 获取本次自增主键 ID
print('新插入记录 ID:', last_id)
```

多条插入用 `executemany(sql, data)`：

```python
data = [('a', '111'), ('b', '222'), ('c', '333')]
with conn.cursor() as cur:
    cur.executemany('insert into userinfo(user, pwd) values (%s, %s)', data)
    conn.commit()
```

> **核心要点：** 所有写操作（增/删/改）都必须 `conn.commit()` 才会真正落库；忘了 commit 数据不会保存。查询（SELECT）则不需要 commit。

### 6.3.4 删、改、查

```python
# 改（update）
sql = "update userinfo set pwd=%s where user=%s;"
with conn.cursor() as cur:
    cur.execute(sql, ['newpwd', 'tom'])
    conn.commit()

# 删（delete）
with conn.cursor() as cur:
    cur.execute('delete from userinfo where user=%s', ['a'])
    conn.commit()

# 查（select）
with conn.cursor(cursor=cursors.DictCursor) as cur:
    cur.execute('select * from userinfo')
    one  = cur.fetchone()    # 取一行
    some = cur.fetchmany(3)  # 取最多 3 行
    all_ = cur.fetchall()    # 取全部
```

> **勘误：** 源课件"更新数据"章节贴出的其实是 `delete` 语句（复制粘贴错误）。更新应使用 `update ... set ... where ...` 语句，如上例。

### 6.3.5 游标移动

`cursor.scroll(value, mode)` 用于在结果集中移动游标：

```python
with conn.cursor() as cur:
    cur.execute('select * from userinfo')
    print(cur.fetchone())              # 读第 1 行
    cur.scroll(1, mode='absolute')     # 绝对移动：跳到第 1 行（从 0 开始计）
    cur.scroll(1, mode='relative')     # 相对移动：从当前位置向后 1 行
```

- `mode='absolute'`：移动到绝对位置（`value` 为索引）。
- `mode='relative'`：相对当前位置移动 `value` 行。

> **勘误：** 源课件 `cursor.scroll(1, mode="relative"` 少了一个右括号，正确写法是 `cursor.scroll(1, mode="relative")`。

### 6.3.6 MySQL 命令行建库建表

在命令行里直接管理数据库：

```bash
# 登录（-p 后跟密码，或省略密码后回车交互输入）
mysql -h127.0.0.1 -uroot -p<你的数据库密码>

# 建库
create database spider charset utf8mb4;

# 使用库
use spider;

# 建表
create table userinfo (
    id int auto_increment primary key,
    user varchar(32) not null,
    pwd varchar(64) not null
) engine=innodb default charset=utf8mb4;
```

## 6.4 DBUtils 连接池与 SQLHelper 封装

频繁 `pymysql.connect()` 会反复建立/断开 TCP 连接，开销大。连接池预先维护一批连接，用完归还复用。`DBUtils` 的 `PooledDB` 是最常用的实现。

```python
import pymysql
from pymysql import cursors
from dbutils.pooled_db import PooledDB

pool = PooledDB(
    creator=pymysql,             # 使用 pymysql 作为底层驱动
    mincached=5,                 # 空闲时最少保留的连接数
    maxcached=30,                # 空闲时最多保留的连接数
    maxconnections=30,           # 允许的最大连接数
    blocking=True,               # 连接耗尽时阻塞等待，而非报错
    host='127.0.0.1',
    port=3306,
    user='root',
    password='<你的数据库密码>',
    database='spider',
    charset='utf8mb4',
    cursorclass=cursors.DictCursor,
    connect_timeout=15,
)

conn = pool.connection()   # 从池中取一个连接（不是新建）
# ... 使用 conn 执行 SQL ...
conn.close()               # 归还连接到池，而不是真正关闭
```

基于连接池封装一个 `SQLHelper`，统一 commit/rollback/归还连接：

```python
class SQLHelper:
    def __init__(self, pool):
        self.pool = pool

    def execute(self, sql, params=None, autoclose=True):
        conn = self.pool.connection()
        cursor = conn.cursor()
        try:
            if params:
                count = cursor.execute(sql, params)
            else:
                count = cursor.execute(sql)
            conn.commit()
            return conn, cursor, count
        except Exception:
            conn.rollback()
            raise
        finally:
            if autoclose:
                cursor.close()
                conn.close()    # 归还连接

    def query_all(self, sql, params=None):
        conn, cursor, _ = self.execute(sql, params)
        try:
            return cursor.fetchall()
        finally:
            cursor.close()
            conn.close()

    def query_one(self, sql, params=None):
        conn, cursor, _ = self.execute(sql, params)
        try:
            return cursor.fetchone()
        finally:
            cursor.close()
            conn.close()

    def insert_one(self, sql, params):
        conn, cursor, _ = self.execute(sql, params)
        last_id = cursor.lastrowid
        cursor.close()
        conn.close()
        return last_id

    def insert_many(self, sql, params):
        conn = self.pool.connection()
        cursor = conn.cursor()
        try:
            count = cursor.executemany(sql, params)
            conn.commit()
            return count
        except Exception:
            conn.rollback()
            raise
        finally:
            cursor.close()
            conn.close()

    def delete(self, sql, params):
        conn, cursor, count = self.execute(sql, params)
        cursor.close()
        conn.close()
        return count

    def update(self, sql, params):
        conn, cursor, count = self.execute(sql, params, autoclose=True)
        cursor.close()
        conn.close()
        return count
```

> **勘误：** 源 `db_toolbox.py` 的 `query_one`/`insert_one`/`delete` 解包顺序写反：`execute` 返回 `(conn, cursor, count)`，应写成 `conn, cursor, count = self.execute(...)`。此外 `update` 调用 `execute` 时应补 `autoclose=True` 以归还连接。

> **注意：** 源代码在 `with conn.cursor() as cursor` 内返回 cursor，`with` 退出后游标已关闭，返回的是失效游标。建议如上例显式管理游标生命周期：`execute` 后取结果，用完再 `cursor.close()`。

## 6.5 日志记录（loguru）

日志本质上也是"把运行信息持久化下来"，只是对象不是业务数据，而是程序的事件、状态与错误。日志按时间顺序和严重级别记录，可输出到控制台，也可持久化到文件。

### 6.5.1 为什么用日志而不是 print

| 对比 | `print` | 日志（logging/loguru） |
|---|---|---|
| 分级 | 无级别 | `DEBUG/INFO/WARNING/ERROR/CRITICAL` 五级 |
| 结构化 | 无，纯文本 | 自带时间戳、文件名、行号、颜色 |
| 持久化 | 进程退出即丢失 | 可写文件，长期可追溯 |
| 回溯 | 难以定位 | 自带堆栈，方便排错定位 |
| 管理 | 无 | 可按大小/时间自动分割 |

> **核心要点：** 日志的用途：记录运行轨迹、错误排查定位（时间/文件/行号/堆栈）、关键数据留存、长期可追溯、分级管理。它没有业务副作用，也便于团队统一格式。

### 6.5.2 loguru 五级日志

`loguru` 开箱即用，无需额外配置：

```python
from loguru import logger

logger.debug('调试信息，粒度最细')      # DEBUG：调试
logger.info('爬虫已启动')              # INFO：关键节点
logger.warning('请求被重定向，请留意')   # WARNING：潜在风险
logger.error('解析页面失败')            # ERROR：功能异常
logger.critical('数据库连接崩溃')       # CRITICAL：系统崩溃
```

| 级别 | 含义 | 适用场景 |
|---|---|---|
| `DEBUG` | 调试 | 排查问题时打印变量、中间状态 |
| `INFO` | 关键节点 | 记录程序正常流程（启动、完成） |
| `WARNING` | 潜在风险 | 异常但不影响主流程的情况 |
| `ERROR` | 功能异常 | 某功能失败，需关注 |
| `CRITICAL` | 系统崩溃 | 致命错误，程序无法继续 |

> **注意：** 级别从低到高：`DEBUG < INFO < WARNING < ERROR < CRITICAL`。级别越高越严重。默认 loguru 只输出 `INFO` 及以上，`DEBUG` 需显式启用。

## 记忆口诀

- **文件模式：** `r` 读、`w` 写覆盖、`a` 追加，加 `+` 变读写；`r`/`w` 指针在开头，`a` 在末尾。
- **读文件：** `read()` 全读、`readline()` 一行、`readlines()` 每行组成列表。
- **写文件：** `write(str)` 写字符串、`writelines(list)` 写多行；`writelines` 不自动加换行。
- **CSV：** `csv.writer` + `writerow`/`writerows`，`open(..., newline='')` 防空行。
- **pymysql：** `charset` 用 `utf8mb4`（不能写 `utf-8`）；写操作必须 `conn.commit()`。
- **增删改查：** 占位符 `%s`；`execute` 单条、`executemany` 多条；`lastrowid` 取自增 ID。
- **游标移动：** `scroll(value, mode='absolute'/'relative')`。
- **连接池：** `PooledDB` 维护连接，`pool.connection()` 取、`conn.close()` 归还。
- **日志：** 五级 `DEBUG/INFO/WARNING/ERROR/CRITICAL`，loguru 一行导入即用。
