# 10 图片验证码识别

第 9 章讲过，验证码是网站最常见的反爬手段之一。本章专门讲"如何识别"：从验证码的概念与作用出发，讲解四种处理方案，重点落在 OCR（Tesseract）、图像预处理、百度 OCR 云平台，并补充打码平台与人工识别。

## 10.1 验证码的概念与作用

CAPTCHA（Completely Automated Public Turing test to tell Computers and Humans Apart，全自动区分计算机和人的图灵测试）就是验证码的全称。它用人类容易识别、机器难以自动识别的图形/文字，把人和脚本区分开。

验证码的作用：

- 防止暴力破解密码。
- 防止刷票。
- 防止灌水、垃圾评论。
- 防止恶意刷页面、刷流量。

## 10.2 使用场景与处理方案

验证码通常在注册、登录、以及请求过于频繁时弹出。

图片验证码有四种处理方案：

| 方案 | 说明 | 适用 |
|---|---|---|
| 手动输入（`input`） | 弹出图片人工输入 | 少量、调试 |
| 图像识别引擎（OCR） | 程序自动识别文字 | 简单清晰的验证码 |
| 打码平台 | 付费平台人工打码 | 识别难度高、量大 |
| 人工识别 | 下载图片自己看 | 一次性任务 |

## 10.3 OCR 与 Tesseract

OCR（Optical Character Recognition，光学字符识别）指从图像文件中自动识别并提取文字。Python 生态中最常用的免费 OCR 引擎是 Google 的 Tesseract。

### 10.3.1 安装 Tesseract

不同系统的安装方式：

```bash
# macOS
brew install --with-training-tools tesseract

# Linux
sudo apt-get install tesseract-ocr
```

Windows 需要下载官方 exe 安装包（如 `tesseract-ocr-w64-setup`），安装后：

- 把安装目录（如 `C:\Program Files\Tesseract-OCR`）加入系统 PATH。
- 若使用中文语言包，需设置环境变量 `TESSDATA_PREFIX` 指向 tessdata 目录。

### 10.3.2 Python 库安装与 pytesseract 识别

```bash
pip install pillow        # PIL：图像处理
pip install pytesseract   # 调用 Tesseract 引擎
```

```python
from PIL import Image
import pytesseract

# 指定 Tesseract 引擎的实际安装路径（Windows 常见路径）
pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'

img = Image.open('captcha.png')          # 打开图片（必须传文件路径）
result = pytesseract.image_to_string(img)
print(result.strip())
```

> **勘误：** 源课件写成 `im = Image.open()`，缺少文件路径参数，会直接报 `TypeError`。正确写法是 `Image.open('captcha.png')`（或任意图片路径）。

## 10.4 图像预处理

验证码常带噪点和干扰线，直接 OCR 识别率低。先做灰度化、二值化、降噪，再交给 OCR，识别率大幅提升。

### 10.4.1 灰度化与二值化

```python
from PIL import Image

def binarizing(img, threshold=140):
    """灰度化后按阈值二值化：小于阈值置黑(0)，否则置白(255)"""
    img = img.convert('L')           # 转灰度图
    pixdata = img.load()
    w, h = img.size
    for y in range(h):
        for x in range(w):
            if pixdata[x, y] < threshold:
                pixdata[x, y] = 0      # 小于阈值 → 黑
            else:
                pixdata[x, y] = 255    # 大于等于阈值 → 白
    return img
```

> **勘误：** 源课件注释写"大于阈值的为黑色"，与代码相反。代码实际是 `if pixdata[x, y] < threshold: pixdata[x, y] = 0`，即**小于阈值为黑色**，注释应修正。

### 10.4.2 降噪（去孤立噪点）

```python
def depoint(img):
    """去掉孤立噪点：统计每个像素 8 邻域的白点，白点数过少则视为噪点置白"""
    pixdata = img.load()
    w, h = img.size
    for y in range(1, h - 1):
        for x in range(1, w - 1):
            count = 0
            # 统计 8 邻域（上下左右 + 四个对角）白点数量
            if pixdata[x, y - 1] > 245: count += 1
            if pixdata[x, y + 1] > 245: count += 1
            if pixdata[x - 1, y] > 245: count += 1
            if pixdata[x + 1, y] > 245: count += 1
            if pixdata[x - 1, y - 1] > 245: count += 1
            if pixdata[x - 1, y + 1] > 245: count += 1
            if pixdata[x + 1, y - 1] > 245: count += 1
            if pixdata[x + 1, y + 1] > 245: count += 1
            # 周围白点太少（孤立黑点）→ 置白去掉
            if count > 4:
                pixdata[x, y] = 255
    return img
```

完整预处理 + 识别流程：

```python
img = Image.open('captcha.png')
img = binarizing(img, threshold=140)   # 二值化
img = depoint(img)                     # 降噪
result = pytesseract.image_to_string(img)
print(result.strip())
```

## 10.5 百度 OCR 云平台

Tesseract 对复杂验证码（扭曲、粘连、干扰线）识别率有限。百度 OCR 提供云端识别接口，识别效果更好。使用前先在百度智能云控制台注册应用，生成 `AppKey`/`SecretKey`。

### 10.5.1 获取 access_token

百度云接口需要先用 `client_id`/`client_secret` 换取 `access_token`：

```python
import requests

token_url = 'https://aip.baidubce.com/oauth/2.0/token'
params = {
    'grant_type': 'client_credentials',
    'client_id': '<你的 client_id>',
    'client_secret': '<你的 client_secret>',
}
resp = requests.get(token_url, params=params, timeout=10)
access_token = resp.json().get('access_token')
```

> **注意：** `client_id`/`client_secret`/`access_token` 都是敏感凭据，脱敏后写 `<占位符>`，实际使用请从配置文件或环境变量读取，不要硬编码进提交的代码。

### 10.5.2 使用 AipOcr 识别

`baidu-aip` SDK 封装了 token 换取流程，直接传入三把钥匙即可：

```bash
pip install baidu-aip
```

```python
from aip import AipOcr

APP_ID = '<你的 APP_ID>'
API_KEY = '<你的 API_KEY>'
SECRET_KEY = '<你的 SECRET_KEY>'

client = AipOcr(APP_ID, API_KEY, SECRET_KEY)   # SDK 内部自动管理 token

with open('captcha.jpg', 'rb') as fp:
    image = fp.read()

options = {
    'detect_direction': 'true',      # 检测图片方向
    'language_type': 'CHN_ENG',      # 中英文混合
}
res = client.basicGeneral(image, options)

# 从返回结果中取识别文本
if 'words_result' in res and res['words_result']:
    code = res['words_result'][0]['words']
    print('识别结果:', code)
```

> **核心要点：** 百度 OCR 返回的是 JSON：`res['words_result']` 是列表，每项含 `words` 字段，第一个元素通常是验证码文本。若返回 `error_code`，需根据错误码排查（常见为 token 失效或配额不足）。

## 10.6 打码平台

对难度高、量大的验证码，可付费使用打码平台（人工打码）。如斐斐打码（`http://www.fateadm.com/`），把验证码图片上传后由人工识别并返回结果。平台一般提供 HTTP API 或 SDK，需注册账号并充值。

## 10.7 人工识别

最简单粗暴：把图片显示出来，自己看并输入。

```python
from PIL import Image

img = Image.open('captcha.png')
img.show()                    # 弹出图片窗口
code = input('请输入验证码: ')   # 人工输入
print('你输入的是:', code)
```

> **注意：** `input()` 会阻塞程序等待输入，仅适合调试和少量验证码，不适合大规模自动化。

## 10.8 常见报错处理

| 报错 | 原因 | 处理 |
|---|---|---|
| `TesseractNotFoundError` | 找不到 Tesseract 引擎 | 设置 `pytesseract.pytesseract.tesseract_cmd` 指向实际安装路径 |
| `TypeError: open() missing required argument` | `Image.open()` 没传文件路径 | 传入图片路径 `Image.open('captcha.png')` |
| 识别结果乱码/为空 | 图片未预处理或语言包缺失 | 先二值化降噪；检查是否安装对应语言包 |

```python
import pytesseract
from pytesseract import TesseractNotFoundError

try:
    pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'
    result = pytesseract.image_to_string(img)
except TesseractNotFoundError:
    print('未找到 Tesseract，请检查安装路径并设置 tesseract_cmd')
```

> **核心要点：** `TesseractNotFoundError` 的根因是 Python 找不到 tesseract.exe。解决方法是把安装路径写进 `pytesseract.pytesseract.tesseract_cmd`，或把安装目录加入系统 PATH。

## 记忆口诀

- **CAPTCHA：** 全自动区分计算机和人的图灵测试；防暴力破解、刷票、灌水、刷页。
- **四种方案：** 手动 `input` / OCR（Tesseract）/ 打码平台 / 人工 `Image.show()`。
- **OCR 三步：** `Image.open('captcha.png')` → `image_to_string(img)` → `.strip()`。
- **预处理：** `convert('L')` 灰度 → 小于阈值置黑（二值化）→ 8 邻域统计去孤立噪点。
- **百度 OCR：** `AipOcr(APP_ID, API_KEY, SECRET_KEY)` + `basicGeneral(image, options)`，从 `words_result[0]['words']` 取文本。
- **报错：** `TesseractNotFoundError` → 设置 `tesseract_cmd`；`Image.open()` 必须传路径。
