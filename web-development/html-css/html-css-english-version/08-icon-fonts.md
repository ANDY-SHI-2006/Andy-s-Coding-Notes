# 8 Icon Fonts

Icon fonts are vector icons delivered as a custom font. Because each icon is a glyph, you can style it with `font-size`, `color`, `text-shadow`, and other typography properties just like regular text.

## 8.1 What Are Icon Fonts?

An icon font packages multiple icons into a single font file. The browser renders each icon as text, which gives you several advantages over bitmap images:

| Feature | How it works |
|---------|--------------|
| Scalable | Vector glyphs stay sharp at any size |
| Color control | Change color with `color` or `opacity` |
| Size control | Resize with `font-size` |
| Lightweight | One font file can contain hundreds of icons |
| CSS friendly | Hover states, transitions, and transforms work naturally |

> **Key idea:** Think of icons as characters. If you can style text, you can style icon fonts.

## 8.2 Icon Font Sources

The two most common sources used in the course are:

| Source | URL | Notes |
|--------|-----|-------|
| iconfont (Alibaba) | <https://www.iconfont.cn> | Large Chinese icon library; supports multi-color icons |
| IcoMoon | <https://icomoon.io> | Generator that turns selected SVGs into a custom font |

Both services follow the same general workflow: select icons, generate or download the font package, then include the CSS in your project.

## 8.3 Using an Icon Font

The full workflow looks like this:

1. Select the icons you need and add them to the project cart / library.
2. Generate or download the font code.
3. Unzip the package and copy the `fonts/` folder into your project.
4. Paste the provided `@font-face` and icon class CSS into your stylesheet (or link the bundled `iconfont.css`).
5. Add the icon class or the Unicode character to an HTML tag.
6. Set `font-family` to the font name declared in `@font-face`.

### 8.3.1 Include the Font Files

A typical icon font package contains a CSS file and a `fonts/` directory:

```css
/* iconfont.css generated by the service */
@font-face {
    font-family: 'iconfont';
    src: url('fonts/iconfont.woff2') format('woff2'),
         url('fonts/iconfont.woff') format('woff'),
         url('fonts/iconfont.ttf') format('truetype');
    font-weight: normal;
    font-style: normal;
    font-display: swap;
}

.iconfont {
    font-family: 'iconfont' !important;
    font-size: 16px;
    font-style: normal;
    -webkit-font-smoothing: antialiased;
    -moz-osx-font-smoothing: grayscale;
}
```

> **Path tip:** Make sure the `url(...)` paths in `@font-face` point to the actual location of your `fonts/` folder relative to the CSS file.

### 8.3.2 Use the Icons

Most icon fonts provide class-based usage:

```html
<!-- Use the generated class for the icon -->
<i class="iconfont icon-arrow-down"></i>
```

You can also use the raw Unicode character:

```html
<i class="iconfont">&#xe6b6;</i>
```

| Method | HTML | Use case |
|--------|------|----------|
| Class | `<i class="iconfont icon-arrow-down"></i>` | Recommended; readable and maintainable |
| Unicode | `<i class="iconfont">&#xe6b6;</i>` | Useful when you only have the code point |

```css
.iconfont {
    color: #333;
    font-size: 24px;
}

.iconfont:hover {
    color: #e74c3c;
}
```

## 8.4 Monochrome vs Multi-Color Icons

| Type | How it works | Limitations |
|------|--------------|-------------|
| Monochrome | Single color, controlled by `color` | Cannot display multiple colors |
| Multi-color | Uses color layers inside the font glyph | Requires newer font formats and browser support; harder to recolor with CSS |

> **Recommendation:** Use monochrome icons for UI controls so you can change colors with CSS. Reserve multi-color icons for logos or illustrations where exact brand colors matter.

## 8.5 Rotating Arrow Animation

Icon fonts work well with CSS transitions and transforms. A common pattern is a dropdown arrow that rotates when its menu opens.

```html
<span class="iconfont icon-arrow-down arrow"></span>
```

```css
.arrow {
    display: inline-block;
    transition: transform 0.3s ease;
}

/* Rotate 180 degrees when the parent is active/open */
.open .arrow {
    transform: rotate(180deg);
}
```

**Key points:**
- Use `display: inline-block` so `transform` applies correctly.
- Add `transition` to animate the rotation smoothly.
- Toggle a parent class (like `.open`) with JavaScript or a checkbox hack.

## 8.6 Icon Fonts vs CSS Sprites

Both techniques reduce HTTP requests, but they suit different situations.

| Aspect | Icon Font | CSS Sprite |
|--------|-----------|------------|
| Rendering | Vector, scales cleanly | Bitmap, can blur when scaled |
| Color | Easy to recolor with CSS | Fixed colors in the image |
| Animation | Works with `transform` / `transition` | Requires swapping background positions or images |
| Multi-color | Limited support | Natural, just include colors in the image |
| Accessibility | Can be confusing to screen readers if not marked up correctly | Image-based, needs `alt` text or hidden text |
| Fallback | Older browsers may not load font files | Works wherever images work |

> **When to choose what:** Use icon fonts for scalable, single-color UI icons. Use CSS sprites when you need exact multi-color graphics or must support very old browsers.

## 8.7 Best Practices

| Do | Don't |
|----|-------|
| Keep the font files in a dedicated `fonts/` folder | Hard-code absolute paths that break on different environments |
| Use semantic or descriptive class names | Rely only on Unicode codes without documentation |
| Provide a text fallback or `aria-label` for screen readers | Leave icon-only buttons without accessible labels |
| Prefer monochrome icons for interactive controls | Use multi-color icons when you need CSS color changes |
| Use `font-display: swap` to avoid invisible text during loading | Block page rendering while waiting for the icon font |

**Summary Mnemonic**
- **Icon fonts** = "Icons as text — style them with `font-size` and `color`."
