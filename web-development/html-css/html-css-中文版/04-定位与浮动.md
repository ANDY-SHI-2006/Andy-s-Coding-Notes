# 4 定位与浮动

控制元素在页面上的位置是 CSS 最重要的任务之一。本章介绍背景样式、float 机制以及五种定位模式。

## 4.1 背景样式

### 4.1.1 背景属性

```css
.box {
    background-color: #f0f0f0;              /* 纯色 */
    background-image: url("bg.jpg");         /* 图片 */
    background-repeat: no-repeat;            /* repeat | repeat-x | repeat-y | no-repeat */
    background-position: center top;         /* 在盒子内的位置 */
    background-size: cover;                  /* auto | contain | cover | width height */
    background-attachment: fixed;            /* scroll | fixed | local */
}
```

> **注意：**`url()` 中的引号可选。当 URL 包含空格或特殊字符时必须加引号：`url("path with space/image.png")`。

**background-repeat 取值：**

| 取值 | 行为 |
|-------|----------|
| `repeat` | 在水平方向和垂直方向平铺图片（默认值） |
| `repeat-x` | 仅在水平方向平铺 |
| `repeat-y` | 仅在垂直方向平铺 |
| `no-repeat` | 只显示一次图片 |

**background-position 取值：**

```css
background-position: left top;      /* 关键字 */
background-position: center center; /* 两个轴都居中 */
background-position: 20px 50px;     /* 像素偏移 */
background-position: 50% 50%;       /* 百分比 */
```

**background-size 取值：**

| 取值 | 行为 |
|-------|----------|
| `auto` | 原始图片尺寸 |
| `cover` | 填满整个盒子，必要时裁剪 |
| `contain` | 显示完整图片，必要时加黑边 |
| `100% 50%` | 拉伸到精确尺寸 |

### 4.1.2 背景简写

```css
.box {
    /* color | image | repeat | attachment | position / size */
    background: #f0f0f0 url("bg.jpg") no-repeat fixed center / cover;
}
```

> **注意：**`background-size` 必须写在 `background-position` 之后，并用 `/` 分隔。

### 4.1.3 多重背景

```css
.box {
    background:
        url("overlay.png") no-repeat right bottom,
        url("pattern.png") repeat,
        linear-gradient(to right, red, blue);
}
```

### 4.1.4 不透明度

控制整个元素（包括其内容）的透明度。

```css
.box {
    opacity: 0.5;   /* 0 = 完全透明，1 = 完全不透明 */
}
```

> **替代方案：**使用 `rgba()` 仅让背景透明，而不影响文字。

```css
.box {
    background-color: rgba(255, 0, 0, 0.5);  /* 红色，50% 不透明度 */
}
```

### 4.1.5 CSS 精灵图

CSS 精灵图将多个小图标合并到一张图片中，用 `background-position` 负值偏移显示指定区域，从而减少 HTTP 请求。

```css
.icon {
    width: 24px;
    height: 24px;
    background-image: url("icons-sprite.png");
    background-repeat: no-repeat;
    background-position: -10px -10px; /* 显示该区域图标 */
}

.icon:hover {
    background-position: -10px -40px; /* 悬停时切换坐标 */
}
```

要点：
- 负值的 `background-position` 会把图片向上/向左移动，露出目标区域。
- 元素的 `width` 和 `height` 相当于精灵图上的“视口”。
- 适合成组出现、需要一起加载的小图标。

### 4.1.6 仅背景层透明

如果只想让背景透明，不要把 `opacity` 加给父元素，否则子元素和内容也会一起变透明。应使用 `::before` 伪元素作为覆盖层单独设置透明度。

```css
.card {
    position: relative;
    color: white;
}

.card::before {
    content: "";
    position: absolute;
    inset: 0;
    background: rgba(0, 0, 0, 0.4); /* 也可用 opacity 设置纯色 */
    z-index: -1;
}
```

要点：
- `::before` 在内容背后生成一层。
- 只给覆盖层设置 `opacity` 或 `rgba()`。
- 文字和子元素保持不透明。

## 4.2 浮动

`float` 属性最初用于让文字环绕图片。如今它很大程度上已被 Flexbox 和 Grid 取代，但理解 float 对维护遗留代码仍然很重要。

### 4.2.1 float 的工作原理

设置了 `float` 的元素会脱离正常文档流，并向左或向右移动。行内内容（如文字）会环绕它。

```css
.image-left {
    float: left;     /* 向左移动，内容在右侧环绕 */
    margin-right: 15px;
}

.image-right {
    float: right;    /* 向右移动，内容在左侧环绕 */
    margin-left: 15px;
}
```

**float 行为规则：**
1. 浮动元素尽可能向左/向右移动
2. 行内内容环绕浮动元素
3. 块级元素忽略浮动（除非清除）

### 4.2.2 clear 属性

当你希望某个元素不再环绕其上方的浮动元素时：

```css
.clear-left  { clear: left; }    /* 移动到所有左浮动下方 */
.clear-right { clear: right; }   /* 移动到所有右浮动下方 */
.clear-both  { clear: both; }    /* 移动到所有浮动下方 */
```

### 4.2.3 清除浮动（Clearfix 技巧）

当父元素只包含浮动的子元素时，其高度会塌陷为零。三种常见的修复方法：

**方法 1：overflow hidden**

```css
.parent {
    overflow: hidden;   /* 创建新的块级格式化上下文 */
}
```

**方法 2：空 clear div**

```html
<div class="parent">
    <div class="float-left">...</div>
    <div class="float-right">...</div>
    <div style="clear: both;"></div>
</div>
```

**方法 3：伪元素 clearfix（推荐）**

```css
.clearfix::after {
    content: "";
    display: block;
    clear: both;
}
```

```html
<div class="parent clearfix">
    <div class="float-left">...</div>
    <div class="float-right">...</div>
</div>
```

> **现代替代方案：**使用 `display: flex` 或 `display: grid` 来进行布局，而不是 float。

### 4.2.4 float 与 inline-block 对比

横向布局的传统选择是 `float`。`inline-block` 写法更简单，但存在基线对齐和空白间隙问题。

| 方式 | 优点 | 缺点 |
|---|---|---|
| `float` | 没有行内空白间隙 | 需要清除浮动，可能导致父元素高度塌陷 |
| `inline-block` | 易于使用，保留在文档流中 | 有空白间隙，基线对齐有怪异行为 |

小规模的行内式布局可用 `inline-block`；多列行布局优先使用 `float`（或现代 Flexbox/Grid）。

### 4.2.5 案例小块：小米顶部导航栏

经典顶部导航用一个定宽容器配合 `margin: 0 auto` 居中，左侧用 `float: left` 放 logo 和菜单，右侧用 `float: right` 放用户操作入口。

```html
<nav class="top-bar">
  <div class="container">
    <div class="logo">Logo</div>
    <ul class="nav-left">...</ul>
    <div class="nav-right">...</div>
  </div>
</nav>
```

```css
.container {
    width: 1226px;
    margin: 0 auto;
}

.nav-left { float: left; }
.nav-right { float: right; }
.container::after { /* 清除浮动 */
    content: "";
    display: block;
    clear: both;
}
```

要点：
- `float` 能清晰地把左右两栏分开。
- 容器需要清除浮动，避免高度塌陷。
- 单行链接可用 `line-height` 等于导航高度实现垂直居中。

## 4.3 定位

`position` 属性决定元素在文档中的放置方式。

| 取值 | 行为 | 定位参考 |
|-------|----------|-------------------|
| `static` | 正常文档流（默认值） | 不适用 |
| `relative` | 相对于其正常位置偏移 | 其原始位置 |
| `absolute` | 脱离文档流，绝对定位 | 最近的已定位祖先元素 |
| `fixed` | 脱离文档流，固定于视口 | 浏览器视口 |
| `sticky` | 正常滚动直到阈值，然后粘住 | 其包含块 |

### 4.3.1 static（默认值）

```css
.box {
    position: static;   /* 默认值，通常可以省略 */
}
```

`top`、`right`、`bottom`、`left` 和 `z-index` 对 `static` 元素无效。

### 4.3.2 相对定位

元素保留在文档流中的空间，但在视觉上发生偏移。

```css
.box {
    position: relative;
    top: 20px;      /* 从原始位置向下移动 20px */
    left: 30px;     /* 从原始位置向右移动 30px */
}
```

> **要点：**其他元素不会填补相对定位元素留下的空间。原始空间会被保留。

### 4.3.3 绝对定位

元素完全脱离文档流。它相对于最近的**已定位祖先元素**（`position` 设置为 `relative`、`absolute`、`fixed` 或 `sticky` 的祖先元素）进行定位。如果不存在这样的祖先元素，则相对于 `<html>` 元素定位。

```css
.parent {
    position: relative;   /* 创建定位上下文 */
}

.child {
    position: absolute;
    top: 0;
    right: 0;
}
```

> **最佳实践模式——“父元素相对定位，子元素绝对定位”：**
> 在父容器上设置 `position: relative`，然后在子元素上设置 `position: absolute`。这样可将子元素的定位限制在父元素的边界内。

```html
<div class="card" style="position: relative;">
    <img src="photo.jpg">
    <span class="badge" style="position: absolute; top: 10px; right: 10px;">NEW</span>
</div>
```

### 4.3.4 固定定位

元素相对于**浏览器视口**定位，即使滚动页面也保持在固定位置。

```css
.navbar {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    background: white;
    z-index: 1000;
}
```

> **常见用途：**固定导航栏、返回顶部按钮、模态遮罩层。

### 4.3.5 粘性定位

`relative` 和 `fixed` 的混合体。元素在到达滚动阈值之前表现为 `relative`，然后像 `fixed` 一样“粘”在原地。

```css
.header {
    position: sticky;
    top: 0;           /* 到达视口顶部时粘住 */
    background: white;
}
```

> **要求：**粘性定位元素需要定义 `top`/`bottom`/`left`/`right` 值。其父元素必须足够高，以允许滚动。

### 4.3.6 z-index 与层叠上下文

当元素重叠时，`z-index` 控制哪个元素显示在最上层。

```css
.modal {
    position: absolute;
    z-index: 100;     /* 值越大，越靠近观察者 */
}

.overlay {
    position: absolute;
    z-index: 50;
}
```

**层叠上下文规则：**
- `z-index` 只对**已定位**元素有效（`static` 除外）
- 新的层叠上下文由以下情况创建：`position` + `z-index`、`opacity` < 1、`transform`、`filter`、以及设置了 `z-index` 的 flex 子元素
- 层叠上下文内部的元素无法超出其外部的元素
- 已定位元素永远高于普通文档流元素
- `z-index` 相同或未设置时，后写的元素在上
- 负 `z-index` 可让已定位元素沉到普通流兄弟元素下方

### 4.3.7 案例小块：淘宝搜索栏

搜索框下的下拉列表通常放在 `position: relative` 的容器内，用 `position: absolute` 定位，并通过 `:hover` 或 JS 控制显示隐藏。

```html
<div class="search-box">
  <input type="text" placeholder="搜索...">
  <button>搜索</button>
  <ul class="suggest-list">
    <li>item 1</li>
    <li>item 2</li>
  </ul>
</div>
```

```css
.search-box {
    position: relative;
}

.suggest-list {
    position: absolute;
    top: 100%;
    left: 0;
    width: 100%;
    display: none;
}

.search-box:hover .suggest-list {
    display: block;
}
```

要点：
- 父容器设置 `position: relative` 作为下拉锚点。
- `top: 100%` 让列表紧贴输入框底部。
- 自定义样式时常去除 input 默认的 `border`/`outline`。

## 4.4 居中技巧

### 4.4.1 水平居中（块级元素）

```css
.center-block {
    width: 300px;
    margin: 0 auto;   /* auto 将剩余空间均匀分配 */
}
```

### 4.4.2 使用绝对定位居中

以下三种方法都能让绝对定位元素同时水平、垂直居中。

**方法 1：拉伸四边 + auto margin**

```css
.center-absolute {
    position: absolute;
    top: 0;
    bottom: 0;
    left: 0;
    right: 0;
    margin: auto;   /* 需要显式设置 width 和 height */
}
```

**方法 2：50% + transform**

```css
.center-absolute {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);   /* 按自身尺寸的一半进行偏移 */
}
```

**方法 3：50% + 负 margin**

```css
.center-absolute {
    position: absolute;
    top: 50%;
    left: 50%;
    width: 200px;
    height: 100px;
    margin-top: -50px;   /* 高度一半的负值 */
    margin-left: -100px; /* 宽度一半的负值 */
}
```

### 4.4.3 使用 Flexbox 居中

```css
.parent {
    display: flex;
    justify-content: center;   /* 水平居中 */
    align-items: center;       /* 垂直居中 */
    height: 100vh;
}
```

### 4.4.4 固定侧边栏垂直居中

固定元素可以通过 `top: 50%` 配合 `transform: translateY(-50%)` 在视口中垂直居中。

```css
.side-tool {
    position: fixed;
    right: 0;
    top: 50%;
    transform: translateY(-50%);
}
```

要点：
- `top: 50%` 把元素的顶部对齐到视口中心。
- `translateY(-50%)` 再向上移动自身高度的一半。
- 同理，水平居中可用 `left: 50%` + `translateX(-50%)`。

## 4.5 最佳实践

| 应该 | 不应该 |
|----|-------|
| 使用 Flexbox/Grid 进行现代布局 | 使用 float 进行主页面布局（已过时） |
| 使用 `position: sticky` 实现章节标题 | 在 sticky 更合适时使用 `position: fixed` |
| 对遗留 float 代码使用 `::after` clearfix | 让浮动元素保持未清除状态 |
| 使用 `rgba()` 实现半透明背景 | 在只想让背景透明时使用 `opacity` |
| 为绝对定位子元素的父元素设置 `position: relative` | 让绝对定位子元素相对于 `<body>` 定位 |

**记忆口诀**
- **定位** = "Static → Relative → Absolute → Fixed → Sticky（SR-AFS）"
