# 3 盒模型与布局

CSS 盒模型（Box Model）是网页布局的基础。每个 HTML 元素都被视为一个矩形盒子，理解这些盒子的尺寸和间距是构建任何网页的关键。

## 3.1 盒模型

每个元素从内到外由四层组成：

```
+---------------------------+  ← margin（外部空间）
|       +---------------+   |
|       |   +-------+   |   |
|       |   |content|   |   |
|       |   +-------+   |   |
|       |    padding    |   |
|       +---------------+   |
|          border           |
+---------------------------+
```

| 层级 | 属性 | 说明 |
|------|------|------|
| **Content** | `width` / `height` | 实际内容区域（文本、图片等） |
| **Padding** | `padding` | 内容与边框之间的间距 |
| **Border** | `border` | 围绕 padding 的边界 |
| **Margin** | `margin` | 边框外部的间距（用于分隔元素） |

### 3.1.1 Content

```css
.box {
    width: 200px;
    height: 100px;
    background-color: lightblue;
}
```

使用 `min-width` 和 `max-width` 可以让盒子保持在一个宽度范围内，而不必写死单一尺寸：

```css
.responsive {
    min-width: 600px;
    max-width: 800px;
}
```

### 3.1.2 Padding

Padding 在盒子内部创建空间，位于内容与边框之间。

```css
.box {
    /* 所有方向 */
    padding: 20px;

    /* 垂直 | 水平 */
    padding: 10px 20px;

    /* 上 | 右 | 下 | 左（顺时针） */
    padding: 10px 20px 10px 20px;

    /* 单独设置各边 */
    padding-top: 10px;
    padding-right: 20px;
    padding-bottom: 10px;
    padding-left: 20px;
}
```

### 3.1.3 Border

```css
.box {
    /* 简写：width | style | color */
    border: 2px solid red;

    /* 单独设置各边 */
    border-top: 1px dashed blue;
    border-right: 2px dotted green;
    border-bottom: 3px double black;
    border-left: 4px solid gray;

    /* 单独设置属性 */
    border-width: 2px;
    border-style: solid;
    border-color: red;
}
```

**边框样式：**

| 值 | 显示效果 |
|----|----------|
| `solid` | 单实线 |
| `dashed` | 虚线 |
| `dotted` | 点状线 |
| `double` | 双实线 |
| `none` | 无边框 |
| `hidden` | 无边框（隐藏表格边框） |

**边框画三角形：** 将 `width` 和 `height` 设为 `0`，只给一侧边框上色：

```css
.triangle-down {
    width: 0;
    height: 0;
    border: 10px solid transparent;
    border-top-color: red;   /* 上色边朝下 */
}
```

四条边框在中心交汇，让三条边框透明，只留一条即为三角形。

### 3.1.4 Margin

Margin 在盒子外部创建空间，将其与其他元素分隔开。

```css
.box {
    /* 所有方向 */
    margin: 20px;

    /* 垂直 | 水平 */
    margin: 10px auto;   /* auto 实现水平居中 */

    /* 上 | 右 | 下 | 左 */
    margin: 10px 20px 10px 20px;

    /* 单独设置各边 */
    margin-top: 10px;
    margin-right: 20px;
    margin-bottom: 10px;
    margin-left: 20px;
}
```

> **块级元素居中：** `margin: 0 auto;` 可使块级元素在其父元素中水平居中。

### 3.1.5 溢出控制 overflow

`overflow` 属性控制内容超出容器时的表现。

| 值 | 行为 |
|----|------|
| `visible` | 默认值：内容溢出到容器外部 |
| `hidden` | 超出部分被裁剪，无滚动条 |
| `scroll` | 始终显示滚动条 |
| `auto` | 内容溢出时才显示滚动条 |

```css
.scroll-box {
    height: 100px;
    overflow: auto;   /* 需要时出现滚动条 */
}
```

## 3.2 Box Sizing

默认情况下，`width` 和 `height` 仅作用于 **content** 区域。添加 padding 和 border 会增加总尺寸。

```css
/* 默认行为（content-box） */
.box {
    width: 200px;
    padding: 20px;
    border: 2px solid black;
    /* 实际渲染宽度：200 + 20*2 + 2*2 = 244px */
}
```

要让 `width` 包含 padding 和 border，使用 `box-sizing`：

```css
.box {
    box-sizing: border-box;   /* width = content + padding + border */
    width: 200px;
    padding: 20px;
    border: 2px solid black;
    /* 实际渲染宽度：200px */
}
```

> **最佳实践：** 全局设置 `box-sizing: border-box;` 以简化布局计算。

```css
*, *::before, *::after {
    box-sizing: border-box;
}
```

## 3.3 Margin Collapse

当两个垂直 margin 相遇时，它们会折叠为一个 margin，其值等于两者中 **较大** 的那个。

```css
.box1 { margin-bottom: 30px; }
.box2 { margin-top: 20px; }
/* 它们之间的间距：30px（不是 50px） */
```

**margin 折叠规则：**
- 只发生在 **垂直** margin（top/bottom）之间，不发生在水平方向
- 元素之间存在 `padding` 或 `border` 时不会发生
- flex 或 grid 子项不会发生

> **常见陷阱：** 如果父元素没有 `padding` 或 `border`，子元素的 `margin-top` 可能会“逃出”父元素。可通过给父元素添加 `padding-top: 1px` 或 `overflow: hidden` 来解决。

## 3.4 Display Types

`display` 属性决定元素在布局流中的行为。

| 值 | 行为 | 示例 |
|----|------|------|
| `block` | 独占一行，宽度填满父元素 | `<div>`、`<p>`、`<h1>`~`<h6>` |
| `inline` | 宽度仅由内容决定，随文本流动 | `<span>`、`<a>`、`<strong>` |
| `inline-block` | 具有 inline 流动特性，但可设置 width/height | `<img>`、`<input>` |
| `none` | 元素隐藏并从文档流中移除 | — |

```css
span {
    display: block;        /* 将 inline 转为 block */
}

div {
    display: inline;       /* 将 block 转为 inline */
}

.button {
    display: inline-block; /* inline 流动，但可设置 width/height */
    width: 100px;
    height: 40px;
}
```

### 3.4.1 inline / inline-block 的限制

| 特性 | `inline` | `inline-block` |
|------|----------|----------------|
| 设置 `width` / `height` | 不可 | 可 |
| `margin` / `padding` | 只能设置水平方向 | 四个方向都可设置 |
| `margin: auto` | 不支持 | 不支持 |

> **注意：** `inline` 和 `inline-block` 元素不能用 `margin: auto` 居中。可在父元素上设置 `text-align: center`，或改为 `display: block`。

### 3.4.2 行内块空白间隙的成因与消除

HTML 源码中 `inline-block` 元素之间的换行/空格会被渲染为小间隙。常用解决方法：

1. 去掉 HTML 中的空白（标签写在一行）。
2. 父元素设置 `font-size: 0`，子元素再单独恢复 `font-size`。
3. 父元素使用 `display: flex`（推荐）。

```css
.parent {
    font-size: 0;   /* 消除间隙 */
}
.child {
    display: inline-block;
    font-size: 16px;   /* 恢复文字大小 */
}
```

## 3.5 Border Radius and Box Shadow

### 3.5.1 Border Radius

使元素的角变圆。

```css
.box {
    /* 所有角 */
    border-radius: 10px;

    /* 左上 | 右上 | 右下 | 左下 */
    border-radius: 10px 20px 10px 20px;

    /* 创建圆形 */
    border-radius: 50%;
}
```

### 3.5.2 Box Shadow

```css
.box {
    /* offset-x | offset-y | blur-radius | spread-radius | color */
    box-shadow: 5px 5px 10px 2px rgba(0, 0, 0, 0.3);

    /* 多重阴影 */
    box-shadow: 2px 2px 5px red, -2px -2px 5px blue;

    /* 内阴影 */
    box-shadow: inset 0 0 10px gray;
}
```

| 参数 | 说明 |
|------|------|
| `offset-x` | 水平偏移（正值 = 向右） |
| `offset-y` | 垂直偏移（正值 = 向下） |
| `blur-radius` | 阴影边缘的模糊程度 |
| `spread-radius` | 阴影的扩展/收缩量 |
| `color` | 阴影颜色（通常为半透明） |

### 3.5.3 椭圆角与百分比计算

斜杠 `/` 用于分别设置每个角的水平半径和垂直半径，从而形成椭圆角：

```css
.ellipse {
    border-radius: 10px / 20px;   /* 水平半径 10px，垂直半径 20px */
}
```

使用 `50%` 时，浏览器按每条边的一半计算圆角半径。正方形会变成正圆，长方形会变成椭圆。

```css
.circle {
    width: 100px;
    height: 100px;
    border-radius: 50%;   /* 正圆 */
}
```

## 3.6 Text and Font Styling

### 3.6.1 Text Decoration

```css
a { text-decoration: none; }                     /* 移除下划线 */
.underline { text-decoration: underline; }
.overline { text-decoration: overline; }         /* 上划线 */
.line-through { text-decoration: line-through; }

/* 拆分为独立属性 */
.wavy {
    text-decoration-line: underline;
    text-decoration-color: red;
    text-decoration-style: wavy;   /* solid | double | dotted | dashed | wavy */
}
```

`text-decoration` 常用值：`none`、`underline`、`overline`、`line-through`。可用 `text-decoration-color` 和 `text-decoration-style` 单独控制装饰线颜色和样式。

### 3.6.2 Text Alignment

```css
.left { text-align: left; }
.center { text-align: center; }
.right { text-align: right; }
.justify { text-align: justify; }   /* 均匀分布单词间距 */
```

### 3.6.3 Character Spacing

```css
.spaced {
    letter-spacing: 2px;   /* 字符间距 */
    word-spacing: 5px;     /* 单词间距 */
}
```

### 3.6.4 Font Properties

```css
.text {
    /* 单独属性 */
    font-family: Arial, "Helvetica Neue", sans-serif;
    font-size: 16px;
    font-weight: bold;        /* normal | bold | 100~900 */
    font-style: italic;       /* normal | italic | oblique */
    line-height: 1.5;         /* 倍数或固定值 */

    /* 简写：style | weight | size/line-height | family */
    font: italic bold 16px/1.5 Arial, sans-serif;
}
```

> **字体栈最佳实践：** 始终提供后备字体，并以通用字体族（`serif`、`sans-serif`、`monospace`）结尾。

**相对字体大小单位：**

| 单位 | 相对对象 |
|------|----------|
| `em` | 父元素字体大小 |
| `rem` | 根元素（`<html>`）字体大小 |
| `%` | 父元素字体大小 |

```css
html { font-size: 16px; }
.parent { font-size: 20px; }
.child {
    font-size: 1.5rem;   /* 24px，相对 html 计算 */
    padding: 1em;        /* 24px，相对自身 font-size 计算 */
}
```

**`font-weight` 数值：** `100`–`900`，以 `100` 递增。`400` 为正常，`700` 为加粗。并不是所有字体都包含每个字重，浏览器会选取最接近的可用字重。

**`font-style` 取值：** `normal`、`italic`（使用字体自带的斜体字形）、`oblique`（将正常字形倾斜显示）。

### 3.6.5 Text Ellipsis (Truncation)

当文本超出容器时，显示 `...`：

```css
.ellipsis {
    white-space: nowrap;      /* 防止换行 */
    overflow: hidden;         /* 隐藏溢出内容 */
    text-overflow: ellipsis;  /* 显示 ... */
}
```

### 3.6.6 文本颜色表示法

CSS 提供多种颜色写法：

```css
.keyword { color: red; }
.hex { color: #ff0000; }
.hex-alpha { color: #ff000080; }   /* #RRGGBBAA，半透明红色 */
.rgb { color: rgb(255, 0, 0); }
.rgba { color: rgba(255, 0, 0, 0.5); }
```

| 表示法 | 示例 | 说明 |
|--------|------|------|
| 关键字 | `red`、`blue` | 预置颜色名，数量有限 |
| HEX | `#ff0000` | 可简写为 `#f00` |
| HEX + 透明度 | `#ff000080` | 后两位表示不透明度 |
| RGB | `rgb(255, 0, 0)` | 取值 0–255 |
| RGBA | `rgba(255, 0, 0, 0.5)` | alpha 取值 0–1 |

### 3.6.7 文本缩进与 word-spacing

```css
.paragraph {
    text-indent: 2em;   /* 仅首行缩进 */
}

.spacious-words {
    word-spacing: 5px;   /* 单词间距；对中文无效 */
}
```

> **注意：** `word-spacing` 只对单词之间的空格起作用。中文排版需要调整字间距时，应使用 `letter-spacing`。

### 3.6.8 vertical-align 与基线原理

`vertical-align` 控制行内或行内块元素相对于父元素基线的对齐方式。

| 值 | 效果 |
|----|------|
| `baseline` | 默认值：元素基线与父元素基线对齐 |
| `top` | 与行框顶部对齐 |
| `middle` | 元素中线与父元素基线加小写 x 高度的一半对齐 |
| `bottom` | 与行框底部对齐 |
| `text-top` | 与父元素文本顶部对齐 |
| `text-bottom` | 与父元素文本底部对齐 |

```css
.icon {
    display: inline-block;
    vertical-align: middle;
}
```

> **基线提示：** 基线是大多数字母所坐的假想线（即小写 `x` 的底部）。

### 3.6.9 自定义字体 @font-face

```css
@font-face {
    font-family: 'MyFont';
    src: url('fonts/myfont.woff2') format('woff2'),
         url('fonts/myfont.woff') format('woff'),
         url('fonts/myfont.ttf') format('truetype');
    font-weight: normal;
    font-style: normal;
}

.title {
    font-family: 'MyFont', sans-serif;
}
```

> **字体格式：** 优先使用 `woff2`（体积最小），其次 `woff`、`ttf`，以获得最佳浏览器兼容性。

### 3.6.10 cursor 鼠标样式

```css
.button { cursor: pointer; }
.disabled { cursor: not-allowed; }
.draggable { cursor: move; }
```

常用取值：`auto`、`default`、`pointer`、`crosshair`、`move`、`text`、`not-allowed`、`zoom-in`、`help`。

### 3.6.11 user-select: none 禁止选中文本

```css
.no-select {
    user-select: none;   /* 文本无法被高亮选中 */
}
```

常用于按钮、图标、UI 标签等不希望用户选中的场景。

## 3.7 Pseudo-elements

伪元素创建 HTML 中不存在的虚拟元素。

```css
/* 在元素前插入内容 */
.quote::before {
    content: '"';
    font-size: 24px;
    color: gray;
}

/* 在元素后插入内容 */
.quote::after {
    content: '"';
    font-size: 24px;
    color: gray;
}
```

> **注意：** 即使为空，`::before` 和 `::after` 也需要设置 `content: ''` 才能显示。

## 3.8 Resetting Default Styles

浏览器会为许多元素应用默认样式（例如，`<body>` 有 `margin: 8px`，列表有 `padding-left: 40px`）。常见做法是在 CSS 开头重置这些默认值。

```css
/* 简单重置 */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

/* 移除列表符号 */
ul, ol {
    list-style: none;
}

/* 移除链接下划线 */
a {
    text-decoration: none;
    color: inherit;
}
```

### 3.8.1 重置默认样式的常见写法

| 方式 | 代码 | 说明 |
|------|------|------|
| 通配符重置 | `* { margin: 0; padding: 0; }` | 简单直接，但会清除 focus 轮廓、表单默认样式等可能需要恢复的内容 |
| 针对性重置 | `body, h1, h2, h3, p, ul, ol, dl, dd { margin: 0; padding: 0; }` | 更可控，保留其他元素的实用默认样式 |
| 外部 reset 文件 | `@import url('reset.css');` 或 `<link rel="stylesheet" href="reset.css">` | 便于多项目复用 |
| Normalize | `normalize.css` | 保留有用的浏览器默认样式，而不是全部清零 |

> **建议：** 生产环境优先使用针对性重置或 `normalize.css`，而非简单的 `* { margin: 0; padding: 0; }`。

## 3.9 Best Practices

| 推荐 | 不推荐 |
|------|--------|
| 全局使用 `box-sizing: border-box` | 布局时依赖默认的 `content-box` |
| 使用 `margin: 0 auto` 居中块级元素 | 在块级容器上使用 `text-align: center` |
| 使用 `border-radius: 50%` 创建圆形 | 为响应式圆形使用固定像素值 |
| 在开始时重置浏览器默认样式 | 在每个规则中与浏览器默认值对抗 |
| 对类按钮元素使用 `inline-block` | 对简单水平对齐使用 `float` |

## 3.10 案例小块

### 3.10.1 小米商品卡片 / 九宫格

小米商品卡片的核心是 `inline-block` 定宽 + hover 阴影。

```css
.card {
    display: inline-block;
    box-sizing: border-box;
    width: 234px;
    padding: 20px;
    text-align: center;
    transition: box-shadow 0.3s;
}
.card img { width: 100%; }
.card:hover {
    box-shadow: 0 5px 15px rgba(0, 0, 0, 0.2);
}
```

**要点：**
- `width: 234px` 配合 `inline-block` 可让卡片自动换行，形成网格效果。
- `box-sizing: border-box` 保证 padding 后总宽度仍符合预期。
- 九宫格可每行放三个卡片，或使用 `width: 33.33%` + flex 消除间隙。

### 3.10.2 小米阴影悬浮

常见的悬浮上浮效果通过柔和阴影和鼠标手型实现。

```css
.shadow-box {
    width: 200px;
    height: 200px;
    background-color: #fff;
    cursor: pointer;
    transition: box-shadow 0.3s;
}
.shadow-box:hover {
    box-shadow: 5px 5px 13px 7px rgba(0, 0, 0, 0.2);
}
```

**要点：**
- `cursor: pointer` 提示用户元素可交互。
- `transition` 让阴影变化更平滑，避免生硬跳变。
- 阴影参数顺序为 `offset-x offset-y blur spread color`。

**Summary Mnemonic**
- **盒模型** = "Content → Padding → Border → Margin（CPBM）"
