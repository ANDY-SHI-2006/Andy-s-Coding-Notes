# 7 伪类与交互状态

伪类（pseudo-classes）让你能够根据元素的状态、位置或用户交互来设置样式，而无需在 HTML 中添加额外的 class。

## 7.1 链接与用户行为伪类

```css
/* 未访问过的链接 */
a:link { color: blue; }

/* 已访问过的链接 */
a:visited { color: purple; }

/* 鼠标悬停在元素上 */
a:hover { color: red; text-decoration: underline; }

/* 元素正被激活（鼠标按下） */
a:active { color: green; }

/* 元素获得键盘焦点 */
input:focus { border-color: blue; outline: none; }
```

> **顺序很重要：** 遵循 **LVHA** 顺序：`:link` → `:visited` → `:hover` → `:active`。

### 7.1.1 :hover 配合 cursor: pointer

对于链接、按钮、列表项等可点击元素，`:hover` 时常与 `cursor: pointer` 一起使用，给用户明确的交互反馈。

```css
.nav-item:hover,
.button:hover {
    cursor: pointer;
    color: #e74c3c;
}
```

- `cursor: pointer` 显示手型图标，提示元素可点击。
- 不仅 `<a>` 标签，任何会响应点击的元素都可以使用。

## 7.2 表单状态伪类

```css
/* 被选中的 checkbox 或 radio */
input:checked + label { color: green; }

/* 禁用的输入框 */
input:disabled { background: #eee; cursor: not-allowed; }

/* 启用的输入框 */
input:enabled { background: white; }

/* 有效的输入（通过验证） */
input:valid { border-color: green; }

/* 无效的输入（未通过验证） */
input:invalid { border-color: red; }

/* 必填字段 */
input:required { border-left: 3px solid orange; }

/* 显示 placeholder 时 */
input:placeholder-shown { font-style: italic; }
```

## 7.3 结构伪类

```css
/* 父元素的第一个子元素 */
li:first-child { font-weight: bold; }

/* 父元素的最后一个子元素 */
li:last-child { border-bottom: none; }

/* 父元素的唯一子元素 */
p:only-child { text-align: center; }

/* 第 N 个子元素（从 1 开始计数） */
li:nth-child(3) { background: yellow; }        /* 第 3 个子元素 */
li:nth-child(odd) { background: #f0f0f0; }    /* 奇数子元素 */
li:nth-child(even) { background: white; }      /* 偶数子元素 */
li:nth-child(2n) { background: lightblue; }    /* 每第 2 个子元素 */
li:nth-child(3n+1) { background: pink; }       /* 第 1、4、7……个 */

/* 同类兄弟元素中的第一个 */
p:first-of-type { font-size: 1.2em; }

/* 同类兄弟元素中的最后一个 */
p:last-of-type { margin-bottom: 0; }

/* 同类兄弟元素中的第 N 个 */
p:nth-of-type(2) { color: red; }

/* 空元素（没有子元素） */
div:empty { display: none; }

/* 不匹配某个选择器的元素 */
li:not(.active) { opacity: 0.5; }
```

### 7.3.1 nth-child 公式速查

| 公式 | 选择 |
|------|------|
| `nth-child(5)` | 仅第 5 个子元素 |
| `nth-child(odd)` | 第 1、3、5、7……个 |
| `nth-child(even)` | 第 2、4、6、8……个 |
| `nth-child(2n)` | 每第 2 个子元素（同 even） |
| `nth-child(2n+1)` | 从第 1 个起每第 2 个（同 odd） |
| `nth-child(3n)` | 每第 3 个子元素（3、6、9……） |
| `nth-child(n+4)` | 从第 4 个起的所有子元素 |
| `nth-child(-n+3)` | 仅前 3 个子元素 |

### 7.3.2 用 nth-of-type(even) 做斑马纹

使用 `:nth-of-type(even)` 为同类型元素（如段落或表格行）交替设置背景色，实现斑马纹效果。

```css
.article p:nth-of-type(even) {
    background-color: #f5f5f5;
}

table tr:nth-of-type(even) {
    background-color: #eef;
}
```

- `nth-of-type(even)` 只统计同类型兄弟元素。
- 与 `nth-child(even)` 不同，它会忽略行之间的其他元素类型（如标题、图片）。
- 给元素加上适当的 padding，让条纹效果更清晰。

## 7.4 CSS 自定义属性（变量）

CSS 变量（variables）允许你定义可复用的值。它们特别适用于颜色、间距和主题设置。

```css
:root {
    --primary-color: #3498db;
    --secondary-color: #2ecc71;
    --spacing-unit: 8px;
    --font-stack: Arial, sans-serif;
}

.button {
    background-color: var(--primary-color);
    padding: calc(var(--spacing-unit) * 2);
    font-family: var(--font-stack);
}

.button:hover {
    background-color: var(--secondary-color);
}
```

| 语法 | 说明 |
|------|------|
| `--name` | 定义变量 |
| `var(--name)` | 使用变量 |
| `var(--name, fallback)` | 使用变量并带 fallback 值 |

> **作用域：** 在 `:root` 中定义的变量是全局的。在选择器中定义的变量仅作用于该选择器及其后代。

```css
.card {
    --card-bg: white;        /* 作用于 .card 及其子元素 */
    background: var(--card-bg);
}

.card.dark {
    --card-bg: #333;         /* 深色变体覆盖 */
}
```

## 7.5 最佳实践

| 推荐 | 不推荐 |
|------|--------|
| 使用 `:hover` 提供交互反馈 | 在 CSS 伪类足以实现时使用 JavaScript |
| 使用 `:focus-visible` 设置键盘焦点样式 | 移除 focus 轮廓而不提供替代方案（可访问性问题） |
| 使用 CSS 变量进行主题设置 | 到处硬编码颜色和间距值 |
| 使用 `:nth-child` 实现表格斑马纹 | 每隔一行手动添加 class |
| 使用 `:not()` 简化选择器 | 创建过于复杂的选择器链 |

**总结口诀**
- **伪类** = "按状态而非 class 来设置样式"
