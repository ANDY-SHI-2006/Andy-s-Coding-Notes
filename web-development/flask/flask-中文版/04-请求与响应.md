# 4 请求与响应

本章讲解 Flask 中请求与响应的两个进阶主题：如何在请求中接收并保存客户端上传的文件，以及如何灵活地构建响应对象（基础响应与 JSON 响应）。

## 4.1 请求——文件上传

Flask 处理客户端传入的文件数据时，文件会先被存储在内存或文件系统中的一个临时位置，通过 `request` 对象的 `files` 属性获取：

- `request.files` 是一个 `MultiDict`（多重字典），通过表单字段名（键）获取对应的文件数据对象；
- 取到的文件对象是 `FileStorage` 类型；
- 调用 `FileStorage` 对象的 `save()` 方法，并传入保存路径，即可把文件保存到服务器的文件系统上。

### 4.1.1 获取上传的文件

```python
from flask import Flask, request
from werkzeug.utils import secure_filename
import os
from hashlib import md5

app = Flask(__name__)

"""
flask在处理客户出入的文件数据：存储在内存或者文件系统中一个临时位置
------ request对象 ---》 files属性获取文件数据： MultiDict
------ 通过键获取文件数据对象： FileStorage
------ FileStorage对象 ---》 save方法： 保存到服务器的文件系统上 ---》 保存信息路径
"""

@app.route('/demo', methods=['GET', 'POST'])
def demo():
    # 表单form
    # ImmutableMultiDict([('my_files', <FileStorage: '1d7346d9-956c-4145-a6a5-ca83ab6e51c8.jpg' ('image/jpeg')>)])
    print(request.files)
    # <FileStorage: '1d7346d9-956c-4145-a6a5-ca83ab6e51c8.jpg' ('image/jpeg')>
    print(request.files.get('my_files'))
    # 1d7346d9-956c-4145-a6a5-ca83ab6e51c8.jpg
    print(request.files.get('my_files').filename)

    # mime类型
    # print(request.content_type)  # multipart/form-data; boundary=------------------------823013153256183608392438

    return 'demo'

if __name__ == '__main__':
    print(app.url_map)  # 查看路由信息
    app.run(debug=True)
```

要点：

- `request.files` 打印出来是 `ImmutableMultiDict`，键是表单中文件字段的名字（这里是 `my_files`），值是 `FileStorage` 对象；
- `request.files.get('my_files')` 取出文件对象，其 `.filename` 属性是客户端上传时的原始文件名；
- 文件上传请求的 `Content-Type` 是 `multipart/form-data`，并带有 boundary 分隔符。

### 4.1.2 文件名的安全合理化

直接使用客户端传来的文件名保存文件存在安全风险，需要先处理文件名。

**方式一：`secure_filename`**

`secure_filename` 需要传入一个文件名，返回一个安全的文件名：

```python
from werkzeug.utils import secure_filename

print(secure_filename(request.files.get('my_files').filename))
```

处理效果示例：

- 文件名称如果包含中文不行：`雪人.jpg` → `jpg`（中文部分会被丢弃）
- `logo配色图-2.png` → `logo-2.png`
- `WIN 20231022_23_25_11_Pro.jpg` → `WIN_20231022_23_25_11_Pro.jpg`（空格被替换为下划线）

**方式二：md5 文件名安全化**

md5 用于数据加密——同样的数据用 MD5 加密出来的结果是一样的。加密字符串要先做编码 `encode('utf-8')`，再用 `hexdigest()` 获取加密结果：

```python
from hashlib import md5

# 对文件名做md5加密
md5_filename = md5(request.files.get('my_files').filename.encode('utf-8')).hexdigest()
# WIN 20231022_23_25_11_Pro.jpg ----> bfc4e00e42b10f8c9f371a505f7241f8
# print(md5_filename)

# 获取文件后缀名  WIN 20231022_23_25_11_Pro.jpg
old_filename = request.files.get('my_files').filename
dot_index = old_filename.rindex('.')  # rindex ---> right index 右索引
# print(dot_index)  # 25
file_suffix = old_filename[dot_index:]  # .jpg
# print(file_suffix)
new_filename = md5_filename + file_suffix
# print(new_filename)  # bfc4e00e42b10f8c9f371a505f7241f8.jpg
```

思路：用 md5 加密原文件名得到唯一且安全的字符串，再通过 `rindex('.')` 取出原文件的扩展名拼接到新文件名后面。

### 4.1.3 构建保存路径并保存文件

正式的开发场景中要使用灵活的绝对路径：

```python
# os.getcwd()：获取当前文件所在目录的绝对路径
# print(os.getcwd())  # E:\pythonfile\flask0228

# 构建上传文件的保存目录绝对路径 ---- 路径拼接 os.path.join()
fileCWD = os.path.join(os.getcwd(), 'fileUP')

# 保障这个目录存在：先判断（os.path.exists判断目录是否存在）---》 不存在：创建
if not os.path.exists(fileCWD):  # 如果fileCWD所指定的目录不存在
    os.makedirs(fileCWD)  # 创建目录：os.mkdir  os.makedirs--》多级创建

f = request.files.get('my_files')
# 完整的保存文件路径
sava_file = os.path.join(fileCWD, f.filename)
f.save(sava_file)
```

更简单的保存方式（直接保存到当前工作目录）：

```python
# save保存 ---- 文件对象的filename获取文件名称
f = request.files.get('my_files')
f.save(f.filename)

# 或者指定一个文件名
request.files.get('my_files').save('ceshi.jpg')
```

## 4.2 响应——基础响应

参考资料：

- mime 类型：<https://www.runoob.com/http/mime-types.html>
- 状态码：<https://developer.mozilla.org/zh-CN/docs/Web/HTTP/Reference/Status>

一次完整的请求响应过程是：`客户端 ---请求---》 服务端 ---响应---》 客户端`。服务端返回给客户端的是响应对象（response），它包含三个部分：**响应数据、响应状态码、响应头**。

视图函数构建响应有三种情况：

1. `return` 返回的是字符串 —— 响应对象会用「字符串 + 默认参数」构建；
2. `return` 返回的是元组 —— 必须包含（响应数据 response data、响应状态码 status、响应头 headers）；其中响应头 headers 是字典，不能存在中文、特殊符号；
3. 使用 `make_response` 构建合理的响应对象：`from flask import make_response`。

```python
from flask import Flask, make_response, jsonify

app = Flask(__name__)

@app.route('/demo', methods=['GET', 'POST'])
def demo():
    # 情况1：直接返回字符串
    # return 'demo'

    # 情况2：返回元组（响应数据, 状态码, 响应头字典）
    # return ('demos', 200, {'Content-Type': 'text/plain'})
    # return ('demos', 200, {'Content-Type': 'text/plain', "demo": 'abai'})

    # 响应头的值不能包含中文，否则会报编码错误：
    # UnicodeEncodeError: 'latin-1' codec can't encode character '\u963f' in position 10: ordinal not in range(256)
    # return ('demos', 200, {'Content-Type': 'text/plain', "demo": 'abai阿'})

    # 情况3：make_response 构建响应对象
    # return make_response('hello world')
    respose = make_response()
    # 响应数据
    respose.data = 'flask 框架'
    # 状态码
    respose.status_code = 200
    # 响应头
    respose.content_type = 'text/plain'
    # respose.content_type = 'text/plain; charset=UTF-8'
    respose.headers['demo'] = 'abai'

    return respose

if __name__ == '__main__':
    print(app.url_map)  # 查看路由信息
    app.run(debug=True)
```

要点：

- 元组返回方式中，响应头字典的值如果包含中文（如 `'abai阿'`），会抛出 `UnicodeEncodeError: 'latin-1' codec can't encode character ...`——只要涉及 Web 编程，就会涉及编码问题；
- `make_response()` 可以先创建一个空响应对象，再分别设置 `data`（响应数据）、`status_code`（状态码）、`content_type`（响应的数据类型）以及 `headers`（自定义响应头）。

## 4.3 响应——JSON 响应

先回顾 Python 标准库 `json` 模块的两个基本操作：

```python
>>> data = {'name': '阿白'}
>>> import json

>>> json_string = json.dumps(data)
>>> json_string
'{"name": "\\u963f\\u767d"}'

>>> json_data = json.loads(json_string)
>>> json_data
{'name': '阿白'}
```

- `json.dumps()`：把 Python 对象转成 JSON 字符串（默认会把中文转成 `\uXXXX` 转义序列）；
- `json.loads()`：把 JSON 字符串解析回 Python 对象。

在 Flask 中构建 JSON 响应有两种方式。

**方式一：`jsonify`**

`jsonify` 是 Flask 自带的模块，直接构建 JSON 响应对象，返回的响应对象是可以继续操作的：

```python
from flask import Flask, jsonify

@app.route('/demo', methods=['GET', 'POST'])
def demo():
    # 直接返回
    # return jsonify({'name': '阿白'})

    # 或者先构建响应对象再返回
    json_response = jsonify({'name': '阿白'})
    return json_response
```

**方式二：通过 `make_response`**

```python
from flask import Flask, make_response
import json

app = Flask(__name__)

@app.route('/demo', methods=['GET', 'POST'])
def demo():
    # - 构建响应对象
    response = make_response()
    # - 设置响应头 -- 数据类型 Content-Type: application/json; charset=utf-8
    # 注意中间的;是英文状态下的
    response.headers['Content-Type'] = 'application/json; charset=utf-8'

    # - 响应数据构建：json字符串
    data = {'name': '阿白'}
    # json模块中的dumps完成 json 转为 json字符串
    json_data_string = json.dumps(data)

    response.data = json_data_string

    return response

if __name__ == '__main__':
    print(app.url_map)  # 查看路由信息
    app.run(debug=True)
```

要点：

- `jsonify` 会自动把数据序列化为 JSON 并设置正确的 `Content-Type`，是最简便的方式；
- 手动方式需要三步：构建响应对象 → 设置响应头 `Content-Type: application/json; charset=utf-8` → 用 `json.dumps()` 把数据转成 JSON 字符串赋给 `response.data`。
