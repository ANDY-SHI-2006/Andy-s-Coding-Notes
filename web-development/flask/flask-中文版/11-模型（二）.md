# 11 模型（二）

本章基于上一章定义的模型，讲解数据的增、删、改、查操作：新增数据、基本查询与常用查询、过滤/分组/排序/分页查询、模糊查询与逻辑运算、关联查询、删除与更新数据，以及 Flask CLI 命令。

本章所有示例使用同一套应用配置与模型定义：

```python
from flask import Flask
from flask_sqlalchemy import SQLAlchemy
from sqlalchemy import func  # 聚合函数（分组查询时使用）

app = Flask(__name__, template_folder='templates')

# 1. 连接的目标数据库存在 --不存在--> create database demo default charset utf8;
# 2. 导包：from flask_sqlalchemy import SQLAlchemy
# 3. 设置连接配置 --- SQLALCHEMY_DATABASE_URI
#    ---> '数据库服务://用户名:密码@数据库host:数据库端口/数据库名称'
#    例如 sqlite：'sqlite:///test.db'
app.config['SQLALCHEMY_DATABASE_URI'] = 'mysql://root:qwe123@127.0.0.1:3306/demo'

# 4. 创建数据库对象
db = SQLAlchemy(app)  # SQLAlchemy 实例关联 flask 应用对象，同时加载配置数据 ---> db 对象（orm 实例对象 ---> SQLAlchemy 实例）
ctx = app.app_context()  # 获取 flask 应用上下文
ctx.push()  # 将应用上下文推入栈中（激活上下文）
```

删表顺序注意事项：

```
一对一、一对多：先删子表（存在外键）再删主表
多对多：先删中间表
```

示例模型（一对多关系）：

```python
class Father(db.Model):
    __tablename__ = 'father'
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(20), unique=True, nullable=False)
    age = db.Column(db.Integer, nullable=False, default=18)

    son = db.relationship('Son', backref='father', uselist=True)

    def __str__(self):
        return f"<{self.name} id:{self.id}>"

    def __repr__(self):
        return f"<{self.name} id:{self.id}>"


class Son(db.Model):
    __tablename__ = 'son'
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(20), unique=True, nullable=False)
    father_id = db.Column(db.Integer, db.ForeignKey('father.id'))
```

`__str__` / `__repr__` 用于控制对象的输出信息，打印查询结果时更直观。

## 11.1 新增数据

新增数据的流程：创建模型对象 → `db.session.add()` 添加到会话 → `db.session.commit()` 提交。整个过程中 SQLAlchemy 把对象操作转化为数据库操作（sql 语句），再交由 MySQL 执行：

```
python ----> SQLAlchemy（对象操作 转化为 数据库操作（sql语句）） ------> mysql
```

### 11.1.1 添加单条数据

```python
if __name__ == '__main__':
    # db.create_all()  # 建立所有的表
    # db.drop_all()  # 删除所有的表 ----- 根据模型去删的

    # 创建对象数据
    wanger = Father(name='测试3', age=18)
    # 添加数据对象到会话消息（db 中 session）
    db.session.add(wanger)
    # 提交会话数据
    db.session.commit()

    app.run()
```

在 MySQL 中验证结果：

```
mysql> select * from father;
+----+------+-----+
| id | name | age |
+----+------+-----+
|  1 | 张三 |  18 |
+----+------+-----+
1 row in set (0.01 sec)
```

`add_all` 中传入列表，列表中包含多个数据对象：

## 11.2 查询数据

### 11.2.1 基本查询：query.all()

`query` 是模型类的查询管理器对象，查询所有数据使用 `模型类.query.all()`：

```python
    # query：管理器对象
    # 查询所有 -----》 模型类.query.all()
    father = Father.query.all()
    # <Father 1> 一个对象数据 --- <类名 主键id> ---》 orm 构建出来的
    # __str__  __repr__：对象输出信息
    print(father)  # [<Father 1>, <Father 3>, <Father 5>, <Father 6>, <Father 8>, <Father 9>, <Father 11>]
    # 定义 __str__/__repr__ 后：[<张三 id:1>, <王二 id:3>, <mazi1 id:5>, <mazi2 id:6>, <测试1 id:8>, <测试2 id:9>, <测试3 id:11>]
```

### 11.2.4 分组与聚合：group_by + func

聚合函数需要先导入 `from sqlalchemy import func`。`group_concat` 将组内的多个值连接成一个字符串，`label` 用于指定别名：

```python
    # group_by：分组   18：。。。。。。  20：。。。。。。
    print(db.session.query(Father.age, func.group_concat(Father.name).label("people")).group_by(Father.age).all())
    # [(18, '张三,王二,测试1,测试2,测试3'), (20, 'mazi1,mazi2')]
```

对应的 SQL 语句及结果：

```
mysql> SELECT father.age AS father_age, group_concat(father.name) AS people FROM father GROUP BY father.age;
+------------+--------------------------+
| father_age | people                   |
+------------+--------------------------+
|         18 | 张三,王二,测试1,测试2,测试3 |
|         20 | mazi1,mazi2              |
+------------+--------------------------+
2 rows in set (0.00 sec)
```

不使用 `label` 时，聚合列会自动生成别名 `group_concat_1`：

```python
    # label：指定别名
    # print(db.session.query(Father.age, func.group_concat(Father.name)).group_by(Father.age).all())
    # [(18, '张三,王二,测试1,测试2,测试3'), (20, 'mazi1,mazi2')]
    # print(db.session.query(Father.age, func.group_concat(Father.name)).group_by(Father.age))
    # SELECT father.age AS father_age, group_concat(father.name) AS group_concat_1 FROM father GROUP BY father.age
```

不加 `group_by` 时，整表视为一组，所有值被连接到一起：

```
mysql> SELECT father.age AS father_age, group_concat(father.name) AS group_concat_1 FROM father;
+------------+------------------------------------------+
| father_age | group_concat_1                           |
+------------+------------------------------------------+
|         18 | 张三,王二,mazi1,mazi2,测试1,测试2,测试3  |
+------------+------------------------------------------+
1 row in set (0.01 sec)
```

`group_concat` 的常用变体：

```python
    # 聚合函数 --> from sqlalchemy import func
    # group_concat：将组内的多个值连接成一个字符串
    # func.group_concat(Father.name)  # 默认用 , 连接
    # func.group_concat(Father.name, '-')  # 自定义连接符号
    # func.group_concat(Father.name.distinct())  # .distinct() 去重连接
```

注意：`模型类.query.group_by(...)` 返回的仍是模型对象列表，不能体现分组聚合，不符合需求：

```python
    # print(Father.query.group_by(Father.age).all())  # [<张三 id:1>, <mazi1 id:5>]  ---- 不符合
```


## 11.3 关联查询

通过外键字段和 `relationship` 定义的关联属性，可以跨表访问数据：

```python
    print(Son.query.filter_by(id=12).first().father_id)

    # f1 = Father.query.filter_by(id=9).first()
    # s1 = Son(name='方丈2', father_id=f1)  # 这里直接添加对象是不行的
    # db.session.add(s1)
    # db.session.commit()

    # print(f1.id, f1.name, f1.son[1].name)

    # 1、添加 son 数据，一定需要添加关联数据吗？
    # s1 = Son(name='方丈', father_id=9)  # 直接赋外键值即可
    # db.session.add(s1)
    # db.session.commit()
```

要点：

- 子表添加数据时不一定要先添加关联数据，直接给外键字段赋值（如 `father_id=9`）即可。
- 外键字段不能直接赋关联对象（`father_id=f1` 是不行的）。
- 通过 `f1.son` 可以反向访问主表对象关联的所有子表数据。

## 11.6 Flask CLI 命令

Flask 自带的 CLI 需要指定启动文件，使用步骤如下：

1. 设置环境变量：

```

# windows
set FLASK_APP=app.py       # 启动文件
```

2. 创建环境变量配置文件 `.flaskenv`，与项目启动文件同级：

```
FLASK_APP=app.py
FLASK_ENV=development
```

3. 自动加载环境变量需要安装模块：`pip install python-dotenv`

4. 指令操作：
