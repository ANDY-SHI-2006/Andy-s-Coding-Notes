# 8 上下文与模板

本章讲解 Flask 的两类上下文（应用上下文与请求上下文），以及 Jinja2 模板的核心用法：模板渲染与变量传递、全局/局部变量、`if` 分支、`for` 循环、运算符、注释、过滤器，以及模板继承与模板内置变量。

## 8.1 Flask 上下文

### 8.1.1 什么是上下文

在 Python 中，上下文通常指一段代码执行时的临时环境或状态，涉及资源的获取与释放、环境的设置与恢复。Flask 中有两类上下文：

- **应用上下文**：作用于整个 Flask 应用实例（Flask 项目里面），代表对象是 `current_app` 和 `g`；
- **请求上下文**：保存客户端与服务器交互的数据，代表对象是 `request` 和 `session`。

### 8.1.2 应用上下文：current_app 与 g

- `current_app`：绑定到当前应用实例对象的引用，即 `current_app` 指向 Flask 应用实例对象。

  ```python
  from flask import current_app
  ```

- `g` 对象：每一个请求进来都会构建一次 `g` 对象（每个请求进来 `g` 对象都会先置空），它是作用于 app 应用的全局变量。

  ```python
  from flask import g
  ```

典型用途：在钩子函数与视图函数之间传递变量——可以用 `g` 对象作为全局变量进行数据传递。

```python
from flask import Flask, current_app, g

app = Flask(__name__, template_folder='templates')

@app.before_request
def before_request():
    g.s = 'g对象传递的参数'

@app.route('/index')
def index():
    # print(current_app.name)  # app
    # print(g.s)  # g对象传递的参数
    # print(g.get('s'))
    return "请求钩子"

if __name__ == '__main__':
    print(app.url_map)  # 查看路由信息
    app.run(debug=True)
```

### 8.1.3 请求上下文：request 与 session

请求上下文保存客户端与服务器交互的数据：

- `request` 对象：封装本次请求的数据（请求参数、表单、文件、Cookie 等）；
- `session` 对象：保存跨请求的会话数据。

## 8.2 模板（Jinja2）

Flask 使用 Jinja2 作为模板引擎，其特点：

- **沙箱环境**：提供基本的安全保护，自动转义系统保护页面免受 XSS 攻击；
- **模板封装继承**：支持模板的继承与复用；
- **灵活构建**：模板编译时间灵活；
- **Jinja2 语法可自定义**。

安装：

```bash
pip install jinja2
```

正常情况下不需要单独安装——安装 Flask 时会自动将 Jinja2 作为依赖安装进来。

## 8.3 模板渲染与上下文变量传递

视图函数通过 `render_template` 渲染模板，向 Jinja2 模板传递上下文变量时使用 `key=value` 的形式：

```python
from flask import Flask, render_template

app = Flask(__name__, template_folder='templates')

"""
jinja2 ---> 上下文传递 ------ key=value 传递
"""

@app.route('/')
def index():
    name = '阿白'
    age = 20
    return render_template('demo.html', name=name, age=age)

if __name__ == '__main__':
    print(app.url_map)  # 查看路由信息
    app.run(debug=True)
```

模板（`templates/demo.html`）中用 `{{ 变量 }}` 语法取出上下文传递过来的变量，`{# ... #}` 是模板注释：

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>测试模版</title>
</head>
<body>
{# 变量语法： {{ 变量 }}    变量 ---》 上下文传递过来 #}
<h1>你好 --》 {{ name }} => {{ age }}</h1>
</body>
</html>
```

## 8.4 全局变量与局部变量

### 8.4.1 全局变量：{% set %}

在模板中用 `{% set key键=value值 %}` 定义全局变量，定义后在模板任意位置都可以使用：

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>测试模版</title>
</head>
<body>
{# 全局变量定义  {% set key键=value值 %} #}

{% set name1='python' %}

<h1>你好 --》 {{ name1 }}</h1>
</body>
</html>
```

### 8.4.2 局部变量：{% with %}

用 `{% with %}` 块定义的变量只在块内有效：

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>测试模版</title>
</head>
<body>

{% with b="局部变量" %}
    =--- {{ b }}
{% endwith %}

</body>
</html>
```

### 8.4.3 同名变量的覆盖

模板中后定义的同名变量会覆盖前面的值；`{% with %}` 块内的局部变量只在块内覆盖，块外不受影响：

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>测试模版</title>
</head>
<body>

<h1>-----》 {{ name }}</h1>

{% set name = "全局变量" %}
<h1>-----》 {{ name }}</h1>

{% with name="局部变量" %}
    <h1>-----》 {{ name }}</h1>
{% endwith %}

</body>
</html>
```

## 8.5 if 语句

模板中的分支结构使用 `{% if %}`，必须以 `{% endif %}` 结束，支持 `elif` 与 `else`：

```html
{# 单分支 #}
{% if 条件 %}
    条件成立执行
{% endif %}
```

```html
{# 双分支 #}
{% if 条件 %}
    条件成立执行
{% else %}
    条件不成立
{% endif %}
```

```html
{# 多分支 #}
{% if 条件 %}
    条件成立执行
{% elif 条件 %}
    条件成立执行
{% else %}
    条件不成立
{% endif %}
```

完整示例——视图函数传递 `name` 与 `age`：

```python
from flask import Flask, render_template

app = Flask(__name__, template_folder='templates')

"""
jinja2 ---> 上下文传递 ------ key=value 传递
"""

@app.route('/')
def index():
    name = '阿白'
    age = 20
    return render_template('demo.html', name=name, age=age)

if __name__ == '__main__':
    print(app.url_map)  # 查看路由信息
    app.run(debug=True)
```

模板中按 `name` 的值进行分支判断：

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>测试模版</title>
</head>
<body>

{% if name == "abai" %}
    <h1>你是阿白</h1>
{% elif name == "阿白" %}
    <h1>你是阿白吗？</h1>
{% else %}
    <h1>你是谁？</h1>
{% endif %}

</body>
</html>
```

## 8.6 for 循环

### 8.6.1 基本语法

```html
{% for i in datalist %}
    {{ i }}
{% endfor %}
```

视图函数一次传递列表与字典两种数据：

```python
from flask import Flask, render_template

app = Flask(__name__, template_folder='templates')

"""
jinja2 ---> 上下文传递 ------ key=value 传递
"""

@app.route('/')
def index():
    name = '阿白'
    age = 20
    datalist = ['a1', 'b2', 'c3', 'd4', 'e5', 'f6']
    datadict = {'a1': 123, 'b2': 223, 'c3': 333, 'd4': 444, 'e5': 555}
    return render_template('demo.html',
                           name=name,
                           age=age,
                           datalist=datalist, datadict=datadict)

if __name__ == '__main__':
    print(app.url_map)  # 查看路由信息
    app.run(debug=True)
```

### 8.6.2 遍历列表与字典

模板中直接 `for` 遍历字典时拿到的是键，可以通过 `datadict.get(i)` 取对应的值：

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>测试模版</title>
</head>
<body>

{% for i in datalist %}
    <h1>{{ i }}</h1>
{% endfor %}

{% for i in datadict %}
    <h1>datadict-for:  {{ i }}</h1>
{% endfor %}

{% for i in datadict %}
    <h1>datadict-for-value:  {{ datadict.get(i) }}</h1>
{% endfor %}

</body>
</html>
```

### 8.6.3 内置变量：loop 对象

在 `for` 循环内部可以使用内置的 `loop` 对象获取迭代信息：

- `loop.index`：当前迭代索引（从 1 开始的）；
- `loop.index0`：当前迭代索引（从 0 开始的）；
- `loop.first`：是否是第一次迭代；
- `loop.last`：是否是最后一次迭代；
- `loop.length`：序列长度（迭代数据长度）。

```html
<body>

{#
内置变量----loop对象

loop.index ---> 当前迭代索引（从1开始的）
loop.index0 ---> 当前迭代索引（从0开始的）

loop.first ---> 是否是第一次迭代
loop.last  ---> 是否是最后一次迭代

loop.length ---> 序列长度（迭代数据长度）
#}

{% for i in datalist %}
    <h1>{{ i }} ---- {{ loop.length }}</h1>
{% endfor %}

</body>
```

## 8.7 运算符

Jinja2 模板中支持常见运算符：

| 运算符 | 作用说明 | 示例 |
| ------ | -------- | ---- |
| `+` | 加法（也可拼接字符串） | `{{ 1 + 2 }}` → `3`；`{{ name + '123' }}` → 变量 name 拼接 `'123'` |
| `-` | 减法 | `{{ 5 - 2 }}` → `3` |
| `*` | 乘法 | `{{ 1 * 2 }}` → `2` |
| `/` | 除法 | `{{ 6 / 2 }}` → `3` |
| `%` | 取模（取余） | `{{ 7 % 3 }}` → `1` |
| `**` | 幂运算 | `{{ 2 ** 3 }}` → `8` |
| `in` | 判断元素是否在序列 / 集合中：`a in b` 表示 a 数据是否在 b 里面 | `{{ 3 in [1,2,3] }}` → `True` |
| `~` | 字符串拼接（推荐，可跨类型拼接，类型更安全） | `{{ name ~ '123' }}` → 变量 name 拼接 `'123'` |

```html
{{ 1 * 2 }}

{{ name + '123' }}
{{ name ~ '123' }}
```

注意 `+` 与 `~` 的区别：

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>测试模版</title>
</head>
<body>

{{ name + '123' }}
{{ name ~ '123' }}

{{ age ~ '123' }}  {# ~ 跨类型拼接 #}

{{ age + '123' }}  {# + 不能跨类型
TypeError: unsupported operand type(s) for +: 'int' and 'str' #}

</body>
</html>
```

## 8.8 模板注释

模板注释的语法是 `{# 注释内容 #}`，注释内容不会渲染到最终的 HTML 中：

```html
{# 注释内容 #}
```

## 8.9 模板过滤器

过滤器用于在模板中对变量进行加工处理，语法是 `变量名 | 过滤器`：

```html
{{ 变量名 | 过滤器 }}
```

### 8.9.1 safe 与 escape

默认情况下 Jinja2 会自动转义变量中的 HTML 特殊字符（防 XSS）。`safe` 禁用转义、直接渲染 HTML；`escape` 开启转义：

```html
{{ '<h1>阿白</h1>' }}
{{ '<h1>阿白</h1>' | safe }}
{{ '<h1>阿白</h1>' | escape }}<br>
```

### 8.9.2 round 数字取舍

`round` 对数字进行四舍五入，可指定保留位数与取舍方式（`'floor'` 向下取舍）：

```html
{{ 12.888888 | round }} <br>
{{ 12.888888 | round(2) }}<br>
{{ 12.888888 | round(2, 'floor') }}
```

### 8.9.3 常用过滤器一览

字符串相关：

| 过滤器 | 作用 | 示例 |
| ------ | ---- | ---- |
| `safe` | 禁用转义，直接渲染 HTML 内容 | `{{ 'hello' \| safe }}` |
| `capitalize` | 把变量值的首字母转成大写，其余字母转小写 | `{{ 'hello' \| capitalize }}` |
| `lower` | 字符串转成小写 | `{{ 'HELLO' \| lower }}` |
| `upper` | 字符串转成大写 | `{{ 'hello' \| upper }}` |
| `title` | 把值中的每个单词的首字母都转成大写 | `{{ 'hello world' \| title }}` |
| `trim` | 把值的首尾空格去掉 | `{{ '  hello world  ' \| trim }}` |
| `reverse` | 字符串反转 | `{{ 'hello' \| reverse }}` |
| `format` | 格式化输出（类似 Python 的 `%` 格式化） | `{{ '%s is %d' \| format('name', 17) }}` |
| `striptags` | 渲染之前把值中所有的 HTML 标签都删掉 | `{{ 'hello' \| striptags }}` |
| `truncate` | 截取前几个字符，后面使用 `...` 表示 | `{{ name \| truncate(3, True) }}` |
| `escape` | 开启转义，把 HTML 特殊字符转义 | `{{ 'name' \| escape }}` |

数值与序列相关：

| 过滤器 | 作用 | 示例 |
| ------ | ---- | ---- |
| `length` / `count` | 获取列表、字符串、字典的长度 | `{{ [1,2,3] \| length }}` → `3` |
| `default` | 变量为空时，显示默认值 | `{{ name \| default('匿名用户') }}` |
| `first` | 取列表的第一个元素 | `{{ [1,2,3] \| first }}` → `1` |
| `last` | 取列表的最后一个元素 | `{{ [1,2,3] \| last }}` → `3` |
| `sort` | 对列表进行排序 | `{{ [3,1,2] \| sort }}` → `[1,2,3]` |
| `join` | 把列表拼接成字符串 | `{{ ['a','b','c'] \| join('-') }}` → `a-b-c` |
| `int` | 把值转为整数 | `{{ '123' \| int }}` → `123` |
| `float` | 把值转为浮点数 | `{{ '3.14' \| float }}` → `3.14` |
| `round` | 对数字进行四舍五入 | `{{ 3.14159 \| round(2) }}` → `3.14` |
| `abs` | 取绝对值 | `{{ -5 \| abs }}` → `5` |
| `replace` | 替换字符串中的指定内容 | `{{ 'hello world' \| replace('world', 'Jinja2') }}` → `hello Jinja2` |
| `wordcount` | 统计字符串中的单词数 | `{{ 'hello world' \| wordcount }}` → `2` |
| `list` | 把字符串转为字符列表 | `{{ 'abc' \| list }}` → `['a','b','c']` |
| `batch` | 把列表按指定数量分块 | `{{ [1,2,3,4] \| batch(2) }}` → `[[1,2],[3,4]]` |
| `dictsort` | 对字典按键排序 | `{{ {'b':2, 'a':1} \| dictsort }}` → `[('a',1), ('b',2)]` |

## 8.10 模板继承与模板内置变量

### 8.10.1 模板继承：extends 与 block

把多个页面共用的结构抽取到基模板中，用 `{% block %}` 定义可覆盖的区域；子模板用 `{% extends %}` 继承基模板，并重写对应的 `block`：

基模板 `base.html`：

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>{% block title %}默认标题{% endblock %}</title>
    <style>
        .box{margin: 50px auto;width: 600px}
        .tip{color: #666;margin:20px 0;}
        .btn{padding: 6px 15px; background: #0062ff;color: #fff;border-radius: 4px;text-decoration: none}
    </style>
</head>
<body>
    <div class="box">
        <h2>{{ config.WEB_TITLE }}</h2>
        <p class="tip">{{ config.AUTHOR }}</p>

        <!-- 子页面内容 -->
        {% block content %}{% endblock %}

        <!-- 展示请求信息 -->
        <hr style="margin-top: 40px;">
        <p>请求路径：{{ request.path }}</p>
        <p>请求方式：{{ request.method }}</p>
    </div>
</body>
</html>
```

子模板 `index.html`：

```html
{% extends 'base.html' %}

{% block title %}首页{% endblock %}

{% block content %}
    <h3>欢迎访问首页</h3>

    {% if username %}
        {# 登录状态 #}
        <p style="color: green">√ 登录成功！当前用户：{{ username }}</p>
        <p style="color: #333;">登录方式：{{ login_type }}</p>
        <a href="{{ url_for('admin') }}" class="btn">进入管理员后台</a>
        <a href="{{ url_for('logout') }}" style="margin-left: 10px;" class="btn">退出登录</a>
    {% else %}
        <p style="color: red;">× 当前未登录，请先登录！</p>
        <p>登录示例：<a href="/login?username=test">/login?username=test</a></p>
    {% endif %}
{% endblock %}
```

子模板 `admin.html`：

```html
{% extends 'base.html' %}

{% block title %}管理员后台{% endblock %}

{% block content %}
    <h3>管理员后台</h3>
    <p>{{ username }}</p>
    <p>{{ login_type }}</p>
    <a href="{{ url_for('index') }}" class="btn">返回首页</a>
    <a href="{{ url_for('logout') }}" style="margin-left: 10px;" class="btn">退出登录</a>
{% endblock %}
```

### 8.10.2 模板内置变量

模板中可以直接使用 Flask 注入的内置变量与函数，无需视图函数显式传递：

- `config`：当前应用的配置对象，如 `{{ config.WEB_TITLE }}`（对应 `app.config['WEB_TITLE']`）；
- `request`：当前请求上下文对象，如 `{{ request.path }}`、`{{ request.method }}`；
- `url_for()`：根据视图函数名生成 URL，如 `{{ url_for('admin') }}`；
- 此外还有 `session`、`g` 等上下文对象。

视图函数中只需传递页面特有的变量，公共数据交给内置变量：

```python
from flask import Flask, render_template, request

app = Flask(__name__, template_folder='templates')
app.config['WEB_TITLE'] = '个人权限管理'
app.config['AUTHOR'] = '666'

@app.route('/', methods=['GET', 'POST'])
def index():
    return render_template('index.html', username=username, login_type=login_type)

@app.route('/admin', methods=['GET', 'POST'])
def admin():
    # 从上下文request获取登录用户信息
    return render_template('admin.html', username=request.user, login_type=request.login_type)

if __name__ == '__main__':
    print(app.url_map)
    app.run(debug=True)
```
