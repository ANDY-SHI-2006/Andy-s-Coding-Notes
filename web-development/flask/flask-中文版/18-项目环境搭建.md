# 18 项目环境搭建

本章开始搭建二手房项目（house2）：创建虚拟环境并安装依赖、规划项目目录结构、搭建应用主体（启动文件、配置文件、蓝图）、定义数据模型、注入房源数据，最后渲染首页验证整个环境是否打通。

## 18.1 创建虚拟环境与安装依赖

创建名为 `house2` 的虚拟环境：

```shell
mkvirtualenv house2
```

在虚拟环境中安装项目所需的第三方库：

```shell
pip install flask
pip install jinja2
pip install Flask-SQLAlchemy
pip install flask-migrate
pip install Flask-Mail
pip install flask-restful
pip install pymysql
pip install scikit-learn
pip install numpy
```

下载较慢时可以使用清华镜像源加速：

```shell
pip install flask Flask-SQLAlchemy -i https://pypi.tuna.tsinghua.edu.cn/simple/
pip install flask-migrate Flask-Mail flask-restful pymysql scikit-learn numpy -i https://pypi.tuna.tsinghua.edu.cn/simple/
```

查看当前虚拟环境的解释器位置：

```shell
where python  # 查一下虚拟环境的解释器位置
```

> **mysqlclient 安装失败的版本适配问题**：如果遇到 mysqlclient 安装失败，需要指定与 Python 版本适配的包版本：
>
> - `pip install mysqlclient==1.4.6` ---> 适配 python 3.5 - 3.9
> - `pip install mysqlclient==1.4.0` ---> 适配 python 3.5 - 3.8
>
> 本项目使用 `pymysql` 作为 MySQL 驱动，因此一般不涉及该问题。

## 18.3 主体搭建

### 18.3.1 启动文件 app.py

`app.py` 是项目的启动文件：创建 Flask 应用实例、加载配置、注册各功能模块的蓝图：

```python
from flask import Flask

from apps.user import app_user
from apps.list_page import app_list
from apps.index_page import app_index
from apps.detail_page import app_detail
from setting import Setting

app = Flask(__name__,
            template_folder='templates',
            static_folder='static')
app.config.from_object(Setting)  # 加载配置 ---> 类

app.register_blueprint(app_user)
app.register_blueprint(app_list)
app.register_blueprint(app_detail)
app.register_blueprint(app_index)

if __name__ == '__main__':
    app.run()
```

### 18.3.2 配置文件 setting.py

`setting.py` 中创建 `db` 实例（SQLAlchemy 对象）并定义配置类：

```python
import pymysql
from flask_sqlalchemy import SQLAlchemy

# 初始化SQLAlchemy对象
db = SQLAlchemy()

pymysql.install_as_MySQLdb()  # 初始化MySQL连接


class Setting:
    DEBUG = False

    # 创建数据库：create database house default charset utf8;
    # 配置数据库连接
    SQLALCHEMY_DATABASE_URI = 'mysql+pymysql://root:qwe123@127.0.0.1:3306/house'
    SQLALCHEMY_TRACK_MODIFICATIONS = True
```

说明：

- `db = SQLAlchemy()` 先创建「空」的 SQLAlchemy 对象，稍后在 `app.py` 中通过 `db.init_app(app)` 与应用绑定（见 18.4.1）。
- `pymysql.install_as_MySQLdb()` 让 pymysql 伪装成 MySQLdb 驱动，供 SQLAlchemy 连接 MySQL 使用。
- 连接数据库前需要先在 MySQL 中创建 `house` 数据库：`create database house default charset utf8;`
- 连接串格式：`mysql+pymysql://用户名:密码@主机:端口/数据库名`。

### 18.3.3 apps 下面的蓝图构建

`apps/` 目录下的每个模块都创建一个蓝图对象，供 `app.py` 注册：

```python
from flask import Blueprint

app_user = Blueprint(name='app_user', __name__)
```

其余模块同理：`app_list = Blueprint(name='app_list', __name__)`、`app_index = Blueprint(name='app_index', __name__)`、`app_detail = Blueprint(name='app_detail', __name__)`。

### 18.3.4 模板资源和静态资源引入

将前端页面资源复制进项目：

- `static/`：静态资源目录，包含 `css`、`fonts`、`img`、`js`、`scss`、`vendor` 等子目录，以及 `house.png`、`LICENSE` 等文件。
- `templates/`：模板目录，包含 `detail_page.html`、`index.html`、`list.html`、`search_list.html`、`user_page.html` 五个页面模板。

## 18.4 模型搭建

### 18.4.1 db 对象与应用绑定

模型定义在 `model.py` 中，从 `setting.py` 导入 `db` 对象。同时，`app.py` 中也要导入 `db` 并完成初始化绑定：

```python
from setting import Setting, db

app = Flask(__name__, template_folder='templates', static_folder='static')
app.config.from_object(Setting)  # 加载配置 ---> 类

# db对象 --> SQLAlchemy对象
db.init_app(app)  # 初始化配置信息
```

### 18.4.2 House 模型（house_info 表）

`house_info` 表存储房源信息，对应 `House` 模型类：

```python
from setting import db


# house_info表的模型类
class House(db.Model):
    # 指定表名
    __tablename__ = 'house_info'
    # 主键
    id = db.Column(db.Integer, primary_key=True)
    # 房源标题
    title = db.Column(db.String(100))
    # 房源户型
    rooms = db.Column(db.String(100))
    # 房源面积
    area = db.Column(db.String(100))
    # 房源价格
    price = db.Column(db.String(100))
    # 房源朝向
    direction = db.Column(db.String(100))
    # 租住类型
    rent_type = db.Column(db.String(100))
    # 房源所在区
    region = db.Column(db.String(100))
    # 房源所在街道
    block = db.Column(db.String(100))
    # 房源所在小区
    address = db.Column(db.String(100))
    # 交通条件
    traffic = db.Column(db.String(100))
    # 发布时间
    publish_time = db.Column(db.Integer)
    # 配套设施
    facilities = db.Column(db.TEXT)
    # 房屋优势
    highlights = db.Column(db.TEXT)
    # 周边
    matching = db.Column(db.TEXT)
    # 公交出行
    travel = db.Column(db.TEXT)
    # 浏览量
    page_views = db.Column(db.Integer)
    # 房东姓名
    landlord = db.Column(db.String(100))
    # 房东电话
    phone_num = db.Column(db.String(100))
    # 房源编号
    house_num = db.Column(db.String(100))

    # 重写__repr__方法，方便查看对象的输出内容
    def __repr__(self):
        return 'House: %s, %s' % (self.address, self.id)
```

## 18.7 首页的初始数据渲染

首页的「为您为家」（最新房源）和「为您推荐」（热点房源）两个版块需要在渲染模板时就带上数据。在 18.6 的 `index` 视图中补充三类查询：

- 房源总数：`House.query.count()`；
- 最新房源 top6：按发布时间 `publish_time` 降序取前 6 条；
- 热点房源 top4：按浏览量 `page_views` 降序取前 4 条。

`apps/index_page.py`：

```python
from flask import Blueprint, render_template
from model import House

app_index = Blueprint('app_index', __name__)


@app_index.route('/')
def index():
    # 获取房源总数
    num = House.query.count()

    # 最新房源 top6  ---> 排序依据：publish_time 发布时间  ---> 降序 desc
    house_new_list = House.query.order_by(House.publish_time.desc()).limit(6).all()

    # 热点房源 top4  ---> 排序依据：page_views 浏览量  ---> 降序 desc
    house_hot_list = House.query.order_by(House.page_views.desc()).limit(4).all()

    return render_template('index.html',
                           num=num,
                           house_hot_list=house_hot_list,
                           house_new_list=house_new_list)
```

`render_template` 把 `num`、`house_new_list`、`house_hot_list` 传入模板，首页打开时「为您为家」「为您推荐」版块即可渲染出真实的房源数据。

## 18.8 搜索提示实现

首页搜索框支持「地区搜索」和「户型搜索」两种类型，输入关键字时前端以 POST 请求 `/search/keyword/` 获取提示列表。后端用 `with_entities` 只查询目标字段和计数、用 `contains` 做模糊匹配，再按字段分组、按数量降序取前 9 条作为提示。

先在 `apps/index_page.py` 顶部补充导入：

```python
from flask import request, jsonify
from sqlalchemy import func
```

搜索提示视图：

```python
# http://127.0.0.1:5000/search/keyword/  --- post  --- form表单
# ----- kw 搜索关键    info 搜索类型（户型搜索/地区搜索）
@app_index.route('/search/keyword/', methods=['POST'])
def search_keyword():
    kw = request.form.get('kw')
    info = request.form.get('info')

    if info == "地区搜索":
        # with_entities：指定只查询 房源所在小区 和 计数结果
        # address：门头沟-双峪-门头沟小园村 ---> 1289
        # contains：模糊查询---》 包含
        house_data = House.query.with_entities(House.address, func.count()).filter(House.address.contains(kw))

        # 分组   排序（分组的address进行聚合count --- 排序 desc降序）
        result = house_data.group_by("address").order_by(func.count().desc()).limit(9).all()
        # [('门头沟-双峪-门头沟小园村', 382), ('门头沟-双峪-石门营小区', 372), ...]

        if len(result):
            # 数据重构为前端预期的结构：
            # {'code': 1, 'info': [{'t_name': '东城-xxx-xxxx', 'num': 108}, {}, {}]}
            data = []
            for i in result:  # ('门头沟-双峪-门头沟小园村', 382)
                data.append({"t_name": i[0], "num": i[1]})

            return jsonify({'code': 1, 'info': data})
        else:
            return jsonify({'code': 0, 'info': []})

    elif info == "户型搜索":
        house_data = House.query.with_entities(House.rooms, func.count()).filter(House.rooms.contains(kw))

        result = house_data.group_by("rooms").order_by(func.count().desc()).limit(9).all()

        if len(result):
            data = []
            for i in result:
                data.append({"t_name": i[0], "num": i[1]})

            return jsonify({'code': 1, 'info': data})
        else:
            return jsonify({'code': 0, 'info': []})
```

要点：

- `with_entities(House.address, func.count())`：只查询小区字段和每组的房源数量，不加载完整记录；
- `contains(kw)`：模糊查询，匹配字段中包含关键字的记录；
- `group_by("address")` + `order_by(func.count().desc())` + `limit(9)`：按小区分组、按数量降序、最多返回 9 条提示；
- 两种搜索类型逻辑相同，只是查询字段分别是 `address`（小区）和 `rooms`（户型）；没有匹配结果时统一返回 `{'code': 0, 'info': []}`。
