# 4 模板

Django 的模板引擎将表现层与业务逻辑分离。模板是定义渲染输出结构的文本文件，带有用于动态内容的特殊语法。

---

## 4.1 模板语法

Django 模板使用三种核心结构：**变量**、**标签**和**过滤器**。

### 4.1.1 变量

使用双花括号输出上下文字典中的值：

```django
<h1>{{ post.title }}</h1>
<p>Author: {{ post.author.name }}</p>
<p>Score: {{ user.score|default:0 }}</p>
```

变量解析遵循点号（`.`）表示法：
1. 字典查找：`{{ dict.key }}`
2. 属性/方法查找：`{{ obj.attr }}` 或 `{{ obj.method }}`
3. 列表索引：`{{ list.0 }}`

> **注意：** 模板中调用的方法不能带参数（内置标签除外）。

### 4.1.2 标签

标签使用 `{% %}` 执行逻辑和控制流：

```django
{% if user.is_authenticated %}
    <p>Welcome, {{ user.username }}!</p>
{% else %}
    <p>Please <a href="{% url 'login' %}">log in</a>.</p>
{% endif %}

{% for post in posts %}
    <h2>{{ post.title }}</h2>
{% empty %}
    <p>No posts available.</p>
{% endfor %}
```

### 4.1.3 过滤器

过滤器使用 `|` 转换变量的值：

```django
{{ post.title|upper }}
{{ post.created_at|date:"Y-m-d H:i" }}
{{ post.content|truncatewords:30 }}
{{ post.views|default:"N/A" }}
```

### 4.1.4 注释

```django
{# 单行注释 #}

{% comment %}
    多行注释。
    用于禁用模板块。
{% endcomment %}
```

---

## 4.2 内置标签参考

| 标签 | 用途 | 示例 |
|-----|---------|---------|
| `{% if %}` | 条件渲染 | `{% if user.is_staff %}...{% endif %}` |
| `{% for %}` | 遍历可迭代对象 | `{% for item in list %}...{% endfor %}` |
| `{% empty %}` | 空循环的兜底 | 在 `{% for %}` 块内部 |
| `{% url %}` | URL 反向解析 | `{% url 'detail' pk=1 %}` |
| `{% csrf_token %}` | 表单中的 CSRF 防护 | 在 `<form>` 标签内 |
| `{% extends %}` | 模板继承 | `{% extends 'base.html' %}` |
| `{% block %}` | 定义可覆盖的区块 | `{% block content %}...{% endblock %}` |
| `{% include %}` | 包含子模板 | `{% include 'navbar.html' %}` |
| `{% load %}` | 加载自定义标签/过滤器 | `{% load custom_tags %}` |
| `{% static %}` | 引用静态文件 | `{% static 'css/style.css' %}` |

---

## 4.3 内置过滤器参考

| 过滤器 | 用途 | 示例 |
|--------|---------|---------|
| `default` | 兜底值 | `{{ value\|default:"N/A" }}` |
| `length` | 统计项目数 | `{{ list\|length }}` |
| `upper` / `lower` | 大小写转换 | `{{ name\|upper }}` |
| `truncatewords:N` | 限制单词数 | `{{ text\|truncatewords:50 }}` |
| `truncatechars:N` | 限制字符数 | `{{ text\|truncatechars:100 }}` |
| `date` | 格式化日期时间 | `{{ dt\|date:"Y-m-d" }}` |
| `safe` | 标记为安全的 HTML | `{{ html_content\|safe }}` |
| `join` | 用分隔符连接列表 | `{{ list\|join:", " }}` |
| `first` / `last` | 获取第一项/最后一项 | `{{ list\|first }}` |
| `slugify` | 转换为 slug | `{{ title\|slugify }}` |

> **安全：** 绝不要对不受信任的用户输入使用 `|safe`。它会绕过 HTML 转义并暴露 XSS 漏洞。

## 4.4 模板继承

模板继承是 Django 维护一致布局最强大的特性。

### 基础模板

```django
<!-- templates/base.html -->
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>{% block title %}My Site{% endblock %}</title>
    {% block extra_css %}{% endblock %}
</head>
<body>
    {% include 'navbar.html' %}

    <main>
        {% block content %}{% endblock %}
    </main>

    {% include 'footer.html' %}
    {% block extra_js %}{% endblock %}
</body>
</html>
```

### 子模板

```django
<!-- templates/blog/post_list.html -->
{% extends 'base.html' %}

{% block title %}Blog Posts{% endblock %}

{% block content %}
    <h1>All Posts</h1>
    {% for post in posts %}
        <article>
            <h2>{{ post.title }}</h2>
            <p>{{ post.summary }}</p>
        </article>
    {% endfor %}
{% endblock %}
```

### 继承规则

| 规则 | 说明 |
|------|-------------|
| `{% extends %}` 必须是第一个标签 | 在它之前不能放任何内容 |
| 使用 `{{ block.super }}` | 包含父模板区块的内容 |
| 允许定义多个区块 | 按需定义任意多个 |
| 区块可以嵌套 | 用于细粒度定制 |

```django
{% block content %}
    {{ block.super }}   {# 包含父级内容 #}
    <p>Additional content</p>
{% endblock %}
```

## 4.5 模板加载与上下文

### 4.5.1 模板搜索路径

Django 按以下顺序搜索模板：
1. 应用目录（如果 `APP_DIRS = True`）
2. `settings.py` 中的 `DIRS` 列表

```python
# settings.py
TEMPLATES = [
    {
        'BACKEND': 'django.template.backends.django.DjangoTemplates',
        'DIRS': [BASE_DIR / 'templates'],   # 全局模板目录
        'APP_DIRS': True,                    # 搜索应用模板文件夹
    },
]
```

> **命名：** 使用 `app_name/template_name.html` 来避免应用之间的冲突。

### 4.5.2 从视图传递上下文

```python
from django.shortcuts import render

def post_list(request):
    posts = Post.objects.all()
    return render(request, 'blog/post_list.html', {
        'posts': posts,
        'page_title': 'Latest Posts',
    })
```

### 4.5.3 上下文处理器

上下文处理器会自动向每个模板上下文添加变量：

```python
# settings.py
TEMPLATES = [{
    'OPTIONS': {
        'context_processors': [
            'django.template.context_processors.debug',
            'django.template.context_processors.request',
            'django.contrib.auth.context_processors.auth',
            'django.contrib.messages.context_processors.messages',
        ],
    },
}]
```

内置上下文处理器会在所有模板中提供 `request`、`user`、`messages`、`perms` 和 `debug` 变量。

## 4.6 自定义过滤器

### 4.6.1 创建自定义过滤器

```python
# blog/templatetags/blog_extras.py
from django import template

register = template.Library()

@register.filter
def multiply(value, arg):
    """Multiply value by arg."""
    return value * arg

@register.filter(name='add_class')
def add_class(field, css_class):
    """Add CSS class to form field."""
    return field.as_widget(attrs={'class': css_class})
```

```python
# blog/templatetags/__init__.py
# Python 包必需的空文件
```

```django
<!-- 在模板中使用 -->
{% load blog_extras %}

<p>Total: {{ price|multiply:quantity }}</p>
{{ form.name|add_class:"form-control" }}
```

## 4.7 静态文件

在模板中引用 CSS、JavaScript 和图片：

```django
{% load static %}

<link rel="stylesheet" href="{% static 'css/style.css' %}">
<script src="{% static 'js/app.js' %}"></script>
<img src="{% static 'images/logo.png' %}" alt="Logo">
```

```python
# settings.py
STATIC_URL = '/static/'
STATICFILES_DIRS = [BASE_DIR / 'static']
```

## 4.8 最佳实践

| 建议 | 避免 |
|----|-------|
| 使用模板继承保持布局一致 | 在每个模板中复制粘贴相同的 HTML |
| 清晰地命名区块（`content`、`title`、`extra_css`） | 使用含糊的区块名 |
| 在模板中保持逻辑最小化 | 在模板中执行数据库查询或复杂计算 |
| 对可复用组件使用 `{% include %}` | 重复导航栏/页脚代码 |
| 始终转义用户输入（默认行为） | 对不受信任的数据使用 `\|safe` |
| 将模板组织为 `app_name/template.html` | 把所有模板堆在一个目录里 |

- **模板** = "变量 `{{ }}`、标签 `{% %}`、过滤器 `|`、继承 `{% extends %}`"
