# 16 会员管理

本章实现订餐管理后台的会员管理模块：会员列表（搜索 + 分页）、会员详情、编辑会员、删除/恢复会员。会员是小程序端的注册用户，数据存放在 `member` 表中，后台通过 Flask 蓝图 `route_member` 提供 `/member` 前缀下的一组管理页面。本章还会封装一个通用分页器 `iPagination`，后续所有列表页都会复用它。

## 16.1 功能准备

### 16.1.4 模型添加转换方法

数据库中的 `status`、`sex` 等字段存的是数字，页面上需要显示文字。在 `Member` 模型中用 `@property` 添加两个转换方法，模板里直接当属性用：

```python
# coding: utf-8
from application import db, app

class Member(db.Model):
    __tablename__ = 'member'

    # ......

    @property
    def status_desc(self):
        return app.config['STATUS_MAPPING'][int(self.status)]

    @property
    def sex_desc(self):
        sex_mapping = {
            "0": "未知",
            "1": "男",
            "2": "女"
        }
        return sex_mapping[str(self.sex)]
```

## 16.2 会员列表

列表页是会员管理的核心页面，要求支持按昵称关键字搜索、按状态筛选，并对结果分页。

### 16.2.1 构建通用分页器

在 `common/libs/Helper.py` 中封装分页函数 `iPagination`。它接收分页参数字典，计算页码范围并生成 Bootstrap 风格的分页 HTML，返回包含 HTML 和分页元数据的字典：

```python
import math

def iPagination(params):
    """
    分页函数
    :param params: 分页参数字典
        total：数据总量
        page_size：每一页多少条数据
        page：当前页
        display：页码框生成数量（默认10个）
        url：带查询参数的url
    :return: 分页HTML及相关数据
    """
    total = params['total']
    page_size = params['page_size']
    page = params['page']
    display = params['display']
    url = params['url']

    # 数据总量能分多少页：100/5=20 页；101/5=20.2 向上取整为 21 页
    total_pages = math.ceil(total / page_size)
    total_pages = total_pages if total_pages > 0 else 1

    # 计算显示的页码范围
    start = 1
    end = total_pages

    if total_pages > display:  # 总页数大于页码框数量时才需要截断
        if page <= (display // 2 + 1):  # 当前页在左侧区域
            start = 1
            end = display
        elif page > (total_pages - display // 2):  # 当前页在右侧区域
            start = total_pages - display + 1
            end = total_pages
        else:  # 当前页居中
            start = page - display // 2
            end = page + display // 2

    # 生成分页HTML
    html = []

    # 上一页
    if page > 1:
        html.append(f'<li><a href="{url}&p={page - 1}">&laquo;</a></li>')
    else:
        html.append('<li class="disabled"><a href="javascript:void(0);">&laquo;</a></li>')

    # 页码
    for i in range(int(start), int(end) + 1):
        if i == page:
            html.append(f'<li class="active"><a href="javascript:void(0);">{i}</a></li>')
        else:
            html.append(f'<li><a href="{url}&p={i}">{i}</a></li>')

    # 下一页
    if page < total_pages:
        html.append(f'<li><a href="{url}&p={page + 1}">&raquo;</a></li>')
    else:
        html.append('<li class="disabled"><a href="javascript:void(0);">&raquo;</a></li>')

    return {
        'html': ''.join(html),
        'total': total,
        'page_size': page_size,
        'page': page,
        'total_pages': total_pages,
        'start': start,
        'end': end
    }
```

页码范围的计算逻辑以 `display = 10` 为例：当前页靠前时固定显示 `1~10`，靠后时固定显示最后 10 页，否则以当前页为中心左右各取 5 页。

### 16.2.2 列表视图

在 `web/views/member/Member.py` 中实现 `index()` 视图。处理流程：取页码参数 → 拼接搜索条件 → 构建分页参数 → 查询当前页数据 → 渲染模板。注意 `url` 参数用 `request.full_path` 去掉已有的 `p` 参数，保证分页链接能带上搜索条件：

```python
# -*- coding: utf-8 -*-
from flask import Blueprint, request, redirect, url_for
from common.libs.render_helper import ops_render
from web.models.Member import Member
from common.libs.Helper import iPagination
from application import app

route_member = Blueprint('member_page', __name__)

@route_member.route("/index")
def index():
    resp_data = {}
    req = request.values
    # 查询参数 p 代表获取第几页数据，默认第 1 页
    page = int(req['p']) if ('p' in req and req['p']) else 1
    query = Member.query

    # 搜索条件：形如 /member/index?status=1&mix_kw=你好
    if 'mix_kw' in req and req['mix_kw']:
        # ilike 匹配时不区分大小写
        query = query.filter(Member.nickname.ilike("%{0}%".format(req['mix_kw'])))

    if 'status' in req and int(req['status']) > -1:
        query = query.filter(Member.status == int(req['status']))

    # 分页参数
    page_params = {
        'total': query.count(),  # 数据总量
        'page_size': app.config['PAGE_SIZE'],  # 每一页多少条数据
        'page': page,  # 当前页
        'display': app.config['PAGE_DISPLAY'],  # 页码框生成数量
        # 去掉已有的 p 参数，分页链接再重新拼接
        'url': request.full_path.replace("&p={}".format(page), "")
    }

    pages = iPagination(page_params)
    offset = (page - 1) * app.config['PAGE_SIZE']
    member_list = query.order_by(Member.id.desc()).offset(offset).limit(app.config['PAGE_SIZE']).all()

    resp_data['list'] = member_list
    resp_data['pages'] = pages
    resp_data['search_con'] = req  # 搜索条件回显
    resp_data['status_mapping'] = app.config['STATUS_MAPPING']
    resp_data['current'] = 'index'
    return ops_render("member/index.html", resp_data)
```

## 16.5 删除与恢复会员

删除和恢复都不真正删除数据，而是修改 `status` 字段（`0` 已删除、`1` 正常），即软删除。两个操作共用一个 `/ops` 接口。

### 16.5.1 前端入口

列表页的删除/恢复按钮通过 `data` 属性把会员 id 传给 js：

```html
<a class="m-l remove" href="javascript:void(0);" data="{{ item.id }}">
    <i class="fa fa-trash fa-lg"></i>
</a>
```

页面底部引入 `web/static/js/member/index.js`：

```html
<script src="{{ buildStaticUrl('/js/member/index.js') }}"></script>
```

`index.js` 中绑定删除、恢复按钮的点击事件，统一交给 `ops` 方法发送 ajax 请求到 `/member/ops`（携带 `act` 与 `id` 参数）：

```js

        this.eventBind();

    eventBind: function () {
        var that = this;

        $(".recover").click(function () {
            that.ops("recover", $(this).attr("data"));
        });
    },
    // ops 方法：向 /member/ops 发送 POST 请求，参数为 act 和 id
    // ......
};
```

### 16.5.2 后端统一操作接口

`ops()` 视图只接受 POST 请求，后端必须再次验证 `act` 和 `id` 的合法性（不能信任前端传参），然后按操作类型修改状态：

```python
@route_member.route("/ops", methods=['POST'])
def ops():
    if request.method == 'POST':
        resp = {"code": 200, "msg": "操作成功", "data": {}}
        req = request.values
        act = req["act"] if "act" in req else ""
        id = req["id"] if "id" in req else 0

        if act not in ["remove", "recover"]:
            resp["code"] = -1
            resp["msg"] = "操作有误"
            return jsonify(resp)
        if not id:
            resp["code"] = -1
            resp["msg"] = "请选择要操作的会员"
            return jsonify(resp)

        member_info = Member.query.filter_by(id=id).first()
        if not member_info:
            resp["code"] = -1
            resp["msg"] = "指定会员不存在"
            return jsonify(resp)

        if act == "remove":
            member_info.status = 0  # 删除状态
        elif act == "recover":
            member_info.status = 1  # 恢复正常状态
        member_info.updated_time = datetime.now()
        db.session.add(member_info)
        db.session.commit()
        return jsonify(resp)
```

        </a>
        <a class="m-l remove" href="javascript:void(0);" data="{{ item.id }}">
            <i class="fa fa-trash fa-lg"></i>

    {% else %}

    {% endif %}
