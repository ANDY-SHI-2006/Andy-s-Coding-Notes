# 18 小程序后台接口

前面章节完成了点餐系统的 Web 后台（账号、会员、美食管理）。本章开始打通小程序端：在 Flask 后台中新建专门的 `api` 蓝图包对外提供 JSON 接口，补充接口所需的配置与数据模型，并把小程序前端工程挂载导入微信开发者工具，完成第一次前后端联调。

## 18.1 API 构建及模型

### 18.1.1 创建 api 包

在点餐系统后台的 `web/views` 包中创建 `api` 包，并在其中创建 `Food.py` 和 `Member.py` 两个模块，分别承载美食相关和会员相关的接口：

启动项目后在浏览器访问 `http://127.0.0.1:8999/api/`，页面返回 `小程序 Api V1.0~~`，说明 api 蓝图注册成功。

### 18.1.3 接口相关配置

在 `base_settings.py` 中补充两项配置：

```python
# 登录拦截器的放行列表：/api 开头的请求不走后台登录校验
API_IGNORE_URLS = [
    "^/api"
]

# 小程序的 appid 与 appkey（微信公众平台上小程序的凭证，需替换为你自己的）
MINA_APP = {
    "appid": "your-appid",
    "appkey": "your-appsecret",
}
```

- `API_IGNORE_URLS`：后台的登录拦截器会对请求做登录校验，小程序接口面向客户端、不走后台账号体系，因此把 `^/api` 加入忽略列表。
- `MINA_APP`：保存小程序的 `appid` 和 `appkey`，后续微信登录（用 code 换 openid）等接口会用到。

## 18.3 接口联调：美食列表接口雏形

最后在 `api/Food.py` 中编写第一个真正的业务接口 `/api/food/index`，先实现轮播图数据（banner），验证小程序到后台的整条请求链路。

```python
from . import route_api
from web.models.Food import Food
from common.libs.UrlManager import UrlManager
from flask import jsonify


@route_api.route("/food/index")  # 完整路径为 /api/food/index
def food_index():
    resp = {"code": 200, "msg": "操作成功", "data": {}}

    # 根据分类显示不同的美食，分页，搜索（后续完善）
    query = Food.query.filter_by(status=1)

    # 轮播图功能，返回的数据结构：
    # [
    #     {"id": 1, "pic_url": "/images/food.jpg"},
    #     {"id": 2, "pic_url": "/images/food.jpg"},
    #     {"id": 3, "pic_url": "/images/food.jpg"}
    # ]
    food_list = query.order_by(Food.total_count.desc(), Food.id.desc()).all()
    data_food_list = []
    if food_list:
        for food in food_list:
            data_food_list.append({
                "id": food.id,
                "pic_url": UrlManager.buidImageUrl(food.main_image),
            })

    resp["data"]["banner_list"] = data_food_list

    return jsonify(resp)
```

要点：

- 接口统一返回 `{"code": 200, "msg": "...", "data": {...}}` 结构，`code` 为 200 表示成功，业务数据放在 `data` 中。
- 图片路径通过 `UrlManager.buidImageUrl()` 拼接成完整可访问的 URL，小程序端才能正常加载。
- 轮播图数据按销量 `total_count` 降序、再按 `id` 降序排列。

### 18.3.1 小程序端封装请求地址

在小程序的 `app.js` 中封装 `buildUrl` 方法，统一拼接域名和查询参数：

```javascript
buildUrl: function (path, params) {
    var url = this.globalData.domain + path;
    var paramUrl = "";
    if (params) {
        paramUrl = Object.keys(params).map(function (k) {
            return [encodeURIComponent(k), encodeURIComponent(params[k])].join("=");
        }).join("&");
        paramUrl = "?" + paramUrl;
    }
    return url + paramUrl;
},
```

其中 `globalData.domain` 指向后台服务地址（如 `http://127.0.0.1:8999/api`），`path` 传入接口路径（如 `/food/index`）。

### 18.3.2 小程序端发起请求

在首页 `food/index.js` 中调用接口获取轮播图数据：

```javascript
getBannerAndCat: function () {
    var that = this;
    wx.request({
        url: app.buildUrl("/food/index"),
        header: app.getRequestHeader(),
        success: function (res) {
            console.log("res---", res.data)
        }
    })
},
```

控制台能打印出后台返回的 JSON 数据，说明小程序到 Flask 后台的接口链路已经打通。后续章节会在此基础上完善美食列表的分页、搜索与详情接口。
