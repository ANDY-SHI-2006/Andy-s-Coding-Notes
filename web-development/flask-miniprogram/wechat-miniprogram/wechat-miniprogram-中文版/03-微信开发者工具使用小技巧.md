# 3 微信开发者工具使用小技巧

本章整理微信开发者工具中几个能明显提升开发效率的实用技巧：快速创建页面、常用快捷键、文件自动保存、外观主题设置和字体大小缩放。

## 3.1 快速创建小程序页面

新建页面时，不需要手动创建目录和文件：直接在 `app.json` 的 `pages` 配置项中填写页面路径，保存后开发者工具会**自动创建对应的页面目录和四个基础文件**（`.js`、`.json`、`.wxml`、`.wxss`）。

```json
{
  "pages": [
    "pages/index/index",
    "pages/logs/logs",
    "pages/test/test",
    "pages/demo/demo"
  ]
}
```

例如在 `pages` 数组末尾加入 `"pages/demo/demo"` 并保存，工具会自动生成 `pages/demo/` 目录及 `demo.js`、`demo.json`、`demo.wxml`、`demo.wxss` 四个文件。

![[ch03-01.png]]

> 提示：`pages` 数组的第一项就是小程序的首页，调整数组顺序即可改变首页。

## 3.2 快捷键使用

快捷键的查看与设置入口：

- 方式一：`文件` → `首选项` → `Keyboard Shortcuts`（`Ctrl+K Ctrl+S`）
- 方式二：`设置` → `快捷键设置`

常用快捷键：

| 功能 | 快捷键 |
| --- | --- |
| 单行注释 | `Ctrl + /` |
| 多行（块）注释 | `Shift + Alt + A` |
| 格式化文档 | `Shift + Alt + F` |
| 剪切 | `Ctrl + X` |
| 复制 | `Ctrl + C` |
| 粘贴 | `Ctrl + V` |

> 注意：wxml、js、wxss 三种文件的注释语法有差异（wxml 用 `<!-- -->`，js 用 `//` 和 `/* */`，wxss 用 `/* */`），使用注释快捷键时工具会自动按当前文件类型插入对应的注释符。

## 3.3 文件自动保存

开发者工具默认开启自动保存。可在菜单栏 `文件` → `自动保存` 中勾选或取消该功能。

![[ch03-02.png]]

也可以在 `文件` → `首选项` → `设置` 中，通过 `Files: Auto Save` 选项（如 `afterDelay`，延迟一段时间后自动保存）进行更细粒度的配置。

## 3.4 设置外观与主题

进入方式：`设置` → `外观` → `主题`。

可配置的内容包括：

- **主题**：深色 / 浅色 / 跟随系统（应用于除调试器外的整体界面）。
- **调试器主题**：深色 / 浅色 / 跟随系统 / 跟随自定义外观。
- **自定义外观**：使用默认外观或自定义外观，可分别编辑深色、浅色外观配置；更换编辑器主题时可询问适配。
- **标题内容**：项目主窗口标题栏显示的信息（当前文件或项目名称）。

![[ch03-03.png]]

## 3.5 字体大小缩放

进入方式：`文件` → `首选项` → `设置`，在"常用设置"中直接修改：

- `Editor: Font Size`：以像素为单位控制编辑器字体大小（如 `16`）。
- `Editor: Font Family`：控制编辑器字体系列（如 `Consolas`）。
- `Editor: Tab Size`：制表符长度（如 `2`）。
