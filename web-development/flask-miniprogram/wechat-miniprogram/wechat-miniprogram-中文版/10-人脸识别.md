# 10 人脸识别

本章实现一个完整的人脸识别小程序：前端通过相机组件在线采集人脸图片，把图片的 base64 字符串传给云开发中的云函数，云函数调用腾讯云人脸识别（人脸检测与分析 DetectFace）接口，最后把识别结果回传到小程序页面展示。

> 云函数使用量（GBs）的统计规则为：**云函数配置内存（GB）× 运行时长（s）**。例如，若云函数内存设置为 512MB（即 0.5GB），运行 1 秒则消耗 `0.5GB × 1s = 0.5GBs`。

## 10.1 实现方式

整体链路分为三段：

1. **前端采集**：小程序页面使用 `<camera>` 相机组件拍摄人脸照片；
2. **云端识别**：把照片转成 base64 字符串，通过 `wx.cloud.callFunction` 调用云函数，云函数内部使用腾讯云 SDK（`tencentcloud-sdk-nodejs`）调用人脸识别接口；
3. **结果回传**：云函数把识别结果返回给小程序，页面通过数据绑定展示性别、年龄、表情、魅力值、人脸框位置等信息。

## 10.2 实现流程概览

- 第一步：开通云开发控制台并创建云端项目环境
- 第二步：配置云函数目录
- 第三步：创建人脸识别云函数并配置 `tencentcloud-sdk-nodejs` 依赖
- 第四步：在云函数入口文件 `index.js` 中实现人脸检测与分析 API 调用，并上传部署到云端
- 第五步：在小程序中实现人脸图片在线采集页面

## 10.3 第一步：开通云开发控制台并创建云端项目环境

在微信开发者工具中开通云开发，进入云开发控制台，确认当前环境已创建（如云环境 `cloudbase`），并可在「云函数 → 云函数列表」中管理云函数。

## 10.4 第二步：云函数目录

在小程序项目根目录下建立本地云函数目录（如 `cloudfunctions`），并在项目根目录的 `project.config.json` 中通过 `cloudfunctionRoot` 字段指定该目录：

```json
{
  "miniprogramRoot": "miniprogram/",
  "cloudfunctionRoot": "cloudfunctions/"
}
```

配置后，`cloudfunctions` 目录会显示为云函数根目录（带当前环境标识）。

## 10.5 第三步：创建人脸识别云函数并配置依赖

右键 `cloudfunctions` 目录，选择「新建 Node.js 云函数」，命名为 `face`。新建的云函数目录包含：

```
face/
├── config.json
├── index.js
└── package.json
```

在 `face/package.json` 的 `dependencies` 中添加腾讯云 SDK 依赖：

```json
"dependencies": {
  "wx-server-sdk": "~3.0.1",
  "tencentcloud-sdk-nodejs": "latest"
}
```

## 10.6 第四步：实现人脸检测 API 调用并上传云函数

### 10.6.1 准备腾讯云密钥与参考资料

- 腾讯云 SecretId / SecretKey 获取地址：https://console.cloud.tencent.com/cam/capi
- **注意**：自 2023 年 11 月 30 日起，新建的密钥只在创建时提供 SecretKey，后续不可再进行查询，请妥善保存。
- 接口调试台（可在线调试 DetectFace 接口）：https://console.cloud.tencent.com/api/explorer?Product=iai&Version=2020-03-03&Action=DetectFace
- API 文档：https://cloud.tencent.com/document/product/867/44989

### 10.6.2 云函数入口文件 index.js

在云函数 `face/index.js` 中实现人脸检测与分析（DetectFace）的 API 调用：

```javascript
// 云函数入口文件
const cloud = require('wx-server-sdk')

cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV }) // 使用当前云环境

// 云函数入口函数
exports.main = async (event, context) => {
  const tencentcloud = require("tencentcloud-sdk-nodejs");
  const IaiClient = tencentcloud.iai.v20200303.Client; // 初始化服务

  // 构建配置
  // 密钥可前往官网控制台 https://console.cloud.tencent.com/cam/capi 进行获取
  // 生产环境建议从环境变量读取密钥（TENCENTCLOUD_SECRET_ID / TENCENTCLOUD_SECRET_KEY），
  // 避免把密钥硬编码在代码中
  const clientConfig = {
    credential: {
      secretId: "",
      secretKey: "",
    },
    region: "ap-guangzhou",
    profile: {
      httpProfile: {
        endpoint: "iai.tencentcloudapi.com",
      },
    },
  };
  // 实例化要请求产品的 client 对象，clientProfile 是可选的
  const client = new IaiClient(clientConfig);
  // 接收客户端 post 的 x 参数，值类型为 base64 字符串
  let base64Data = event.x
  // 定义 SDK 的请求参数字典
  const params = {
    Image: base64Data, // 图片 base64 数据
    NeedFaceAttributes: 1 // 是否需要返回人脸属性信息（FaceAttributesInfo）。0 为不需要返回，1 为需要返回。
  };
  // 通过 Promise 容器来接收异步 API 的回调，然后通过当前脚本返回给客户端
  return new Promise((resolve, reject) => {
    // 此接口是异步的，那么当前脚本无法对外直接访问接口返回值
    client.DetectFace(params, function (errmsg, response) {
      if (errmsg) {
        resolve({
          "Result": errmsg
        })
      }
      resolve({
        "Result": response
      })
    })
  })
}
```

关键点：

- `region` 指定接口地域（如 `ap-guangzhou`），`endpoint` 固定为 `iai.tencentcloudapi.com`；
- 请求参数 `Image` 接收图片的 base64 字符串；`NeedFaceAttributes` 设为 1 时返回人脸属性信息 `FaceAttributesInfo`（性别、年龄、表情、魅力值等）；
- `DetectFace` 是异步接口，用 `Promise` 包装回调后再把结果返回给小程序端；
- 云函数默认模板中通过 `cloud.getWXContext()` 可获取 `OPENID`、`APPID`、`UNIONID`，本例中未使用。

### 10.6.3 上传并部署

右键云函数目录 `face`，选择「上传并部署：云端安装依赖（不上传 node_modules）」，把云函数上传至云端。

### 10.7.2 camerac.wxml

页面包含相机组件、拍照按钮和识别结果展示区：

```html
<!--pages/camerac/camerac.wxml-->
<camera device-position="front" flash="off" binderror="error" style="width: 100%; height: 300px;"></camera>
<button type="primary" bindtap="takePhoto">拍照</button>

<!-- 人脸属性：性别、年龄、表情、魅力值 -->
<view wx:if="{{ FaceInfos['0']['FaceAttributesInfo']['Gender'] > 50 }}">性别：男</view>
<view wx:if="{{ FaceInfos['0']['FaceAttributesInfo']['Gender'] < 50 }}">性别：女</view>
<view>年龄：{{ FaceInfos['0']['FaceAttributesInfo']['Age'] }}</view>
<view wx:if="{{ FaceInfos['0']['FaceAttributesInfo']['Expression'] == 0 }}">表情：正常</view>
<view wx:if="{{ FaceInfos['0']['FaceAttributesInfo']['Expression'] < 50 }}">表情：微笑</view>
<view wx:if="{{ FaceInfos['0']['FaceAttributesInfo']['Expression'] > 50 }}">表情：大笑</view>
<view wx:if="{{ FaceInfos['0']['FaceAttributesInfo']['Beauty'] == 0 }}">魅力值：一般</view>
<view wx:if="{{ FaceInfos['0']['FaceAttributesInfo']['Beauty'] < 50 }}">魅力值：有点迷人</view>
<view wx:if="{{ FaceInfos['0']['FaceAttributesInfo']['Beauty'] > 50 }}">魅力值：偶像级</view>

<!-- 图片尺寸与人脸框位置 -->
<view>请求的图片宽度：{{ ImageWidth }}</view>
<view>请求的图片高度：{{ ImageHeight }}</view>
<view>人脸框左上角横坐标：{{ FaceInfos['0']['X'] }}</view>
<view>人脸框左上角纵坐标：{{ FaceInfos['0']['Y'] }}</view>
<view>人脸框宽度：{{ FaceInfos['0']['Width'] }}</view>
<view>人脸框高度：{{ FaceInfos['0']['Height'] }}</view>

<!-- 显示拍摄的照片 -->
<image mode="widthFix" src="{{src}}"></image>
```

说明：

- `<camera>` 组件 `device-position="front"` 使用前置摄像头，`binderror` 绑定相机错误处理函数；
- 返回值中 `FaceInfos` 是人脸信息数组，`FaceInfos[0].FaceAttributesInfo` 包含人脸属性：`Gender`（>50 男 / <50 女）、`Age`（年龄）、`Expression`（==0 正常 / <50 微笑 / >50 大笑）、`Beauty`（==0 一般 / <50 有点迷人 / >50 偶像级）；
- `X`、`Y` 为人脸框左上角坐标，`Width`、`Height` 为人脸框宽高。

### 10.7.3 camerac.js

```javascript
takePhoto() {
  var that = this; // 指定 this 到 that，避免绑定的对象改变
  const ctx = wx.createCameraContext() // 创建 camera 上下文 CameraContext 对象
  // 拍摄照片
  ctx.takePhoto({
    quality: 'high',
    success: (res) => {
      this.setData({
        // 把拍完照的照片路径赋值给 src 属性
        src: res.tempImagePath
      })
      // Sync 同步读取
      // wx.getFileSystemManager().readFile() 用于读取本地文件内容，
      // 支持读取文本或二进制数据，单个文件大小上限为 100MB。
      // 把照片数据转换为 base64 编码的数据
      var base64 = wx.getFileSystemManager().readFileSync(res.tempImagePath, 'base64')
      // 初始化云服务
      wx.cloud.init()
      // 调用云函数
      wx.cloud.callFunction({
        name: 'face', // 云函数名称
        data: { // 传给云函数的参数
          x: base64 // 传图片的 base64 字符串
        },
        success: function (res) {
          that.setData({
            ImageWidth: res.result.Result.ImageWidth + "px",
            ImageHeight: res.result.Result.ImageHeight + "px",
            FaceInfos: res.result.Result.FaceInfos,
          })
        },
        fail: console.error
      })
    },
    error(e) {
      console.log(e.detail)
    }
  })
},
```

流程：`wx.createCameraContext()` 创建相机上下文 → `ctx.takePhoto()` 拍照拿到临时路径 `tempImagePath` → `readFileSync(path, 'base64')` 同步读取为 base64 字符串 → `wx.cloud.callFunction` 调云函数 `face` 并把 base64 放在参数 `x` 中 → 成功后把 `ImageWidth`、`ImageHeight`、`FaceInfos` 写入页面数据。
