# 6 自定义组件

> 官方文档：https://developers.weixin.qq.com/miniprogram/dev/framework/custom-component/

## 6.1 什么是自定义组件

小程序中常常会有些通用的交互模块，比如：下拉选择列表、搜索框、日期选择器等。这些界面交互模块可能会在多个页面中用到，逻辑也相对独立；然而，用传统的小程序开发方法来实现非常繁琐。小程序基础库提供了让开发者自己创建界面组件的特性，称之为"自定义组件"。通过这个特性，开发者就能够将这样的交互模块抽象成界面组件，使界面代码的组织变得非常灵活。

## 6.2 使用场景

- 多个页面用到同样的东西（复用）。
- 页面功能很多、很复杂，使用组件来拆分逻辑。

## 6.3 自定义组件组成

一个自定义组件由 4 个文件组成，与页面结构类似：

- `json` 文件：用于放置一些最基本的组件配置。
- `wxml` 文件：组件模板。
- `wxss` 文件：组件的样式（无法直接使用全局样式，需要通过 `@import` 导入）。
- `js` 文件：组件的 js 代码，承载组件的主要逻辑。

## 6.4 创建自定义组件

### 6.4.1 新建自定义组件文件

在根目录新建 `components` 目录，然后右键新建自定义组件目录。例如新建 `SearchInput` 组件后，目录结构为：

```
components/
└── SearchInput/
    ├── SearchInput.js
    ├── SearchInput.json
    ├── SearchInput.wxml
    └── SearchInput.wxss
```

### 6.4.2 配置组件 json 文件

需要在 json 文件中进行自定义组件声明：将 `component` 字段设为 `true`，可将这一组文件设为自定义组件。

```json
{
  "component": true,
  "usingComponents": {}
}
```

### 6.4.3 配置组件 js 文件

在自定义组件的 js 文件中，需要使用 `Component()` 来注册组件，并提供组件的属性定义、内部数据和自定义方法。

组件的属性值和内部数据将被用于组件 wxml 的渲染，其中，属性值是可由组件外部传入的。更多细节参见官方文档的 Component 构造器。

```js
// components/SearchInput/SearchInput.js
Component({
  /**
   * 组件的属性列表
   */
  properties: {
  },
  /**
   * 组件的初始数据
   */
  data: {
  },
  /**
   * 组件的方法列表
   */
  methods: {
  }
})
```

### 6.4.4 在 SearchInput.wxml 中写入内容

```html
<view class="search_input">
  <navigator url="/pages/logs/logs" open-type="navigate">搜索</navigator>
</view>
```

### 6.4.5 在 SearchInput.wxss 配置样式

```css
.search_input {
  height: 90rpx;
  padding: 10rpx;
  background-color: var(--themeColor);
}

.search_input navigator {
  height: 100%;
  display: flex;
  justify-content: center;
  align-items: center;
  background-color: #fff;
  border-radius: 15rpx;
  color: #666;
}
```

其中主题色变量 `--themeColor` 定义在全局样式 `app.wxss` 中：

```css
page {
  --themeColor: #eb4450;
}
```

## 6.5 引入自定义组件

以在 `/pages/index/index` 父组件中引入子组件为例。

### 6.5.1 在父组件 json 文件的 usingComponents 中导入组件

键是组件名称（即 wxml 中使用的标签名），值是子组件路径：

```json
{
  "usingComponents": {
    "SearchInput": "/components/SearchInput/SearchInput"
  }
}
```

### 6.5.2 在父组件 wxml 文件中以组件名称作为标签使用组件

```html
<!-- index.wxml -->
<SearchInput></SearchInput>
```

## 6.6 组件参数传递

与 Vue 父子组件传参原理一样。

### 6.6.1 父传子

- 父组件：通过属性传递，如 `<child message="{{data}}">`。
- 子组件：通过 `properties` 接收。

父组件：

```html
<!-- parent.wxml -->
<view>
  <text>我是父组件</text>
  <!-- 传递数据给子组件 -->
  <child-component message="{{parentMessage}}"></child-component>
</view>
```

```js
// parent.js
Page({
  data: {
    parentMessage: "这是来自父组件的数据"
  }
})
```

```json
// parent.json
{
  "usingComponents": {
    "child-component": "/components/child-component"
  }
}
```

子组件：

```html
<!-- components/child-component.wxml -->
<view>
  <text>我是子组件</text>
  <text>接收到的数据：{{message}}</text>
</view>
```

```js
// components/child-component.js
Component({
  properties: {
    // 接收父组件传递的数据
    message: {
      type: String,
      value: '默认值'
    }
  }
})
```

**结果**：子组件会显示"接收到的数据：这是来自父组件的数据"。

### 6.6.2 子传父

- 子组件：通过 `this.triggerEvent('事件名', 数据)` 发送。
- 父组件：通过 `bind:事件名="处理函数"` 接收，数据在 `e.detail` 中。

子组件：

```html
<!-- components/child-component.wxml -->
<view>
  <text>我是子组件</text>
  <button bindtap="sendDataToParent">向父组件发送数据</button>
</view>
```

```js
// components/child-component.js
Component({
  methods: {
    sendDataToParent() {
      // 触发自定义事件，向父组件传递数据
      this.triggerEvent('myevent', {
        data: '这是来自子组件的数据',
        time: new Date().toLocaleTimeString()
      })
    }
  }
})
```

父组件：

```html
<!-- parent.wxml -->
<view>
  <text>我是父组件</text>
  <text>收到子组件数据：{{childData}}</text>
  <!-- 监听子组件事件 -->
  <child-component bind:myevent="onChildEvent"></child-component>
</view>
```

```js
// parent.js
Page({
  data: {
    childData: ''
  },

  // 接收子组件传递的数据
  onChildEvent(e) {
    const dataFromChild = e.detail.data;
    this.setData({
      childData: `${dataFromChild} - ${e.detail.time}`
    });
  }
})
```

**结果**：点击子组件按钮后，父组件会显示"收到子组件数据：这是来自子组件的数据 - 当前时间"。

### 6.6.3 案例：自定义 tab 栏

最终效果：

实现步骤如下：

**1. 定义 Tabs 组件**：在 `components` 目录创建 `Tabs` 文件夹并添加 Tabs 组件。

**2. 编写组件的 Tabs.wxml**：

```html
<view class="tabs">
  <view class="tabs_title">
    <view wx:for="{{tabs}}" wx:key="id" class="title_item {{item.isActive?'active':''}}">
      {{item.value}}
    </view>
  </view>
  <view class="tabs_content">
  </view>
</view>
```

**3. 编写组件的 Tabs.wxss**：

```css
.tabs {}

.tabs_title {
  display: flex;
}

.title_item {
  display: flex;
  justify-content: center;
  align-items: center;
  flex: 1;
  padding: 15rpx 0;
}

.active {
  color: var(--themeColor);
  border-bottom: 5rpx solid currentColor;
}

.tabs_content {}
```

**4. 编写组件的 Tabs.js**：通过 `properties` 声明要接收的 `tabs` 属性。

```js
// components/Tabs/Tabs.js
Component({
  /**
   * 组件的属性列表
   */
  properties: {
    tabs: {
      type: Array,
      value: []
    }
  },
  /**
   * 组件的初始数据
   */
  data: {
  },
  /**
   * 组件的方法列表
   */
  methods: {
  }
})
```

**5. 在商品列表的 index.js 定义数据**：

```js
// pages/goods_list/index.js
Page({
  /**
   * 页面的初始数据
   */
  data: {
    tabs: [
      {
        id: 0,
        value: "综合",
        isActive: true
      },
      {
        id: 1,
        value: "销量",
        isActive: false
      },
      {
        id: 2,
        value: "价格",
        isActive: false
      }
    ],
  },
  /**
   * 生命周期函数--监听页面加载
   */
  onLoad: function (options) {
    // 输出传递过来的参数
    console.log(options)
  },
})
```

**6. 在商品列表的 index.json 引用组件**：

```json
{
  "usingComponents": {
    "SearchInput": "/components/SearchInput/SearchInput",
    "Tabs": "/components/Tabs/Tabs"
  },
  "navigationBarTitleText": "商品列表"
}
```

**7. 在商品列表的 index.wxml 添加组件**，并通过属性把 `tabs` 数据传给子组件：

```html
<view>
  <SearchInput></SearchInput>
  <Tabs tabs="{{tabs}}"></Tabs>
</view>
```

### 6.6.4 Tabs 点击事件实现

点击标题需要切换激活项，这是典型的"子传父"：子组件触发事件，父组件修改数据后再传回子组件。

**1. 在 Tabs.wxml 绑定点击事件**：通过 `bindtap` 绑定处理函数，并用 `data-index` 把当前索引传给事件处理函数。

```html
<view class="tabs">
  <view class="tabs_title">
    <view
      wx:for="{{tabs}}"
      wx:key="id"
      class="title_item {{item.isActive?'active':''}}"
      bindtap="handleItemTap"
      data-index="{{index}}"
    >
      {{item.value}}
    </view>
  </view>
  <view class="tabs_content">
    <slot></slot>
  </view>
</view>
```

**2. 在 Tabs.js 编写绑定事件 handleItemTap**：获取被点击的索引，通过 `this.triggerEvent` 触发自定义事件通知父组件。

```js
// components/Tabs/Tabs.js
Component({
  /**
   * 组件的属性列表
   */
  properties: {
    tabs: {
      type: Array,
      value: []
    }
  },
  /**
   * 组件的方法列表
   */
  methods: {
    // 点击事件
    handleItemTap(e) {
      // 1.获取点击的索引
      const { index } = e.currentTarget.dataset;
      // console.log(index)
      // 2.触发父组件中的事件 自定义
      this.triggerEvent("tabsItemChange", { index });
    }
  }
})
```

**3. 在父组件 goods_list 的 index.js 编写绑定事件 tabsItemChange**：取出索引，修改源数组中各项的 `isActive`，再用 `setData` 赋值回 `data`。

```js
// 标题点击事件 从子组件传递过来（写在 onLoad 方法之后）
handleTabsItemChange(e) {
  // 1 获取被点击的标题索引
  console.log(e)
  const { index } = e.detail;
  // 2 修改源数组
  let { tabs } = this.data;
  tabs.forEach((v, i) => i === index ? v.isActive = true : v.isActive = false);
  // 3 赋值到data中
  this.setData({
    tabs
  })
},
```

**4. 在 Tabs.wxml 添加插槽 slot**：`slot` 用于在组件中预留位置，让父组件可以自定义插入内容。

```html
<view class="tabs_content">
  <slot></slot>
</view>
```

> 插槽文档：https://developers.weixin.qq.com/miniprogram/dev/framework/custom-component/wxml-wxss.html

**5. 在父组件编写内容，传递给插槽**：在 `Tabs` 标签内部编写内容，并根据激活项用 `wx:if` / `wx:elif` 控制展示。

```html
<view>
  <SearchInput></SearchInput>
  <Tabs tabs="{{tabs}}" bindtabsItemChange="handleTabsItemChange">
    <block wx:if="{{tabs[0].isActive}}">综合</block>
    <block wx:elif="{{tabs[1].isActive}}">销量</block>
    <block wx:elif="{{tabs[2].isActive}}">价格</block>
  </Tabs>
</view>
```
