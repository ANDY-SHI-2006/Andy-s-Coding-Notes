# 17 二手房项目简介

## 17.1 项目概述

从本章开始，我们用一个完整的实战项目——**二手好房网**，把前面学过的 Flask 知识（路由、模板、SQLAlchemy 模型、蓝图、RESTful 等）串联起来。

项目基本情况：

- **项目类型**：二手房/租房信息网站，名为「二手好房网」。
- **技术栈**：Flask + Flask-SQLAlchemy + MySQL（配合 Flask-Migrate 做数据库迁移，后续章节逐步引入）。
- **数据来源**：真实的二手房源数据，通过课程提供的 `house.sql` 文件导入 MySQL 数据库（`house_info` 表约 11 万条房源记录）。

项目包含五大功能模块，下面逐一介绍。

## 17.2 功能介绍

### 17.2.1 首页

首页是网站的门面，主要包含：

- 顶部横幅与搜索框：支持「地区搜索」和「户型搜索」两种方式。
- 当前城市与房源总数统计（如：当前城市 北京，房源总数 113318）。
- 「为您为家」板块：展示推荐的优质房源。

![[ch17-01.png]]

### 17.2.2 登录与注册

以弹出窗口（模态框）的形式提供用户登录与注册：

- **登录**：用户名 + 密码，提供「还没有账号？点我注册」入口。
- **注册**：用户名（6–15 位字母或数字）、密码（至少 6 位字母或数字）、再次输入密码、邮箱，提供「已有账号？点我登录」入口。

![[ch17-02.png]]

### 17.2.3 搜索房源

在搜索框中输入关键词时，页面会**自动补全**匹配的房源地址（如「朝阳-高碑店-北花园小区」），并在右侧显示该小区大约有多少套房，方便用户快速定位目标房源。

![[ch17-03.png]]

### 17.2.4 房源列表

列表页以卡片形式展示房源，每条房源包含：

- 房源图片、标题、价格
- 房源地址（区域-街道-小区）
- 建筑面积、户型、朝向
- 交通条件、浏览量（多少人浏览过）

![[ch17-04.png]]

### 17.2.5 房源详情

详情页展示单套房源的完整信息：

- 房源大图、价格、**收藏**按钮
- 「基本信息」：房屋户型、建筑面积、房屋朝向、所在区域、租住类型、房东电话、交通条件、房源亮点等
- **数据可视化图表**（基于 ECharts）：
  - 所在小区的**价格走势**散点图
  - 所在小区的**户型占比**饼图

![[ch17-05.png]]

## 17.3 数据表概览

课程提供的 `house.sql` 中包含三张表，导入后即可为项目提供数据支持。

### 17.3.1 房源表 house_info

核心数据表，存储全部房源信息（约 11 万条记录）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | int | 主键，自增 |
| `title` | varchar(100) | 房源标题 |
| `rooms` | varchar(100) | 房源户型（如 2室1厅） |
| `area` | varchar(100) | 房源面积 |
| `price` | varchar(100) | 房源价格 |
| `direction` | varchar(100) | 房源朝向 |
| `rent_type` | varchar(100) | 租住类型（整租/合租主卧等） |
| `region` | varchar(100) | 房源所在区（如 朝阳区） |
| `block` | varchar(100) | 房源所在街道（如 朝阳-高碑店） |
| `address` | varchar(200) | 房源所在小区 |
| `traffic` | varchar(100) | 交通条件 |
| `publish_time` | int | 发布时间（时间戳） |
| `facilities` | text | 配套设施 |
| `highlights` | text | 房屋优势/亮点 |
| `matching` | text | 周边配套 |
| `travel` | text | 公交出行 |
| `page_views` | int | 浏览量 |
| `landlord` | varchar(30) | 房东姓名 |
| `phone_num` | varchar(100) | 房东电话 |
| `house_num` | varchar(100) | 房源编号 |

建表语句（节选）：

```sql
CREATE TABLE `house_info`  (
  `id` int UNSIGNED NOT NULL AUTO_INCREMENT,
  `title` varchar(100) NULL DEFAULT NULL,        -- 房源标题
  `rooms` varchar(100) NULL DEFAULT NULL,        -- 房源户型
  `area` varchar(100) NULL DEFAULT NULL,         -- 房源面积
  `price` varchar(100) NULL DEFAULT NULL,        -- 房源价格
  `direction` varchar(100) NULL DEFAULT NULL,    -- 房源朝向
  `rent_type` varchar(100) NULL DEFAULT NULL,    -- 租住类型
  `region` varchar(100) NULL DEFAULT NULL,       -- 房源所在区
  `block` varchar(100) NULL DEFAULT NULL,        -- 房源所在街道
  `address` varchar(200) NULL DEFAULT NULL,      -- 房源所在小区
  `traffic` varchar(100) NULL DEFAULT NULL,      -- 交通条件
  `publish_time` int NULL DEFAULT NULL,          -- 发布时间
  `facilities` text NULL,                        -- 配套设施
  `highlights` text NULL,                        -- 房屋优势
  `matching` text NULL,                          -- 周边配套
  `travel` text NULL,                            -- 公交出行
  `page_views` int NULL DEFAULT NULL,            -- 浏览量
  `landlord` varchar(30) NULL DEFAULT NULL,      -- 房东姓名
  `phone_num` varchar(100) NULL DEFAULT NULL,    -- 房东电话
  `house_num` varchar(100) NULL DEFAULT NULL,    -- 房源编号
  PRIMARY KEY (`id`)
) ENGINE = InnoDB CHARACTER SET = utf8;
```

### 17.3.2 用户表 user_info

存储注册用户的信息，以及用户的收藏和浏览记录（以逗号分隔的房源编号字符串保存）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | int | 主键，自增 |
| `name` | varchar(100) | 用户昵称 |
| `password` | varchar(100) | 用户密码 |
| `email` | varchar(100) | 邮箱地址 |
| `addr` | varchar(100) | 用户住址 |
| `collect_id` | varchar(250) | 用户收藏的房源编号 |
| `seen_id` | varchar(250) | 用户浏览记录 |

### 17.3.3 推荐表 house_recommend

存储为用户推荐的房源及推荐评分，用于首页推荐和个性化推荐功能：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | int | 主键，自增 |
| `user_id` | int | 用户 id |
| `house_id` | int | 房源 id |
| `title` | varchar(100) | 房源标题 |
| `address` | varchar(100) | 房源所在小区 |
| `block` | varchar(100) | 房源所在街道 |
| `score` | int | 推荐评分 |

## 17.4 小结

- 二手好房网是一个基于 Flask + SQLAlchemy + MySQL 的二手房信息网站实战项目。
- 五大功能模块：首页、登录与注册、搜索房源、房源列表、房源详情。
- 数据由 `house.sql` 提供，包含 `house_info`（房源）、`user_info`（用户）、`house_recommend`（推荐）三张表。
