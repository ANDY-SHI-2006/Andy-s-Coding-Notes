# 20 列表页设计与实现

本章实现二手房项目的列表页：搜索列表页（按地区 / 户型搜索 + 分页）、最热与最新房源列表页，并补充房源详情页、推荐列表与数据可视化、房价预测等课程内容。列表页相关代码集中在新蓝图 `app_list` 中。

## 20.1 搜索列表页

搜索列表页支持两种搜索条件——地区（`addr`）和户型（`rooms`），通过查询字符串传递，并支持分页。路由设计如下：

```
http://127.0.0.1:5000/query?addr=       地区
http://127.0.0.1:5000/query?rooms=      户型
http://127.0.0.1:5000/query/1?addr=     地区（带页码）
http://127.0.0.1:5000/query/1?rooms=    户型（带页码）
```

### 20.1.1 搜索视图与分页

同一个视图函数 `search_info` 通过两个装饰器注册两条路由：`/query`（默认第 1 页）和 `/query/<int:page>`（指定页码）。视图内部根据查询参数判断是地区搜索还是户型搜索，查询结果按发布时间降序排列，每页 10 条：

```python
from flask import Blueprint, request, redirect, url_for, render_template
from model import House
import math

app_list = Blueprint('app_list', __name__)


@app_list.route('/query')
@app_list.route('/query/<int:page>')
def search_info(page=1):
    # 地区搜索 ？ 户型搜索
    if request.args.get("addr"):  # 地区搜索
        address = request.args.get("addr")
        data = House.query.filter(House.address == address)

        # 数据总量
        num = data.count()
        # 总页数
        total_num = math.ceil(num / 10)

        result = data.order_by(House.publish_time.desc()).paginate(page=page, per_page=10)

        return render_template('list.html', house_list=result, page_num=page, total_num=total_num)
    elif request.args.get("rooms"):  # 户型搜索
        rooms = request.args.get("rooms")
        data = House.query.filter(House.rooms == rooms)

        # 数据总量
        num = data.count()
        # 总页数
        total_num = math.ceil(num / 10)

        result = data.order_by(House.publish_time.desc()).paginate(page=page, per_page=10)

        return render_template('list.html', house_list=result, page_num=page, total_num=total_num)

    # 没有任何搜索条件，重定向回首页
    return redirect(url_for("app_index.index"))
```

分页的关键点：

- `data.count()` 先查出符合条件的数据总量 `num`；
- 总页数 `total_num = math.ceil(num / 10)`，即总条数除以每页条数向上取整；
- `paginate(page=page, per_page=10)` 完成真正的分页查询；
- 模板需要三个变量：`house_list`（分页结果）、`page_num`（当前页码）、`total_num`（总页数）。

### 20.1.3 前端分页插件

前端使用 jQuery 分页插件 `createPage` 渲染页码。总页码数由模板变量 `{{ total_num }}` 注入，当前页码从 `#fill-data` 元素的 class 中读取；点击页码时在回调函数 `backfun` 中拼接新 URL 并跳转：

```html
<script>
    $(document).ready(function () {
        $(".zxf_pagediv").createPage({
            pageNum: {{total_num}},  // 总的页码数
            {#pageNum: 10,  // 总的页码数#}
            current: Number($('#fill-data').attr('class')),  // 当前的页码
            backfun: function (e) {  // 回调函数
                console.log(e['current']);  // e['current'] 是单击更多房源链接文本时候的页码
                var n_current = e['current'];
                // 获取当前页的地址
                var part_path = window.location.pathname;

                if (part_path.includes('query')) {
                    var path_list = part_path.split('/');
                    {#console.log('demo:', path_list.length)#}
                    if (path_list.length === 2) {
                        // 当前是 /query，直接在路径后追加页码，并保留查询字符串
                        var n_url = part_path + '/' + n_current.toString() + window.location.search
                        window.location.replace(n_url);
                        return;
                    } else {
                        // 将单击下一页的页码替换原来的页码
                        path_list[2] = n_current;
                        // 获取重新拼接的新URL地址
                        var n_url = path_list.join('/') + window.location.search;
                        console.log(n_url);
                        // 重新加载
                        window.location.replace(n_url);
                        return;
                    }
                }

                // 最新/最热列表页，形如 /list/pattern/1
                var path_list = part_path.split('/');
                // 将单击下一页的页码替换原来的页码
                path_list[3] = n_current;
                // 获取重新拼接的新URL地址
                var n_url = path_list.join('/') + window.location.search;
                console.log(n_url);
                // 重新加载
                window.location.replace(n_url);
            }
        });
    });
</script>
```

拼接逻辑分三种情况：

- `/query`（`path_list` 长度为 2）：直接追加 `/页码`，并带上 `window.location.search` 保留 `?addr=` / `?rooms=` 查询参数；
- `/query/2` 这类已带页码的搜索地址：替换 `path_list[2]` 为点击的页码，同样保留查询字符串；
- `/list/pattern/1` 这类最新 / 最热列表地址：替换 `path_list[3]` 为点击的页码。

## 20.3 房源详情页与浏览记录

详情页在 `app_detail` 蓝图中实现。进入详情页时取出房源对象，将配套设施字段按 `-` 拆分成列表传给模板；如果用户已登录（cookie 中有 `name`），同时把当前房源记入该用户的浏览记录。

```python
# http://127.0.0.1:5000/house/72306
@app_detail.route('/house/<int:hid>')
def detail_page(hid):
    house = House.query.get_or_404(hid)
    facilities = house.facilities
    facilities = facilities.split('-')

    # 登录状态cookie---name   浏览记录
    name = request.cookies.get('name')

    # 推荐列表
    recommend_li = []

    if name:
        # 获取当前用户
        user = User.query.filter(User.name == name).first()
        seen_id_str = user.seen_id
        if seen_id_str:
            seen_id_list = seen_id_str.split(',')

            # 去重
            seen_id = set(seen_id_list)
            # 当前浏览的房源不在浏览记录里面，就进行添加
```

浏览记录的存储方式：`User` 表的 `seen_id` 字段保存逗号分隔的房源 id 字符串，如 `"72306,72310"`。每次访问详情页时拆分、去重（用 `set` 判断当前房源是否已记录），未记录过则追加并提交。

## 20.4 推荐列表与户型占比

### 20.4.1 推荐列表

`house_recommend` 推荐表用来分析用户访问习惯：每访问一次某房源，该用户对应这条房源记录的 `score` 加 1。生成推荐房源时调用简易推荐模型 `recommend(user.id)`，返回 `[(房源id, 浏览次数), ...]` 形式的列表，例如：

```python
[(111957, 9), (112178, 9), (112500, 9), (112507, 9), (113103, 9), (111445, 8)]
```

如果推荐模型没有结果（或用户未登录），就退化为推荐**同一地区浏览量最高的房源**（最多 6 条）。完整的详情页视图如下：

```python
# http://127.0.0.1:5000/house/72306
@app_detail.route('/house/<int:hid>')
def detail_page(hid):
    house = House.query.get_or_404(hid)
    facilities = house.facilities
    facilities = facilities.split('-')

    # 登录状态cookie---name   浏览记录
    name = request.cookies.get('name')

    # 推荐列表
    recommend_li = []

    if name:
        # 获取当前用户
        user = User.query.filter(User.name == name).first()
        seen_id_str = user.seen_id
        if seen_id_str:
            seen_id_list = seen_id_str.split(',')

            # 去重
            seen_id = set(seen_id_list)
            # 当前浏览的房源不在浏览记录里面，就进行添加
            if str(hid) not in seen_id:
                new_seen_id = seen_id_str + ',' + str(hid)
                user.seen_id = new_seen_id
                db.session.commit()
        else:
            user.seen_id = str(hid)
            db.session.add(user)

        # house_recommend推荐表--用来分析用户访问习惯
        # 获取当前用户对于当前房源的访问数据
        info = Recommend.query.filter(Recommend.house_id == hid, Recommend.user_id == user.id).first()

        if info:
            new_score = info.score + 1
            info.score = new_score
            db.session.commit()
        else:
            # 首次访问该房源
            new_info = Recommend(house_id=hid, user_id=user.id,
                                 title=house.title, address=house.address,
                                 block=house.block, score=1)
            db.session.add(new_info)
            db.session.commit()

        # 生成推荐房源，使用简易模型
        res = recommend(user.id)
        if res:
            # 存在推荐房源
            for c_hid, c_num in res:
                recommend_li.append(House.query.get(c_hid))
        else:
            # 不存在推荐房源 ---- 相同小区的房源
            o_re = House.query.filter(House.address == house.address
                                      ).order_by(House.page_views.desc()).all()
            if len(o_re) > 6:
                recommend_li = o_re[:6]
            else:
                recommend_li = o_re
    else:
        # 未登录：推荐相同小区浏览量最高的房源
        o_re = House.query.filter(House.address == house.address
                                  ).order_by(House.page_views.desc()).all()
        if len(o_re) > 6:
            recommend_li = o_re[:6]
        else:
            recommend_li = o_re

    return render_template('detail_page.html',
                           facilities=facilities,
                           house=house,
                           recommend_li=recommend_li)
```

### 20.4.2 户型占比接口

详情页需要展示所在街道的户型占比饼图。后端接口按街道（`block`）分组统计每种户型的数量，返回 JSON 数据给前端图表：

```python
# /get/piedata/{{ house.block }}
@app_detail.route('/get/piedata/<block>')
def get_piedata(block):  # 街道
    # 所在街道 ---》 所有的户型 ---》 每个户型数量
    # 查询街道的所有户型 ---》 分组、数量统计 ---》 聚合查询
    res = House.query.with_entities(House.rooms, func.count()).filter(House.block == block
                                ).group_by(House.rooms).order_by(func.count().desc()).all()
    # print(res)  # [('2室1厅', 806), ('1室1厅', 513), ('3室1厅', 337)]

    data = []
    for r in res:
        data.append({'name': r[0], 'value': r[1]})

    return jsonify({'data': data})
```

返回结构为 `{'data': [{'name': 户型名称, 'value': 数量}, ...]}`，直接对应前端饼图所需的数据格式。

### 20.5.1 top20 小区柱状图

统计所在街道下每个小区的房源数量，取数量最多的前 20 个小区，x 轴为小区名称、y 轴为房源数量：

```python

# /get/columndata/{{ house.block }}
@app_detail.route('/get/columndata/<block>')

    res = House.query.with_entities(House.address, func.count()

    num_li = []
    for addr, num in res:

        num_li.append(num)

    if len(name_li) > 20:
        data = {
            "name_list_x": name_li[:20],
            "num_list_y": num_li[:20]
        }
    else:
        data = {
```

前端取 `data['name_list_x']` 作为 x 轴、`data['num_list_y']` 作为 y 轴渲染柱状图。

### 20.5.2 户型均价走势折线图

折线图展示所在街道常见 4 种户型（1室1厅、2室1厅、2室2厅、3室2厅）最近 14 天的平均单价（`price / area`）变化：

```python
# /get/brokenlinedata/{{ house.block }}  --- 折线图
@app_detail.route('/get/brokenlinedata/<block>')
def get_broken_line_data(block):
    # 先处理时间 ---》 生成时间序列
    # 时间戳可在线转换：https://tool.lu/timestamp/
    time_h = House.query.filter(House.block == block).with_entities(House.publish_time).all()
    # print('time_h', time_h)  # [(1558022400,), (1558281600,), (1558454400,), (1558713600,)]

    # 使用列表方法进行降序排序（最新发布时间在前面）
    time_h.sort(reverse=True)

    # 生成最近14天的时间列表
    data_list = []
    for i in range(1, 14):  # 推导13天
        latest = datetime.fromtimestamp(int(time_h[0][0]))
        # 往前推 i 天
        day = latest + timedelta(days=-i)
        data_list.append(day.strftime('%m-%d'))
    data_list.reverse()

    # 街道 --- 户型 --- 指定户型 --- 平均价格  func.avg 平均数据计算 --- price/面积 --- 单价
    # 1室1厅的平均单价走势
    res = House.query.with_entities(func.avg(House.price / House.area)
                              ).filter(House.block == block, House.rooms == '1室1厅'
                              ).group_by(House.publish_time).order_by(House.publish_time).all()
    # 提取14天的价格数据，保留两位小数 --- Y轴
    data = []
    for r in res[-14:]:
        data.append(round(r[0], 2))  # 保留两位小数

    # 2室1厅
    res1 = House.query.with_entities(func.avg(House.price / House.area)
                                    ).filter(House.block == block, House.rooms == '2室1厅'
                                             ).group_by(House.publish_time).order_by(House.publish_time).all()
    data1 = []
    for r in res1[-14:]:
        data1.append(round(r[0], 2))

    # 2室2厅
    res2 = House.query.with_entities(func.avg(House.price / House.area)
                                     ).filter(House.block == block, House.rooms == '2室2厅'
                                              ).group_by(House.publish_time).order_by(House.publish_time).all()
    data2 = []
    for r in res2[-14:]:
        data2.append(round(r[0], 2))

    # 3室2厅
    res3 = House.query.with_entities(func.avg(House.price / House.area)
                                     ).filter(House.block == block, House.rooms == '3室2厅'
                                              ).group_by(House.publish_time).order_by(House.publish_time).all()
    data3 = []
    for r in res3[-14:]:
        data3.append(round(r[0], 2))

    return jsonify({'data': {
        "1室1厅": data,
        "2室1厅": data1,
        "2室2厅": data2,
        "3室2厅": data3,
        "date_li": data_list
    }})
```

要点：

- 时间轴：取该街道最新的发布时间，往前推 13 天生成 `%m-%d` 格式的日期列表，再反转成时间正序；
- 每个户型单独做一次聚合查询：`func.avg(House.price / House.area)` 按 `publish_time` 分组求平均单价；
- `res[-14:]` 只取最近 14 条数据，价格保留两位小数。

### 20.5.3 房价走势预测（线性回归）

在折线图的基础上，用线性回归模型对未来一天的平均单价做预测。先按发布时间分组求出该街道每天的平均单价，以数据点索引作为特征 x、单价作为标签 y，调用 `linear_model_main(x, y, pre_value)` 预测下一个时间点（`pre_value = len(data)`）的价格：

```python
# 预测房价走势
# block --- 一个时间段的房价 --- 价格走势推导
# /get/scatterdata/{{ house.block }}
@app_detail.route('/get/scatterdata/<block>')
def get_scatterdata(block):
    res = House.query.with_entities(func.avg(House.price / House.area)
                                    ).filter(House.block == block
                                    ).group_by(House.publish_time
                                    ).order_by(House.publish_time).all()
    # print('res---', res)  # [(169.0,), (44.82174572540024,), (37.301157305027274,)]

    time_st = House.query.filter(House.block == block).with_entities(House.publish_time).all()

    # 降序排序
    time_st.sort(reverse=True)

    data_list = []
    for i in range(1, 30):  # 推导29天
        latest = datetime.fromtimestamp(int(time_st[0][0]))
        # 往前推 i 天
        day = latest + timedelta(days=-i)
        data_list.append(day.strftime('%m-%d'))
    data_list.reverse()

    data = []  # 完整数据点列表
    x = []
    y = []

    for index, i in enumerate(res):  # (0, (169.0,))
        x.append([index])
        y.append(round(i[0], 2))
        data.append([index, round(i[0], 2)])  # [索引，价格]

    # 对未来一天的预测
    pre_value = len(data)  # 下一个时间点

    # 线性回归模型预测
    pre_outcome = linear_model_main(x, y, pre_value)
    # pre_outcome --- [77.18901639] --- [66.22184376]

    data.append([pre_value, round(pre_outcome[0], 2)])

    return jsonify({
        "data": {
            "data-predict": data,
            "date_li": data_list
        }
    })
```

说明：

- `linear_model_main` 是课程提供的线性回归封装函数（基于 sklearn 的线性回归模型），课件中未给出其内部实现；
- 时间轴生成方式与折线图一致，但跨度为最近 29 天；
- 返回的 `data-predict` 是 `[索引, 价格]` 数据点列表，最后一个点即预测值，前端据此绘制散点 / 趋势图。
