# 3 路由与请求

本章讲解 Flask 中与路由和请求相关的核心内容：反向解析 `url_for`、动态路由与转换器、自定义正则转换器，以及用于获取请求数据的 `request` 对象。

## 3.1 反向解析 url_for

在项目开发中，路由一旦变动，所有硬编码引用该路由的位置都要同步修改，非常麻烦。反向解析可以解决这一问题：通过**端点（endpoint）名称**生成对应的真实路由 path。endpoint 默认与视图函数名一致。

`url_for` 需从 flask 中导入：`from flask import url_for`。

```python
from flask import Flask, request, url_for

app = Flask(__name__)


@app.route('/index12334', methods=['GET', "POST"])
def index():
    print(url_for('index'))    # 通过endpoint反解析出真实路由：/index12334
    return 'index'


if __name__ == '__main__':
    print(app.url_map)  # 查看路由信息
    app.run(debug=True)
```

补充说明：

- `app.add_url_rule` 是注册路由的另一种写法，可显式指定 endpoint：

```python
app.add_url_rule('/index', endpoint='index', view_func=index)
# 生成的路由规则：<Rule '/index' (HEAD, GET, OPTIONS) -> index>

app.add_url_rule('/index', endpoint='index123', view_func=index)
# 生成的路由规则：<Rule '/index' (OPTIONS, GET, HEAD) -> index123>
```

- 路由规则的完整形态是 `<Rule '路径' (请求方法) -> endpoint>`，`url_for` 按 endpoint 查找对应路径。

## 3.2 动态路由

动态路由用于从 URL 路径中提取数据并传入视图。例如访问 `http://127.0.0.1:5000/index/2025`，提取路径中的 `2025` 传入视图函数。提取方式有以下几种。

### 3.2.1 直接提取（默认 str 类型）

在路由中用 `<变量名>` 命名要提取的路径段，视图函数必须用同名参数接收：

```python
from flask import Flask

app = Flask(__name__)


# http://127.0.0.1:5000/index/2025 ---> 提取2025传入视图
# 路由规则：<Rule '/index/<year>' (GET, HEAD, OPTIONS, POST) -> index>
@app.route('/index/<year>', methods=['GET', "POST"])
def index(year):  # 注意接受参数数据，默认是str类型
    print(year)
    return 'index'


if __name__ == '__main__':
    print(app.url_map)  # 查看路由信息
    app.run(debug=True)
```

### 3.2.2 内置转换器

使用 `<转换器:变量>` 的形式限制参数类型。常用内置转换器：

| 转换器 | 说明 |
| ------ | ---- |
| `int` | 匹配整数 |
| `float` | 匹配浮点数 |
| `path` | 匹配带 `/` 的路径（默认转换器不匹配 `/`） |

```python
# 匹配整数：http://127.0.0.1:5000/index/2025
@app.route('/index/<int:year>', methods=['GET', "POST"])
def index(year):  # 注意接受参数数据
    print(year)
    return 'index'


# 匹配浮点数：http://127.0.0.1:5000/index/2025.9
@app.route('/index/<float:year>', methods=['GET', "POST"])
def index(year):  # 注意接受参数数据
    print(year)
    return 'index'


# 匹配带/的路径：http://127.0.0.1:5000/index/2025.9/
@app.route('/index/<path:year>', methods=['GET', "POST"])
def index(year):  # 注意接受参数数据
    print(year)  # 2025.9/
    return 'index'
```

## 3.3 自定义正则转换器

当内置转换器不能满足需求时，可以基于正则表达式自定义转换器。

### 3.3.1 定义与注册

自定义转换器必须继承 `werkzeug.routing.BaseConverter` 类，并重写其初始化 `__init__` 方法；然后通过 `app.url_map.converters` 注册（`url_map` 保存了所有路由转换器，是 dict 类型）：

```python
from flask import Flask, url_for
from werkzeug.routing import BaseConverter

app = Flask(__name__)


class RegexConverter(BaseConverter):
    def __init__(self, url_map, *args):  # *args不定长参数 ---》接受正则数据进来
        # 继承原有初始化逻辑
        super(RegexConverter, self).__init__(url_map)
        # 更新正则数据
        self.regex = args[0]

    # 转换器提取数据后的操作
    # def to_python(self, value):
    #     print(f"转换器获取到数据:{value}，类型: {type(value)}")
    #     return value

    # 反解析携带转换器路由的时候
    # def to_url(self, value):
    #     print(f"反解析---》转换器获取到数据:{value}，类型: {type(value)}")
    #     return value


# 注册转换器：转换器名称    转换器类
app.url_map.converters['re'] = RegexConverter
```

使用方式（注意字符串转义问题，路由字符串建议加 `r` 前缀）：

```python
# http://127.0.0.1:5000/index/2025 ---> 提取2025的数据 --》传入到视图
@app.route(r'/index/<re("\d+"):year>', methods=['GET', "POST"])
def index(year):  # 注意接受参数数据
    print(year)
    return 'index'
```

### 3.3.2 配合 url_for 反解析

带转换器的路由同样可以反解析，`url_for` 中按变量名传参：

```python
@app.route('/demo')
def demo():
    print(url_for('index', year="2018"))  # 反解析出 /index/2018
    return 'demo'


if __name__ == '__main__':
    print(app.url_map)  # 查看路由信息
    app.run(debug=True)
```

## 3.4 request 对象

Flask 中获取请求数据的方式与 Django 不同：Django 视图的第一个参数必须是 HttpRequest 对象，而 Flask 需要从 flask 中导入 `request` 对象，`request` 中已经封装了所有的请求参数。

数据流向：客户端（浏览器）发起获取数据的请求（携带标准数据）→ 服务端 flask 解析数据 → `request` 对象。

### 3.4.1 常用属性总览

| 属性名    | 核心功能与说明 | 数据类型 |
| --------- | ------------------------------------------------------------ | ------------------- |
| `form`    | 存储 POST/PUT 请求中提交的**表单键值对数据**（如登录页的账号、密码）。注意：上传的文件**不在该属性中**，而是存放在 `files` 属性里。 | `MultiDict` |
| `args`    | 存储 URL 地址中**问号后的查询字符串参数**（即 GET 请求的传参，如 `?id=1&name=test`）。 | `MultiDict` |
| `values`  | 合并了 `form` 和 `args` 的全部内容，无需区分请求方式，可直接统一获取所有传参。 | `CombinedMultiDict` |
| `cookies` | 存储当前请求中客户端携带的**所有 Cookie 数据**，可直接读取用户的登录态、偏好设置等 Cookie 信息。 | `dict` |
| `headers` | 存储当前请求的**所有请求头信息**（如 User-Agent、Content-Type、Token 等），是类字典的可读取对象。 | `dict` |
| `method`  | 标识当前请求的 **HTTP 请求方法**，常用值为 `GET`、`POST`、`PUT`、`DELETE` 等，可用于区分同一路由的不同请求逻辑。 | `string` |
| `files`   | 存储 POST/PUT 请求中**上传的所有文件数据**，每个文件都是 `FileStorage` 对象，该对象自带 `save()` 方法，可直接将上传的文件保存到服务器文件系统中。 | `MultiDict` |

与路径相关的属性：`path`、`script_root`、`url`、`base_url`、`url_root`。

另外，`request.json` 用于获取非表单格式的 JSON 请求体数据。

查询字符串示例：`https://cn.bing.com/search?q=csdn...` 中 `?` 后面的这一串就是查询字符串数据，通过 `request.args` 获取。

### 3.4.2 获取请求数据示例

```python
from flask import Flask, request

app = Flask(__name__)


@app.route('/demo', methods=['GET', 'POST'])
def demo():
    # 表单form
    # print(request.form)  # ImmutableMultiDict([('name', 'abai'), ('happy', '1')])

    # 非表单 --- json
    # print(request.json)  # {'name': 'abai', 'age': 18}

    # 获取所有参数（args + post表单，不包含非表单数据）
    print(request.values)
    # CombinedMultiDict([ImmutableMultiDict([('a', '1'), ('a', 'shuai')]),
    # ImmutableMultiDict([('name', 'abai'), ('happy', '1')])])

    # get只取第一个值；getlist取同名键的所有值
    print(request.values.get('a'))
    print(request.values.getlist('a'))  # ['1', 'shuai', '1990']

    # 查询字符串
    # print(request.args)  # ImmutableMultiDict([('a', '1')])
    # print(request.args)  # ImmutableMultiDict([('a', '1'), ('a', 'shuai')])
    # print(request.args.get('a'))  # 1
    # print(request.args.getlist('a'))  # ['1', 'shuai']

    # 与路径相关的属性
    # print(request)  # <Request 'http://127.0.0.1:5000/demo?a=1' [GET]>
    # print(request.path)     # /demo
    # print(request.url)      # http://127.0.0.1:5000/demo?a=1
    # print(request.base_url) # http://127.0.0.1:5000/demo
    # print(request.url_root) # http://127.0.0.1:5000/
    return 'demo'


if __name__ == '__main__':
    print(app.url_map)  # 查看路由信息
    app.run(debug=True)
```

要点：

- `MultiDict` / `ImmutableMultiDict` 允许一个键对应多个值：`.get('键')` 只返回第一个值，`.getlist('键')` 返回该键的所有值组成的列表。
- `request.values` 合并了查询字符串和表单数据（`args` + `form`），但不包含 JSON 等非表单数据。
- 路由未声明某请求方法时访问会返回 `405 Method Not Allowed`。

### 3.4.3 文件上传

Flask 处理客户端上传文件的数据流：文件数据存储在内存或文件系统的临时位置 → 通过 `request.files` 属性获取（ImmutableMultiDict）→ 通过键获取文件数据对象 `FileStorage` → 调用其 `save()` 方法保存到服务器文件系统的指定路径。

```python
import os
from hashlib import md5

from flask import Flask, request
from werkzeug.utils import secure_filename

app = Flask(__name__)


@app.route('/index', methods=['GET', 'POST'])
def demo():
    # request.files ImmutableMultiDict([('ttt', <FileStorage: '001.png' ('image/png')>)])
    # print("request--file", request.files)

    # 通过键获取文件对象
    # request--file <FileStorage: '001.png' ('image/png')>
    # print("request--file", request.files.get('ttt'))

    # save方法：直接保存到指定路径
    # request.files.get('ttt').save("ces.png")

    # 文件名称的安全合理化
    # secure_filename：传入一个文件名，返回一个安全的文件名
    # 中文会被直接删除，空格会替换成下划线
    # print("secure_filename", secure_filename(request.files.get('ttt').filename))

    # 正式开发场景----》灵活的绝对路径
    # os.getcwd()：获取当前文件所在目录的绝对路径
    # print("os.getcwd()", os.getcwd())

    # 构建上传文件的保存目录绝对路径----》路径拼接：os.path.join()
    fileCWD = os.path.join(os.getcwd(), "fileUP")

    # 保证这个目录存在，先判断（os.path.exists判断目录是否存在）---》不存在：创建
    if not os.path.exists(fileCWD):
        os.makedirs(fileCWD)  # 创建目录

    # 得到文件对象
    f = request.files.get('ttt')

    # 直接使用用户输入的文件名非常危险，容易出bug
    # 正确做法：自己生成唯一文件名（时间戳、随机数、uuid等方案）
    # md5文件名安全化：同样的数据用md5加密出来的结果一样
    # 加密字符串要先编码 encode('utf-8')，hexdigest()获取加密结果
    md5_filename = md5(f.filename.encode("utf-8")).hexdigest()
    # 例如：c36625d731a8602531c9ad084b74b3bf

    # 获取文件后缀名
    o_filename = f.filename  # 例如 demo.py
    d_index = o_filename.rindex('.')  # right index 右索引
    file_su = o_filename[d_index:]

    # 拼接新文件名并保存
    new_filename = md5_filename + file_su
    save_path = os.path.join(fileCWD, new_filename)
    f.save(save_path)

    return 'demo'


if __name__ == '__main__':
    print(app.url_map)  # 查看路由信息
    app.run(debug=True)
```

要点：

- `secure_filename()` 用于文件名安全合理化：中文字符会被直接删除，空格替换成下划线。
- 让用户输入的文件名直接作为保存名是危险做法，正确做法是自己生成唯一文件名（时间戳、随机数、uuid，或本例的 md5 + 原后缀名）。
- `os.getcwd()` 获取当前目录绝对路径，`os.path.join()` 拼接路径，`os.path.exists()` + `os.makedirs()` 确保保存目录存在。
