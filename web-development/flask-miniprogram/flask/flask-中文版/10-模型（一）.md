# 10 模型（一）

本章介绍 Flask-SQLAlchemy 的模型（Model）定义：字段类型、约束条件、表关系，以及一对多、一对一、多对多三种关系模型的建立方式，最后补充 `relationship()` 的常用参数和数据的添加与基本查询。

## 10.1 模型的基本要素

SQLAlchemy 创建模型类的时候，跟 MySQL 使用 SQL 语句去创建表的流程很相似，需要明确四件事：

1. id 主键列需要自己定义；
2. 需要指定字段类型；
3. 需要指定约束条件；
4. 表关系。

## 10.2 常用的 SQLAlchemy 字段类型

| 类型名 | Python 中类型 | 说明 |
| ------ | ------------- | ---- |
| Integer | int | 普通整数，一般是 32 位 |
| SmallInteger | int | 小整数 |
| BigInteger | int 或 long | 大整数 |
| Float | float | 浮点数 |
| Numeric | decimal.Decimal | 精确数值类型（通常用于财务计算等需要高精度的场景） |
| String | str | 变长字符串 |
| Text | str | 变长字符串，对较长或不限长度的字符串做了优化 |
| Unicode | unicode | 变长 Unicode 字符串 |
| UnicodeText | unicode | 变长 Unicode 字符串，对较长或不限长度的字符串做了优化 |
| Boolean | bool | 布尔值 |
| Date | datetime.date | 日期（年月日） |
| Time | datetime.datetime | 日期和时间 |
| LargeBinary | str | 二进制数据 |

## 10.3 约束条件

### 10.3.1 常用约束

| 约束 | 说明 |
| ---- | ---- |
| primary_key | 主键 |
| unique | 唯一约束，True 不允许重复 |
| index | 索引，如果为 True，为这列创建索引，提高查询效率 |
| nullable | 空值，如果为 True，允许有空值，如果为 False，不允许有空值 |
| default | 默认值 |

### 10.3.2 进阶约束补充

| 约束名 | 核心说明 | SQLAlchemy 代码示例 | 补充说明 |
| ------ | -------- | ------------------- | -------- |
| autoincrement | 自增约束，整数列自动按规则递增，通常与主键配合 | `id = db.Column(db.Integer, primary_key=True, autoincrement=True)` | MySQL 的 INT 主键默认会开启自增，显式声明更清晰 |
| foreign_key | 外键约束，建立两张表的关联关系，保证数据一致性 | `user_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)` | 格式为 `db.ForeignKey('表名.列名')`，通常与 `relationship` 配合实现 ORM 关联查询 |
| server_default | 数据库级默认值，在数据库层面设置默认值，与代码语言无关 | `update_time = db.Column(db.DateTime, server_default=db.func.now())` | 通过 `db.func` 调用数据库原生函数（如 `now()`），默认值由数据库自己维护 |
| onupdate | 更新自动赋值约束，数据行更新时自动给该列刷新值 | `update_time = db.Column(db.DateTime, onupdate=datetime.now, default=datetime.now)` | 每次更新数据时，该列自动刷新为当前时间，适合做「最后更新时间」字段 |
| comment | 字段注释约束，给列添加业务注释，同步到数据库表结构 | `status = db.Column(db.SmallInteger, default=1, comment='用户状态：1-正常，0-禁用')` | 注释会直接写入数据库的表结构，提升后续维护的可读性 |
| CheckConstraint | 检查约束，自定义校验规则 | `age = db.Column(db.SmallInteger, db.CheckConstraint('age >= 0 AND age <= 150'))` | MySQL 8.0+ 原生支持检查约束，能从数据库层面拦截非法数据 |
| UniqueConstraint | 联合唯一约束，多个列组合起来不可重复 | `__table_args__ = (db.UniqueConstraint('user_id', 'goods_id', name='uk_user_goods'),)` | 适用于多字段联合去重场景，比如同一用户不能重复收藏同一商品 |

注意：`default` 传入动态值（函数）时**不要加 `()`**，例如 `default=datetime.now`，否则会在模型加载时就执行，而不是在插入数据时执行。

## 10.4 表关系

| 关系 | 说明 |
| ---- | ---- |
| One To Many（一对多） | 表示一对多的关系时，在子表类中通过 foreign key（外键）引用父表类，在父表类中通过 `relationship()` 方法来引用子表的类 |
| One To One（一对一） | 一对一是两张表之间本质上的双向关系。只需要在一对多关系基础上的父表中使用 `uselist=False` 参数来表示 |
| Many To Many（多对多） | 多对多关系会在两个类之间增加一个关联的表，两个关系表中使用 `relationship()` 方法中通过 `secondary` 来引用关联表，关联表通过 MetaData 对象来与声明基类关联，使用 ForeignKey 连接来定位到远程的表 |

## 10.5 模型建立体验

完整流程：确认目标数据库存在 → 导包 → 设置连接配置 → 创建数据库对象 → 定义模型类 → 建表。

```python
from flask import Flask
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__,
            template_folder='templates')

# 1.连接的目标数据库存在    --不存在---》 create database demo default charset utf8;
# 2.导包:  from flask_sqlalchemy import SQLAlchemy
# 3.设置连接配置  --- SQLALCHEMY_DATABASE_URI
#    ---> '数据库服务://用户名:密码@数据库host:数据库端口/数据库名称'
#    例如 SQLite：'sqlite:///test.db'
app.config['SQLALCHEMY_DATABASE_URI'] = 'mysql://root:qwe123@127.0.0.1:3306/demo'

# 4.创建数据库对象
db = SQLAlchemy(app)  # SQLAlchemy实例关联flask应用对象，同时加载配置数据 ---> db对象（orm实例对象 ---> SQLAlchemy实例）
ctx = app.app_context()  # 获取flask应用上下文
ctx.push()  # 将应用上下文推入栈中（激活上下文）


# 建立一张表 ---> 建立一个模型 ---> 类
class User(db.Model):  # 继承db对象（orm实例对象 ---> SQLAlchemy实例）的Model基类
    # 建立主键（唯一、自增长） ---> 常规主键用的int类型
    # db.Column() ----> 构建字段数据类型、限制条件
    id = db.Column(db.Integer, primary_key=True)
    # 用户名 ----- 字符串-》20字节    唯一  非空
    username = db.Column(db.String(20), unique=True, nullable=False)
    # 年龄 ----》 整数，默认值 18
    age = db.Column(db.Integer, default=18)


if __name__ == '__main__':
    db.create_all()  # 建立所有的表
    # db.drop_all()  # 删除所有的表 ----- 根据模型去删的
    # print(app.url_map)  # 查看路由信息
    app.run(debug=True)
```

运行后在 MySQL 中验证，可以看到 `user` 表已经按模型定义建好：

```shell
mysql> use demo;
Database changed
mysql> show tables;
+----------------+
| Tables_in_demo |
+----------------+
| user           |
+----------------+
1 row in set (0.03 sec)

mysql> desc user;
+----------+-------------+------+-----+---------+----------------+
| Field    | Type        | Null | Key | Default | Extra          |
+----------+-------------+------+-----+---------+----------------+
| id       | int         | NO   | PRI | NULL    | auto_increment |
| username | varchar(20) | NO   | UNI | NULL    |                |
| age      | int         | YES  |     | NULL    |                |
+----------+-------------+------+-----+---------+----------------+
3 rows in set (0.01 sec)

mysql> show create table user;
CREATE TABLE `user` (
  `id` int NOT NULL AUTO_INCREMENT,
  `username` varchar(20) NOT NULL,
  `age` int DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `username` (`username`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb3
```

可以看到：模型类名 `User` 默认转成小写作为表名；`primary_key=True` 的整型主键自动带 `AUTO_INCREMENT`；`unique=True` 生成了唯一索引；`nullable=False` 对应 `NOT NULL`。

`db.drop_all()` 用于删除所有根据模型建立的表：

```shell
mysql> show tables;
+----------------+
| Tables_in_demo |
+----------------+
| user           |

+----------------+
2 rows in set (0.00 sec)

# 执行 db.drop_all() 之后：只剩非模型管理的表或不剩
mysql> show tables;
+----------------+
| Tables_in_demo |
+----------------+
| user           |
+----------------+
1 row in set (0.01 sec)
```

## 10.6 关系模型——一对多

一对多关系的结构：

```
father  ---》  son
一              多
主表            子表

====  外键  ---》  子表：son
------  外键关联的是主表的主键
```

ORM 操作数据库数据时，数据库中的一行数据对应一个数据对象（对象的属性就是字段）。ORM 查询一对多的时候：

- son 数据 `--father_id--》` father 数据（通过外键正向查询）；
- father 数据 `---》` son 数据？解决方案：**在主表上面构建一个关系反查字段**——它不会在数据库里面存在，只在 Python ORM 操作中生效。

```python
from flask import Flask
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__,
            template_folder='templates')

app.config['SQLALCHEMY_DATABASE_URI'] = 'mysql://root:qwe123@127.0.0.1:3306/demo'

# 创建数据库对象
db = SQLAlchemy(app)
ctx = app.app_context()  # 获取flask应用上下文
ctx.push()  # 将应用上下文推入栈中（激活上下文）


class Father(db.Model):
    # 自定义表名称  __tablename__
    __tablename__ = 'father'

    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(50))

    # db.relationship 反查字段：指明反查模型，backref创建反向引用
    # uselist：是否返回列表    True：返回列表（一对多）    False（默认值）：一条数据（一对一）
    son = db.relationship('Son', backref='father', uselist=True)
    # father数据 ---> son数据：father构建数据对象的时候，添加一个该数据所关联的数据对象
    # （son的数据对象）---》 son属性（反查字段属性名我们设置的是son）
    # backref创建反向引用：反查模型（Son模型）在构建数据对象时，添加一个该数据所关联的
    # 数据对象（father数据对象）--》 father属性（backref='father'）


class Son(db.Model):
    __tablename__ = 'son'

    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(50))

    # 外键字段 ----> db.ForeignKey 构建外键关联 ---》 主表的主键
    # ---》 father.id ---> father是表的名称
    father_id = db.Column(db.Integer, db.ForeignKey('father.id'))


if __name__ == '__main__':
    db.create_all()  # 建立所有的表
    # db.drop_all()  # 删除所有的表 ----- 根据模型去删的
    # print(app.url_map)  # 查看路由信息
    app.run(debug=True)
```

MySQL 中验证建表结果：

```shell
mysql> show tables;
+----------------+
| Tables_in_demo |
+----------------+
| father         |
| son            |
| user           |
+----------------+
3 rows in set (0.00 sec)

mysql> show create table father;
CREATE TABLE `father` (
  `id` int NOT NULL AUTO_INCREMENT,
  `name` varchar(50) DEFAULT NULL,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb3

mysql> show create table son;
CREATE TABLE `son` (
  `id` int NOT NULL AUTO_INCREMENT,
  `name` varchar(50) DEFAULT NULL,
  `father_id` int DEFAULT NULL,
  PRIMARY KEY (`id`),
  KEY `father_id` (`father_id`),
  CONSTRAINT `son_ibfk_1` FOREIGN KEY (`father_id`) REFERENCES `father` (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb3
```

注意 `son` 表中自动生成了外键约束 `FOREIGN KEY (father_id) REFERENCES father (id)`；而主表 `father` 中并没有 `son` 字段——反查字段只存在于 ORM 层。

## 10.7 关系模型——一对一

一对一的典型场景：

```
用户  --一对多--  文章
|
| 一对一          用户表作为主表来用
|
用户信息详情
```

一对一本质上是一对多的特例：在一对多的基础上，把父表中 `relationship()` 的 `uselist` 参数设为 `False`，关联查询返回的就是单条数据而不是列表。

```python
class Father(db.Model):
    # 自定义表名称  __tablename__
    __tablename__ = 'father'

    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(50))

    # db.relationship 反查字段：指明反查模型，backref创建反向引用
    # uselist：是否返回列表    True：返回列表（一对多）    False（默认值）：一条数据（一对一）
    son = db.relationship('Son', backref='father', uselist=False)
    # 不写 uselist 时默认也是返回一条数据：
    # son = db.relationship('Son', backref='father')


class Son(db.Model):
    __tablename__ = 'son'

    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(50))

    # 外键字段 ----> db.ForeignKey 构建外键关联 ---》 主表的主键
    father_id = db.Column(db.Integer, db.ForeignKey('father.id'))
```

数据库表结构与一对多完全一致（外键仍在子表），区别只在 ORM 层面反查返回的是单个对象还是列表。

## 10.8 关系模型——多对多

多对多关系需要一张中间表来关联两张主表：

```
作者
|
| 多对多关系 -----》  作者 --中间表（作者表主键，书籍表主键）-- 书籍
|
书籍
```

中间表用 `db.Table()` 直接构建（不需要模型类），两张主表通过 `relationship()` 的 `secondary` 参数引用中间表，并用 `back_populates` 建立双向关系（需要在两方都定义）。

```python
from flask import Flask
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__,
            template_folder='templates')

app.config['SQLALCHEMY_DATABASE_URI'] = 'mysql://root:qwe123@127.0.0.1:3306/demo'

# 创建数据库对象
db = SQLAlchemy(app)
ctx = app.app_context()  # 获取flask应用上下文
ctx.push()  # 将应用上下文推入栈中（激活上下文）

# 中间表
# db.Table(表的名称, 表的元数据, 关联表字段值-外键) 构建中间表
association_table = db.Table('association_table', db.metadata,
                             # 字段名称    字段类型    外键关联
                             db.Column('author_id', db.Integer, db.ForeignKey('author.id')),
                             db.Column('book_id', db.Integer, db.ForeignKey('book.id'))
                             )


class Author(db.Model):
    __tablename__ = 'author'

    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(20), unique=True, nullable=False)

    # back_populates 双向关系 ---》 需要在两方都定义
    # secondary 中间表（中间表实例）指定
    book = db.relationship('Book', back_populates='author', secondary=association_table)


class Book(db.Model):
    __tablename__ = 'book'

    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(20), unique=True, nullable=False)

    son = db.relationship('Author', back_populates='book', secondary=association_table)


if __name__ == '__main__':
    db.create_all()  # 建立所有的表
    # db.drop_all()  # 删除所有的表 ----- 根据模型去删的
    # print(app.url_map)  # 查看路由信息
    app.run(debug=True)
```

MySQL 中验证，三张表（含中间表）都已建立：

```shell
mysql> show tables;
+-------------------+
| Tables_in_demo    |
+-------------------+
| association_table |
| author            |
| book              |
| father            |
| son               |
| user              |
+-------------------+
6 rows in set (0.00 sec)

mysql> show create table association_table;
CREATE TABLE `association_table` (
  `author_id` int DEFAULT NULL,
  `book_id` int DEFAULT NULL,
  KEY `author_id` (`author_id`),
  KEY `book_id` (`book_id`),
  CONSTRAINT `association_table_ibfk_1` FOREIGN KEY (`author_id`) REFERENCES `author` (`id`),
  CONSTRAINT `association_table_ibfk_2` FOREIGN KEY (`book_id`) REFERENCES `book` (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb3

mysql> show create table author;
CREATE TABLE `author` (
  `id` int NOT NULL AUTO_INCREMENT,
  `name` varchar(20) NOT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `name` (`name`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb3

mysql> show create table book;
CREATE TABLE `book` (
  `id` int NOT NULL AUTO_INCREMENT,
  `name` varchar(20) NOT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `name` (`name`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb3
```

中间表 `association_table` 只有两个外键字段，分别指向 `author` 表和 `book` 表的主键。

## 10.9 relationship() 参数说明

### 10.9.1 relationship() 常用参数

| 参数 | 类型 | 说明 | 示例 |
| ---- | ---- | ---- | ---- |
| `backref` | str | 在关联模型中创建反向引用 | `backref='posts'` |
| `back_populates` | str | 双向关系，需在两方都定义 | `back_populates='author'` |
| `secondary` | 中间表对象 | 多对多必备，指定中间关联表 | `secondary=association_table` |
| `lazy` | str | 加载策略 | `lazy='dynamic'` |
| `uselist` | bool | 是否返回列表（一对一关系设为 False） | `uselist=False` |
| `cascade` | str | 级联操作 | `cascade='all, delete-orphan'` |
| `order_by` | 模型字段 | 关联对象默认排序规则 | `order_by=Book.id` |
| `foreign_keys` | list | 指定外键 | `foreign_keys=[address_id]` |
| `primaryjoin` | expression | 自定义主连接条件 | - |
| `secondaryjoin` | expression | 自定义次连接条件 | - |
| `post_update` | bool | 在更新后处理关系 | `post_update=True` |

### 10.9.2 lazy 加载策略选项

| 选项 | 说明 |
| ---- | ---- |
| `'select'` | 默认，首次访问时加载 |
| `'joined'` | 使用 JOIN 立即加载 |
| `'subquery'` | 使用子查询立即加载 |
| `'dynamic'` | 返回查询对象，可进一步过滤 |
| `'immediate'` | 父对象加载后立即加载 |
| `'noload'` | 不加载 |

### 10.9.3 cascade 级联操作选项

| 选项 | 说明 |
| ---- | ---- |
| `'save-update'` | 自动将对象添加到会话 |
| `'merge'` | 合并会话 |
| `'expunge'` | 从会话中移除 |
| `'delete'` | 删除父对象时删除关联对象 |
| `'delete-orphan'` | 删除不再与父对象关联的对象 |
| `'refresh-expire'` | 刷新过期属性 |
| `'all'` | 包含除 `'delete-orphan'` 外的所有选项 |

## 10.10 数据的添加

通过模型类创建数据对象，加入会话（`db.session`），最后提交：

```python
if __name__ == '__main__':
    # 创建对象数据
    f1 = Father(name='麻子2')
    f2 = Father(name='麻子3')
    f3 = Father(name='麻子4')

    # add_all传入列表，列表中包含多个数据对象
    db.session.add_all([f1, f2, f3])

    # 添加单个数据对象到会话信息（db中session）
    # db.session.add(f1)
    # 提交会话数据
    db.session.commit()

    app.run(debug=True)
```

- `db.session.add(obj)`：添加单个数据对象到会话；
- `db.session.add_all([obj1, obj2, ...])`：传入列表，批量添加多个数据对象；
- `db.session.commit()`：提交会话，数据真正写入数据库。

## 10.11 基本查询

模型类上的 `query` 是查询管理器对象，常用查询方法如下。为方便查看输出，可给模型类定义 `__repr__`：

```python
class Father(db.Model):
    __tablename__ = 'father'

    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(50))

    son = db.relationship('Son', backref='father', uselist=True)

    def __repr__(self):
        return f'id:{self.id},name:{self.name}'
```

```python
# query：管理器对象
# 查询所有
f1 = Father.query.all()
print(f1)  # [id:1,name:麻子1, id:2,name:麻子1]

# get()：返回指定主键对应的数据
print(Father.query.get(7))  # id:7,name:麻子3

# get_or_404()：返回指定主键对应的数据，数据未获取到则返回 404
print(Father.query.get_or_404(9))  # werkzeug.exceptions.NotFound: 404 Not Found

# first()：返回查询到的第一个结果
print(Father.query.first())  # id:1,name:麻子1

# first_or_404()：返回第一个结果，未获取到则返回 404
print(Son.query.first_or_404())

# count()：返回查询结果数量
print(Father.query.count())

# 分页查询：paginate() 返回 Pagination 对象
# page：获取指定页的数据  per_page：每页数据数量
data = Father.query.paginate(page=2, per_page=2)
print([i for i in data])  # [id:3,name:麻子2, id:4,name:麻子3]
print(list(data))         # [id:3,name:麻子2, id:4,name:麻子3]

# 过滤查询：filter_by ----- 根据指定数据进行等值过滤查询
data = Father.query.filter_by(id=7)
print([i for i in data])              # [id:7,name:麻子3]
print(Father.query.filter_by(id=7).all())  # [id:7,name:麻子3]
```

使用 Flask + Flask-SQLAlchemy 设计一对多两张数据表：

- 主表（一）：用户表 User；从表（多）：文章表 Article
- 关系：一个用户可以发布多篇文章，一篇文章只属于一个作者（用户）

字段设计要求：

- User 用户表：`id` 主键；`username` 用户名，长度 20 以内，非空，唯一；`nickname` 昵称，长度 30，非空；`status` 账号状态，数字，默认 1（正常）
- Article 文章表：`id` 主键；`title` 文章标题，长度 100，非空；`content` 文章内容，长文本，非空；`publish` 是否发布，布尔，默认 False；`user_id` 外键，关联用户 id，允许为空
