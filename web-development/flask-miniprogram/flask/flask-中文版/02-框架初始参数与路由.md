# 2 框架初始参数与路由

## 2.2 Flask 应用初始化参数

创建 Flask 应用实例时，第一个参数通常传入 `__name__`（当前模块名），Flask 以此为依据定位项目中的资源文件；还可以通过 `template_folder` 指定模板文件所在的目录：

```python
from flask import Flask

# __name__：导入名称；template_folder：指定模板目录
app = Flask(__name__, template_folder='templates')
```

路由就是根据请求的 url 找到对应处理函数（视图函数）的过程。在请求到来之前，应该先建立好一张路由表，保存 url 与视图的对应关系，这样请求过来才能正确找到对应的视图。

## 2.3 路由配置

Flask 中有两种常用方式构建路由规则：

1. `@app.route('url规则')` 装饰器方式
2. `app.add_url_rule()` 方法方式

### 2.3.1 @app.route 装饰器

```python
from flask import Flask

app = Flask(__name__)


# http://127.0.0.1:5000
@app.route('/')  # '/' ---> 路由路径
def hello_world():
    return 'Hello World!'


# http://127.0.0.1:5000/index/
@app.route('/index/')
def index():
    return '我是首页'


# methods：请求方式 ---> 列表数据，数据大写，标准请求方式
@app.route('/me/', methods=['GET', 'POST'])
def me():
    return '我是me'


# 通过装饰器完成路由注册，endpoint 端点默认与视图函数名一致
if __name__ == '__main__':
    app.run(debug=True)
```

### 2.3.2 add_url_rule 方法

`add_url_rule(self, rule, endpoint=None, view_func=None, **options)` 参数含义：

- **rule**：url 规则字符串，可以是静态的 `/path`，也可以包含 `/`
- **endpoint**：要注册规则的 endpoint（命名空间），默认是 `view_func` 的名字，通常与视图函数名一致
- **view_func**：对应 url 的处理函数，也被称为视图函数

```python
from flask import Flask

app = Flask(__name__)


def hello_world():
    return 'Hello World!'


# 1.rule：路由路径
# 2.endpoint：命名空间 ---> 与视图函数名一致
# 3.view_func：视图函数
app.add_url_rule('/hello_world', 'hello_world', hello_world)

if __name__ == '__main__':
    app.run(debug=True)
```

路由规则较多时，也可以先定义一张路由映射表，再循环批量注册：

```python
# 装饰器将路由映射到视图 index
@app.route('/')
def index():
    return 'ok'


# 定义路由映射表
route_map = [
    ('/', index),
    ('/user', get_user),
    ('/order', get_order)
]

# 循环批量注册
for url, func in route_map:
    app.add_url_rule(url, view_func=func)
```

## 2.4 查看路由信息

在 Django 中 url 统一配置在 URLconf 配置文件中，而 Flask 的路由直接配置在视图上，没有统一的配置文件。可以通过 `app.url_map` 查看所有路由信息：

```python
from flask import Flask

app = Flask(__name__)


# http://127.0.0.1:5000/index/
@app.route('/index/')
def index():
    return '我是首页'


def hello_world():
    return 'Hello World!'


# http://127.0.0.1:5000/hello_world
app.add_url_rule('/hello_world', 'hello_world', hello_world)

if __name__ == '__main__':
    print(app.url_map)  # app.url_map 查看路由信息
    app.run(debug=True)
```

打印结果：

```text
Map([<Rule '/static/<filename>' (OPTIONS, HEAD, GET) -> static>,
 <Rule '/index/' (OPTIONS, HEAD, GET) -> index>,
 <Rule '/hello_world' (OPTIONS, HEAD, GET) -> hello_world>])
```

每一条 `Rule` 对应的信息：

- url 规则（路由路径）
- 支持的请求方式（默认支持 GET，不支持 POST）
- 指向的视图 —— endpoint 端点名称

## 2.5 同一路由装饰不同视图

同一个路由规则装饰不同的视图函数时，虽然都会生成路由表记录，但 url 匹配到第一条规则之后就会调用对应视图，不再继续往下匹配——**匹配到了就不往后面走**，只有第一个视图函数会被匹配到。

```python
from flask import Flask

app = Flask(__name__)


# 同一路由装饰不同视图
@app.route('/index/')
def index():
    return '我是首页'


@app.route('/index/')
def index2():
    return '我是首页-2'


if __name__ == '__main__':
    print(app.url_map)  # app.url_map 查看路由信息
    app.run(debug=True)

"""
Map([<Rule '/static/<filename>' (GET, HEAD, OPTIONS) -> static>,
 <Rule '/index/' (GET, HEAD, OPTIONS) -> index>,
 <Rule '/index/' (GET, HEAD, OPTIONS) -> index2>])
"""
```

## 2.6 一个视图函数多个路由装饰器

同一个视图函数可以叠加多个路由装饰器，会生成多条路由信息，每条规则对应的 url 都可以访问到这个视图函数：

```python
from flask import Flask

app = Flask(__name__)


# 一个视图函数多个路由
@app.route('/index/')
@app.route('/index2/')
@app.route('/index3/')
def index():
    return '我是首页'


if __name__ == '__main__':
    print(app.url_map)  # app.url_map 查看路由信息
    app.run(debug=True)

"""
Map([<Rule '/static/<filename>' (OPTIONS, GET, HEAD) -> static>,
 <Rule '/index3/' (OPTIONS, GET, HEAD) -> index>,
 <Rule '/index2/' (OPTIONS, GET, HEAD) -> index>,
 <Rule '/index/' (OPTIONS, GET, HEAD) -> index>])
"""
```

## 2.7 methods 参数

HTTP（与 Web 应用会话的协议）有许多不同的访问 URL 方法。默认情况下，路由只回应 GET 请求，但是通过 `route()` 装饰器传递 `methods` 参数可以改变这个行为：

- `methods` 参数接收一个列表，元素为字符串形式的请求方式名称；如果不传 `methods` 参数，默认支持 GET、HEAD、OPTIONS。
- OPTIONS 给客户端提供一个敏捷的途径来弄清这个 URL 支持哪些 HTTP 方法。从 Flask 0.6 开始，实现了自动处理。
- HEAD 是浏览器告诉服务器：欲获取信息，但是只关心消息头。应用应像处理 GET 请求一样来处理它，但是不分发实际内容。在 Flask 中完全无需人工干预，底层的 Werkzeug 库已经替你打点好了。

```python
from flask import Flask, render_template, request

app = Flask(__name__, template_folder='templates')


@app.route('/index/', methods=['GET', 'POST'])
def index():
    # 通过请求对象 request 中的 method 属性获取请求方式 GET/POST
    print(request.method)

    if request.method == 'GET':
        return render_template('login.html')
    elif request.method == 'POST':
        return 'post'


if __name__ == '__main__':
    print(app.url_map)  # app.url_map 查看路由信息
    app.run(debug=True)

"""
Map([<Rule '/static/<filename>' (OPTIONS, GET, HEAD) -> static>,
 <Rule '/index/' (OPTIONS, GET, POST, HEAD) -> index>])
"""
```

配套的 `templates/login.html` 表单页面（`method="post"` 提交到同一路由）：

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Title</title>
</head>
<body>
    <form method="post" action="/login">
        用户名: <input name="username"> <br>
        密码: <input name="password"> <br>
        <button type="submit">提交</button>
    </form>
</body>
</html>
```

## 2.8 反向解析 url_for

`url_for()` 函数可以通过 endpoint 端点值，反向解析得到对应的 url。endpoint 默认是视图函数名，也可以在注册路由时显式指定：

```python
from flask import Flask, url_for

app = Flask(__name__, template_folder='templates')


def index():
    return 'hello world'


# 注册路由时指定 endpoint 为 'index123'
# <Rule '/index' (OPTIONS, HEAD, GET) -> index123>
app.add_url_rule('/index', 'index123', index)


# url_for(endpoint端点值)
@app.route('/login/')
def login():
    return f'登录一下--{url_for("index123")}'


if __name__ == '__main__':
    print(app.url_map)  # app.url_map 查看路由信息
    app.run(debug=True)
```

典型应用场景：进入订单页面前判断用户是否登录，未登录则通过反向解析重定向到登录页面，避免在代码中硬编码 url：

```python
@app.route("/order")
def order():
    # 进入到订单页面：假如用户没有登录，则先进入登录页面；假如登录了，则直接进入订单页面
    # 假设获取到 username 不为空，则认为该用户已登录
    username = request.values.get("username")
    if username == "" or username is None:
        # redirect 重定向
        # return redirect('/login')
        # 反向解析 url_for("endpoint")，通过对端点反向解析到对应的 url
        login_url = url_for('login')
        print("通过端点反向解析取得的路由:", login_url)
        return redirect(login_url)
    else:
        # 用户已登录，进入订单页面
        return "订单页面"
```

## 2.9 动态路由

要给 URL 添加变量部分，把这些特殊的字段标记为 `<variable_name>`，这个部分将会作为命名参数传递到视图函数中。

### 2.9.1 默认转换器

变量直接放在 `<>` 中，默认匹配的是不带 `/` 的字符串：

```python
from flask import Flask

app = Flask(__name__, template_folder='templates')


# 参数命名：http://127.0.0.1:5000/index/abai/
# <Rule '/index/<name>/' (HEAD, OPTIONS, GET) -> index>]
@app.route('/index/<name>/')  # 提取赋值，赋值给了 name
def index(name):  # 接收参数 name
    return f'hello world-{name}'


if __name__ == '__main__':
    print(app.url_map)  # app.url_map 查看路由信息
    app.run(debug=True)
```

### 2.9.2 指定转换器

规则可以用 `converter:variable_name` 指定一个可选的转换器：

- `int`：接受整数
- `float`：接受浮点数
- `path`：和默认的相似，但也接受斜线

```python
from flask import Flask

app = Flask(__name__, template_folder='templates')


# 转换器转换  int: 整数   float: 浮点数   path: 路径转换
# http://127.0.0.1:5000/index/123/
@app.route('/index/<int:id>/')
def index(id):
    print(type(id))  # <class 'int'>
    return f'hello world-{id}'


# http://127.0.0.1:5000/index/123.0/
# @app.route('/index/<float:id>/')
# def index(id):
#     print(type(id))  # <class 'float'>
#     return f'hello world-{id}'


# http://127.0.0.1:5000/index/123hahah/ghhaha/
# @app.route('/index/<path:p>/')  # 匹配到 123hahah/ghhaha
# def index(p):
#     print(type(p))  # <class 'str'>
#     return f'hello world-{p}'


if __name__ == '__main__':
    print(app.url_map)  # app.url_map 查看路由信息
    app.run(debug=True)
```

## 2.10 自定义正则转换器

Flask 自带的路由转换器没有提供基于正则表达式的，但是我们可以自定义基于正则的路由转换器：

- 自定义转换器必须继承 `BaseConverter` 类，并重写父类的 `__init__` 方法；
- 转换器需要注册：`url_map` 中保存了所有的路由转换器，`converters` 是字典类型；
- `to_python` 在路由匹配提取参数后调用，可对参数做类型转换等处理；
- `to_url` 在使用 `url_for` 反向解析时调用，可对参数进行处理。

```python
from flask import Flask, url_for
from werkzeug.routing import BaseConverter  # 转换器基类

app = Flask(__name__)


# 正则转换器
class RegexConverter(BaseConverter):
    def __init__(self, url_map, *args):
        super(RegexConverter, self).__init__(url_map)
        # 将正则表达式传递给转换器对象，flask 在解析路径的时候会来这里获取 regex 保存的正则表达式
        self.regex = args[0]

    def to_python(self, value):
        # 对获取到的参数进行处理
        # 默认获取到的是字符串，可以做类型转换等处理，这样就可以在视图中直接使用
        print(type(value))
        print(value)
        return value

    def to_url(self, value):
        # 当使用 url_for 反向解析的时候会调用这个方法，value 保持出入的原类型
        return f'to_url--{value}'


# 正则转换器 -- 注册
app.url_map.converters['zhengze'] = RegexConverter


@app.route(r'/index/<zhengze("\d+"):id>/')
def index(id):
    print(type(id))  # <class 'str'>
    # 反向解析时会先经过 to_url 处理参数
    print(url_for('index', id=456))  # /index/to_url--456/
    return f'hello world-{id}'


if __name__ == '__main__':
    print(app.url_map)  # app.url_map 查看路由信息
    app.run(debug=True)
```

要点：

- 路由规则中写 `<zhengze("\d+"):id>`，表示该段 url 必须匹配正则 `\d+`（一个或多个数字），匹配到的内容作为参数 `id` 传给视图；
- 建议使用原始字符串 `r'...'` 书写规则，避免正则中的反斜杠被转义；
- `url_for('index', id=456)` 反向解析时，`to_url` 的返回值会拼进最终 url，所以上面打印出 `/index/to_url--456/`。
