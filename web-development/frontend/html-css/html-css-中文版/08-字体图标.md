# 8 字体图标

字体图标（Icon Font）是把矢量图标打包成一种自定义字体。每个图标就是一个字形，因此可以像普通文字一样用 `font-size`、`color`、`text-shadow` 等属性来控制样式。

## 8.1 什么是字体图标

字体图标把多个图标放进一个字体文件里。浏览器把它们当作文字来渲染，相比位图有如下优势：

| 特性 | 说明 |
|------|------|
| 可缩放 | 矢量字形任意放大都不会模糊 |
| 可改色 | 通过 `color` 或 `opacity` 改变颜色 |
| 可改大小 | 通过 `font-size` 调整尺寸 |
| 体积小 | 一个字体文件可包含上百个图标 |
| 易于配合 CSS | hover、transition、transform 都能直接使用 |

> **核心思路：** 把图标当成文字来用。能设置文字样式的地方，就能设置字体图标。

## 8.2 字体图标的获取途径

课程中常用的两个平台是：

| 平台 | 网址 | 说明 |
|------|------|------|
| 阿里巴巴 iconfont | <https://www.iconfont.cn> | 中文图标资源丰富，支持多色图标 |
| IcoMoon | <https://icomoon.io> | 可以把选中的 SVG 生成自定义字体 |

两者的工作流基本相同：选图标 → 生成/下载字体代码 → 引入 CSS → 在标签中使用。

## 8.3 字体图标的使用流程

完整使用流程如下：

1. 选择所需图标，加入项目购物车/库。
2. 生成或下载字体代码。
3. 解压压缩包，把 `fonts/` 文件夹复制到项目中。
4. 将提供的 `@font-face` 和图标 class CSS 粘贴到自己的样式表（或直接引入生成的 `iconfont.css`）。
5. 在 HTML 标签中加入图标 class 或 Unicode 字符。
6. 给标签设置 `@font-face` 中声明的 `font-family`。

### 8.3.1 引入字体文件

典型的字体图标包里包含一个 CSS 文件和一个 `fonts/` 目录：

```css
/* 由平台生成的 iconfont.css */
@font-face {
    font-family: 'iconfont';
    src: url('fonts/iconfont.woff2') format('woff2'),
         url('fonts/iconfont.woff') format('woff'),
         url('fonts/iconfont.ttf') format('truetype');
    font-weight: normal;
    font-style: normal;
    font-display: swap;
}

.iconfont {
    font-family: 'iconfont' !important;
    font-size: 16px;
    font-style: normal;
    -webkit-font-smoothing: antialiased;
    -moz-osx-font-smoothing: grayscale;
}
```

> **路径提示：** `@font-face` 里的 `url(...)` 路径必须相对于 CSS 文件，指向实际存放 `fonts/` 的位置。

### 8.3.2 使用图标

通常使用 class 方式调用：

```html
<!-- 使用生成的图标 class -->
<i class="iconfont icon-arrow-down"></i>
```

也可以直接使用 Unicode 字符编码：

```html
<i class="iconfont">&#xe6b6;</i>
```

| 方式 | HTML | 适用场景 |
|------|------|----------|
| class | `<i class="iconfont icon-arrow-down"></i>` | 推荐；可读性高，便于维护 |
| Unicode | `<i class="iconfont">&#xe6b6;</i>` | 只有字符编码时的备选 |

```css
.iconfont {
    color: #333;
    font-size: 24px;
}

.iconfont:hover {
    color: #e74c3c;
}
```

## 8.4 单色与多色图标

| 类型 | 原理 | 限制 |
|------|------|------|
| 单色图标 | 单一颜色，由 `color` 控制 | 无法显示多种颜色 |
| 多色图标 | 字体字形内部自带颜色分层 | 需要较新的字体格式和浏览器支持；难以用 CSS 重新着色 |

> **建议：** 交互型控件优先用单色图标，方便通过 CSS 改色。只有对品牌色要求严格的 logo 或插画才用多色图标。

## 8.5 下拉箭头旋转动画

字体图标和 CSS 过渡、变换配合很方便。常见需求是下拉菜单展开时箭头旋转。

```html
<span class="iconfont icon-arrow-down arrow"></span>
```

```css
.arrow {
    display: inline-block;
    transition: transform 0.3s ease;
}

/* 父元素处于展开状态时旋转 180 度 */
.open .arrow {
    transform: rotate(180deg);
}
```

**要点：**
- 给图标加 `display: inline-block`，`transform` 才能生效。
- 加 `transition` 让旋转平滑过渡。
- 通过切换父级 class（如 `.open`）控制展开状态，可用 JavaScript 或 checkbox 实现。

## 8.6 字体图标与精灵图的取舍

两种方式都能减少 HTTP 请求，但适合的场景不同。

| 维度 | 字体图标 | CSS 精灵图 |
|------|----------|------------|
| 渲染 | 矢量，缩放清晰 | 位图，放大可能模糊 |
| 颜色 | 用 CSS 轻松改色 | 图片颜色固定 |
| 动画 | 可直接用 transform/transition | 需要切换 background-position 或图片 |
| 多色 | 支持有限 | 天然支持，颜色可画在图中 |
| 可访问性 | 若标记不当可能影响读屏软件 | 需要 alt 文本或隐藏文本 |
| 兼容性 | 老浏览器可能无法加载字体文件 | 只要支持图片即可 |

> **选择原则：** 需要缩放、单色的 UI 图标用字体图标；需要精确多色图形或必须兼容旧浏览器时用 CSS 精灵图。

## 8.7 最佳实践

| 推荐 | 不推荐 |
|------|--------|
| 把字体文件放在专门的 `fonts/` 目录 | 使用在不同环境下会断裂的绝对路径 |
| 使用语义化、可描述的 class 名 | 只用 Unicode 编码而不加说明 |
| 为读屏软件提供文字 fallback 或 `aria-label` | 图标按钮没有任何可访问标签 |
| 交互控件优先使用单色图标 | 在需要 CSS 改色时使用多色图标 |
| 使用 `font-display: swap` 避免字体加载期间文字不可见 | 因等待图标字体而阻塞页面渲染 |

**记忆口诀**
- **字体图标** = "图标当文字，大小颜色 `font-size` / `color` 控。"
