# 5 表格与表单

本章介绍高级表格特性以及 HTML 表单——网页上收集用户输入的主要机制。

## 5.1 HTML 表单概述

表单是文档中包含交互控件的一个区域，用于向 Web 服务器提交信息。

```html
<form action="/submit" method="POST">
    <!-- 表单控件放在这里 -->
    <button type="submit">Submit</button>
</form>
```

| Attribute | Description |
|-----------|-------------|
| `action` | 表单数据提交的 URL |
| `method` | HTTP 方法：`GET` 或 `POST` |
| `enctype` | 编码类型（文件上传时使用 `multipart/form-data`） |
| `target` | 响应显示位置（`_self`、`_blank` 等） |

> **GET vs POST：**
> - `GET`：将数据附加到 URL 上，大小受限（约 2048 个字符），常用于搜索/筛选。
> - `POST`：将数据放在请求体中发送，没有大小限制，常用于敏感数据和文件上传。

## 5.2 Input 元素

`<input>` 元素是最灵活的表单控件，其行为随 `type` 属性变化。

### 5.2.1 常用 Input 类型（综合示例）

一个综合小表单，涵盖文本类输入、单选按钮、复选框、文件上传和按钮：

```html
<style>
    .demo label { display: block; margin: 10px 0 4px; font-weight: bold; }
    .demo input { padding: 6px 8px; border: 1px solid #ccc; border-radius: 4px; }
    .demo .row label { display: inline; font-weight: normal; margin-right: 12px; }
    .demo button { margin: 12px 6px 0 0; padding: 6px 20px; border: none; border-radius: 4px;
                   background: #4a90e2; color: #fff; cursor: pointer; }
</style>
<form class="demo">
    <!-- 文本 / 密码 / 数字 -->
    <label for="user">Username</label>
    <input type="text" id="user" name="username" placeholder="Enter username">
    <label for="pwd">Password</label>
    <input type="password" id="pwd" name="password" placeholder="Enter password">
    <label for="age">Age</label>
    <input type="number" id="age" name="age" min="1" max="120" value="18">

    <!-- 单选按钮：同组共享同一个 name，只能选一个 -->
    <label>Gender</label>
    <div class="row">
        <input type="radio" name="gender" value="male" id="male"> <label for="male">Male</label>
        <input type="radio" name="gender" value="female" id="female" checked> <label for="female">Female</label>
    </div>

    <!-- 复选框：同组可同时选多个 -->
    <label>Hobbies</label>
    <div class="row">
        <input type="checkbox" name="hobbies" value="reading" id="read" checked> <label for="read">Reading</label>
        <input type="checkbox" name="hobbies" value="sports" id="sport"> <label for="sport">Sports</label>
    </div>

    <!-- 文件上传（表单需加 enctype="multipart/form-data"） -->
    <label for="avatar">Avatar</label>
    <input type="file" id="avatar" name="avatar" accept="image/*">

    <button type="submit">Submit</button>
</form>
```
![[ch5-input-types.png]]

**常用 input 属性：**

| Attribute | Description |
|-----------|-------------|
| `name` | 向服务器发送数据时使用的键 |
| `value` | 默认值 |
| `placeholder` | 为空时显示的提示文本 |
| `required` | 提交前必须填写 |
| `readonly` | 不可编辑（仍会提交） |
| `disabled` | 不可编辑（不会提交） |
| `maxlength` | 最大字符数 |
| `min` / `max` | 范围限制（用于 number、date 等） |
| `autofocus` | 页面加载后自动聚焦该控件 |

> **规则：** 同一组的单选按钮共享同一个 `name`，同一组的复选框也共享同一个 `name`。

**文件上传属性：**

| Attribute | Description |
|-----------|-------------|
| `accept` | 允许的文件类型（例如 `.jpg`、`.png`、`image/*`） |
| `multiple` | 允许选择多个文件 |

> **要求：** 文件上传时，表单必须使用 `enctype="multipart/form-data"`。

> **最佳实践：** 使用 `<button>` 而不是 `<input type="submit">`。`<button>` 更灵活（可包含图标等 HTML 内容），也更容易设置样式。

### 5.2.2 其他 Input 类型

| Type | Description | Example |
|------|-------------|---------|
| `date` | 日期选择器 | `<input type="date">` |
| `time` | 时间选择器 | `<input type="time">` |
| `datetime-local` | 日期和时间 | `<input type="datetime-local">` |
| `color` | 颜色选择器 | `<input type="color" value="#ff0000">` |
| `range` | 滑块 | `<input type="range" min="0" max="100">` |
| `search` | 搜索框 | `<input type="search">` |
| `url` | URL 验证 | `<input type="url">` |
| `hidden` | 隐藏字段（仍会发送数据） | `<input type="hidden" name="token" value="abc">` |

### 5.2.3 去除表单控件默认样式

浏览器会给表单控件添加各自的边框和聚焦轮廓。自定义设计时可以清除，但务必补充可见的 `:focus` 状态，保证键盘可访问性。

```css
input, textarea, select, button {
    border: none;      /* 去除默认边框 */
    outline: none;     /* 去除默认聚焦轮廓 */
}

/* 提供自定义聚焦指示器 */
input:focus, textarea:focus, select:focus, button:focus {
    box-shadow: 0 0 0 2px #4a90e2;
}
```

> **可访问性提示：** 移除 `outline` 后如果不加替代样式，会影响键盘导航。`outline: none` 必须搭配自定义 `:focus` 样式一起使用。

### 5.2.4 案例小块：登录/注册表单

一个精简的登录表单，演示 `<label>`、必填字段、`autofocus` 和自定义样式。

```html
<form action="/login" method="POST">
    <label for="user">用户名</label>
    <input id="user" type="text" name="username" required autofocus>

    <label for="pwd">密码</label>
    <input id="pwd" type="password" name="password" required>

    <button type="submit">登录</button>
</form>
```

```css
input, button {
    border: none;
    outline: none;
    border-radius: 4px;
}
input:focus {
    box-shadow: 0 0 0 2px #4a90e2;
}
button {
    background: #4a90e2;
    color: #fff;
    cursor: pointer;
}
```

**要点：**
- 每个 `<input>` 都通过 `for` + `id` 与 `<label>` 关联。
- 使用 `autofocus` 让页面加载后光标自动进入用户名字段。
- 清除默认边框和聚焦轮廓，并补一个自定义的 `:focus` 光环。
- 添加 `required` 做基础客户端验证。

## 5.3 标签

`<label>` 用于将描述文本与表单控件关联起来。点击标签会聚焦或切换关联的控件。

**方式一：显式关联（推荐）**

```html
<input type="checkbox" id="agree" name="terms">
<label for="agree">I agree to the terms and conditions</label>
```

**方式二：隐式关联**

```html
<label>
    <input type="checkbox" name="terms">
    I agree to the terms and conditions
</label>
```

> **可访问性：** 始终使用标签。当用户聚焦输入框时，屏幕阅读器会朗读标签文本。

## 5.4 多行文本与选择

### 5.4.1 Textarea 与 Select（综合示例）

`<textarea>` 用于多行文本输入，`<select>` 用于从选项列表中选择（也可多选）：

```html
<style>
    .demo label { display: block; margin: 10px 0 4px; font-weight: bold; }
    .demo textarea, .demo select { padding: 6px 8px; border: 1px solid #ccc; border-radius: 4px; }
    .demo textarea { width: 260px; height: 80px; resize: vertical; }  /* 仅允许垂直方向调整 */
</style>
<form class="demo">
    <!-- 多行文本 -->
    <label for="msg">Message</label>
    <textarea id="msg" name="message" placeholder="Enter your message..."></textarea>

    <!-- 下拉菜单：optgroup 分组，selected 表示默认选中 -->
    <label for="city">City</label>
    <select id="city" name="city">
        <optgroup label="Asia">
            <option value="beijing">Beijing</option>
            <option value="tokyo" selected>Tokyo</option>
        </optgroup>
        <optgroup label="Europe">
            <option value="london">London</option>
            <option value="paris">Paris</option>
        </optgroup>
    </select>

    <!-- multiple 允许多选，size 控制可见行数 -->
    <label for="skills">Skills</label>
    <select id="skills" name="skills" multiple size="4">
        <option value="html">HTML</option>
        <option value="css" selected>CSS</option>
        <option value="js">JavaScript</option>
        <option value="py">Python</option>
    </select>
</form>
```
![[ch5-textarea-select.png]]

**textarea 常用属性：**

| Attribute | Description |
|-----------|-------------|
| `rows` | 可见高度（以行数计） |
| `cols` | 可见宽度（以字符数计） |
| `maxlength` | 最大字符数 |
| `placeholder` | 提示文本 |

> **CSS 替代方案：** 用 CSS 控制 `textarea` 的尺寸（如上面的 `width` / `height` / `resize`）比 `rows` / `cols` 更灵活。

**`resize` 取值：**

| 值 | 含义 |
|----|------|
| `none` | 禁止调整大小 |
| `vertical` | 只允许垂直方向调整 |
| `horizontal` | 只允许水平方向调整 |
| `both` | 两个方向均可调整（浏览器默认） |

> **标签规则：** 开始标签和结束标签应写在同一行：`<textarea>...</textarea>`。如果内容另起一行，字段内会出现前置空白。

- 在 `<option>` 上写 `selected`，可让它成为页面加载后的默认选中项。
- 使用 `<select multiple>` 允许用户多选。按住 **Ctrl**（Windows/Linux）或 **Cmd**（macOS）点击即可选择或取消选择项目。

## 5.5 表单验证

现代浏览器支持使用 HTML 属性进行内置表单验证。

```html
<style>
    /* 浏览器根据当前值自动切换 :valid / :invalid 状态 */
    .demo label { display: block; margin: 10px 0 4px; font-weight: bold; }
    .demo input { padding: 6px 8px; border: 2px solid #ccc; border-radius: 4px; }
    .demo input:valid { border-color: #2ecc71; }    /* 通过验证：绿色 */
    .demo input:invalid { border-color: #e74c3c; }  /* 未通过验证：红色 */
    .demo button { margin-top: 12px; padding: 6px 20px; border: none; border-radius: 4px;
                   background: #4a90e2; color: #fff; cursor: pointer; }
</style>
<form class="demo">
    <!-- 必填且至少 3 个字符：已填写 → 绿色 -->
    <label for="user">Username (required, 3+ chars)</label>
    <input type="text" id="user" name="username" required minlength="3" maxlength="20" value="Andy">

    <!-- 邮箱格式：当前值合法 → 绿色 -->
    <label for="mail">Email</label>
    <input type="email" id="mail" name="email" value="andy@example.com">

    <!-- 正则要求 5 位数字："123" 不匹配 → 红色 -->
    <label for="zip">Zip code (5 digits)</label>
    <input type="text" id="zip" name="zipcode" pattern="[0-9]{5}" value="123" title="Five digit zip code">

    <!-- 必填但留空 → 红色 -->
    <label for="qty">Quantity (1-10)</label>
    <input type="number" id="qty" name="quantity" min="1" max="10" required>

    <button type="submit">Submit</button>
</form>
```
![[ch5-validation.png]]

上图中绿色边框表示当前值通过验证，红色边框表示未通过——全部由 CSS 根据 `:valid` / `:invalid` 状态自动切换，无需 JavaScript。

| Attribute | Validation |
|-----------|------------|
| `required` | 字段不能为空 |
| `minlength` / `maxlength` | 字符数限制 |
| `min` / `max` | 数值/日期范围 |
| `pattern` | 正则表达式匹配 |
| `type="email"` | 必须包含 @ 和域名 |
| `type="url"` | 必须是有效的 URL 格式 |

> **注意：** 客户端验证可以改善用户体验，但并不安全。务必在服务器端也进行数据验证。

## 5.6 最佳实践

| Do | Don't |
|----|-------|
| 为每个输入框关联 `<label>` | 让输入框没有标签 |
| 使用语义化的 `type` 属性（`email`、`tel` 等） | 所有输入都用 `type="text"` |
| 提供 `placeholder` 提示 | 用 placeholder 替代标签 |
| 在客户端和服务器端都进行验证 | 只依赖客户端验证 |
| 使用 `button type="submit"` | 在新项目中使用 `<input type="submit">` |
| 用 `<fieldset>` 分组相关字段 | 让表单成为一长串列表 |

## 5.7 表格样式

下面是一张综合了合并边框、表头配色和斑马纹的样式化表格：

```html
<style>
    table { border-collapse: collapse; width: 420px; }  /* 合并相邻单元格边框 */
    th, td { border: 1px solid #d1d5db; padding: 8px 12px; text-align: left; }
    th { background: #4a90e2; color: #fff; }            /* 表头配色 */
    tbody tr:nth-child(even) { background: #f3f6fb; }   /* 斑马纹：偶数行变色 */
</style>
<table>
    <thead>
        <tr><th>Name</th><th>Language</th><th>Score</th></tr>
    </thead>
    <tbody>
        <tr><td>Alice</td><td>HTML</td><td>92</td></tr>
        <tr><td>Bob</td><td>CSS</td><td>88</td></tr>
        <tr><td>Carol</td><td>JavaScript</td><td>95</td></tr>
        <tr><td>David</td><td>Python</td><td>90</td></tr>
    </tbody>
</table>
```
![[ch5-table-styles.png]]

| 属性 | 取值 | 说明 |
|------|------|------|
| `border-collapse` | `collapse` / `separate` | 合并相邻单元格边框，或保持分离 |
| `border-spacing` | 长度值（如 `5px`） | `border-collapse: separate` 时单元格之间的间距 |
| `empty-cells` | `show` / `hide` | 是否显示无内容单元格的边框/背景 |

> **注意：** `border-spacing` 只在 `border-collapse` 为 `separate`（默认值）时生效。
