# 6 过渡、动画与 Flexbox

本章介绍 CSS 过渡（transition）、变换（transform）、关键帧动画（@keyframes）以及 Flexbox——现代一维布局的标准方案。

## 6.1 CSS 过渡

过渡可以在指定的持续时间内，将某个 CSS 属性从一个值平滑地变化到另一个值。下面把按钮的正常态与 `:hover` 结束态并排展示，右侧按钮直接写死了悬停后的样式，方便对比：

```html
<style>
    .row { display: flex; gap: 50px; align-items: center; padding: 20px; font-family: sans-serif; }
    .btn {
        width: 120px; padding: 10px 0; border-radius: 6px;
        text-align: center; color: #fff; background-color: #3b82f6;
        transition: background-color 0.3s ease, width 0.3s ease;
    }
    .btn:hover { background-color: #ef4444; width: 160px; }
    /* 右侧按钮写死为 hover 结束状态，方便截图做两态对比 */
    .btn-end { background-color: #ef4444; width: 160px; }
    .cap { margin: 0 0 6px; font-size: 13px; color: #6b7280; text-align: center; }
</style>
<div class="row">
    <div><p class="cap">normal</p><div class="btn">Button</div></div>
    <div><p class="cap">:hover end state</p><div class="btn btn-end">Button</div></div>
</div>
```
![[ch6-transition.png]]

### 6.1.1 过渡属性

| 属性 | 说明 | 示例 |
|----------|-------------|---------|
| `transition-property` | 要动画的 CSS 属性 | `background-color`、`all` |
| `transition-duration` | 动画持续多久 | `0.3s`、`500ms` |
| `transition-timing-function` | 过渡的速度曲线 | `ease`、`linear`、`ease-in-out` |
| `transition-delay` | 动画开始前的延迟 | `0.2s` |

### 6.1.2 计时函数

| 值 | 效果 |
|-------|----------|
| `linear` | 匀速 |
| `ease` | 慢开始、快中间、慢结束（默认值） |
| `ease-in` | 慢开始 |
| `ease-out` | 慢结束 |
| `ease-in-out` | 慢开始和慢结束 |
| `cubic-bezier(x1, y1, x2, y2)` | 自定义贝塞尔曲线 |
| `steps(n)` | 离散步骤 |

```css
.box {
    /* 简写：property | duration | timing-function | delay */
    transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}
```

> **注意：** 只有具有中间值的属性才能过渡。`display`、`visibility` 和 `position` 不能直接过渡。

### 6.1.3 案例：书亦侧边工具条

固定在右侧的工具条，悬停时图标宽度展开并淡入文字标签。

```css
.toolbar {
    position: fixed;
    right: 0;
    top: 50%;
    transform: translateY(-50%);
}

.tool {
    width: 40px;
    overflow: hidden;
    transition: width 0.3s, opacity 0.3s;
}

.tool:hover { width: 120px; }

.label {
    opacity: 0;
    transform: scale(0);
    transform-origin: left center;
    transition: opacity 0.3s, transform 0.3s;
}

.tool:hover .label { opacity: 1; transform: scale(1); }
```

- `transition` 同时过渡 `width` 和 `opacity`。
- `transform-origin` 让标签从左侧开始缩放，而不是从中心。

### 6.1.4 案例：小米 APP 下载二维码悬停展开

悬停下载链接时，下方展开二维码面板；用 `::before` 绘制 CSS 三角形，面板通过 `height` 和 `opacity` 过渡展开。

```css
.download { position: relative; }

.qr {
    position: absolute;
    top: 100%; left: 50%;
    transform: translateX(-50%);
    height: 0; opacity: 0;
    overflow: hidden;
    transition: height 0.3s, opacity 0.3s;
}

.download:hover .qr { height: 150px; opacity: 1; }

.qr::before {
    content: '';
    position: absolute;
    top: -20px; left: 50%;
    transform: translateX(-50%);
    border: 10px solid transparent;
    border-bottom-color: #fff;
}
```

- 用 `height` + `opacity` 实现平滑展开；`display: none` 不能直接过渡。
- 三角形从面板指回触发元素。

## 6.2 CSS 变换

`transform` 属性可对元素应用 2D 或 3D 变换。

### 6.2.1 2D 变换

下面把四种常见的 2D 变换并排展示，每组左边是正常态，右边写死了变换后的样子：

```html
<style>
    .stage { display: flex; gap: 44px; padding: 30px 24px 10px; font-family: sans-serif; font-size: 13px; text-align: center; }
    .box {
        width: 70px; height: 70px; margin: 0 auto 8px;
        background: #93c5fd; border: 2px solid #3b82f6; border-radius: 4px;
    }
    /* 右侧盒子写死对应变换；translateX()/translateY() 可只移动一个轴 */
    .t-translate { transform: translate(20px, -14px); }
    /* scaleX()/scaleY() 可只缩放一个轴；rotate() 负值为逆时针 */
    .t-rotate { transform: rotate(45deg); }
    .t-scale { transform: scale(1.4); }
    .t-skew { transform: skewX(20deg); }
</style>
<div class="stage">
    <div><div class="box"></div><div class="box t-translate"></div>translate</div>
    <div><div class="box"></div><div class="box t-rotate"></div>rotate</div>
    <div><div class="box"></div><div class="box t-scale"></div>scale</div>
    <div><div class="box"></div><div class="box t-skew"></div>skew</div>
</div>
```
![[ch6-transform.png]]

> **重要：** `transform` 不会影响文档流。被变换的元素不会把其他元素推开。

### 6.2.2 变换原点

控制变换的支点位置。

```css
.box {
    transform-origin: center center;   /* 默认值 */
    transform-origin: top left;
    transform-origin: 50% 50%;
    transform-origin: 20px 40px;
}
```

### 6.2.3 变换细节补充

| 细节 | 效果 |
|------|------|
| `scale(-n)` | 负缩放会沿对应轴翻转元素并缩放 |
| `skewX()` / `skewY()` | 元素及其内容会一起倾斜 |
| `rotate()` | 正角度顺时针旋转，负角度逆时针旋转 |

```css
.flip {
    transform: scaleX(-1);        /* 水平镜像 */
}

.tilt {
    transform: skewX(10deg);      /* 内容随盒子一起倾斜 */
}

.spin {
    transform: rotate(45deg);     /* 顺时针 */
}
```

## 6.3 CSS 动画

对于包含多个关键帧的复杂动画，使用 `@keyframes`。

### 6.3.1 关键帧语法

下面定义一个 `bounce` 弹跳动画，并把三个关键帧状态并排展示；右侧两个球直接写死了关键帧样式，方便截图对比（实际运行时球会连续弹跳）：

```html
<style>
    .track {
        display: flex; gap: 80px; align-items: flex-end;
        height: 170px; padding: 0 40px;
        border-bottom: 2px solid #9ca3af; font-family: sans-serif;
    }
    .col { height: 100%; display: flex; flex-direction: column; justify-content: flex-end; align-items: center; }
    .col p { margin: 0 0 6px; font-size: 13px; color: #6b7280; }
    .ball {
        width: 46px; height: 46px; border-radius: 50%;
        background: radial-gradient(circle at 32% 30%, #fca5a5, #dc2626);
        animation: bounce 1s ease-in-out infinite;
    }
    @keyframes bounce {
        0%   { transform: translateY(0); }
        50%  { transform: translateY(-56px); }
        100% { transform: translateY(0); }
    }
    /* 截图对比用：后两个球写死 50% 与 100% 关键帧的状态 */
    .at-50 { animation: none; transform: translateY(-56px); }
    .at-100 { animation: none; }
</style>
<div class="track">
    <div class="col"><p>0% — start</p><div class="ball"></div></div>
    <div class="col"><p>50% — peak</p><div class="ball at-50"></div></div>
    <div class="col"><p>100% — return</p><div class="ball at-100"></div></div>
</div>
```
![[ch6-animation.png]]

### 6.3.2 动画属性

| 属性 | 说明 |
|----------|-------------|
| `animation-name` | `@keyframes` 规则的名称 |
| `animation-duration` | 一个周期持续多久 |
| `animation-timing-function` | 速度曲线 |
| `animation-delay` | 开始前的延迟 |
| `animation-iteration-count` | 播放次数（`1`、`2`、`infinite`） |
| `animation-direction` | `normal`、`reverse`、`alternate`、`alternate-reverse` |
| `animation-fill-mode` | 动画前后的样式（`none`、`forwards`、`backwards`、`both`） |
| `animation-play-state` | `running` 或 `paused` |

```css
.box {
    /* 简写：name | duration | timing-function | delay | count | direction | fill-mode */
    animation: bounce 1s ease-in-out 0.5s infinite alternate both;
}
```

### 6.3.3 动画填充模式

| 值 | 效果 |
|-------|----------|
| `none` | 动画结束后恢复原始样式 |
| `forwards` | 保持最后一帧的样式 |
| `backwards` | 延迟期间应用第一帧的样式 |
| `both` | 同时应用 forwards 和 backwards |

### 6.3.4 往复动画与暂停

将 `infinite` 与 `alternate` 组合，可实现动画无限往复循环；用 `animation-play-state` 可控制暂停/继续。

```css
@keyframes move {
    0% { transform: translateX(0); }
    100% { transform: translateX(100px); }
}

.mover {
    animation: move 1s linear infinite alternate;
}

.mover:hover {
    animation-play-state: paused;
}
```

### 6.3.5 案例：加载动画旋转圆环

圆形元素只给一条边框上色，配合旋转关键帧实现加载环。

```css
.spinner {
    width: 40px;
    height: 40px;
    border: 4px solid #ddd;
    border-top-color: #3498db;
    border-radius: 50%;
    animation: spin 1s linear infinite;
}

@keyframes spin {
    to { transform: rotate(360deg); }
}
```

- `border-radius: 50%` 让元素变成圆形。
- 只有一条边框有颜色，形成旋转的“缺口”效果。

## 6.4 Flexbox 布局

Flexbox（Flexible Box Layout）是一种一维布局系统，用于在容器内分配空间并对齐项目。

### 6.4.1 Flex 容器

```css
.container {
    display: flex;           /* 启用 flexbox */
    display: inline-flex;    /* 行内级 flex 容器 */
}
```

当容器需要和周围内容同行排列，同时子元素仍按 flex 布局时，使用 `display: inline-flex`。

先看一个综合示例：红框是 flex 容器，色块是 flex 项目；上面一排展示 `justify-content`，下面一排展示 `align-items`：

```html
<style>
    .cap { margin: 14px 0 4px; font-family: sans-serif; font-size: 13px; color: #6b7280; }
    .container {
        display: flex; gap: 10px; width: 430px; padding: 10px;
        border: 2px dashed #ef4444;   /* 红框标出 flex 容器的边界 */
        font-family: sans-serif; font-size: 13px;
    }
    .container + .container { margin-top: 18px; }
    .item {
        width: 70px; padding: 8px 0; text-align: center; background: #93c5fd;
        display: flex; align-items: center; justify-content: center;
    }
    .item:nth-child(2) { background: #86efac; }
    .item:nth-child(3) { background: #fca5a5; }
    .between { justify-content: space-between; }
    .middle { align-items: center; height: 110px; }
    .tall { height: 84px; }
    .mid { height: 52px; }
</style>
<p class="cap">justify-content: space-between</p>
<div class="container between">
    <div class="item">Item 1</div>
    <div class="item">Item 2</div>
    <div class="item">Item 3</div>
</div>
<p class="cap">align-items: center (items have different heights)</p>
<div class="container middle">
    <div class="item tall">Item 1</div>
    <div class="item mid">Item 2</div>
    <div class="item">Item 3</div>
</div>
```

### 6.4.2 主轴方向

**主轴**是 flex 项目排列的主要方向。

```css
.container {
    flex-direction: row;            /* 默认值：从左到右 */
    flex-direction: row-reverse;    /* 从右到左 */
    flex-direction: column;         /* 从上到下 */
    flex-direction: column-reverse; /* 从下到上 */
}
```

### 6.4.3 换行

默认情况下，flex 项目会尝试排成一行。使用 `flex-wrap` 允许换行。

```css
.container {
    flex-wrap: nowrap;       /* 默认值：单行 */
    flex-wrap: wrap;         /* 允许多行 */
    flex-wrap: wrap-reverse; /* 反向换行 */
}
```

> **简写：** `flex-flow: row wrap;` 同时设置 `flex-direction` 和 `flex-wrap`。

### 6.4.4 justify-content（主轴对齐）

控制项目沿主轴的分布方式。

```css
.container {
    justify-content: flex-start;     /* 默认值：靠起始端 */
    justify-content: flex-end;       /* 靠结束端 */
    justify-content: center;         /* 居中 */
    justify-content: space-between;  /* 项目之间等距 */
    justify-content: space-around;   /* 项目两侧等距 */
    justify-content: space-evenly;   /* 真正等距 */
}
```

| 值 | 间距 |
|-------|---------|
| `flex-start` | ```[A B C]      ``` |
| `flex-end` | ```      [A B C]``` |
| `center` | ```   [A B C]   ``` |
| `space-between` | ```A     B     C``` |
| `space-around` | ``` A   B   C ``` |
| `space-evenly` | ```  A  B  C  ``` |

### 6.4.5 align-items（交叉轴对齐——单行）

控制项目在交叉轴（垂直于主轴）上的对齐方式。

```css
.container {
    align-items: stretch;       /* 默认值：填满容器高度 */
    align-items: flex-start;    /* 靠顶部对齐 */
    align-items: flex-end;      /* 靠底部对齐 */
    align-items: center;        /* 垂直居中 */
    align-items: baseline;      /* 文本基线对齐 */
}
```

### 6.4.6 align-content（交叉轴对齐——多行）

当项目换行成多行时，`align-content` 控制行与行之间的间距。

```css
.container {
    align-content: stretch;       /* 默认值 */
    align-content: flex-start;    /* 行靠起始端 packing */
    align-content: flex-end;      /* 行靠结束端 packing */
    align-content: center;        /* 行居中 */
    align-content: space-between; /* 行之间等距 */
    align-content: space-around;  /* 行两侧等距 */
}
```

> **区别：** `align-items` 控制单个项目，`align-content` 控制项目的行。

### 6.4.7 Flex 项目属性

| 属性 | 说明 |
|----------|-------------|
| `order` | 改变视觉顺序（默认值：0） |
| `flex-grow` | 相对于其他项目伸展的比例（默认值：0） |
| `flex-shrink` | 空间不足时收缩的比例（默认值：1） |
| `flex-basis` | 伸展/收缩前的理想起始大小 |
| `align-self` | 仅覆盖当前项目的 `align-items` |

```css
.item1 {
    flex-grow: 1;        /* 占据剩余空间 */
    flex-shrink: 0;      /* 不收缩 */
    flex-basis: 200px;   /* 起始大小为 200px */
    /* 简写：grow | shrink | basis */
    flex: 1 0 200px;
}

.item2 {
    order: -1;           /* 显示在其他项目之前 */
    align-self: center;  /* 仅该项目居中对齐 */
}
```

> **常见模式——等宽列：**
> ```css
> .column { flex: 1; }   /* 所有列均分空间 */
> ```

## 6.5 最佳实践

| 应该做 | 不应该做 |
|----|-------|
| 对简单悬停效果使用 `transition` | 对简单悬停效果使用 `@keyframes` |
| 使用 `transform` 而非 `top`/`left` 来实现动画 | 动画化 `width`、`height`、`margin`（会导致重排） |
| 将 Flexbox 用于一维布局（行或列） | 将 Flexbox 用于完整的二维网格布局（应使用 CSS Grid） |
| 使用 `flex: 1` 实现等宽列 | 使用百分比加 `float` 实现等宽列 |
| 优先使用 `transform` 和 `opacity` 做动画 | 动画化会触发布局重计算的属性 |

**总结口诀**
- **Flexbox** = “主轴用 justify，交叉轴用 align”
