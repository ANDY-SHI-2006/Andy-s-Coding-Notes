# 7 字符串、数组、日期与正则表达式

用于操作文本、集合、时间和模式匹配的核心内置对象与方法。

## 7.1 字符串方法

### 7.1.1 读取与查找

```javascript
let text = "Hello, World!";

text.length;                       // 13
text[0];                           // "H"
text.charAt(0);                    // "H"
text.charCodeAt(0);                // 72（Unicode 码点）
String.fromCharCode(72, 105);      // "Hi"

text.indexOf("World");             // 7（首次出现）
text.indexOf("o", 8);              // 10（从索引 8 开始搜索）
text.lastIndexOf("l");             // 10（最后一次出现）
text.includes("World");            // true
text.startsWith("Hello");          // true
text.endsWith("!");                // true

text.concat(" ", "Again");         // "Hello, World! Again"（返回新字符串）
```

### 7.1.2 提取子字符串

```javascript
let text = "Hello, World!";

text.slice(0, 5);         // "Hello"（起始，结束）
text.slice(7);            // "World!"（起始到末尾）
text.slice(-6);           // "World!"（负数 = 从末尾计算）

text.substring(0, 5);     // "Hello"（起始，结束）
text.substring(5, 0);     // "Hello"（start > end 时自动交换）
text.substr(7, 5);        // "World"（起始，长度）——已弃用
```

> **注意：** `substring` 将负值视为 `0`，并在 `start > end` 时交换参数。`substr(start, length)` 已弃用；新代码中优先使用 `slice`。

### 7.1.3 修改字符串

```javascript
let text = "  Hello, World!  ";

text.trim();              // "Hello, World!"（移除两端空白）
text.trimStart();         // "Hello, World!  "
text.trimEnd();           // "  Hello, World!"

text.toUpperCase();       // "  HELLO, WORLD!  "
text.toLowerCase();       // "  hello, world!  "

text.replace("World", "JavaScript");   // "  Hello, JavaScript!  "
text.replaceAll("l", "L");             // "  HeLLo, WorLd!  "
```

### 7.1.4 分割与连接

```javascript
let csv = "Alice,25,Engineer";
let parts = csv.split(",");            // ["Alice", "25", "Engineer"]
let limited = csv.split(",", 2);       // ["Alice", "25"]（限制片段数）

let words = "Hello World".split(" ");  // ["Hello", "World"]
let chars = "ABC".split("");           // ["A", "B", "C"]

// 将数组重新拼接为字符串
let joined = ["Hello", "World"].join(" ");  // "Hello World"
```

### 7.1.5 模板字面量

```javascript
let name = "Alice";
let age = 25;

// 反引号字符串支持插值与多行
let message = `Hello, ${name}! You are ${age} years old.`;

let html = `
    <div>
        <h1>${name}</h1>
        <p>Age: ${age}</p>
    </div>
`;
```

### 7.1.6 数字格式化

`Number.prototype.toFixed` 返回保留固定位数小数的字符串。

```javascript
let pi = 3.14159;

pi.toFixed(2);        // "3.14"
pi.toFixed(0);        // "3"
(2.5).toFixed(1);     // "2.5"
```

> **注意：** `toFixed` 会四舍五入，且始终返回**字符串**。如需继续计算，请用 `Number()` 或 `parseFloat()` 转回数字。

## 7.2 数组方法

### 7.2.1 读取与查找

```javascript
let arr = ["Alice", "Bob", "Carol"];

arr.length;                    // 3
arr[0];                        // "Alice"
arr.indexOf("Bob");            // 1
arr.includes("Bob");           // true
arr.find(item => item.startsWith("C"));     // "Carol"
arr.findIndex(item => item === "Bob");      // 1
```

### 7.2.2 添加与删除

```javascript
let arr = [1, 2, 3];

let len1 = arr.push(4);     // 4 — 新长度；arr 变为 [1, 2, 3, 4]
let last = arr.pop();       // 4 — 被移除的元素；arr 变为 [1, 2, 3]
let len2 = arr.unshift(0);  // 4 — 新长度；arr 变为 [0, 1, 2, 3]
let first = arr.shift();    // 0 — 被移除的元素；arr 变为 [1, 2, 3]

arr.splice(1, 1);       // [1, 3] — 删除索引 1 处的 1 个元素
arr.splice(1, 0, "a");  // [1, "a", 3] — 在索引 1 处插入
arr.splice(1, 1, "b");  // [1, "b", 3] — 在索引 1 处替换
```

### 7.2.3 迭代

```javascript
let numbers = [1, 2, 3, 4, 5];

// 高阶回调接收（currentValue, index, array）
numbers.forEach((num, i, arr) => console.log(num, i));

// map — 转换每个元素，返回新数组
let doubled = numbers.map((num, i, arr) => num * 2);    // [2, 4, 6, 8, 10]

// filter — 保留通过测试的元素
let evens = numbers.filter((num, i, arr) => num % 2 === 0);  // [2, 4]

// reduce — 归约为单个值
// 回调签名：(accumulator, currentValue, index, array)
let sum = numbers.reduce((acc, cur, idx, arr) => acc + cur, 0);  // 15

// some — 是否有任意元素通过测试？
let hasEven = numbers.some((num, i, arr) => num % 2 === 0);   // true

// every — 是否所有元素都通过测试？
let allPositive = numbers.every((num, i, arr) => num > 0);    // true
```

> **注意：** `forEach` 不能用 `break` 或 `continue` 中断。需要提前退出时，请使用普通 `for` 循环或 `some`/`find`。

### 7.2.4 其他常用方法

```javascript
let arr = [3, 1, 4, 1, 5];

// 排序比较：< 0 → a 在前；> 0 → b 在前；0 → 保持顺序
arr.sort((a, b) => a - b);     // [1, 1, 3, 4, 5] — 数字排序
arr.reverse();                  // [5, 4, 3, 1, 1]
arr.concat([9, 2]);             // [5, 4, 3, 1, 1, 9, 2]
arr.slice(1, 3);                // [4, 3] — 提取片段
arr.join("-");                  // "5-4-3-1-1"

Array.isArray(arr);             // true
Array.from("ABC");              // ["A", "B", "C"]（类数组/可迭代对象 → 数组）
Array.from({length: 3}, (_, i) => i); // [0, 1, 2]
```

> **重要：** `sort()` 和 `reverse()` 会修改原数组。如需保留原数组，先使用 `slice()`。

```javascript
// 在不修改原数组的情况下创建排序副本
let sorted = [...arr].sort((a, b) => a - b);
```

## 7.3 日期

### 7.3.1 创建日期

```javascript
let now = new Date();                    // 当前日期和时间
let specific = new Date("2024-12-25");   // 从字符串创建
let fromNumbers = new Date(2024, 11, 25, 10, 30, 0);  // 年、月（0-11）、日……
let fromTimestamp = new Date(1703502600000);  // 从毫秒时间戳创建
```

### 7.3.2 读取日期分量

```javascript
let date = new Date();

date.getFullYear();       // 2024
date.getMonth();          // 0-11（0 = 一月）
date.getDate();           // 1-31
date.getDay();            // 0-6（0 = 星期日）
date.getHours();          // 0-23
date.getMinutes();        // 0-59
date.getSeconds();        // 0-59
date.getMilliseconds();   // 0-999
date.getTime();           // 自 1970-01-01 以来的毫秒时间戳
```

### 7.3.3 格式化日期

```javascript
let date = new Date();

// 人类可读格式
date.toDateString();                // "Wed Dec 25 2024"
date.toTimeString();                // "10:30:00 GMT+0800 (...)"
date.toUTCString();                 // "Wed, 25 Dec 2024 02:30:00 GMT"

// 本地化格式
date.toLocaleDateString("en-US");   // "12/25/2024"
date.toLocaleDateString("zh-CN");   // "2024/12/25"
date.toLocaleTimeString("en-US");   // "10:30:00 AM"
date.toLocaleString("zh-CN");       // "2024/12/25 10:30:00"

// ISO 格式
date.toISOString();                 // "2024-12-25T10:30:00.000Z"
```

### 7.3.4 日期计算

```javascript
let date = new Date();

date.setDate(date.getDate() + 7);     // 加 7 天
date.setMonth(date.getMonth() + 1);   // 加 1 个月

date.setHours(date.getHours() + 3);   // 加 3 小时

// 两个日期之间的差值
let d1 = new Date("2024-01-01");
let d2 = new Date("2024-12-31");
let diff = d2 - d1;                   // 毫秒
let days = diff / (1000 * 60 * 60 * 24);  // 转换为天数
```

### 7.3.5 时间戳

获取当前毫秒时间戳的三种常见方式：

```javascript
Date.now();                 // 静态方法（推荐）
new Date().getTime();       // 从 Date 实例获取
+new Date();                // 一元加号将 Date 强制转为数字
```

### 7.3.6 实例片段：倒计时

将秒差转换为天、时、分、秒，并补零。

```javascript
function countdown(targetDate) {
  let diff = Math.max(0, Math.floor((targetDate - Date.now()) / 1000));
  let d = Math.floor(diff / 86400);
  let h = Math.floor((diff / 3600) % 24);
  let m = Math.floor((diff / 60) % 60);
  let s = diff % 60;
  let pad = n => (n < 10 ? "0" + n : n);
  return `${pad(d)}d ${pad(h)}h ${pad(m)}m ${pad(s)}s`;
}

setInterval(() => console.log(countdown(new Date("2025-01-01"))), 1000);
```

- 使用 `Date.now()` 获取当前时间戳。
- 先除以 `1000`，再使用 `/ 86400`、`/ 3600 % 24`、`/ 60 % 60`、`% 60`。
- 用 `"0" + n` 或 `String(n).padStart(2, "0")` 为个位数补零。

## 7.4 正则表达式

正则表达式（regex）定义了用于搜索和操作文本的模式。

### 7.4.1 创建正则表达式

```javascript
let pattern1 = /abc/;           // 字面量语法
let pattern2 = new RegExp("abc"); // 构造函数语法
```

### 7.4.2 常见模式

| 模式 | 匹配内容 |
|---------|---------|
| `.` | 除换行符外的任意单个字符 |
| `\d` | 任意数字（0-9） |
| `\w` | 任意单词字符（a-z、A-Z、0-9、_） |
| `\s` | 任意空白字符 |
| `^` | 字符串开头 |
| `$` | 字符串末尾 |
| `[abc]` | 字符集中的任意字符（a、b 或 c） |
| `[^abc]` | 不在字符集中的任意字符 |
| `a\|b` | a 或 b |
| `a*` | 零个或多个 a |
| `a+` | 一个或多个 a |
| `a?` | 零个或一个 a |
| `a{3}` | 正好 3 个 a |
| `a{2,4}` | 2 到 4 个 a |
| `a{2,}` | 2 个或更多 a |
| `[\u4e00-\u9fa5]` | 任意常用汉字 |

> **转义：** 在正则字面量中，以下字符若表示字面含义，必须用 `\` 转义：`(`、`)`、`[`、`]`、`{`、`}`、`^`、`$`、`*`、`?`、 `\`、`|`、`+`、`.`。在字符类 `[...]` 中，通常只需转义 `\`、`]`、`^`（若在首位）和 `-`（在两个字之间）。

### 7.4.3 正则方法

```javascript
let text = "My email is alice@example.com";
let emailPattern = /\w+@\w+\.\w+/;

// test — 字符串是否匹配？
emailPattern.test(text);        // true

// match — 返回匹配项
let match = text.match(emailPattern);   // ["alice@example.com"]

// matchAll — 返回所有匹配（含捕获组）
let text2 = "Prices: $10, $20, $30";
let matches = [...text2.matchAll(/\$(\d+)/g)];
// [["$10", "10"], ["$20", "20"], ["$30", "30"]]

// exec — 返回包含捕获组的结果数组，global 模式下更新 lastIndex
let numberPattern = /(\d{3})-(\d{4})/g;
let result = numberPattern.exec("Tel: 123-4567, 999-8888");
// result[0] = "123-4567", result[1] = "123", result[2] = "4567"

// RegExp.$1 ~ $9 保存上一次匹配的捕获组（遗留特性，仍受支持）
/^(\d{4})-(\d{2})-(\d{2})$/.test("2024-12-25");
RegExp.$1;   // "2024"
RegExp.$2;   // "12"
RegExp.$3;   // "25"

// replace — 替换匹配项
text.replace(emailPattern, "[hidden]");
// "My email is [hidden]"

// search — 查找首次匹配的索引
text.search(emailPattern);      // 12

// split — 按模式分割
"a,b;c".split(/[,;]/);          // ["a", "b", "c"]
```

### 7.4.4 标志

```javascript
/abc/g    // g = global（查找所有匹配）
/abc/i    // i = 忽略大小写
/abc/m    // m = 多行（^ 和 $ 匹配行边界）
/abc/s    // s = dotall（. 匹配换行符）
/abc/u    // u = Unicode
/abc/y    // y = sticky（仅从 lastIndex 开始匹配）
```

### 7.4.5 常见正则示例

```javascript
// 邮箱（简化版）
/^\w+@\w+\.\w+$/

// 电话号码（例如 123-456-7890）
/^\d{3}-\d{3}-\d{4}$/

// URL
/^https?:\/\/.+/

// 强密码（8 位以上，含大写、小写、数字）
/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}$/
```

### 7.4.6 前瞻与后顾

断言匹配的是一个位置，而非字符。

| 模式 | 名称 | 含义 |
|---------|------|---------|
| `(?=...)` | 正向前瞻 | 后面跟着 `...` |
| `(?!...)` | 负向前瞻 | 后面不跟着 `...` |
| `(?<=...)` | 正向后顾 | 前面是 `...` |
| `(?<!...)` | 负向后顾 | 前面不是 `...` |

```javascript
let price = "$100";
/\d+(?=\s*USD)/.test(price);      // false（后面没有 "USD"）
/(?<=\$)\d+/.exec(price);          // ["100"]（前面有 $）
```

### 7.4.7 贪婪与惰性量词

默认情况下，量词是**贪婪**的（尽可能多地匹配）。加上 `?` 可使其变为**惰性**（尽可能少地匹配）。

```javascript
let html = "<div>one</div><div>two</div>";

html.match(/<div>.*<\/div>/);      // 贪婪 — "<div>one</div><div>two</div>"
html.match(/<div>.*?<\/div>/);     // 惰性 — "<div>one</div>"
```

| 贪婪 | 惰性 |
|--------|------|
| `+` | `+?` |
| `*` | `*?` |
| `?` | `??` |
| `{n,m}` | `{n,m}?` |

### 7.4.8 实例片段

**文本查找与高亮**

将关键词的每次出现都用 `<span>` 包裹。

```javascript
const input = document.querySelector("#search");
const box = document.querySelector("#text");

input.addEventListener("input", () => {
  let keyword = input.value.trim();
  if (!keyword) return;
  let pattern = new RegExp(`(${keyword})`, "gi");
  box.innerHTML = box.textContent.replace(pattern, '<span class="highlight">$1</span>');
});
```

- 当关键词是动态时，使用 `RegExp` 构建模式。
- 在 `replace` 中使用 `$1` 插入捕获的关键词。
- 如果关键词可能包含正则元字符，记得对用户输入进行消毒处理。

**注册表单验证**

在 `blur` 事件上验证用户名、手机号和密码。

```javascript
const rules = {
  username: /^[a-zA-Z0-9_]{4,16}$/,
  phone: /^1[3-9]\d{9}$/,
  password: /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}$/
};

function validate(field) {
  let ok = rules[field.name].test(field.value);
  field.nextElementSibling.style.display = ok ? "none" : "block";
}

document.querySelectorAll("input[data-rule]").forEach(input => {
  input.addEventListener("blur", () => validate(input));
});
```

- 每个字段使用一个正则，使逻辑清晰可读。
- 在输入框旁边显示/隐藏错误提示。

## 7.5 Math

`Math` 是一个内置对象，包含数值常量与工具函数。它不是构造函数。

```javascript
Math.PI;            // 3.141592653589793
Math.E;             // 2.718281828459045

Math.abs(-5);       // 5
Math.ceil(2.1);     // 3
Math.floor(2.9);    // 2
Math.round(2.5);    // 3
Math.trunc(2.9);    // 2（整数部分；优先于 `~~`，后者受 32 位限制）

Math.max(1, 5, 3);          // 5
Math.max(...[1, 5, 3]);     // 5（展开数组）
Math.min(1, 5, 3);          // 1

Math.pow(2, 3);     // 8
Math.sqrt(16);      // 4
Math.cbrt(27);      // 3

Math.random();      // 0 <= x < 1
```

在闭区间 `[min, max]` 内生成随机整数：

```javascript
function randomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}
```

### 7.5.1 实例片段：随机背景色

```javascript
function randomColor() {
  let r = Math.floor(Math.random() * 256);
  let g = Math.floor(Math.random() * 256);
  let b = Math.floor(Math.random() * 256);
  return `rgb(${r}, ${g}, ${b})`;
}

document.body.style.backgroundColor = randomColor();
```

- `Math.random() * 256` 产生 `[0, 256)` 范围内的值。
- `Math.floor` 将其转为 0-255 的整数。

## 7.6 解构赋值

解构赋值将数组中的值或对象中的属性解包到独立的变量中。

```javascript
// 数组解构
let [a, b] = [1, 2];
let [first, , third] = [1, 2, 3];     // 跳过第二个元素
let [head, ...tail] = [1, 2, 3, 4];   // rest 收集剩余元素

// 默认值
let [x = 0, y = 0] = [10];            // x = 10, y = 0

// 对象解构
let { name, age } = { name: "Alice", age: 25 };
let { name: userName } = { name: "Alice" }; // 重命名变量

// 嵌套解构
let user = { profile: { score: 90 } };
let { profile: { score } } = user;    // score = 90

// 带默认值的函数参数解构
function greet({ name = "Guest", age = 0 } = {}) {
  return `Hello, ${name}, age ${age}`;
}
greet({ name: "Bob" });               // "Hello, Bob, age 0"
```

- 数组解构按位置匹配；对象解构按属性名匹配。
- 使用默认值以避免值缺失时出现 `undefined`。
- Rest 模式（`...rest`）将剩余元素收集为真正的数组。

## 7.7 最佳实践

| 推荐 | 避免 |
|----|-------|
| 使用 `slice` 替代 `substr`（已弃用） | 在新代码中使用 `substr` |
| 将 `indexOf` 结果与 `===` 比较（`!== -1`） | 忘记 `indexOf` 未找到时返回 `-1` |
| 如需保留原数组，在 `sort`/`reverse` 前使用展开 `[...arr]` | 无意中修改原数组 |
| 面向用户的日期使用 `toLocaleDateString` | 面向用户的日期使用 `toString()`（格式不固定） |
| 使用 regex101.com 等工具测试正则模式 | 未经测试就编写复杂正则 |
| 使用 `map`/`filter`/`reduce` 进行数据转换 | 数组方法更简洁时仍使用 `for` 循环 |
| 使用 `Math.trunc` 去除小数部分 | 对大数使用 `~~`（会截断为 32 位） |
| 为可选值提供解构默认值 | 假设所有解构的属性都存在 |

**记忆口诀**
- **数组方法** = "Map 转换，Filter 筛选，Reduce 归约"
- **排序比较** = "负数 → a 在前，正数 → b 在前"
- **随机整数** = `floor(random() * (max - min + 1) + min)`
