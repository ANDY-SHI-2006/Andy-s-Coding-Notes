# 1 JS 基础

JavaScript 是一种让网页具备交互能力的编程语言。它在浏览器中运行，可以操作 HTML、处理用户输入、与服务器通信，等等。

## 1.1 引入 JavaScript

### 1.1.1 内部脚本

将 JavaScript 直接放在 `<script>` 标签内。

```html
<script>
    alert("Hello, World!");
</script>
```

> **最佳实践：** 将 `<script>` 标签放在 `<body>` 末尾，以确保 HTML 在脚本运行前完全解析。

### 1.1.2 外部脚本

链接到一个独立的 `.js` 文件。这是生产环境中的首选方式。

```html
<script src="app.js"></script>
```

```javascript
// app.js
console.log("Hello from external file!");
```

| 属性 | 说明 |
|-----------|-------------|
| `src` | JavaScript 文件路径 |
| `defer` | HTML 解析完成后执行（保持顺序） |
| `async` | 下载完成后立即执行（不阻塞，不保证顺序） |
| `type="module"` | 作为 ES 模块处理（启用 `import`/`export`） |

```html
<!-- defer: 后台下载，HTML 就绪后执行 -->
<script src="app.js" defer></script>

<!-- async: 后台下载，就绪后立即执行 -->
<script src="analytics.js" async></script>
```

### 1.1.3 浏览器输入与输出

JavaScript 可以通过内置对话框和直接写入文档与用户交互。这些在快速演示中很有用，但在生产用户界面中应避免使用。

| 方法 | 用途 | 返回值 | 说明 |
|--------|---------|--------------|-------|
| `alert(message)` | 显示模态消息 | `undefined` | 阻塞页面，直到被关闭 |
| `confirm(question)` | 询问是/否问题 | `true` 或 `false` | 阻塞页面，直到被关闭 |
| `prompt(label, default?)` | 请求文本输入 | 一个 **字符串**，取消则返回 `null` | 结果始终是字符串；如需数字，请用 `Number()` 转换 |
| `document.write(html)` | 在解析过程中向文档写入原始 HTML | 写入的字符串 | 文档解析完成后调用会清空页面；优先使用 DOM 方法 |

```javascript
let name = prompt("Enter your name:", "Guest");
if (name !== null) {
    alert("Hello, " + name + "!");
}

let ok = confirm("Continue?");
console.log(ok ? "User agreed" : "User cancelled");
```

> **注意：** `document.write` 在现代代码中几乎从不使用，因为它的行为取决于运行时机，并且可能清除已有内容。

## 1.2 变量与数据类型

### 1.2.1 声明变量

JavaScript 有三种声明变量的方式：

```javascript
var name = "Alice";        // 函数作用域，可重复声明（现代代码中应避免）
let age = 25;              // 块级作用域，可重新赋值
const PI = 3.14159;        // 块级作用域，不可重新赋值
```

| 关键字 | 作用域 | 可重新赋值 | 可重复声明 | 使用场景 |
|---------|-------|-------------|--------------|----------|
| `var` | 函数 | 是 | 是 | 现代代码中 **永远不要** 使用 |
| `let` | 块 | 是 | 否 | 值会改变时 |
| `const` | 块 | 否 | 否 | 值恒定时 |

> **最佳实践：** 默认使用 `const`。只有在需要重新赋值时才使用 `let`。

**为什么 `var` 会泄漏出块：**

因为 `var` 是函数作用域，在 `if` 或 `for` 块内声明的变量在块外仍然可见。`let` 和 `const` 不会泄漏。

```javascript
if (true) {
    var leaked = "I escape the block";
    let trapped = "I stay inside";
}
console.log(leaked);   // "I escape the block"
console.log(trapped);  // ReferenceError: trapped is not defined
```

### 1.2.2 数据类型

JavaScript 有八种数据类型：

**原始类型（按值存储）：**

| 类型 | 说明 | 示例 |
|------|-------------|---------|
| `string` | 文本 | `"Hello"`, `'World'` |
| `number` | 整数或浮点数 | `42`, `3.14`, `NaN`, `Infinity` |
| `boolean` | 真或假 | `true`, `false` |
| `undefined` | 变量已声明但未赋值 | `let x;` |
| `null` | 刻意表示没有值 | `let y = null;` |
| `symbol` | 唯一标识符（ES6+） | `Symbol('desc')` |
| `bigint` | 任意精度整数（ES2020+） | `9007199254740991n` |

**引用类型（按引用存储）：**

| 类型 | 说明 | 示例 |
|------|-------------|---------|
| `object` | 键值对集合 | `{ name: "Alice", age: 25 }` |

使用 `typeof` 检查变量类型：

```javascript
typeof "hello";     // "string"
typeof 42;          // "number"
typeof true;        // "boolean"
typeof undefined;   // "undefined"
typeof null;        // "object"（历史 bug，记住这一点！）
typeof {};          // "object"
typeof [];          // "object"（数组是对象）
typeof function(){} // "function"
```

### 1.2.3 变量命名规则与保留字

标识符（变量、函数和属性名）必须遵循以下规则：

- 允许的字符：字母、数字、`_` 和 `$`
- 不能以数字开头
- 区分大小写（`Name` 和 `name` 不同）
- 不能使用保留字

应避免使用的常见保留字：`break`, `case`, `catch`, `class`, `const`, `continue`, `debugger`, `default`, `delete`, `do`, `else`, `export`, `extends`, `finally`, `for`, `function`, `if`, `import`, `in`, `instanceof`, `let`, `new`, `return`, `super`, `switch`, `this`, `throw`, `try`, `typeof`, `var`, `void`, `while`, `with`, `yield`。

```javascript
let $price = 9.99;      // 有效
let _count = 0;         // 有效
let userName = "Alice"; // 有效（camelCase）
// let 1stPlace = 1;    // SyntaxError
// let class = "Math";  // SyntaxError
```

### 1.2.4 严格模式

在脚本或函数顶部添加 `"use strict";` 可启用更严格的解析和错误处理。它能捕获静默错误并禁用一些不安全特性。

```javascript
"use strict";

x = 10; // ReferenceError: x is not declared
```

严格模式下，上述赋值会抛出引用错误；非严格模式下会创建一个全局变量。现代模块默认处于严格模式，但普通脚本仍可手动启用。

### 1.2.5 数字精度与 BigInt

JavaScript 数字采用 IEEE-754 双精度浮点数。它能安全表示的整数范围是：

```javascript
Number.MAX_SAFE_INTEGER; // 9007199254740991  (2^53 - 1)
Number.MIN_SAFE_INTEGER; // -9007199254740991 (-(2^53 - 1))
```

超出此范围后，整数运算可能产生意外结果：

```javascript
9007199254740991 + 2 === 9007199254740992; // true（精度丢失）
```

浮点数运算也是近似值：

```javascript
0.1 + 0.2;        // 0.30000000000000004
0.1 + 0.2 === 0.3 // false
```

常见的 workaround 是先缩放数字：

```javascript
(0.1 * 10 + 0.2 * 10) / 10; // 0.3
```

对于任意大的整数，使用 `BigInt`：

```javascript
let big = 9007199254740992n;
big + 2n; // 9007199254740994n
```

> **注意：** 不能将 `BigInt` 与普通 `Number` 混合运算。需要时显式转换。

### 1.2.6 null、undefined 与 typeof 细节

`null` 和 `undefined` 都表示“没有值”，但它们在算术中的行为不同：

```javascript
null + 1;      // 1  （null 转换为 0）
null / 1;      // 0
undefined + 1; // NaN
undefined / 1; // NaN
```

`typeof` 可以加括号也可以不加：

```javascript
typeof "hello";    // "string"
typeof("hello");   // "string" — 括号是可选的
```

`typeof` 对可调用值返回 `"function"`，但对数组返回 `"object"`。要可靠地检测数组，请使用 `Array.isArray`：

```javascript
typeof [];                // "object"
Array.isArray([]);        // true
Array.isArray({});        // false
```

### 1.2.7 对象属性名规则

对象键是字符串或 symbol。定义键时：

- 合法标识符可使用点号表示法：`obj.name`
- 包含空格、以数字开头或使用保留字的键必须加引号，并用括号表示法访问

```javascript
let item = {
    name: "Laptop",
    "in stock": true,
    "123": "numeric string key",
    42: "also valid, converted to string"
};

console.log(item.name);        // "Laptop"
console.log(item["in stock"]); // true
console.log(item[42]);         // "also valid, converted to string"
console.log(item["123"]);      // "numeric string key"
```

## 1.3 运算符

### 1.3.1 算术运算符

| 运算符 | 含义 | 示例 |
|----------|---------|---------|
| `+` | 加法 | `5 + 3` → `8` |
| `-` | 减法 | `5 - 3` → `2` |
| `*` | 乘法 | `5 * 3` → `15` |
| `/` | 除法 | `5 / 2` → `2.5` |
| `%` | 取模（余数） | `5 % 2` → `1` |
| `**` | 幂运算 | `2 ** 3` → `8` |

```javascript
let count = 10;
count++;        // 自增 1（后缀）
++count;        // 自增 1（前缀）
count--;        // 自减 1
count += 5;     // 加并赋值（等同于 count = count + 5）
count -= 3;     // 减并赋值
count *= 2;     // 乘并赋值
count /= 4;     // 除并赋值
```

**前缀与后缀 `++` / `--`：**

单独使用时，前缀和后缀行为相同。在表达式中，前缀先改变值再使用；后缀先使用再改变值。

```javascript
let a = 1;
let b = ++a; // a 先变成 2，然后 b = 2
let c = a++; // c = 2，然后 a 变成 3
console.log(a, b, c); // 3, 2, 2
```

### 1.3.2 比较运算符

| 运算符 | 含义 | 示例 |
|----------|---------|---------|
| `==` | 宽松相等（带类型强制转换） | `5 == "5"` → `true` |
| `===` | 严格相等（类型 + 值） | `5 === "5"` → `false` |
| `!=` | 宽松不相等 | `5 != "5"` → `false` |
| `!==` | 严格不相等 | `5 !== "5"` → `true` |
| `>` | 大于 | `5 > 3` → `true` |
| `<` | 小于 | `5 < 3` → `false` |
| `>=` | 大于等于 | `5 >= 5` → `true` |
| `<=` | 小于等于 | `5 <= 3` → `false` |

> **最佳实践：** 始终使用 `===` 和 `!==`，避免意外的类型强制转换。

**字符串比较使用 Unicode 码点：**

```javascript
"a" < "b";  // true  (97 < 98)
"Z" < "a";  // true  （大写排在小写前面）
"10" < "2"; // true  （字符串逐字符比较）
```

**`NaN` 不与任何东西相等，包括它自己：**

```javascript
NaN > 5;   // false
NaN < 5;   // false
NaN === NaN; // false
Number.isNaN(NaN); // true
```

**不要链式比较范围：**

像 `5 < num < 10` 这样的数学写法不起作用。它会按 `(5 < num) < 10` 求值，其中布尔值 `true`/`false` 会变成 `1`/`0`。

```javascript
let num = 20;
5 < num < 10; // (5 < 20) < 10 → true < 10 → 1 < 10 → true（错误！）
```

应使用 `&&`：

```javascript
5 < num && num < 10; // false
```

### 1.3.3 逻辑运算符

| 运算符 | 含义 | 示例 |
|----------|---------|---------|
| `&&` | 与 | `true && false` → `false` |
| `\|\|` | 或 | `true \|\| false` → `true` |
| `!` | 非 | `!true` → `false` |

**短路求值：**

```javascript
// && 返回第一个 falsy 值，否则返回最后一个值
let result = 0 && "hello";      // 0（第一个 falsy）
let result2 = "hi" && "hello";  // "hello"（最后一个 truthy）

// || 返回第一个 truthy 值，否则返回最后一个值
let fallback = "" || "default"; // "default"
let value = "yes" || "no";      // "yes"
```

### 1.3.4 运算符优先级

优先级高的运算符先求值。使用括号让意图更明确。

| 优先级（高 → 低） | 运算符 |
|-------------------------|-----------|
| 分组 | `(...)` |
| 后缀自增/自减 | `++`, `--` |
| 前缀自增/自减、逻辑非 | `++`, `--`, `!` |
| 幂运算 | `**` |
| 乘/除/取模 | `*`, `/`, `%` |
| 加/减 | `+`, `-` |
| 关系/比较 | `<`, `<=`, `>`, `>=` |
| 相等 | `==`, `!=`, `===`, `!==` |
| 逻辑与 | `&&` |
| 逻辑或 | `\|\|` |
| 赋值 | `=`, `+=`, `-=`, 等 |

```javascript
let x = 2 + 3 * 4;      // 14，不是 20
let y = (2 + 3) * 4;    // 20
let z = !true || false;  // false
```

## 1.4 类型转换

### 1.4.1 隐式转换（强制类型转换）

JavaScript 会在某些运算中自动转换类型。

```javascript
"5" + 3;       // "53"（数字转换为字符串）
"5" - 3;       // 2（字符串转换为数字）
"5" * "2";     // 10（两者都转换为数字）
"hello" - 5;   // NaN（"hello" 无法转换为数字）
```

### 1.4.2 显式转换

```javascript
// 转为数字
Number("42");       // 42
Number("hello");    // NaN
parseInt("42px");   // 42
parseFloat("3.14"); // 3.14

// 转为字符串
String(42);         // "42"
(42).toString();    // "42"

// 转为布尔值
Boolean(1);         // true
Boolean(0);         // false
Boolean("");        // false
Boolean("hello");   // true
```

**`Number` 转换规则：**

| 输入 | `Number(input)` |
|-------|-----------------|
| `undefined` | `NaN` |
| `null` | `0` |
| `true` | `1` |
| `false` | `0` |
| `""`（空字符串） | `0` |
| `"42"` | `42` |
| `"42px"` | `NaN` |
| 空白字符串 | `0` |

**`parseInt` 和 `parseFloat` 更宽容：**

它们从左到右读取，遇到第一个非数字字符时停止。如果字符串不是以有效数字开头，则返回 `NaN`。

```javascript
parseInt("42abc");    // 42
parseFloat("3.14px"); // 3.14
parseInt("  56  ");   // 56
parseInt("abc42");    // NaN
parseInt("FF", 16);   // 255（显式指定 radix）
```

> **最佳实践：** 始终向 `parseInt` 传入 radix（通常是 `10`），以避免八进制解析带来的意外。

**`String` 和 `Boolean` 转换规则：**

| 输入 | `String(input)` | `Boolean(input)` |
|-------|-----------------|------------------|
| `undefined` | `"undefined"` | `false` |
| `null` | `"null"` | `false` |
| `0` | `"0"` | `false` |
| `NaN` | `"NaN"` | `false` |
| `""` | `""` | `false` |
| `" "` | `" "` | `true` |
| `"0"` | `"0"` | `true` |
| `[]` | `""` | `true` |
| `{}` | `"[object Object]"` | `true` |

**JavaScript 中的 falsy 值：**
- `false`
- `0`
- `""`（空字符串）
- `null`
- `undefined`
- `NaN`

其他所有值都是 **truthy**。

## 1.5 控制流

### 1.5.1 条件语句

**if / else if / else：**

```javascript
let score = 85;

if (score >= 90) {
    console.log("Grade A");
} else if (score >= 80) {
    console.log("Grade B");
} else if (score >= 60) {
    console.log("Grade C");
} else {
    console.log("Grade F");
}
```

**三元运算符（简单 if/else 的简写）：**

```javascript
let age = 18;
let status = age >= 18 ? "Adult" : "Minor";
```

**switch 语句：**

```javascript
let day = 3;

switch (day) {
    case 1:
        console.log("Monday");
        break;
    case 2:
        console.log("Tuesday");
        break;
    case 3:
        console.log("Wednesday");
        break;
    case 4:
        console.log("Thursday");
        break;
    case 5:
        console.log("Friday");
        break;
    default:
        console.log("Weekend");
}
```

> **注意：** 每个 case 后都要加 `break`。没有它会“穿透”到下一个 case。

### 1.5.2 循环

**while 循环：**

```javascript
let i = 0;
while (i < 5) {
    console.log(i);  // 0, 1, 2, 3, 4
    i++;
}
```

**do...while 循环：**

```javascript
let i = 0;
do {
    console.log(i);  // 至少执行一次
    i++;
} while (i < 5);
```

**for 循环：**

```javascript
for (let i = 0; i < 5; i++) {
    console.log(i);  // 0, 1, 2, 3, 4
}
```

**循环控制：**

```javascript
for (let i = 0; i < 10; i++) {
    if (i === 3) continue;   // 跳过本次迭代
    if (i === 7) break;      // 完全退出循环
    console.log(i);          // 0, 1, 2, 4, 5, 6
}
```

| 语句 | 效果 |
|-----------|--------|
| `break` | 立即退出循环 |
| `continue` | 跳到下一次迭代 |

**`for...in` 遍历对象键：**

使用 `for...in` 遍历对象的可枚举属性名。不要用它遍历数组（应使用 `for...of` 或 `forEach`）。

```javascript
let person = { name: "Alice", age: 25 };

for (let key in person) {
    console.log(key, person[key]);
    // name Alice
    // age 25
}
```

> **提示：** 遍历可能包含继承属性的对象时，使用 `Object.hasOwn(person, key)` 或直接 `if (person.hasOwnProperty(key))` 检查。

## 1.6 对象（基础）

对象用于存储键值对集合。

```javascript
let person = {
    name: "Alice",
    age: 25,
    isStudent: false,
    greet: function() {
        return "Hello, " + this.name;
    }
};

// 访问属性
console.log(person.name);       // "Alice"（点号表示法）
console.log(person["age"]);     // 25（括号表示法）

// 修改属性
person.age = 26;
person["isStudent"] = true;

// 添加新属性
person.email = "alice@example.com";

// 删除属性
delete person.isStudent;

// 查看键和值
console.log(Object.keys(person));   // ["name", "age", "email"]
console.log(Object.values(person)); // ["Alice", 26, "alice@example.com"]
console.log(Object.entries(person)); // [["name","Alice"], ["age",26], ...]
```

## 1.7 最佳实践

| 推荐 | 不推荐 |
|----|-------|
| 默认使用 `const`，需要时再用 `let` | 在现代代码中使用 `var` |
| 比较时使用 `===` 和 `!==` | 使用 `==` 和 `!=`（类型强制转换不可预测） |
| 在作用域顶部声明变量 | 在块中间声明变量 |
| 变量名使用 `camelCase` | 普通变量使用 snake_case 或 PascalCase |
| 使用有意义的名称（`userCount`，而非 `uc`） | 除非在循环中，否则使用单字母名称 |

## 1.8 `debugger` 语句

`debugger` 语句创建一个断点。开发者工具打开时，执行会在该行暂停，以便检查变量并逐步执行代码。

```javascript
function sum(a, b) {
    let result = a + b;
    debugger; // 如果开发者工具打开，会在此暂停
    return result;
}

sum(2, 3);
```

常用调试控制：

| 控制 | 快捷键（大多数浏览器） | 效果 |
|---------|--------------------------|--------|
| 继续 / 播放 | F8 | 继续运行直到下一个断点 |
| 单步跳过 | F10 | 执行当前行，然后暂停 |
| 单步进入 | F11 | 进入当前行的函数调用 |
| 单步退出 | Shift + F11 | 完成当前函数并暂停 |

> **提示：** 提交代码前移除 `debugger` 语句。Linter 或 pre-commit 钩子可以自动标记它们。

**记忆口诀**
- **变量** = "默认 const，可变用 let，永远不用 var"
- **作用域** = "let/const 待在块内；var 会泄漏出去"
- **比较** = "三等号求真相，双等号出 bug"
- **范围** = "用 `&&`，不要链式 `<`"
- **转换** = "parseInt 从左往右读；Number 需要干净字符串"
- **对象** = "干净键用点号，其余用括号"
