# 6 类、原型与存储

JavaScript 对象、构造函数、ES6 类以及客户端存储机制。

## 6.1 面向对象的 JavaScript

面向对象编程（OOP，Object-Oriented Programming）将代码组织成自包含的 **对象**，把数据和行为打包在一起。主要设计目标包括 **模块化**（将程序拆分为聚焦的部件）、**可复用性**（从一个蓝图创建多个实例）、**可维护性**（将相关代码集中在一起）、**灵活性**（通过继承替换实现）、**可扩展性**（无需重写现有代码即可添加功能）以及 **可读性**（直接建模现实世界概念）。

### 6.1.1 构造函数

在 ES6 之前，构造函数是创建对象“类型”的主要方式。

```javascript
function Person(name, age) {
    this.name = name;
    this.age = age;
}

Person.prototype.greet = function() {
    return "Hello, I'm " + this.name;
};

let alice = new Person("Alice", 25);
console.log(alice.greet());   // "Hello, I'm Alice"
```

### 6.1.2 ES6 类

更现代的语法，对其他语言开发者来说更清晰、更熟悉。

```javascript
class Person {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }

    greet() {
        return `Hello, I'm ${this.name}`;
    }

    haveBirthday() {
        this.age++;
    }
}

let bob = new Person("Bob", 30);
bob.haveBirthday();
console.log(bob.age);   // 31
```

### 6.1.3 继承

```javascript
class Employee extends Person {
    constructor(name, age, jobTitle) {
        super(name, age);           // 调用父类构造函数
        this.jobTitle = jobTitle;
    }

    greet() {
        let parentGreeting = super.greet();
        return `${parentGreeting} and I work as a ${this.jobTitle}`;
    }
}

let carol = new Employee("Carol", 28, "Developer");
console.log(carol.greet());
```

### 6.1.4 私有字段与方法（ES2022）

私有成员使用 `#` 前缀，无法从类外部访问。

```javascript
class BankAccount {
    #balance = 0;            // 私有字段

    #validate(amount) {      // 私有方法
        return amount > 0;
    }

    deposit(amount) {
        if (this.#validate(amount)) {
            this.#balance += amount;
        }
    }

    getBalance() {
        return this.#balance;
    }
}

let account = new BankAccount();
account.deposit(100);
console.log(account.getBalance());  // 100
// console.log(account.#balance);   // SyntaxError: private field
// account.#validate(10);           // SyntaxError: private method
```

### 6.1.5 静态方法与属性

属于类本身而非实例的方法与属性。

```javascript
class MathUtils {
    static add(a, b) {
        return a + b;
    }

    static PI = 3.14159;
}

console.log(MathUtils.add(2, 3));   // 5
console.log(MathUtils.PI);          // 3.14159
```

### 6.1.6 new 的五步操作

调用 `new Constructor(...)` 时，JavaScript 会执行以下步骤：

1. 创建一个空对象 `{}`。
2. 将该对象的内部原型链接到 `Constructor.prototype`。
3. 在构造函数内部把 `this` 绑定到这个新对象。
4. 执行构造函数体。
5. 返回这个新对象（除非构造函数显式返回一个非基本类型值）。

```javascript
function Person(name) {
    this.name = name;
}
Person.prototype.greet = function () {
    return `Hello, I'm ${this.name}`;
};

let alice = new Person("Alice");
console.log(alice.__proto__ === Person.prototype); // true
console.log(alice.greet());                        // "Hello, I'm Alice"
```

> **注意：** `__proto__` 是内部原型的遗留访问器。在生产代码中请优先使用 `Object.getPrototypeOf(obj)`。

### 6.1.7 ES5 构造函数模式与 ES6 类的对比

ES6 类本质上只是 ES5 构造函数的语法糖，二者都依赖 `prototype` 实现方法共享。

| 特性 | ES5 构造函数 | ES6 类 |
|---------|-----------------|-----------|
| 定义 | `function Person(name) { this.name = name; }` | `class Person { constructor(name) { this.name = name; } }` |
| 共享方法 | `Person.prototype.greet = function(){}` | `class` 体内的 `greet() {}` |
| 继承 | `Object.create(Parent.prototype)` + 手动 `Parent.call(this)` | `class Child extends Parent` + `super()` |
| 可读性 | 冗长，需要显式操作 prototype | 更简洁、更熟悉的语法 |

```javascript
// ES5
function PersonES5(name) {
    this.name = name;
}
PersonES5.prototype.greet = function () {
    return `Hello, I'm ${this.name}`;
};

// ES6
class PersonES6 {
    constructor(name) {
        this.name = name;
    }
    greet() {
        return `Hello, I'm ${this.name}`;
    }
}
```

### 6.1.8 构造函数的返回行为

默认情况下，构造函数返回 `this`（新实例）。

- 返回 **基本类型**（`string`、`number`、`boolean`、`null`、`undefined`、`symbol`、`bigint`）会被忽略，仍然返回 `this`。
- 返回 **对象**（包括数组、函数、日期等）会覆盖默认值，改为返回该对象。

```javascript
function Foo() {
    this.value = 1;
    return 2;              // 基本类型：被忽略
}
let f1 = new Foo();
console.log(f1.value);     // 1

function Bar() {
    this.value = 1;
    return { value: 9 };   // 对象：覆盖默认返回值
}
let f2 = new Bar();
console.log(f2.value);     // 9
```

### 6.1.9 重写方法与属性

当子类定义了与父类同名的方法或属性时，使用子类的版本。可用 `super.method()` 调用父类的实现。

```javascript
class Animal {
    speak() { return "some sound"; }
    legs = 4;
}

class Dog extends Animal {
    legs = 4;   // 公共字段，此处值相同，但子类字段会遮蔽父类字段
    speak() {
        return super.speak() + " → woof";
    }
}

let dog = new Dog();
console.log(dog.speak()); // "some sound → woof"
```

> **经验法则：** 名称冲突时子类成员优先；`super` 让你复用父类行为。

## 6.2 原型链

每个 JavaScript 对象都有一个指向另一个对象的内部链接，称为其 **原型**。当访问对象上不存在的属性时，JavaScript 会沿原型链查找。

```javascript
let animal = {
    eats: true,
    walk() {
        console.log("Animal walks");
    }
};

let rabbit = {
    jumps: true,
    __proto__: animal    // 设置原型（生产环境不推荐）
};

rabbit.walk();   // Found on prototype: "Animal walks"
rabbit.eats;     // Found on prototype: true
```

> **现代方式：** 使用 `Object.create()` 创建具有特定原型的对象。

```javascript
let rabbit = Object.create(animal);
rabbit.jumps = true;
```

### 6.2.1 `__proto__` 与 `prototype` 的区别

- `prototype` 是 **构造函数 / 类** 上的属性。它将成为未来实例的原型。
- `__proto__` 是 **实例** 的内部原型。它指向该对象的原型。

```javascript
class Person {}
let p = new Person();

console.log(p.__proto__ === Person.prototype);        // true
console.log(Person.prototype.__proto__ === Object.prototype); // true
console.log(Object.prototype.__proto__);              // null
```

原型链为：`instance → Class.prototype → Object.prototype → null`。如果到链尾仍未找到属性，结果为 `undefined`。

### 6.2.2 对象比较与合并

`Object.is(a, b)` 的行为类似 `===`，但会把 `NaN` 视为等于 `NaN`，并区分 `+0` 与 `-0`。

`Object.assign(target, ...sources)` 执行 **浅合并**：将源对象的自身可枚举属性复制到目标对象。后出现的源对象会覆盖前面源对象的同名键。

```javascript
console.log(Object.is(NaN, NaN)); // true
console.log(Object.is(+0, -0));   // false

let defaults = { theme: "light", lang: "en", prefs: { font: 14 } };
let user = { lang: "zh" };
let settings = Object.assign({}, defaults, user);

console.log(settings); // { theme: "light", lang: "zh", prefs: { font: 14 } }

// 浅合并：嵌套对象按引用复制
settings.prefs.font = 16;
console.log(defaults.prefs.font); // 16
```

## 6.3 this 关键字

`this` 的值取决于函数的调用方式。

```javascript
let user = {
    name: "Alice",
    greet() {
        console.log(this.name);   // "Alice" — this 指向 user
    }
};

user.greet();

// 箭头函数从外层作用域继承 this
let team = {
    name: "Developers",
    members: ["Alice", "Bob"],
    showMembers() {
        this.members.forEach(member => {
            console.log(this.name + ": " + member);   // 正确运行
        });
    }
};
```

| 上下文 | `this` 指向 |
|---------|-----------------|
| 全局作用域 | `window`（浏览器）或 `global`（Node.js） |
| 对象方法 | 该对象 |
| 构造函数 | 新实例 |
| 事件处理函数 | 触发事件的元素 |
| 箭头函数 | 从外层作用域继承 |

## 6.4 客户端存储

### 6.4.1 localStorage

持久化存储数据（浏览器重启后仍然保留）。容量：约 5-10 MB。

```javascript
// 存储数据
localStorage.setItem("username", "Alice");
localStorage.setItem("theme", "dark");

// 读取数据
let username = localStorage.getItem("username");   // "Alice"
let theme = localStorage.getItem("theme");         // "dark"

// 删除数据
localStorage.removeItem("theme");

// 清空所有数据
localStorage.clear();

// 存储对象（必须先序列化）
let user = { name: "Alice", age: 25 };
localStorage.setItem("user", JSON.stringify(user));

// 读取对象
let storedUser = JSON.parse(localStorage.getItem("user"));
```

### 6.4.2 sessionStorage

与 `localStorage` API 相同，但数据会在页面会话结束时清除（关闭标签页）。

```javascript
sessionStorage.setItem("tempData", "123");
let data = sessionStorage.getItem("tempData");
```

### 6.4.3 存储方式对比

| 特性 | `localStorage` | `sessionStorage` | Cookies |
|---------|---------------|------------------|---------|
| 生命周期 | 手动清除前一直保留 | 标签页关闭前 | 可配置（expires） |
| 容量 | 约 5-10 MB | 约 5-10 MB | 约 4 KB |
| 是否随请求发送给服务器 | 否 | 否 | 是（每个请求都会带） |
| 能否通过 JS 访问 | 能 | 能 | 能 |

### 6.4.4 Cookies

Cookie 是浏览器存储的小段字符串，会随每个发往匹配域的 HTTP 请求一起发送。使用 `document.cookie` 读写。

**读取** 会返回所有可见 cookie，以分号分隔：

```javascript
console.log(document.cookie);
// "username=Alice; session=abc123"
```

**写入** 需要赋值一个特殊格式的字符串：

```javascript
let date = new Date();
date.setDate(date.getDate() + 7);   // 7 天后

document.cookie = `username=Alice; expires=${date.toUTCString()}; path=/`;
```

**Cookie 属性：**

| 属性 | 说明 |
|-----------|-------------|
| `expires` | 过期日期，UTC 字符串。若同时存在 `max-age` 则忽略。 |
| `max-age` | 有效期，单位为 **秒**。优先级高于 `expires`。 |
| `path` | cookie 能被发送到的 URL 路径。`/` 表示全站可用。 |
| `domain` | 哪些主机可以接收该 cookie。默认为当前主机。 |
| `secure` | 仅通过 HTTPS 发送。 |
| `HttpOnly` | 无法通过 JavaScript 读取；由服务器设置。 |

对非 ASCII 值（如中文）使用 `encodeURIComponent` 编码，并用 `decodeURIComponent` 解码：

```javascript
let name = "用户名";
document.cookie = `name=${encodeURIComponent(name)}; path=/; max-age=86400`;

function getCookie(key) {
    let match = document.cookie.match(new RegExp("(?:^|; )" + key + "=([^;]*)"));
    return match ? decodeURIComponent(match[1]) : null;
}

console.log(getCookie("name")); // "用户名"
```

### 6.4.5 实用片段：Cookie 工具函数

一个用于设置、获取和删除 cookie 的小助手：

```javascript
const CookieUtil = {
    set(name, value, days = 7, path = "/") {
        let expires = "";
        if (days) {
            let date = new Date();
            date.setTime(date.getTime() + days * 24 * 60 * 60 * 1000);
            expires = `; expires=${date.toUTCString()}`;
        }
        document.cookie = `${name}=${encodeURIComponent(value)}${expires}; path=${path}`;
    },
    get(name) {
        let match = document.cookie.match(new RegExp("(?:^|; )" + name + "=([^;]*)"));
        return match ? decodeURIComponent(match[1]) : null;
    },
    remove(name) {
        this.set(name, "", -1);
    }
};
```

- 写入前用 `encodeURIComponent` 编码值。
- 只需要相对有效期时，使用 `max-age`（秒）代替 `expires`。
- 删除 cookie 意味着将其过期时间设为过去。

### 6.4.6 实用片段：记住用户名

结合 `localStorage` 与 JSON 记住上次登录的用户名：

```javascript
let form = document.querySelector("#login-form");
let usernameInput = document.querySelector("#username");
let rememberBox = document.querySelector("#remember");

let saved = localStorage.getItem("rememberedUser");
if (saved) {
    usernameInput.value = JSON.parse(saved);
    rememberBox.checked = true;
}

form.addEventListener("submit", () => {
    if (rememberBox.checked) {
        localStorage.setItem("rememberedUser", JSON.stringify(usernameInput.value));
    } else {
        localStorage.removeItem("rememberedUser");
    }
});
```

- 存储前始终 `JSON.stringify`，读取后 `JSON.parse`。
- 敏感数据优先使用仅会话存储或服务器端会话。

## 6.5 JSON

JSON（JavaScript Object Notation）是数据交换的标准格式。

```javascript
let user = {
    name: "Alice",
    age: 25,
    hobbies: ["reading", "coding"]
};

// Object → JSON string
let jsonString = JSON.stringify(user);
// '{"name":"Alice","age":25,"hobbies":["reading","coding"]}'

// JSON string → Object
let parsed = JSON.parse(jsonString);
console.log(parsed.name);   // "Alice"
```

| 方法 | 说明 |
|--------|-------------|
| `JSON.stringify(obj)` | 将对象转换为 JSON 字符串 |
| `JSON.parse(string)` | 将 JSON 字符串转换为对象 |

## 6.6 最佳实践

| 应该 | 不应该 |
|----|-------|
| 面向对象代码使用 ES6 `class` 语法 | 在新代码中使用原始构造函数 |
| 真正私有数据使用 `#privateField` | 用下划线前缀（`_private`）并寄希望于没人碰它 |
| 用户偏好使用 `localStorage` | 敏感数据使用 `localStorage`（它未加密） |
| 存储对象前始终 `JSON.stringify` | 直接将对象引用存入存储 |
| 在子类构造函数访问 `this` 前先调用 `super()` | 在调用 `super()` 前访问 `this` |
| 非 ASCII cookie 值使用 `encodeURIComponent` | 在 cookie 中存放原始中文或特殊字符 |
| 简单 cookie 有效期优先使用 `max-age`（秒） | 相对时长已足够时仍依赖 `expires` |

**记忆口诀**
- **OOP** = "对象把状态和行为打包；原型把实例连接起来"
- **new** = "空对象 → 链接原型 → 绑定 this → 运行构造函数 → 返回对象"
- **Prototype chain** = "instance → Class.prototype → Object.prototype → null"
- **Object tools** = "Object.is 修正 NaN；Object.assign 执行浅合并"
- **Storage** = "local 持久，session 随会话过期，cookie 随请求发送"
