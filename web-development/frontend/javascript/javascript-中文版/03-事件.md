# 3 事件

事件（event）是在浏览器中发生的动作——用户点击按钮、在输入框中打字或调整窗口大小。JavaScript 可以监听这些事件并作出响应。

## 3.1 添加事件监听器

### 3.1.1 addEventListener

处理事件的现代推荐方式。

```javascript
let button = document.getElementById("myButton");

button.addEventListener("click", function() {
    console.log("Button clicked!");
});

// 使用箭头函数
button.addEventListener("click", () => {
    console.log("Button clicked!");
});

// 使用命名函数（便于移除）
function handleClick() {
    console.log("Clicked!");
}

button.addEventListener("click", handleClick);
button.removeEventListener("click", handleClick);
```

| 参数 / 选项 | 说明 |
|-------------|------|
| `type` | 事件名称：`"click"`、`"mouseover"`、`"keydown"` 等 |
| `listener` | 事件触发时执行的函数 |
| `useCapture` | `true` = 捕获阶段，`false` = 冒泡阶段（默认） |
| `options` | 选项对象，例如 `{ once: true }` 或 `{ passive: true }` |

```javascript
// 只执行一次并自动移除
button.addEventListener("click", () => {
    console.log("Only once");
}, { once: true });

// 告诉浏览器该监听器不会调用 preventDefault()
// 对于 wheel/touch 事件，现代浏览器通常默认 passive
window.addEventListener("wheel", handleWheel, { passive: true });
```

> **移除监听器：** `removeEventListener(type, listener)` 需要与 `addEventListener` 使用的**同一个函数引用**。匿名内联函数无法被移除。

### 3.1.2 内联事件处理程序（避免使用）

```html
<!-- 不推荐 -->
<button onclick="alert('Clicked!')">Click</button>
```

> **避免原因：** 混合了 HTML 与 JavaScript，难以维护，且每个事件只能绑定一个处理程序。

### 3.1.3 三种事件绑定方式

| 方式 | 语法 | 能否叠加 | 移除方式 |
|------|------|---------|---------|
| 内联 HTML | `<button onclick="fn()">` | 不能（一个属性） | 移除属性 |
| DOM0 | `element.onclick = fn` | 不能（后赋值覆盖前者） | `element.onclick = null` |
| DOM2 | `element.addEventListener("click", fn)` | 能（同一事件可多个监听器） | `removeEventListener` 并传入相同引用 |

```javascript
let btn = document.getElementById("btn");

// DOM0：简单，但一次只能有一个处理程序
btn.onclick = function () {
    console.log("DOM0 first");
};

btn.onclick = function () {
    console.log("DOM0 second — overwrites the first");
};

// DOM2：两个处理程序都会执行
btn.addEventListener("click", () => console.log("DOM2 first"));
btn.addEventListener("click", () => console.log("DOM2 second"));
```

> 生产代码中优先使用 DOM2（`addEventListener`）；DOM0 仅作为兼容性简写保留。

### 3.1.4 移除事件处理程序

```javascript
let btn = document.getElementById("btn");

// DOM0 解绑
btn.onclick = null;

// DOM2 解绑 —— 需要相同引用和相同捕获选项
function handler() {
    console.log("hi");
}
btn.addEventListener("click", handler);
btn.removeEventListener("click", handler);
```

> 如果你用 `{ capture: true }` 添加了监听器，移除时也要使用相同选项。匿名箭头函数无法被移除。

## 3.2 常见事件类型

### 3.2.1 鼠标事件

| 事件 | 触发时机 |
|------|----------|
| `click` | 在元素上按下并释放鼠标按钮 |
| `dblclick` | 双击 |
| `mousedown` | 鼠标按钮被按下 |
| `mouseup` | 鼠标按钮被释放 |
| `mousemove` | 鼠标在元素上移动 |
| `mouseenter` | 鼠标进入元素（不冒泡） |
| `mouseleave` | 鼠标离开元素（不冒泡） |
| `mouseover` | 鼠标进入元素或其子元素（冒泡） |
| `mouseout` | 鼠标离开元素或其子元素（冒泡） |
| `contextmenu` | 右键点击（上下文菜单） |

```javascript
element.addEventListener("mouseenter", () => {
    element.style.backgroundColor = "yellow";
});

element.addEventListener("mouseleave", () => {
    element.style.backgroundColor = "transparent";
});
```

> **提示：** 当只需要响应当前元素本身时，优先使用 `mouseenter` / `mouseleave`。`mouseover` / `mouseout` 会冒泡，因此鼠标在元素与其子元素之间移动时会再次触发。

### 3.2.2 键盘事件

| 事件 | 触发时机 |
|------|----------|
| `keydown` | 按键被按下 |
| `keyup` | 按键被释放 |
| `keypress` | 按键被按下（已废弃，请使用 `keydown`） |

```javascript
document.addEventListener("keydown", (event) => {
    console.log(event.key);        // "Enter"、"Escape"、"a" 等
    console.log(event.code);       // "KeyA"、"Enter" 等（物理按键）
    console.log(event.ctrlKey);    // 按住 Ctrl 时为 true
    console.log(event.shiftKey);   // 按住 Shift 时为 true
});
```

### 3.2.3 表单事件

| 事件 | 触发时机 |
|------|----------|
| `submit` | 表单提交 |
| `reset` | 表单重置（绑定到 `<form>`） |
| `change` | 值改变且元素失去焦点 |
| `input` | 值立即改变 |
| `select` | input/textarea 中的文本被选中 |
| `focus` | 元素获得焦点 |
| `blur` | 元素失去焦点 |

```javascript
let input = document.getElementById("username");

input.addEventListener("input", (e) => {
    console.log(e.target.value);   // 当前输入值
});
```

### 3.2.4 窗口 / 文档事件

| 事件 | 触发时机 |
|------|----------|
| `load` | 页面及所有资源完全加载 |
| `DOMContentLoaded` | HTML 解析完成，DOM 已就绪（图片可能仍在加载） |
| `resize` | 窗口大小改变 |
| `scroll` | 页面或元素滚动 |

```javascript
document.addEventListener("DOMContentLoaded", () => {
    console.log("DOM is ready!");
});

window.addEventListener("resize", () => {
    console.log(window.innerWidth, window.innerHeight);
});
```

## 3.3 事件对象

当事件触发时，浏览器会把一个**事件对象**传给处理函数，其中包含该事件的详细信息。

```javascript
button.addEventListener("click", (event) => {
    console.log(event.type);       // "click"
    console.log(event.target);     // 被点击的元素
    console.log(event.currentTarget); // 绑定监听器的元素
    console.log(event.clientX);    // 鼠标相对于视口的 X 坐标
    console.log(event.clientY);    // 鼠标相对于视口的 Y 坐标
});
```

| 属性 | 说明 |
|------|------|
| `event.type` | 事件名称 |
| `event.target` | 触发事件的元素 |
| `event.currentTarget` | 监听器所绑定的元素 |
| `event.preventDefault()` | 阻止浏览器默认行为 |
| `event.stopPropagation()` | 阻止事件继续冒泡 |

### 3.3.1 阻止默认行为

```javascript
let link = document.getElementById("externalLink");

link.addEventListener("click", (event) => {
    event.preventDefault();        // 不跳转到 URL
    console.log("Link clicked, but navigation prevented.");
});
```

### 3.3.2 鼠标位置属性

对于鼠标事件，事件对象包含四组坐标：

| 属性 | 参照点 |
|------|--------|
| `clientX` / `clientY` | 可视视口左上角 |
| `pageX` / `pageY` | 完整文档左上角，包含滚动区域 |
| `offsetX` / `offsetY` | 目标元素 padding 边距左上角 |
| `screenX` / `screenY` | 物理屏幕左上角 |

```javascript
box.addEventListener("mousemove", (e) => {
    console.log("Viewport:", e.clientX, e.clientY);
    console.log("Document:", e.pageX, e.pageY);
    console.log("Inside element:", e.offsetX, e.offsetY);
});
```

### 3.3.3 `currentTarget` 与 `this`

在普通（非箭头）事件处理函数中，`this` 就是绑定了监听器的元素——与 `event.currentTarget` 相同。

```javascript
button.addEventListener("click", function (e) {
    console.log(this === e.currentTarget); // true
    console.log(this === e.target);        // 如果点击的是子元素则为 false
});
```

箭头函数**没有**自己的 `this`，它会继承外层作用域的 `this`，因此应改用 `e.currentTarget`：

```javascript
button.addEventListener("click", (e) => {
    console.log(e.currentTarget); // 绑定监听器的元素
    console.log(this);            // 可能是 window，而不是按钮
});
```

> 不要依赖旧代码中使用的全局 `event` 变量。始终将事件对象作为处理函数的第一个参数接收。

### 3.3.4 显式绑定 `this`：`call`、`apply`、`bind`

这些方法允许你控制函数运行时的 `this` 指向。在把对象方法作为回调传递时（例如传给定时器或事件监听器）非常有用。

```javascript
let user = {
    name: "Andy",
    greet() {
        console.log("Hello, " + this.name);
    }
};

// call：立即调用，参数逐个传入
user.greet.call({ name: "Bob" }); // Hello, Bob

// apply：立即调用，参数以数组传入
user.greet.apply({ name: "Bob" });

// bind：返回一个永久绑定 this 的新函数
let bound = user.greet.bind({ name: "Bob" });
setInterval(bound, 1000);
```

> `bind` 特别有用：当某个方法需要在延迟回调（如 `setInterval` 或 `addEventListener`）中保持其 `this` 时。

## 3.4 事件传播

当事件触发时，它会在 DOM 中经历三个阶段：

1. **捕获阶段：** 事件从 `window` 向下经过祖先节点到达目标元素的父节点。
2. **目标阶段：** 事件到达目标元素本身。
3. **冒泡阶段：** 事件从目标元素向上返回到 `window`。

```
Capture:  window → document → html → body → div → button
Target:   button
Bubble:   button → div → body → html → document → window
```

默认情况下，事件监听器在**冒泡**阶段触发。使用 `true`（或 `{ capture: true }`）可在捕获阶段监听。

```javascript
// 在捕获阶段触发
element.addEventListener("click", handler, true);

// 或使用选项对象
element.addEventListener("click", handler, { capture: true });
```

目标元素上的监听器按注册顺序执行。祖先的捕获监听器在目标之前执行，祖先的冒泡监听器在目标之后执行。

```javascript
outer.addEventListener("click", () => console.log("outer capture"), true);
outer.addEventListener("click", () => console.log("outer bubble"), false);
inner.addEventListener("click", () => console.log("inner"));

// 点击 inner 输出：
// outer capture → inner → outer bubble
```

### 3.4.1 停止传播

```javascript
child.addEventListener("click", (event) => {
    event.stopPropagation();   // 事件不会到达父元素
    console.log("Child clicked");
});

parent.addEventListener("click", () => {
    console.log("Parent clicked");  // 点击 child 时不会触发
});
```

## 3.5 事件委托

与其给每个子元素都绑定监听器，不如给父元素绑定**一个**监听器，再用 `event.target` 判断实际被点击的是哪个子元素。

```html
<ul id="list">
    <li>Item 1</li>
    <li>Item 2</li>
    <li>Item 3</li>
</ul>
```

```javascript
// 不使用委托（绑定 3 个监听器）
document.querySelectorAll("#list li").forEach(item => {
    item.addEventListener("click", () => console.log("Clicked!"));
});

// 使用委托（绑定 1 个监听器）
document.getElementById("list").addEventListener("click", (event) => {
    if (event.target.tagName === "LI") {
        console.log("Clicked:", event.target.textContent);
    }
});
```

**事件委托的好处：**
- 更少的事件监听器（性能更好）
- 对动态添加的元素也有效
- 更易于维护

## 3.6 最佳实践

| 推荐 | 不推荐 |
|------|--------|
| 所有事件处理都使用 `addEventListener` | 使用内联 `onclick` 属性 |
| 对列表和表格使用事件委托 | 给几十个 item 分别绑定监听器 |
| 使用 `event.target` 判断实际被点击的元素 | 认为 `event.currentTarget` 总是实际被点击的元素 |
| 需要阻止浏览器行为时才调用 `preventDefault()` | 不必要地调用 `preventDefault()` |
| 组件销毁时移除监听器 | 留下孤立监听器造成内存泄漏 |

## 3.7 小型案例片段

### 3.7.1 选项卡切换（互斥模式）

先清除所有激活状态，再只激活被点击的选项卡及其对应面板。

```javascript
const tabs = document.querySelectorAll(".tab");
const panes = document.querySelectorAll(".pane");

tabs.forEach((tab, index) => {
    tab.addEventListener("click", () => {
        tabs.forEach(t => t.classList.remove("active"));
        panes.forEach(p => p.classList.remove("active"));
        tab.classList.add("active");
        panes[index].classList.add("active");
    });
});
```

- “互斥”思路：重置所有，再标记当前项。
- 用选项卡的索引来选取对应的内容面板。

### 3.7.2 倒计时“发送验证码”按钮

倒计时期间禁用按钮，结束后重新启用。

```javascript
const btn = document.getElementById("sendCode");
let seconds = 60;
btn.disabled = true;
btn.textContent = `${seconds}s`;

const timer = setInterval(() => {
    seconds--;
    btn.textContent = `${seconds}s`;
    if (seconds <= 0) {
        clearInterval(timer);
        btn.disabled = false;
        btn.textContent = "Send Code";
    }
}, 1000);
```

- 始终保存定时器 ID，以便结束时调用 `clearInterval`。
- 设置 `disabled` 防止重复点击，并提供视觉反馈。

**记忆口诀**
- **事件** = “Listen on parent, check target, delegate for scale” → 监听父元素，检查目标，委托实现规模扩展
- **绑定** = “DOM2 stacks, DOM0 overwrites, same reference to remove” → DOM2 可叠加，DOM0 会覆盖，移除需同引用
- **流程** = “Capture down, bubble up, currentTarget shows the owner” → 捕获向下，冒泡向上，currentTarget 显示拥有者
