# 5 浏览器对象模型（BOM）

BOM 提供与浏览器窗口本身交互的对象，而不仅仅是页面内容。它包括 `window`、`navigator`、`location`、`history` 和 `screen` 对象。

## 5.1 window 对象

`window` 是浏览器中的全局对象。所有全局变量和函数都是 `window` 的属性。

```javascript
window.innerWidth;       // 视口宽度，单位为像素
window.innerHeight;      // 视口高度，单位为像素
window.outerWidth;       // 包含工具栏的浏览器窗口宽度
window.outerHeight;      // 包含工具栏的浏览器窗口高度

// 滚动
window.scrollX;          // 水平滚动位置
window.scrollY;          // 垂直滚动位置
window.scrollTo(0, 500); // 滚动到指定位置 (x, y)
window.scrollBy(0, 100); // 相对于当前位置滚动

// 现代平滑滚动选项语法
window.scrollTo({ top: 0, left: 0, behavior: "smooth" });
window.scrollBy({ top: 100, behavior: "smooth" });

// 视口尺寸改变与滚动事件
window.addEventListener("resize", () => {
    console.log(window.innerWidth, window.innerHeight);
});

window.addEventListener("scroll", () => {
    console.log(window.scrollX, window.scrollY);
});
```

> **遗留说明：** DOM0 属性如 `window.onresize` 和 `window.onscroll` 仍然可用，但 `addEventListener` 允许绑定多个处理函数，因此更推荐。

| 属性 | 测量范围 | 是否包含滚动条 | 是否包含工具栏 |
|----------|----------|:-------------------:|:------------------:|
| `window.outerWidth/Height` | 整个浏览器窗口 | — | Yes |
| `window.innerWidth/Height` | 以 CSS 像素计的视口 | Yes | No |
| `document.documentElement.clientWidth/Height` | 可用的内容区域 | No | No |

### 5.1.1 定时器

```javascript
// setTimeout：延迟后执行一次
let timeoutId = setTimeout(() => {
    console.log("Delayed message");
}, 3000);   // 3 秒

clearTimeout(timeoutId);   // 取消定时器

// setInterval：重复执行
let intervalId = setInterval(() => {
    console.log("Repeating message");
}, 1000);   // 每 1 秒

clearInterval(intervalId);  // 停止间歇调用
```

| 函数 | 行为 |
|----------|----------|
| `setTimeout(fn, ms)` | 延迟 `ms` 毫秒后执行一次 `fn` |
| `setInterval(fn, ms)` | 每隔 `ms` 毫秒执行一次 `fn` |
| `clearTimeout(id)` | 取消定时器 |
| `clearInterval(id)` | 取消间歇调用 |

> **动画提示：** 对于视觉动画，优先使用 `requestAnimationFrame` 而非 `setInterval`。它会与显示器刷新率同步，并在标签页隐藏时自动暂停。

```javascript
let animationId;
let current = 0;

function step() {
    current += 1;
    element.style.transform = `translateX(${current}px)`;
    animationId = requestAnimationFrame(step);
}

animationId = requestAnimationFrame(step);
cancelAnimationFrame(animationId);  // 需要时停止
```

### 5.1.2 对话框

```javascript
// 警告对话框（仅 OK 按钮）
alert("Hello!");

// 确认对话框（OK 与 Cancel）
let confirmed = confirm("Are you sure?");
// 返回 true（OK）或 false（Cancel）

// 提示对话框（文本输入）
let name = prompt("Enter your name:", "Guest");
// 返回输入的字符串，或 null（Cancel）
```

> **最佳实践：** 生产环境中避免使用 `alert`、`confirm` 和 `prompt`。它们会阻塞主线程，且用户体验较差。请使用自定义模态组件替代。

### 5.1.3 打开与关闭窗口

```javascript
// 打开新标签页（默认 target 为 "_blank"）
let newWindow = window.open("https://example.com");

// 常见 target："_blank"、"_self"、"_parent"、"_top"，或自定义窗口名
let namedWindow = window.open("https://example.com", "myWindow");

// 打开指定尺寸的弹出窗口
let popup = window.open(
    "https://example.com",
    "_blank",
    "width=600,height=400,left=100,top=100,scrollbars=yes"
);

// 关闭由脚本打开的窗口
popup.close();
```

| Target | 行为 |
|--------|----------|
| `_blank` | 新窗口/标签页 |
| `_self` | 当前窗口 |
| `_parent` | 父框架 |
| `_top` | 窗口顶层 |
| custom name | 复用该名称的窗口，或创建新窗口 |

> **注意：** 现代浏览器会阻止 `window.close()`，除非该窗口是由 JavaScript 打开的。弹出窗口通常只有在用户手势触发时才不被拦截。

## 5.2 location 对象

包含当前 URL 的信息，并提供导航方法。

```javascript
// 读取 URL
location.href;        // 完整 URL："https://example.com/page?id=1"
location.origin;      // "https://example.com:8080"（只读）
location.protocol;    // "https:"
location.host;        // "example.com"
location.hostname;    // "example.com"
location.port;        // ""（若指定则为 "8080"）
location.pathname;    // "/page"
location.search;      // "?id=1"
location.hash;        // "#section1"

// 导航
location.href = "https://newsite.com";   // 跳转至新页面
location.assign("https://newsite.com");  // 与设置 href 相同
location.replace("https://newsite.com"); // 跳转但不加入历史记录
location.reload();                        // 刷新当前页面
location.reload(true);                    // 强制从服务器刷新
```

| 方法 | 效果 |
|--------|--------|
| `assign(url)` | 跳转至 URL，并加入历史记录 |
| `replace(url)` | 跳转至 URL，替换当前历史记录条目 |
| `reload()` | 刷新页面 |

## 5.3 history 对象

控制浏览器的会话历史。

```javascript
history.length;          // 历史记录中的条目数

history.back();          // 等同于点击后退按钮
history.forward();       // 等同于点击前进按钮
history.go(-1);          // 后退 1 页
history.go(2);           // 前进 2 页
history.go(0);           // 刷新当前页面
```

### 5.3.1 pushState 与 replaceState（History API）

在不刷新页面的情况下修改 URL，这对单页应用（SPA）至关重要。

```javascript
// 添加一条新的历史记录
history.pushState({ page: 2 }, "Page 2", "/page2");

// 替换当前历史记录条目
history.replaceState({ page: 1 }, "Page 1", "/page1");

// 监听后退/前进按钮点击
window.addEventListener("popstate", (event) => {
    console.log(event.state);   // 传入 pushState/replaceState 的数据
});
```

| 方法 | 说明 |
|--------|-------------|
| `pushState(state, title, url)` | 添加新的历史记录条目并修改 URL |
| `replaceState(state, title, url)` | 替换当前历史记录条目并修改 URL |

## 5.4 navigator 对象

提供浏览器和操作系统的信息。

```javascript
navigator.userAgent;          // 浏览器标识字符串
navigator.language;           // 首选语言（例如 "en-US"）
navigator.languages;          // 首选语言数组
navigator.onLine;             // 联网时为 true
navigator.cookieEnabled;      // 启用 cookie 时为 true

// 地理定位
navigator.geolocation.getCurrentPosition(
    (position) => {
        console.log(position.coords.latitude);
        console.log(position.coords.longitude);
    },
    (error) => {
        console.error(error.message);
    }
);
```

## 5.5 screen 对象

提供用户显示器的信息。

```javascript
screen.width;         // 屏幕总宽度
screen.height;        // 屏幕总高度
screen.availWidth;    // 可用宽度（不含任务栏）
screen.availHeight;   // 可用高度
screen.colorDepth;    // 颜色深度，单位为位（例如 24）
screen.orientation;   // 屏幕方向对象
```

## 5.6 获取元素尺寸与位置

```javascript
let element = document.getElementById("box");

// 相对于视口的位置和总尺寸
let rect = element.getBoundingClientRect();
console.log(rect.top);       // 到视口顶部的距离
console.log(rect.left);      // 到视口左侧的距离
console.log(rect.width);     // 总宽度
console.log(rect.height);    // 总高度

// 相对于定位父元素的偏移
console.log(element.offsetTop);
console.log(element.offsetLeft);
console.log(element.offsetWidth);
console.log(element.offsetHeight);

// 客户区尺寸（content + padding，不含边框）
console.log(element.clientWidth);
console.log(element.clientHeight);

// 可滚动尺寸（实际内容 + padding）
console.log(element.scrollWidth);
console.log(element.scrollHeight);
```

### 5.6.1 元素尺寸模型

| 属性 | 包含 | 不包含 |
|----------|----------|----------|
| `clientWidth/Height` | Content + padding | Border、margin、scrollbar |
| `offsetWidth/Height` | Content + padding + border + scrollbar | Margin |
| `scrollWidth/Height` | 实际 content + padding（含溢出内容） | Border、margin |

> **记忆口诀：** `client` = content + padding；`offset` = 延伸到边框；`scroll` = 总可滚动区域。

### 5.6.2 位置与滚动偏移

`offsetLeft` 和 `offsetTop` 测量元素外边框左上角到其最近的定位祖先元素（`offsetParent`）左上角的距离。

```javascript
let box = document.getElementById("box");

console.log(box.offsetLeft, box.offsetTop);   // 相对于 offsetParent
console.log(box.offsetParent);                // 最近的定位祖先元素
```

`scrollTop` 可读可写。对于页面滚动，从 `document.documentElement` 读取。

```javascript
// 读取当前垂直滚动位置
let scrollY = document.documentElement.scrollTop;

// 平滑滚动回顶部
window.scrollTo({ top: 0, left: 0, behavior: "smooth" });

// 滚动特定元素
let container = document.querySelector(".scrollable");
container.scrollTop = 0;
container.scrollTo({ top: 0, behavior: "smooth" });
```

> **兼容性说明：** 旧浏览器可能在 `document.body` 上报告页面滚动；需要广泛兼容时，使用 `document.documentElement.scrollTop || document.body.scrollTop`。

### 5.6.3 滚动驱动的 UI 模式

**粘性导航**

```javascript
const nav = document.querySelector(".navbar");
const header = document.querySelector(".header");

window.addEventListener("scroll", () => {
    nav.classList.toggle(
        "sticky",
        document.documentElement.scrollTop >= header.offsetHeight
    );
});
```

- 在参考元素的 `offsetHeight` 处切换 CSS 类。
- 避免设置内联样式；让 CSS 处理 `position: fixed`。

**返回顶部按钮**

```javascript
const btn = document.querySelector(".back-to-top");

window.addEventListener("scroll", () => {
    btn.classList.toggle("visible", document.documentElement.scrollTop > 300);
});

btn.addEventListener("click", () => {
    window.scrollTo({ top: 0, behavior: "smooth" });
});
```

- 超过滚动阈值后显示按钮。
- 使用 `behavior: "smooth"` 实现平滑滚动。

**滚动到底部加载更多**

```javascript
let isLoading = false;

window.addEventListener("scroll", () => {
    const { scrollTop, scrollHeight, clientHeight } = document.documentElement;
    if (isLoading) return;
    if (scrollTop + clientHeight >= scrollHeight - 50) {
        isLoading = true;
        loadMoreData().then(() => isLoading = false);
    }
});
```

- 通过 `scrollTop + clientHeight ≈ scrollHeight` 检测接近底部。
- 使用标志位节流，避免重复请求。

## 5.7 最佳实践

| 推荐 | 不推荐 |
|----|-------|
| 使用 `setTimeout`/`setInterval` 实现简单延迟与轮询 | 使用它们做动画（应使用 `requestAnimationFrame`） |
| 使用 `requestAnimationFrame` 实现与帧同步的动画 | 忘记 `cancelAnimationFrame`，导致内存泄漏 |
| 不希望用户通过后退按钮返回时使用 `location.replace` | 每次导航都使用 `location.href =` |
| 使用 `location.origin` 进行源（origin）比较 | 手动拼接 protocol/host/port 来比较源 |
| 使用 `history.pushState` 实现 SPA 路由 | 每次视图变化都刷新整个页面 |
| 发起网络请求前检查 `navigator.onLine` | 假设用户始终联网 |
| 使用 `getBoundingClientRect` 获取精确的元素位置 | 需要相对于视口的位置时使用 `offsetTop` |
| 使用 `document.documentElement.clientWidth` 获取精确可用空间 | 假设 `innerWidth` 不包含滚动条 |
| 使用加载标志位节流基于滚动的数据请求 | 每次滚动事件都发起请求 |

**记忆口诀**
- **BOM** = "Window wraps all, Location navigates, History remembers"
- **Sizing** = "Outer window, Inner viewport, Client minus scrollbar; Client content+padding, Offset adds border, Scroll is total"
- **Scroll** = "offsetTop to parent, scrollTop to top, rAF keeps frames smooth"
