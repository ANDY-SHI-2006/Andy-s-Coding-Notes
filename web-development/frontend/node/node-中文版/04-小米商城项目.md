# 4 小米商城项目

本章用一个 Express 后端 + MySQL 数据库 + 静态 HTML 前端的小型“小米风格”商城，把前几章的 Node 基础、Express 路由和 MySQL 操作串起来，并加入 JWT 鉴权、密码摘要和分页查询。

## 4.1 项目整体介绍

这是一个最小化的全栈商城：

- **后端**：Express 服务器对外暴露用户和商品相关的 REST API。
- **数据库**：MySQL 保存 `userinfo`（用户信息）和 `goods`（商品信息）两张表。
- **前端**：静态 HTML 页面（登录、注册、首页）通过 axios 与后端通信。

核心 API：

| 方法 | 路径 | 作用 |
|------|------|------|
| POST | `/user/reg` | 用户注册 |
| POST | `/user/login` | 用户登录并返回 JWT |
| GET | `/user/text` | 通过校验 JWT 实现自动登录 |
| GET | `/good/all?page=1` | 分页商品列表 |
| GET | `/good/page` | 商品总数，用于分页 |

> **意义：** 真实项目不会只有一个文件。把路由、业务逻辑、数据库访问拆成不同层级，代码才易于维护和测试。

## 4.3 数据库设计

本项目用两张表即可满足需求。

### 4.3.1 userinfo 表

| 字段 | 类型 | 含义 |
|------|------|------|
| `uid` | `INT PRIMARY KEY AUTO_INCREMENT` | 用户 ID |
| `uname` | `VARCHAR(20) NOT NULL UNIQUE` | 用户名 |
| `pwd` | `VARCHAR(200) NOT NULL` | 密码摘要 |
| `tel` | `VARCHAR(20)` | 手机号 |
| `status` | `INT DEFAULT 1` | 1 正常，0 禁用 |

```sql
CREATE TABLE IF NOT EXISTS userinfo (
  uid INT PRIMARY KEY AUTO_INCREMENT,
  uname VARCHAR(20) NOT NULL UNIQUE,
  pwd VARCHAR(200) NOT NULL,
  tel VARCHAR(20),
  status INT DEFAULT 1
);
```

### 4.3.2 goods 表

| 字段 | 类型 | 含义 |
|------|------|------|
| `gid` | `INT PRIMARY KEY AUTO_INCREMENT` | 商品 ID |
| `gname` | `VARCHAR(50)` | 商品名称 |
| `price` | `DECIMAL(10,2)` | 商品价格 |
| `info` | `VARCHAR(200)` | 商品简介 |
| `status` | `INT DEFAULT 1` | 1 在售，0 下架 |

```sql
CREATE TABLE IF NOT EXISTS goods (
  gid INT PRIMARY KEY AUTO_INCREMENT,
  gname VARCHAR(50),
  price DECIMAL(10,2),
  info VARCHAR(200),
  status INT DEFAULT 1
);
```

> **建议：** 金额字段用 `DECIMAL`，不要用 `FLOAT`/`DOUBLE`，可避免浮点精度误差。

## 4.4 JWT 鉴权流程

JWT（JSON Web Token）让服务端保持无状态：登录成功后客户端保存 token，之后每次受保护请求都把 token 带回来。

### 4.4.1 登录成功后签发 token

用户名和密码校验通过后，服务端用 `jsonwebtoken` 签名生成 token：

```js
const jwt = require('jsonwebtoken');
const privateKey = 'jian'; // 密钥，需保密

let token = jwt.sign(
  { value: userRow },        // 载荷
  privateKey,                // 密钥
  { expiresIn: '1 days' }    // 过期时间
);
res.send({ status: 1, msg: 'login ok', info: token });
```

### 4.4.2 前端保存 token

登录页把 token 写入 `localStorage`，然后跳转到首页：

```js
localStorage.setItem('userinfo', data.info);
setTimeout(() => {
  location.href = 'index.html';
}, 1000);
```

### 4.4.3 前端请求携带 token

后续请求把 token 放在 `Authorization` 请求头中：

```js
let { data } = await axios({
  method: 'get',
  url: 'http://127.0.0.1:6080/user/text',
  headers: {
    authorization: localStorage.getItem('userinfo')
  }
});
```

### 4.4.4 后端校验 token

自动登录接口读取请求头并校验签名：

```js
let token = req.headers['authorization'];
if (!token) {
  res.send({ status: 0, msg: 'not logged in' });
  return;
}

jwt.verify(token, privateKey, (err, { value }) => {
  if (err) {
    res.send({ status: 0, msg: 'token invalid' });
    return;
  }
  value.tel = '***'; // 敏感信息打码
  res.send({ status: 1, msg: 'logged in', info: value });
});
```

> **安全提示：** 把 token 存在 `localStorage` 有 XSS（跨站脚本）风险。生产环境建议使用 `HttpOnly Cookie`，JavaScript 无法读取它。

## 4.5 密码加密

课堂项目使用 `md5` 包对密码做摘要，保存或比对前都要先摘要：

```js
const md5 = require('md5');
let hashedPwd = md5(pwd);
```

使用要点：

- 注册时：对密码做摘要后再 `INSERT`。
- 登录时：对输入密码做摘要，再与数据库中的摘要比对。

> **重要：** MD5 已被认为不再适合用于密码存储。它计算速度快，且易受彩虹表攻击。真实项目请使用 `bcrypt` 或 `argon2`，它们计算慢且自动加盐。

生产环境 bcrypt 示例（课堂项目未使用）：

```js
const bcrypt = require('bcrypt');
const saltRounds = 10;

// 保存前哈希
let hashed = await bcrypt.hash(pwd, saltRounds);

// 登录时比对
let ok = await bcrypt.compare(pwd, storedHash);
```

## 4.6 用户接口实现

用户路由文件 `router/user.js` 把三个端点与三个处理函数绑定：

```js
const express = require('express');
const { reg, login, text } = require('../handle/handleUser.js');
const userRouter = express.Router();

userRouter.use(express.json());

userRouter.post('/reg', reg);
userRouter.post('/login', login);
userRouter.get('/text', text); // 自动登录

module.exports = userRouter;
```

> **勘误：** 部分课件把 `express.urlencoded({ extend: true })` 写成 `extend`，正确选项名是 `extended: true`。

### 4.6.1 注册接口：先查重再插入

```js
exports.reg = (req, res) => {
  let { username, pwd, tel } = req.body;

  // 1. 检查用户名是否已存在
  let checkSql = 'SELECT * FROM userinfo WHERE uname = ?';
  mysql.query(checkSql, [username], (err, data) => {
    if (data.length !== 0) {
      res.send({ status: 0, msg: 'user already exists' });
      return;
    }

    // 2. 插入新用户
    let insertSql = 'INSERT INTO userinfo(uname, pwd, tel, status) VALUES(?, ?, ?, ?)';
    mysql.query(insertSql, [username, md5(pwd), tel, 1], (err) => {
      if (err) {
        res.send({ status: 0, msg: 'register failed' });
        return;
      }
      res.send({ status: 1, msg: 'register success' });
    });
  });
};
```

### 4.6.2 登录接口：校验用户名、密码和状态

```js
exports.login = (req, res) => {
  let { username, pwd } = req.body;

  let sql = 'SELECT * FROM userinfo WHERE uname = ? AND pwd = ? AND status = ?';
  mysql.query(sql, [username, md5(pwd), 1], (err, data) => {
    if (err || data.length === 0) {
      res.send({ status: 0, msg: 'wrong username or password' });
      return;
    }

    let token = jwt.sign({ value: data[0] }, privateKey, { expiresIn: '1 days' });
    res.send({ status: 1, msg: 'login success', info: token });
  });
};
```

> **注意：** `res.send()` 不能直接传数字，因为 Express 会把数字当成 HTTP 状态码。数字必须包在对象或字符串里返回。

### 4.6.3 自动登录接口：校验 token 并给手机号打码

```js
exports.text = (req, res) => {
  let token = req.headers['authorization'];
  if (!token) {
    res.send({ status: 0, msg: 'not logged in' });
    return;
  }

  jwt.verify(token, privateKey, (err, { value }) => {
    if (err) {
      res.send({ status: 0, msg: 'token invalid' });
      return;
    }
    value.tel = '***';
    res.send({ status: 1, msg: 'logged in', info: value });
  });
};
```

## 4.7 商品列表与分页

商品路由文件 `router/goods.js` 暴露两个端点：

```js
const express = require('express');
const { all, page } = require('../handle/handleGood.js');
const goodRouter = express.Router();

goodRouter.use(express.json());

goodRouter.get('/all', all);   // 单页商品列表
goodRouter.get('/page', page); // 总页数

module.exports = goodRouter;
```

### 4.7.1 分页列表接口

每页返回 3 条数据，偏移量为 `(page - 1) * 3`。

```js
exports.all = (req, res) => {
  let page = parseInt(req.query.page, 10) || 1;
  let offset = (page - 1) * 3;

  let sql = 'SELECT * FROM goods WHERE status = ? LIMIT ? OFFSET ?';
  mysql.query(sql, [1, 3, offset], (err, data) => {
    if (err) {
      res.send({ status: 0, msg: 'query failed' });
      return;
    }
    res.send({ status: 1, msg: 'ok', info: data });
  });
};
```

### 4.7.2 总页数接口

前端需要知道总页数才能渲染分页条。后端返回在售商品总数，前端再除以每页条数并向上取整：

```js
exports.page = (req, res) => {
  let sql = 'SELECT COUNT(*) AS total FROM goods WHERE status = ?';
  mysql.query(sql, [1], (err, data) => {
    if (err) {
      res.send({ status: 0, msg: 'query failed' });
      return;
    }
    let totalPage = Math.ceil(data[0].total / 3);
    res.send({ status: 1, msg: 'ok', info: totalPage });
  });
};
```

> **建议：** 如果只需要数量，用 `COUNT(*)` 而不是 `SELECT *`，速度更快、占用内存更少。

### 4.8.4 分页条

分页条包含“上一页”、页码和“下一页”。当前页通过 `change` 类高亮显示。

```js
function showPage(total) {
  let html = '<div class="content_bottom_son">Previous</div>';
  for (let i = 1; i <= total; i++) {
    let activeClass = i === currentPage ? 'change' : '';
    html += `<div class="content_bottom_son ${activeClass}">${i}</div>`;
  }
  html += '<div class="content_bottom_son">Next</div>';
  document.querySelector('.content_bottom').innerHTML = html;

  let items = document.querySelectorAll('.content_bottom_son');

  // 页码点击
  for (let i = 1; i < items.length - 1; i++) {
    items[i].onclick = () => {
      currentPage = i;
      getGoods(currentPage);
      updateHighlight(currentPage, items);
    };
  }

  // 上一页
  items[0].onclick = () => changePage(-1, items);
  // 下一页
  items[items.length - 1].onclick = () => changePage(1, items);
}

function changePage(step, items) {
  let next = currentPage + step;
  if (next < 1 || next > totalPage) {
    alert('no more pages');
    return;
  }
  currentPage = next;
  getGoods(currentPage);
  updateHighlight(currentPage, items);
}

function updateHighlight(page, items) {
  items.forEach(el => el.classList.remove('change'));
  items[page].classList.add('change');
}

getPage();
getGoods(currentPage);
```

## 4.9 SQL 注入警告

课堂源码中有时会使用字符串拼接 SQL：

```js
// 危险，生产环境不要用
let sql = `select * from userinfo where uname = '${username}'`;
```

如果 `username` 是 `' OR '1'='1`，条件就会对所有行成立，这就是 SQL 注入。

正确做法是使用 `?` 占位符，把值放在数组里传入：

```js
// 安全
let sql = 'SELECT * FROM userinfo WHERE uname = ?';
mysql.query(sql, [username], (err, data) => {
  // ...
});
```

`mysql2` 会自动转义值，让外部输入被当作数据而不是 SQL 代码。所有来自用户或 URL 的动态值都应该使用占位符。

| 不安全 | 安全 |
|--------|------|
| `` `WHERE uname = '${name}'` `` | `'WHERE uname = ?'` + `[name]` |
| `` `LIMIT 3 OFFSET ${(page-1)*3}` `` | `'LIMIT ? OFFSET ?'` + `[3, offset]` |
| `` `WHERE status = ${status}` `` | `'WHERE status = ?'` + `[status]` |

> **原则：** SQL 字符串里永远不要出现 `${variable}`。每个来自用户或 URL 的值都用 `?` 占位。
