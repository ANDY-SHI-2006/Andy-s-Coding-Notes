# 19 小程序客户端美食展示

本章实现小程序客户端的美食首页（food 页面）：后端在 Flask 项目中提供 `/api/food/index` 接口，一次性返回轮播图、分类列表和分页美食列表；前端通过 `wx.request` 获取数据并渲染，同时支持分类切换与关键词搜索。

## 19.1 展示美食列表（food 页面）

### 19.1.1 后端准备接口

在 `web/views/api/Food.py` 模块中添加 `foodIndex()` 方法，路由为 `/food/index`（挂在 api 蓝图下，完整路径 `/api/food/index`）。接口统一返回 `{'code': 200, 'msg': '操作成功~', 'data': {}}` 结构，`data` 中包含三部分数据：

- `cat_list`：分类列表。查询 `status=1` 的分类并按权重 `weight` 倒序排列，开头手动追加一个 `{'id': 0, 'name': '全部'}` 表示"全部分类"。
- `banner_list`：轮播图。取出未删除（`status=1`）的美食中销量 `total_count` 最大的 3 件商品，只返回 `id` 和 `pic_url`（图片路径通过 `UrlManager.buildImageUrl()` 拼成完整 URL）。
- `list` + `has_more`：美食列表。支持分类筛选、关键词搜索和分页（见下文）。

美食列表的查询逻辑：

- 从 `request.values` 中取参数：`cat_id`（分类 id，默认 0）、`mix_kw`（搜索关键词，默认空）、`p`（页码，默认 1，小于 1 时重置为 1）。
- 每页 `page_size = 10`，`offset = (p - 1) * page_size`。
- `cat_id > 0` 时追加分类过滤；`mix_kw` 非空时用 `or_` 同时对 `name` 和 `tags` 做 `ilike` 模糊匹配。
- 按销量和 id 倒序，用 `offset/limit` 分页；`has_more` 在本页数据不足一页时为 0，否则为 1。

完整代码：

```python
from . import route_api
from web.models.FoodCat import FoodCat
from web.models.Food import Food
from flask import jsonify, request
from sqlalchemy import or_
from common.libs.UrlManager import UrlManager


@route_api.route("/food/index")  # /api/food/index
def foodIndex():
    resp = {'code': 200, 'msg': '操作成功~', 'data': {}}

    # ---------- 美食列表 ----------
    req = request.values
    cat_id = int(req['cat_id']) if 'cat_id' in req else 0
    mix_kw = str(req['mix_kw']) if 'mix_kw' in req else ''
    p = int(req['p']) if 'p' in req else 1
    if p < 1:
        p = 1

    page_size = 10
    offset = (p - 1) * page_size
    query = Food.query.filter_by(status=1)

    if cat_id > 0:
        query = query.filter_by(cat_id=cat_id)

    if mix_kw:
        # 名称或标签中包含关键词即命中（ilike 不区分大小写）
        rule = or_(Food.name.ilike("%{0}%".format(mix_kw)),
                   Food.tags.ilike("%{0}%".format(mix_kw)))
        query = query.filter(rule)

    food_list = query.order_by(Food.total_count.desc(), Food.id.desc())\
        .offset(offset).limit(page_size).all()

    data_food_list = []
    if food_list:
        for item in food_list:
            tmp_data = {
                'id': item.id,
                'name': "%s" % (item.name),
                'price': str(item.price),
                'min_price': str(item.price),
                'pic_url': UrlManager.buildImageUrl(item.main_image)
            }
            data_food_list.append(tmp_data)
    resp['data']['list'] = data_food_list
    resp['data']['has_more'] = 0 if len(data_food_list) < page_size else 1

    # ---------- 分类列表 ----------
    cat_list = FoodCat.query.filter_by(status=1).order_by(FoodCat.weight.desc()).all()
    data_cat_list = []
    data_cat_list.append({
        'id': 0,
        'name': "全部"
    })
    if cat_list:
        for item in cat_list:
            tmp_data = {
                'id': item.id,
                'name': item.name
            }
            data_cat_list.append(tmp_data)
    resp['data']['cat_list'] = data_cat_list  # 类别

    # ---------- 轮播图 ----------
    # status 为 1 表示没有被删除的 food，将销售量最大的三件商品展示出来 total_count
    food_list = Food.query.filter_by(status=1).order_by(Food.total_count.desc(),
                                                        Food.id.desc()).limit(3).all()
    data_food_list = []  # 返回的数据格式化，就是 json 格式的数据
    if food_list:
        for item in food_list:
            tmp_data = {
                'id': item.id,
                'pic_url': UrlManager.buildImageUrl(item.main_image)
            }
            data_food_list.append(tmp_data)
    resp['data']['banner_list'] = data_food_list

    return jsonify(resp)
```

### 19.1.2 前端获取数据

**页面数据定义（`pages/food/index.js`）**

在 `data` 中准备渲染所需字段：`categories`（分类）、`goods`（美食列表）、`banners`（轮播图）三个数组，以及分页和状态控制字段：

```javascript
data: {
    indicatorDots: true,      // 轮播图指示点
    autoplay: true,
    interval: 3000,
    duration: 1000,
    loadingHidden: false,     // loading
    swiperCurrent: 0,
    categories: [],
    goods: [],
    banners: [],
    p: 1,                     // 当前页码
    processing: false,        // 表示正在处理，防止重复请求
    activeCategoryId: 0,      // 当前选中的分类 id，0 表示全部
    scrollTop: "0",
    loadingMoreHidden: true,  // 是否还有更多数据可加载
    searchInput: '',          // 搜索框内容
},
```

**获取轮播图和分类（`getBannerAndCat`）**

页面加载时请求 `/food/index`，把返回的轮播图和分类写入 `data`，然后再调用 `getFoodList()` 拉取美食列表数据：

```javascript
getBannerAndCat: function () {
    var that = this;
    wx.request({
        url: app.buildUrl("/food/index"),
        header: app.getRequestHeader(),
        success: function (res) {
            var resp = res.data;
            if (resp.code != 200) {
                app.alert({
                    "content": resp.msg
                });
                return;
            }
            that.setData({
                banners: resp.data.banner_list,
                categories: resp.data.cat_list,
                goods: resp.data.list
            });
            // 搜索实物数据
            that.getFoodList();
        }
    })
},
```

**分页获取美食列表（`getFoodList`）**

发起请求前先做两个防重复判断：`processing` 为 `true`（上一次请求未结束）或 `loadingMoreHidden` 为 `false`（已经没有更多数据）时直接返回。请求时携带 `cat_id`、`mix_kw`、`p` 三个参数；成功后把列表写入 `goods`、页码加一，若 `has_more == 0` 则把 `loadingMoreHidden` 置为 `false`，表示没有下一页了。

```javascript
getFoodList: function () {
    var that = this;
    if (that.data.processing) {
        return;
    }
    if (!that.data.loadingMoreHidden) {
        return;
    }
    that.setData({
        processing: true
    });
    wx.request({
        url: app.buildUrl("/food/index"),
        header: app.getRequestHeader(),
        data: {
            cat_id: that.data.activeCategoryId,
            mix_kw: that.data.searchInput,
            p: that.data.p
        },
        success: function (res) {
            var resp = res.data;
            if (resp.code != 200) {
                app.alert({
                    "content": resp.msg
                });
                return;
            }
            that.setData({
                goods: resp.data.list,
                p: that.data.p + 1,
                processing: false
            });
            if (resp.data.has_more == 0) {
                that.setData({
                    loadingMoreHidden: false
                });
            }
        }
    })
},
```

> 注：如果要实现"加载更多"时把新数据追加到已有列表后面，可以把 `goods` 改为 `that.data.goods.concat(resp.data.list)`。

**app.js 中的域名与 buildUrl**

接口域名集中放在 `globalData` 中，新增 `buildUrl` 方法拼接完整请求地址（确保 path 以 `/` 开头）：

```javascript
globalData: {
    userInfo: null,
    version: "1.0",
    shopName: "Python3 + Flask 订餐全栈系统",
    domain: "http://127.0.0.1:8999/api"
},
// 新增 buildUrl 方法
buildUrl: function (path) {
    // 确保 path 以 / 开头
    if (path && !path.startsWith('/')) {
        path = '/' + path;
    }
    return this.globalData.domain + (path || '');
},
```

**后端配套调整**

- **拦截器过滤**：`/api/` 下的接口面向小程序，不需要登录校验。在 `AuthInterceptor` 的 `before_request()` 中把配置项 `API_IGNORE_URLS` 读出来加入忽略列表：`ignore_api_url = current_app.config["API_IGNORE_URLS"]`，再合并 `ignore_merge = ignore_urls + ignore_check_login_url + ignore_api_url`。
- **访问日志优化**：微信请求的 `User-Agent` 较长，写访问日志时限制 255 长度，避免超出数据库字段：`target.ua = request.headers.get("User-Agent")[:255]`。

### 19.1.3 前端展示数据

数据拿到后，wxml 中三个区域分别绑定对应字段：

- **轮播图**：`swiper` 组件遍历 `banners`，渲染 `pic_url`。
- **分类列表**：横向 `scroll-view` 遍历 `categories`。
- **美食列表**：遍历 `goods`，每项展示图片、名称和价格（`￥ price`）。

运行效果：首页顶部是搜索框和轮播图，下方是"全部 / 各分类"标签栏，再往下是两列布局的美食卡片（图片 + 名称 + 价格），底部 tabBar 为"首页 / 购物车 / 我的"。

## 19.2 切换不同分类

点击分类标签时，通过事件对象拿到该分类的 id（wxml 中把分类 id 写在标签的 `id` 属性上），更新 `activeCategoryId`；同时把页码 `p` 重置为 1、清空 `goods`、恢复 `loadingMoreHidden`，再重新调用 `getFoodList()` 拉取该分类下的第一页数据：

```javascript
catClick: function (e) {
    this.setData({
        activeCategoryId: e.currentTarget.id
    });
    this.setData({
        loadingMoreHidden: true,
        p: 1, // 每次点击分类时，把 p 值设置为 1，重新开始
        goods: []
    });
    this.getFoodList();
},
```

wxml 中分类导航栏绑定 `catClick`，并根据 `activeCategoryId` 高亮当前选中的分类：

```html
<!--分类展示-->
<view class="type-container">
    <scroll-view class="type-navbar" scroll-x="true">
        <view class="type-box" wx:for-items="{{categories}}" wx:key="id">
            <view id="{{item.id}}" bind:tap="catClick" class="type-navbar-item {{activeCategoryId == item.id ? 'type-item-on' : ''}}" >
                {{item.name}}
            </view>
        </view>
    </scroll-view>
</view>
```

## 19.3 搜索美食

搜索功能由两个事件配合完成，都在 `pages/food/index.js` 中：

- `listenerSearchInput`：监听输入框内容变化，实时把输入值存入 `searchInput`。
- `toSearch`：点击"搜索"按钮时触发，重置分页状态后调用 `getFoodList()`；`getFoodList` 请求时会把 `searchInput` 作为 `mix_kw` 参数发给后端，由后端接口做模糊匹配（见 19.1.1）。

```javascript
listenerSearchInput: function (e) {
    this.setData({
        searchInput: e.detail.value
    });
},
toSearch: function (e) {
    this.setData({
        p: 1,
        goods: [],
        loadingMoreHidden: true
    });
    this.getFoodList();
},
```

wxml 中搜索框与按钮的绑定：

```html
<!--搜索框-->
<view class="search-view">
    <view class="search-content">
        <image src="/images/search-pic.png" class="search-icon" />
        <input placeholder="请输入搜索内容" class="search-input" maxlength="30"
               confirm-type="搜索" bindinput='listenerSearchInput'>
        </input>
        <button class='search-btn' bindtap="toSearch">搜索</button>
    </view>
</view>
```

至此，美食首页完成了"接口提供数据 → 前端请求并渲染 → 分类切换 / 关键词搜索重新查询"的完整闭环。
