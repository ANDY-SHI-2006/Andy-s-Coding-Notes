# 2 小程序文档配置

本章介绍小程序的整体目录结构，以及两类核心配置文件：全局配置 `app.json` 和页面配置 `*.json`。掌握这些配置项，才能控制小程序的页面组织、窗口表现、底部 tab 栏、网络超时和调试模式。

## 2.1 小程序的目录结构

### 2.1.1 整体目录结构

小程序包含一个描述整体程序的 app 和多个描述各自页面的 page。一个小程序的主体部分由三个文件组成，必须放在项目的根目录：

| 文件      | 必需 | 作用             |
| --------- | ---- | ---------------- |
| app.js    | 是   | 小程序逻辑       |
| app.json  | 是   | 小程序公共配置   |
| app.wxss  | 否   | 小程序公共样式表 |

三个文件的分工：

1. **app.js（必需，小程序逻辑）**
   - 小程序的全局逻辑文件，相当于整个小程序的"大脑中枢"。
   - 定义小程序的生命周期函数（如启动、显示、隐藏时触发）。
   - 可设置全局变量和全局方法，所有页面都能直接调用。
   - 是小程序启动时第一个执行的文件，没有它小程序无法正常运行。

2. **app.json（必需，小程序公共配置）**
   - 小程序的全局配置文件，相当于整个小程序的"说明书"。
   - 必须在这里配置页面路径列表，告诉微信哪些文件是页面。
   - 还可设置全局窗口样式（导航栏颜色、标题、窗口背景）、底部 tabBar、网络超时、debug 等公共配置。
   - 没有它，微信无法识别小程序的结构，会直接报错无法启动。

3. **app.wxss（可选，小程序公共样式表）**
   - 小程序的全局样式文件，相当于整个小程序的"公共 CSS"。
   - 这里写的样式作用于所有页面，如全局字体、通用边距、统一按钮样式等。
   - 没有这个文件小程序也能运行，只是每个页面都要单独写样式，不利于统一维护。
   - 页面自己的样式文件（`xxx.wxss`）优先级高于 `app.wxss`，可以覆盖全局样式。

### 2.1.2 pages 目录

项目根目录下的 `pages` 目录存放小程序的各个页面，每个页面由 4 个文件组成：

| 文件类型 | 必需 | 作用       |
| -------- | ---- | ---------- |
| js       | 是   | 页面逻辑   |
| wxml     | 是   | 页面结构   |
| json     | 否   | 页面配置   |
| wxss     | 否   | 页面样式表 |

> 注意：为了方便开发者减少配置项，描述页面的四个文件必须具有相同的路径与文件名。

1. **.js（页面逻辑，必需）**：页面的逻辑中枢，用来写页面的生命周期、事件处理、数据请求等代码，相当于这个页面的"大脑"，没有它页面无法运行。
2. **.wxml（页面结构，必需）**：页面的骨架文件，和 HTML 类似，用来写页面的标签和组件结构，决定页面上显示什么元素，是页面渲染的基础。
3. **.json（页面配置，可选）**：页面的局部配置文件，可单独设置当前页面的导航栏标题、颜色、是否开启下拉刷新等，会覆盖 `app.json` 中相同的配置项。
4. **.wxss（页面样式表，可选）**：页面的局部样式文件，和 CSS 类似，用来写当前页面的样式，优先级高于 `app.wxss`。

> 一个完整的小程序页面，必须同时存在同名的 `.js` 和 `.wxml` 文件，`.json` 和 `.wxss` 可以按需添加。

## 2.2 全局配置 app.json

官方文档：<https://developers.weixin.qq.com/miniprogram/dev/reference/configuration/app.html>

### 2.2.1 app.json 概述

小程序根目录下的 `app.json` 文件用来对微信小程序进行全局配置，决定页面文件的路径、窗口表现、网络超时时间、多 tab 等。

书写 `app.json` 时要注意两点：

1. `app.json` 中不能添加任何注释，否则会报错。
2. 字符串必须用双引号引起来。

下面是一个新建项目的 `app.json` 实际内容，可以看到其中保存的就是小程序的主配置项属性列表：

```json
{
  "pages": [
    "pages/index/index",
    "pages/logs/logs"
  ],
  "window": {
    "navigationBarTextStyle": "black",
    "navigationBarTitleText": "Weixin",
    "navigationBarBackgroundColor": "#ffffff"
  },
  "style": "v2",
  "componentFramework": "glass-easel",
  "sitemapLocation": "sitemap.json",
  "lazyCodeLoading": "requiredComponents"
}
```

`app.json` 中常见的属性设置有以下几项：

| 属性           | 类型     | 必填 | 描述                              |
| -------------- | -------- | ---- | --------------------------------- |
| pages          | string[] | 是   | 页面路径列表                      |
| window         | Object   | 否   | 全局的默认窗口表现                |
| tabBar         | Object   | 否   | 底部 tab 栏的表现                 |
| networkTimeout | Object   | 否   | 网络超时时间                      |
| debug          | boolean  | 否   | 是否开启 debug 模式，默认关闭     |

各属性的作用概览：

1. **pages（必填，页面路径数组）**：小程序的"页面清单"，微信会根据这里配置的路径加载对应的页面文件。数组里的第一个页面默认是小程序的首页。
2. **window（可选，窗口表现对象）**：设置所有页面的默认窗口样式，如导航栏标题文字、背景色、文字颜色、是否开启下拉刷新等；单个页面可通过自己的 `.json` 覆盖。
3. **tabBar（可选，底部导航栏对象）**：配置小程序底部的标签栏，可设置最多 5 个标签，每个标签对应一个页面路径和图标；不配置则不显示底部导航。
4. **networkTimeout（可选，网络超时对象）**：设置小程序各类网络请求（`wx.request`、`wx.downloadFile` 等）的超时时间。
5. **debug（可选，布尔值）**：开启后，开发者工具的控制台会输出详细的调试日志，方便排查问题；上线前应关闭，避免泄露调试信息。

### 2.2.2 pages

`pages` 的值是一个数组，每一项都是字符串，用于指定小程序由哪些页面组成。每一项代表对应页面的"路径 + 文件名（不含后缀名）"信息，文件名不需要写后缀，框架会自动去寻找对应位置的 `.json`、`.js`、`.wxml`、`.wxss` 四个文件进行处理。

未指定 `entryPagePath` 时，数组的第一项代表小程序的初始页面（首页）。

**entryPagePath**：指定小程序的默认启动路径（首页），常见情景是从微信聊天列表页下拉启动、小程序列表启动等。如果不填，将默认为 `pages` 列表的第一项，不支持带页面路径参数。

```json
{
  "entryPagePath": "pages/index/index"
}
```

> 注意：小程序中新增/减少页面，都需要对 `pages` 数组进行修改。

比如开发目录如下：

```text
├── app.js
├── app.json
├── app.wxss
├── pages
│   ├── index
│   │   ├── index.wxml
│   │   ├── index.js
│   │   ├── index.json
│   │   └── index.wxss
│   └── logs
│       ├── logs.wxml
│       └── logs.js
└── utils
```

那么需要在 `app.json` 中注册：

```json
"pages": [
  "pages/index/index",
  "pages/logs/logs"
]
```

### 2.2.3 window

用于设置小程序的状态栏、导航条、标题、窗口背景色。

| 属性                         | 类型     | 默认值  | 描述                                                                                        | 最低版本                                                    |
| ---------------------------- | -------- | ------- | ------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| navigationBarBackgroundColor | HexColor | #000000 | 导航栏背景颜色，如 "#000000"                                                                | -                                                           |
| navigationBarTextStyle       | string   | white   | 导航栏标题颜色，仅支持 black/white                                                          | -                                                           |
| navigationBarTitleText       | string   | -       | 导航栏标题文字内容                                                                          | -                                                           |
| navigationStyle              | string   | default | 导航栏样式，仅支持 default/custom。custom 模式可自定义导航栏，只保留右上角胶囊状的按钮      | iOS/Android 微信客户端 6.6.0，Windows/Mac 微信基础库 3.6.1  |
| backgroundColor              | HexColor | #ffffff | 窗口的背景色                                                                                | -                                                           |
| backgroundTextStyle          | string   | dark    | 下拉 loading 的样式，仅支持 dark/light                                                      | -                                                           |
| backgroundColorTop           | HexColor | #ffffff | 顶部窗口的背景色，仅 iOS 支持                                                               | 微信版本 6.5.16                                             |
| backgroundColorBottom        | HexColor | #ffffff | 底部窗口的背景色，仅 iOS 支持                                                               | 微信版本 6.5.16                                             |
| enablePullDownRefresh        | boolean  | false   | 是否开启下拉刷新，详见页面相关事件处理函数                                                  | -                                                           |
| onReachBottomDistance        | number   | 50      | 页面上拉触底事件触发时距页面底部距离，单位为 px                                             | -                                                           |

配置示例：

```json
"window": {
  "navigationBarBackgroundColor": "#BBFFFF",
  "navigationBarTextStyle": "black",
  "navigationBarTitleText": "微信接口功能演示"
}
```

### 2.2.4 tabBar

如果小程序是一个多 tab 应用（客户端窗口的底部或顶部有 tab 栏可以切换页面），可以通过 `tabBar` 配置项指定 tab 栏的表现，以及 tab 切换时显示的对应页面。

tabBar 支持的属性：

- 当设置 `position` 为 `top` 时，将不会显示 icon。
- `tabBar` 中的 `list` 是一个数组，只能配置最少 2 个、最多 5 个 tab，tab 按数组的顺序排序。

| 属性            | 类型     | 必填 | 默认值 | 描述                                                     |
| --------------- | -------- | ---- | ------ | -------------------------------------------------------- |
| color           | HexColor | 是   | -      | tab 上的文字默认颜色，仅支持十六进制颜色                 |
| selectedColor   | HexColor | 是   | -      | tab 上的文字选中时的颜色，仅支持十六进制颜色             |
| backgroundColor | HexColor | 是   | -      | tab 的背景色，仅支持十六进制颜色                         |
| borderStyle     | string   | 否   | black  | tabBar 上边框的颜色，仅支持 black/white                  |
| list            | Array    | 是   | -      | tab 的列表，详见 list 属性说明，最少 2 个、最多 5 个 tab |
| position        | string   | 否   | bottom | tabBar 的位置，仅支持 bottom/top                         |
| custom          | boolean  | 否   | false  | 自定义 tabBar（基础库 2.5.0 起支持）                     |

tabBar 中 list 支持的属性：

| 属性             | 类型   | 必填 | 说明                                                                                              |
| ---------------- | ------ | ---- | ------------------------------------------------------------------------------------------------- |
| pagePath         | string | 是   | 页面路径，必须在 pages 中先定义                                                                   |
| text             | string | 是   | tab 上按钮文字                                                                                    |
| iconPath         | string | 否   | 图片路径，icon 大小限制为 40kb，建议尺寸为 81px × 81px，不支持网络图片。当 position 为 top 时不显示 icon |
| selectedIconPath | string | 否   | 选中时的图片路径，icon 大小限制为 40kb，建议尺寸为 81px × 81px，不支持网络图片。当 position 为 top 时不显示 icon |

配置示例：

```json
"tabBar": {
  "color": "#00b26a",
  "selectedColor": "#000000",
  "backgroundColor": "#ce9083",
  "list": [
    {
      "pagePath": "pages/index/index",
      "text": "首页",
      "iconPath": "/icons/home.png",
      "selectedIconPath": "/icons/home-o.png"
    },
    {
      "pagePath": "pages/logs/logs",
      "text": "日志",
      "iconPath": "/icons/my.png",
      "selectedIconPath": "/icons/my-o.png"
    }
  ]
}
```

配置后模拟器底部会出现对应的 tab 栏，点击即可在页面间切换：

### 2.2.5 networkTimeout

用于设置各种网络请求的超时时间，单位均为毫秒（1s【秒】= 1000ms【毫秒】）。

| 属性          | 类型   | 必填 | 默认值 | 说明                                  |
| ------------- | ------ | ---- | ------ | ------------------------------------- |
| request       | number | 否   | 60000  | wx.request 的超时时间，单位：毫秒     |
| connectSocket | number | 否   | 60000  | wx.connectSocket 的超时时间，单位：毫秒 |
| uploadFile    | number | 否   | 60000  | wx.uploadFile 的超时时间，单位：毫秒  |
| downloadFile  | number | 否   | 60000  | wx.downloadFile 的超时时间，单位：毫秒 |

配置示例：

```json
"networkTimeout": {
  "request": 20000,
  "connectSocket": 20000,
  "uploadFile": 20000,
  "downloadFile": 20000
}
```

> 注意：上线之前一定要设置一下超时时间，不然小程序在网络状况差时可能出现长时间无响应的情况。

### 2.2.6 debug

可以在开发者工具中开启 `debug` 模式。开启后，在开发者工具的控制台面板中，调试信息以 `info` 的形式给出，包括 Page 的注册、页面路由、数据更新、事件触发等，可以帮助开发者快速定位一些常见的问题。

```json
"debug": true
```

![[ch02-2-06.png]]

> 在开发阶段，建议打开 debug。上线时请关闭此选项，设置为 false。

## 2.3 页面配置文件 *.json

官方文档：<https://developers.weixin.qq.com/miniprogram/dev/reference/configuration/page.html>

每个小程序页面也可以使用同名 `*.json` 文件来对本页面的窗口表现进行配置，页面中的配置项会覆盖 `app.json` 的 `window` 中相同的配置项，同样用于设置小程序的状态栏、导航条、标题、窗口背景色。

### 2.3.1 静态配置参考

```json
{
  "navigationBarBackgroundColor": "#8470FF",
  "navigationBarTextStyle": "black",
  "navigationBarTitleText": "微信接口功能演示",
  "backgroundColor": "#eeeeee",
  "backgroundTextStyle": "light",
  "usingComponents": {}
}
```

配置后当前页面的导航栏颜色、标题和窗口背景会覆盖全局设置：

![[ch02-2-07.png]]

### 2.3.2 动态设置

除了静态配置，还可以使用微信提供的 API 接口在代码中动态修改窗口表现。

语法：`wx.setNavigationBarTitle(Object object)`

例如，在页面加载时动态设置导航栏标题：

```js
/**
 * 生命周期函数--监听页面加载
 */
onLoad(options) {
  wx.setNavigationBarTitle({
    title: '测试标题动态设置',
  })
}
```
