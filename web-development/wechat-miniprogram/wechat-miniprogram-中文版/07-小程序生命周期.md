# 7 小程序生命周期

小程序的生命周期分为两类：**应用生命周期**（整个小程序实例的启动、前后台切换、销毁过程）和**页面生命周期**（单个页面的加载、渲染、显示、隐藏、卸载过程）。理解两类生命周期的触发时机，才能把初始化、数据刷新、资源清理等逻辑放到正确的回调里。

> 官方文档参考：<https://developers.weixin.qq.com/miniprogram/dev/framework/runtime/operating-mechanism.html>

## 7.1 应用生命周期

应用生命周期函数注册在 `app.js` 的 `App({})` 中，描述的是整个小程序实例从启动到销毁的过程。

![[ch07-14.png]]

### 7.1.1 生命周期函数一览

| 生命周期函数       | 触发时机                   | 执行次数 | 常用场景                                 |
| ------------------ | -------------------------- | -------- | ---------------------------------------- |
| `onLaunch`         | 小程序初始化完成时         | 1 次     | 获取用户信息、检查登录状态、获取系统信息 |
| `onShow`           | 小程序启动或从后台进入前台 | 多次     | 刷新数据、统计页面访问、恢复动画         |
| `onHide`           | 小程序从前台进入后台       | 多次     | 保存数据、暂停音乐/视频、清除定时器      |
| `onError`          | 小程序发生脚本错误时       | 按需     | 错误上报、异常监控                       |
| `onPageNotFound`   | 要打开的页面不存在时       | 按需     | 跳转到 404 页面或首页                    |

可以用一个拟人化的方式记忆：

- **出生** → `onLaunch`：小程序启动时
- **醒来** → `onShow`：小程序显示到屏幕时
- **睡觉** → `onHide`：小程序隐藏到后台时
- **生病** → `onError`：小程序出现错误时

### 7.1.2 完整示例：app.js

```js
// app.js
App({
  // 1. 小程序初始化（整个生命周期只执行一次）
  onLaunch(options) {
    console.log('🎉 小程序初始化完成')
    console.log('启动参数:', options)

    // 获取用户信息
    wx.getUserInfo({
      success: (res) => {
        this.globalData.userInfo = res.userInfo
      }
    })

    // 获取系统信息
    wx.getSystemInfo({
      success: (res) => {
        this.globalData.systemInfo = res
      }
    })
  },

  // 2. 小程序显示（启动或从后台切回前台时触发）
  onShow(options) {
    console.log('📱 小程序显示到前台')
    console.log('场景值:', options.scene)

    // 刷新数据
    this.refreshData()
  },

  // 3. 小程序隐藏（从前台切入后台时触发）
  onHide() {
    console.log('💤 小程序进入后台')

    // 保存数据到缓存
    wx.setStorageSync('lastHideTime', new Date())

    // 暂停音乐播放
    this.stopBackgroundMusic()
  },

  // 4. 错误处理（发生脚本错误或 API 调用失败时触发）
  onError(error) {
    console.error('❌ 小程序发生错误:', error)

    // 错误上报
    wx.request({
      url: 'https://api.example.com/error',
      data: { error: error }
    })
  },

  // 5. 页面不存在处理（要打开的页面不存在时触发）
  onPageNotFound(res) {
    console.log('🔍 页面不存在:', res.path)

    // 跳转到首页
    wx.redirectTo({
      url: '/pages/index/index'
    })
  },

  // 自定义方法
  refreshData() {
    console.log('🔄 刷新数据...')
  },

  stopBackgroundMusic() {
    console.log('⏸️ 暂停背景音乐')
  },

  // 全局数据
  globalData: {
    userInfo: null,
    systemInfo: null
  }
})
```

`onLaunch` 中最常见的两类工作是**本地存储初始化**和**登录**，典型写法如下：

```js
// app.js
App({
  onLaunch() {
    // 展示本地存储能力：把本次启动时间写入日志
    const logs = wx.getStorageSync('logs') || []
    logs.unshift(Date.now())
    wx.setStorageSync('logs', logs)

    // 登录：发送 res.code 到后台换取 openId、sessionKey、unionId
    wx.login({
      success: res => {
        // res.code 是临时登录凭证，需发送到自己的服务器换取用户标识
      }
    })
  },
  onShow() {
    console.log('App-->onShow')
  },
  onHide() {
    console.log('App-->onHide')
  },
  globalData: {
    userInfo: null
  }
})
```

## 7.2 页面生命周期

页面生命周期函数注册在页面 js 文件的 `Page({})` 中，描述的是单个页面从加载、初次渲染到显示、隐藏、卸载的过程。打开页面后依次触发 `onLoad` → `onShow` → `onReady`，页面进入活跃状态；此后用户下拉、触底、滚动、分享、切换横竖屏、点击 Tab、切入后台、关闭页面等动作都会触发对应的回调，其中 `onHide` 与 `onShow` 会在前后台切换时反复触发。

### 7.2.1 页面属性与回调函数一览

| 属性                | 类型     | 详细说明                                            |
| ------------------- | -------- | --------------------------------------------------- |
| `data`              | Object   | 页面的初始数据，用于模板渲染的数据对象              |
| `onLoad`            | function | 生命周期回调 - 监听页面加载（只会调用一次）         |
| `onShow`            | function | 生命周期回调 - 监听页面显示（每次打开都会调用）     |
| `onReady`           | function | 生命周期回调 - 监听页面初次渲染完成（只会调用一次） |
| `onHide`            | function | 生命周期回调 - 监听页面隐藏（切入后台时调用）       |
| `onUnload`          | function | 生命周期回调 - 监听页面卸载（页面销毁时调用）       |
| `onPullDownRefresh` | function | 监听用户下拉刷新动作                                |
| `onReachBottom`     | function | 监听用户上拉触底事件                                |
| `onShareAppMessage` | function | 监听用户点击右上角转发                              |
| `onPageScroll`      | function | 监听页面滚动事件                                    |
| `onResize`          | function | 监听页面尺寸变化（横竖屏切换等）                    |
| `onTabItemTap`      | function | 监听 Tab 页点击事件                                 |

## 7.3 页面生命周期图解

小程序的页面运行在**双线程模型**中：

- **视图线程（View Thread）**：负责界面渲染，经历 Start → Inited（等待数据）→ Ready（首次渲染完成）→ 持续渲染（Rerender）→ End 的状态流转。
- **服务线程（AppService Thread）**：负责逻辑处理，经历 Start → Created（等待激活）→ Active（激活状态）→ Alive（后台状态）→ End 的状态流转，各生命周期回调都在服务线程中触发。

两个线程通过「Notify / Send Data」互相通信：服务线程发送初始数据，视图线程完成首次渲染并通知服务线程触发 `onReady`；此后每次 `this.setData` 都会让服务线程向视图线程发送数据，触发页面重新渲染。

### 7.3.1 各阶段说明

1. **创建阶段（页面首次打开）**
   - `onLoad`：页面加载时触发，**只执行一次**，可获取页面参数
   - `onShow`：页面显示时触发，**每次打开页面都会执行**
   - 服务线程向视图线程发送初始数据，视图线程进入等待数据状态
2. **首次渲染阶段**
   - `onReady`：页面初次渲染完成时触发，**只执行一次**
   - 服务线程通知视图线程完成首次渲染，视图线程进入就绪状态
3. **活跃阶段（前台运行）**
   - 服务线程通过 `setData` 向视图线程发送数据，触发页面重渲染
   - 视图线程持续响应用户交互，更新页面内容
4. **后台阶段（页面隐藏）**
   - `onHide`：页面被切入后台时触发，可暂停定时器、保存数据
   - 服务线程进入后台状态，仍可通过 `setData` 发送数据，但视图线程仅在页面切回前台时更新
5. **切回前台**
   - `onShow`：页面从后台切回前台时触发，刷新数据、恢复动画
6. **销毁阶段（页面关闭）**
   - `onUnload`：页面被卸载/销毁时触发，清理资源、关闭定时器
