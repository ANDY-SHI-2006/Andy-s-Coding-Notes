# 20 小程序美食详情展示

本章实现小程序端的美食详情页：从列表页/轮播图点击跳转到详情页并携带美食 id，后端提供 `/food/info` 详情接口与 `/food/comments` 评论接口，前端 `pages/food/info` 页面完成数据拉取、富文本渲染与评论展示。

## 20.1 页面跳转及获取详情 id

详情页的入口有两个：美食列表的每一项，以及首页轮播图。两者都通过 `wx.navigateTo` 跳转到 `/pages/food/info`，并在 URL 上以 `id` 参数携带美食 id。

`pages/food/index.js` 中的两个跳转处理函数：

```js
//点击轮播图跳转详情页
tapBanner: function (e) {
    if (e.currentTarget.dataset.id != 0) {
        wx.navigateTo({
            url: "/pages/food/info?id=" + e.currentTarget.dataset.id
        });
    }
},
//点击美食列表项跳转详情页
toDetailsTap: function (e) {
    wx.navigateTo({
        url: "/pages/food/info?id=" + e.currentTarget.dataset.id
    });
}
```

对应的 `pages/food/index.wxml` 中，列表项通过 `data-id` 把当前美食的 id 挂到节点上，供事件对象的 `dataset` 读取：

```html
<view class="goods-box" wx:for-items="{{goods}}" bindtap="toDetailsTap" data-id="{{item.id}}">
```

详情页 `pages/food/info.js` 在 `onLoad` 中通过页面参数 `e` 拿到 id 并存入 `data`，随后调用 `getInfo()` 拉取详情数据、`getComments()` 拉取评论数据：

```js
onLoad: function (e) {
    var that = this;
    that.setData({
        id: e.id
    });
    that.getInfo();
    that.getComments();
},
```

## 20.2 美食详情

### 20.2.1 后端接口 `/food/info`

在 `web/views/api/Food.py` 中新增详情接口。根据传入的 id 查询美食，若不存在或状态无效则返回"美食已下架"；否则组装详情数据返回，其中 `summary` 是后台编辑器保存的 HTML 富文本，图片地址统一经 `UrlManager.buildImageUrl` 补全：

```python
@route_api.route("/food/info")
def foodInfo():
    resp = {'code': 200, 'msg': '操作成功~', 'data': {}}
    req = request.values
    id = int(req['id']) if 'id' in req else 0
    food_info = Food.query.filter_by(id=id).first()

    if not food_info or not food_info.status:  # 没有找到商品或者状态已经删除
        resp['code'] = -1
        resp['msg'] = "美食已下架"
        return jsonify(resp)

    resp['data']['info'] = {  # 详情页信息
        "id": food_info.id,
        "name": food_info.name,
        "summary": food_info.summary,
        "total_count": food_info.total_count,
        "comment_count": food_info.comment_count,
        'main_image': UrlManager.buildImageUrl(food_info.main_image),
        "price": str(food_info.price),
        "stock": food_info.stock,
        "pics": [UrlManager.buildImageUrl(food_info.main_image)]
    }
    return jsonify(resp)
```

返回的 `info` 字段说明：

| 字段 | 含义 |
| --- | --- |
| `id` / `name` | 美食 id 与名称 |
| `summary` | 图文详情（HTML 富文本，前端用 WxParse 渲染） |
| `total_count` | 销量 |
| `comment_count` | 累计评论数 |
| `main_image` / `pics` | 主图与轮播图片列表 |
| `price` | 价格（转字符串返回，避免精度问题） |
| `stock` | 库存（前端用它限制可购买数量上限） |

### 20.2.2 前端获取详情数据

`pages/food/info.js` 的 `getInfo` 请求 `/food/info`。注意两个细节：

- 请求失败（如美食已下架）时提示用户并跳回美食列表页；
- `WxParse.wxParse` 必须在拿到数据之后再调用，把 `summary` 富文本渲染到页面的 `article` 节点；同时用库存 `stock` 更新可购数量上限 `buyNumMax`，并同步购物车数量 `shopCarNum`。

```js
getInfo: function () {
    var that = this;
    wx.request({
        url: app.buildUrl("/food/info"),
        header: app.getRequestHeader(),
        data: {
            id: that.data.id
        },
        success: function (res) {
            var resp = res.data;
            if (resp.code != 200) {
                app.alter({ "content": resp.msg });
                wx.navigateTo({
                    url: '/pages/food/index',
                });
                return;
            }
            that.setData({
                info: resp.data.info,
                buyNumMax: resp.data.info.stock,
                shopCarNum: resp.data.cart_number
            });
            //拿到详情数据后再解析渲染富文本
            WxParse.wxParse('article', 'html', that.data.info.summary, that, 5);
        }
    })
},
```

## 20.3 美食评论

### 20.3.1 后端：导出评论模型

评论数据存放在 `member_comments` 表中。用 `flask-sqlacodegen` 从数据库反向导出模型，生成 `web/models/MemberComments.py`（需把文件头部的 `db` 导入改为项目统一的 `from application import db`）：

```bash
flask-sqlacodegen mysql://root:qwe123@127.0.0.1/food_db --tables member_comments --outfile "web/models/MemberComments.py" --flask
```

### 20.3.2 后端接口 `/food/comments`

评论接口写在 `web/views/api/Member.py` 中。思路：根据美食 id 查出该美食的所有评论（`food_ids` 字段以 `_id_` 形式存储，用 `ilike("%_{0}_%")` 匹配），按时间倒序取前 5 条展示，同时返回评论总数。

评论列表需要展示用户头像和昵称，为避免循环里逐条查库，先用 `selectFilterObj` 把评论涉及的 `member_id` 集合提取出来，再用 `getDictFilterField` 一次性查出对应的 Member 对象并组装成 `{member_id: Member对象}` 的映射 `member_map`——一个用户可能评论多条，但会员信息只需查一次：

```python
from common.libs.render_helper import getDictFilterField, selectFilterObj
from . import route_api
from flask import request, jsonify
from web.models.MemberComments import MemberComment
from web.models.Member import Member

@route_api.route("/food/comments")
def foodComments():
    resp = {'code': 200, 'msg': '操作成功~', 'data': {}}
    req = request.values
    id = int(req['id']) if 'id' in req else 0

    #美食id ---> 获取对应的所有评论数据
    query = MemberComment.query.filter(MemberComment.food_ids.ilike("%_{0}_%".format(id)))
    list = query.order_by(MemberComment.id.desc()).limit(5).all()

    data_list = []
    if list:
        # selectFilterObj(list, "member_id") ---> 将member_id（评论用户的id）整合出来 ---> [1,2,5,6]
        # {1: 类型数据对象, 2: 类型数据对象} ---- 一个用户评论多条数据，但是我只要一条
        member_map = getDictFilterField(Member, Member.id, "id", selectFilterObj(list, "member_id"))
        for item in list:
            if item.member_id not in member_map:
                continue
            tmp_member_info = member_map[item.member_id]
            tmp_data = {
                'score': item.score_desc,
                'date': item.created_time.strftime("%Y-%m-%d %H:%M:%S"),
                "content": item.content,
                "user": {
                    'nickname': tmp_member_info.nickname,
                    'avatar_url': tmp_member_info.avatar,
                }
            }
            data_list.append(tmp_data)

    resp['data']['list'] = data_list
    resp['data']['count'] = query.count()
    return jsonify(resp)
```

返回结构中 `list` 是最新 5 条评论（含评分描述、时间、内容、用户昵称与头像），`count` 是该美食的评论总数，用于页面显示"共收到 N 次好评"。

### 20.3.3 前端获取评论

`pages/food/info.js` 新增 `getComments`，请求 `/food/comments` 并把评论列表和总数写入 `data`；如 20.1 所示，它在 `onLoad` 中与 `getInfo()` 一起被调用：

```js
getComments: function () {
    var that = this;
    wx.request({
        url: app.buildUrl("/food/comments"),
        header: app.getRequestHeader(),
        data: {
            id: that.data.id
        },
        success: function (res) {
            var resp = res.data;
            if (resp.code != 200) {
                app.alter({ "content": resp.msg });
                return;
            }
            that.setData({
                commentList: resp.data.list,
                commentCount: resp.data.count,
            })
        }
    })
}
```

至此详情页的三块数据——美食信息、图文详情（WxParse 渲染）、评论列表——全部由后端接口驱动，页面底部保留"加入购物车 / 立即购买"入口，为下一章的购物车功能做准备。
