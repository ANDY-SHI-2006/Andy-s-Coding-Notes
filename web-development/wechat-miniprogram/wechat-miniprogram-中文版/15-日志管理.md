# 15 日志管理

后台管理系统需要记录两类运行日志：**访问日志**（记录用户每次正常访问的请求信息）和**错误日志**（记录 404 等错误请求的信息）。本章在 Flask 后端中实现这两类日志：用 `flask-sqlacodegen` 从已有数据表生成模型类，编写统一的 `LogService` 日志服务，再通过拦截器和错误处理钩子把日志自动写入数据库，最后在账号详情页展示个人历史访问记录。

## 15.1 使用表生成 log 日志模型

日志数据存放在 `food_db` 数据库的两张表中：`app_access_log`（访问日志）和 `app_error_log`（错误日志）。使用 `flask-sqlacodegen` 可以直接根据表结构生成对应的模型类。

安装包（之前已安装则无需重复安装）：

```bash
pip install flask-sqlacodegen
```

参考之前生成 User 模型类的方式，生成对应的日志模型类。**注意：不要重新构建 SQLAlchemy**。两条生成命令如下：

```bash
flask-sqlacodegen mysql://root:qwe123@127.0.0.1/food_db --tables app_access_log --outfile "web/models/AppAccessLog.py" --flask

flask-sqlacodegen mysql://root:qwe123@127.0.0.1/food_db --tables app_error_log --outfile "web/models/AppErrorLog.py" --flask
```

生成后的两个模型文件放在 `web/models/` 目录下（与 `user.py` 同级）。**注意重构导入 db 对象**：生成代码顶部的导入要改为项目统一的写法：

```python
from application import db
```

## 15.2 访问日志处理

### 15.2.1 编写 LogService 模块

在 `common/libs` 目录下新建 `LogService.py` 模块，创建 `LogService` 类并添加记录访问日志的静态方法：

```python
from flask import request, g
from application import db
from datetime import datetime
import json
from web.models.AppAccessLog import AppAccessLog


class LogService():
    @staticmethod
    def addAccesslog():
        """添加访问日志到数据库"""
        target = AppAccessLog()
        if "current_user" in g and g.current_user is not None:
            target.uid = g.current_user.uid  # 当前用户的uid
        target.referer_url = request.referrer
        target.target_url = request.url
        target.query_params = json.dumps(request.values.to_dict())
        target.ua = request.headers.get("User-Agent")
        target.created_time = datetime.now()
        # 写入数据库
        db.session.add(target)
        db.session.commit()
        return True
```

记录的字段说明：

| 字段 | 含义 | 来源 |
| --- | --- | --- |
| `uid` | 当前登录用户 id | `g.current_user.uid`（未登录则不写） |
| `referer_url` | 来源页面地址 | `request.referrer` |
| `target_url` | 本次访问的目标地址 | `request.url` |
| `query_params` | 请求参数（JSON 字符串） | `json.dumps(request.values.to_dict())` |
| `ua` | 客户端 User-Agent | `request.headers.get("User-Agent")` |
| `created_time` | 访问时间 | `datetime.now()` |

### 15.2.2 在拦截器中写入访问日志

在登录拦截器 `web/interceptors/AuthInterceptor.py` 的 `before_request()` 中，实现每次能正常访问之前，把访问日志信息写入数据库。在通过登录校验（`g.current_user` 赋值）之后加入：

```python
# 写入日志
from common.libs.LogService import LogService
LogService.addAccesslog()
```

这样每次请求经过拦截器、确认登录合法后，都会自动记录一条访问日志。

### 15.2.3 Account.py 的 info 视图传递日志列表

编写 `Account.py` 模块的 `info` 视图方法，查询当前账号最近的访问日志并传递到页面展示。在原有查询用户信息的基础上增加：

```python
# from web.models.AppAccessLog import AppAccessLog

access_list = AppAccessLog.query.filter_by(uid=uid).order_by(AppAccessLog.id.desc()).limit(10).all()
context['access_list'] = access_list
```

即按 `uid` 过滤、按 id 倒序排列、最多取最近 10 条访问记录。

### 15.2.4 更新 info.html 展示历史访问列表

更新 `account/info.html` 页面，在表格中显示个人历史访问信息列表（访问时间、访问 URL）：

## 15.3 错误日志处理

### 15.3.1 LogService 添加错误日志方法

在 `LogService` 类中添加记录错误日志的静态方法 `addErrorlog`（需要先导入 `AppErrorLog` 模型）：

```python
class LogService():

    @staticmethod
    def addErrorlog(content):
        """添加错误日志到数据库"""
        if "favicon.ico" in request.url:
            print("图标问题报404可以忽略")
            return
        target = AppErrorLog()
        target.referer_url = request.referrer
        target.target_url = request.url
        target.query_params = json.dumps(request.values.to_dict())
        target.content = content
        target.created_time = datetime.now()
        # 写入数据库
        db.session.add(target)
        db.session.commit()
        print("写入数据库成功")
        return True
```

要点：

- 浏览器请求 `favicon.ico` 时经常触发 404，属于无意义的噪音日志，直接忽略不写入数据库。
- `content` 参数保存具体的错误内容（由调用方传入异常信息字符串）。

### 15.3.2 创建错误日志拦截器 ErrorInterceptor

在 `web/interceptors/` 目录下创建 `ErrorInterceptor.py`，对 404 错误实现自定义拦截，把错误信息写入日志（数据库）中，并渲染统一的错误提示页面：

```python
from application import app
from common.libs.LogService import LogService
from common.libs.render_helper import ops_render


@app.errorhandler(404)
def error_404(e):
    LogService.addErrorlog(str(e))  # 错误内容
    return ops_render("error/error.html",
                      {"msg": "温馨提醒您访问的页面不存在~",
                       "status": 404
                       })
```

### 15.3.3 在 www.py 中加载拦截器

拦截器文件创建后，必须在 `www.py` 中导入加载，才能将钩子函数挂载到应用中：

```python
from web.interceptors.AuthInterceptor import *
from web.interceptors.ErrorInterceptor import *
```

至此，404 错误处理钩子随应用启动完成注册：任何不存在的页面访问都会先写入一条错误日志，再向用户展示友好的错误提示页。
