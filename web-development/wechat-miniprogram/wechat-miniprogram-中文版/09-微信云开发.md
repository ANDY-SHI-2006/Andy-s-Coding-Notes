# 9 微信云开发

开发文档：<https://developers.weixin.qq.com/miniprogram/dev/wxcloud/basis/getting-started.html>

开发者可以使用云开发来开发微信小程序、小游戏，**无需搭建服务器**，即可使用云端能力。云开发为开发者提供完整的原生云端支持和微信服务支持，弱化后端和运维概念，使用平台提供的 API 进行核心业务开发，即可实现快速上线和迭代；同时这一能力与开发者已经在使用的云服务相互兼容，并不互斥。

## 9.1 云开发基础信息

| 信息项       | 详情                                                                                           |
| ------------ | ---------------------------------------------------------------------------------------------- |
| 所属平台     | 微信小程序                                                                                     |
| 核心定位     | 为小程序开发者提供一站式后端云服务，无需自建服务器、数据库、存储、CDN 等基础架构，大幅降低小程序后端开发门槛 |
| 核心能力模块 | 云函数、数据库、存储、云调用                                                                   |

**核心能力详情：**

| 能力名称 | 核心作用           | 详细说明                                                                                     |
| -------- | ------------------ | -------------------------------------------------------------------------------------------- |
| 云函数   | 无需自建服务器     | 在云端运行的代码，基于微信私有协议天然鉴权，开发者只需编写自身业务逻辑代码，无需关心服务器运维、鉴权等底层逻辑 |
| 数据库   | 无需自建数据库     | 一个既可在小程序前端直接操作，也能在云函数中读写的 JSON 格式文档型数据库，支持增删改查、聚合查询、事务等常用数据库能力 |
| 存储     | 无需自建存储和 CDN | 支持在小程序前端直接上传 / 下载云端文件，可在云开发控制台进行可视化管理，天然集成 CDN 加速能力，提升文件访问速度 |
| 云调用   | 原生微信服务集成   | 基于云函数免鉴权调用小程序各类开放接口的能力，覆盖服务端接口调用、开放数据获取等场景，无需开发者手动处理接口鉴权逻辑 |

**补充说明：**

1. 云开发的所有能力均与微信小程序生态深度集成，天然支持小程序用户身份鉴权，无需额外开发登录、鉴权体系；
2. 云函数、数据库、存储、云调用四大能力可配合使用，覆盖绝大多数小程序后端业务场景，无需额外对接第三方后端服务；
3. 云开发提供了免费的基础使用额度，可满足小程序开发调试和小型业务的使用需求，超出额度后可按需升级付费套餐。

## 9.2 申请开通云开发

### 9.2.1 申请条件

个人、企业、媒体、政府或其他组织主体的小程序均可申请开通。

### 9.2.2 功能介绍

- **快速开发上线小程序/小游戏/公众号**：免后端配置和域名备案，不限开发语言和框架，低门槛免鉴权调用微信支付、内容安全等微信开放能力。相较于传统开发模式，可有效提升研发效率。
- **后台托管**：提供 serverless 云托管服务，免资源运维，根据业务负载情况自动实时弹性扩缩容。对比服务器的部署方式，可有效降低成本。
- **高并发下快速自动扩容**：支持函数维度的毫秒级快速扩容，可承载亿级流量洪峰，保证线上服务稳定；当流量回落时，可自动缩容。
- **接口隐藏，安全防刷**：小程序/公众号中调用云开发时，在公网上的数据均受微信私有协议保护，且公网网络通讯全程加密，能够有效防止小程序/公众号被盗刷/黑客攻击。
- **实时数据推送**：可以在小程序/小游戏/公众号应用上，使用 SDK 监听数据变更；无需管理长连接、无需编写服务端代码、无需搭建和管理基础设施，即可自动收到更新推送，且支持百万级并发。

### 9.2.3 开通与环境选择

在微信公众平台（mp.weixin.qq.com）的小程序后台中，找到「云服务 → 云开发」，扫码开通。

**注意环境选择**：开通后在云开发控制台确认当前使用的是「云开发」环境（而非云托管、微信网关），并记录下**环境 ID**（形如 `cloudbase-xxxxxxxxxxxx`），后续在 `app.js` 中初始化云能力时需要填写。

## 9.3 创建云开发项目

**注意：创建项目时 AppID 不可使用测试号，需要使用正式的 AppID。**

在微信开发者工具中新建小程序项目：

1. 填写项目名称与目录，选择正式的 AppID；
2. **后端服务选择「微信云开发」**（当前小程序 AppID 需已开通云开发）；
3. 模板可选择官方的「云开发基础模板」，创建后即可看到云开发的示例工程。

创建后的项目目录结构与普通小程序不同，主要包含：

- `cloudfunctions/`：云函数目录（标注了当前环境）；
- `miniprogram/`：小程序前端代码目录；
- `project.config.json`、`uploadCloudFunction.sh` 等项目级文件。

在 `miniprogram/app.js` 中需要填入环境 ID 并初始化云能力：

```js
// app.js
App({
  onLaunch: function () {
    this.globalData = {
      // env 参数说明：
      // env 参数决定接下来小程序发起的云开发调用（wx.cloud.xxx）会请求到哪个云环境的资源
      // 此处请填入环境 ID，环境 ID 可在微信开发者工具顶部工具栏点击「云开发」按钮打开控制台查看
      env: "cloudbase-xxxxxxxxxxxx",
    };
    if (!wx.cloud) {
      console.error("请使用 2.2.3 或以上的基础库以使用云能力");
    } else {
      wx.cloud.init({
        env: this.globalData.env,
        traceUser: true, // 记录用户访问，便于在控制台分析用户
      });
    }
  },
});
```

## 9.4 云数据库

### 9.4.1 介绍

云开发提供了一个 JSON 数据库，顾名思义，数据库中的每条记录都是一个 JSON 格式的对象。一个数据库可以有多个集合（相当于关系型数据库中的表），集合可看做一个 JSON 数组，数组中的每个对象就是一条记录，记录的格式是 JSON 对象。这样数据库的存储也不用考虑了——云开发直接提供了一个类似于 MongoDB 的数据库，而且免费的存储空间达到了 2G，一般的项目足够使用。

规范地说，这是一个**文档型数据库（Document Database）**，JSON 是其核心的数据存储与交互格式。

**关系型数据库与文档型数据库的概念对应关系：**

| 关系型数据库（SQL） | 文档型数据库（NoSQL，JSON 格式） | 对应逻辑与场景说明                                                                                             |
| ------------------- | -------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 数据库（database）  | 数据库（database）               | 两类数据库的顶层容器概念完全一致，均用于管理一组相关的数据集合，一个数据库可包含多个表 / 集合                  |
| 表（table）         | 集合（collection）               | 关系型数据库中，表是结构化数据的存储容器，有固定的列结构；文档型数据库中，集合是一组相关文档的容器，无固定结构 |
| 行（row）           | 记录（record / doc，文档）       | 关系型数据库中，一行是表中的一条完整数据记录；文档型数据库中，一个文档（doc）是集合中的一条完整数据，以 JSON 格式存储 |
| 列（column）        | 字段（field）                    | 关系型数据库中，列是表中定义的固定数据字段，有严格的类型约束；文档型数据库中，字段是 JSON 文档中的键值对，无固定类型约束 |

**两类数据库的核心差异：**

| 对比维度 | 关系型数据库（SQL）                                        | 文档型数据库（JSON 格式）                                                              |
| -------- | ---------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 数据结构 | 严格的结构化，表必须提前定义固定的列结构、数据类型，所有行必须遵循该结构 | 非结构化 / 半结构化，集合无需提前定义结构，每个文档的字段、类型都可以不同，灵活度极高  |
| 数据格式 | 以行、列的二维表格形式存储，数据之间通过主键、外键关联     | 以 JSON 文档的键值对形式存储，支持嵌套结构、数组，可直接在一个文档中存储完整的关联数据 |
| 适用场景 | 适合业务逻辑固定、数据结构稳定、需要强事务支持的场景（如订单系统、财务系统） | 适合业务逻辑灵活、数据结构多变、需要快速迭代的场景（如小程序云开发、内容管理系统）     |
| 代表产品 | MySQL、Oracle、SQL Server                                  | 微信小程序云开发数据库、MongoDB、Firebase Firestore                                    |

### 9.4.2 云数据库操作

**注意：操作数据库前，需要先创建集合。** 打开微信开发者工具顶部工具栏的「云开发」控制台，进入「数据库」标签页，点击集合名称旁的「+」创建数据集合（如 `ceshi`），并选择权限类型（如「仅创建者可读写」）。

下面通过一个 `db` 页面演示增删改查的完整流程。

#### 9.4.2.1 新建 db 页面并初始化数据库

在 `app.json` 的 `pages` 中注册 `pages/db/db`，新建 db 页面。然后在页面 js 顶部初始化云开发环境并获取数据库引用：

```js
// pages/db/db.js
// 初始化微信小程序云开发环境
// https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloud/reference-sdk-api/init/client.init.html
wx.cloud.init();

// 获取云数据库的引用，后续可以通过 db 来操作数据库
const db = wx.cloud.database();

// 获取数据库命令操作符，用于构建复杂的查询条件
// 比如：大于、小于、包含、数组操作等
// https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloud/reference-sdk-api/database/Command.html
const _ = db.command;

// 示例用法：
// db.collection('users').where({
//   age: _.gt(18)  // 查询年龄大于 18 岁的用户
// })
```

常用查询操作符：

| 操作符    | 含义     |
| --------- | -------- |
| `_.gt()`  | 大于     |
| `_.gte()` | 大于等于 |
| `_.lt()`  | 小于     |
| `_.in()`  | 在数组中 |
| `_.and()` | 与操作   |
| `_.or()`  | 或操作   |

**全局初始化与页面内初始化的对比**（正式项目推荐在 `app.js` 的 `onLaunch` 中全局初始化一次）：

| 对比项     | app.js 全局初始化              | 页面内局部初始化                 |
| ---------- | ------------------------------ | -------------------------------- |
| 初始化时机 | 小程序启动时执行 1 次          | 页面加载时执行，多页面会重复执行 |
| 作用域     | 全局可用，所有页面共享         | 仅当前页面可用                   |
| 代码复用   | 高，一次初始化，所有页面可复用 | 低，每个页面都要写一遍           |
| 环境配置   | 统一管理，修改一次即可         | 分散管理，修改需要改所有页面     |
| 适用场景   | 正式项目、多页面项目           | 临时测试、单页面快速开发         |

#### 9.4.2.3 添加数据

语法：`db.collection('集合名称').add(json格式数据)`

添加成功后，记录会自动带上 `_id`（记录唯一标识）和 `_openid`（添加者的用户标识）两个系统字段。

```js
// 添加数据
add: function () {
  db.collection('ceshi').add({
    data: {
      name: "阿白",
      age: 18,
      sex: "男",
    }
  })
  .then(res => {
    console.log(res, "添加成功")
  })
  .catch(err => {
    console.log(err, '添加失败')
  })
},
```

#### 9.4.2.4 查询数据

语法：`db.collection('集合名称').where("查询条件也使用json格式").get()`

**查询所有数据**（不加 `where` 条件）：

```js
get: function () {
  db.collection("ceshi").get()
  .then(res => {
    console.log(res, "查询成功")
  })
  .catch(err => {
    console.log(err, '查询失败')
  })
},
```

**根据指定条件查询**——`age` 等于 18：

```js
get: function () {
  db.collection("ceshi").where({
    age: 18
  }).get()
  .then(res => {
    console.log(res, "查询成功")
  })
  .catch(err => {
    console.log(err, '查询失败')
  })
},
```

**使用操作符查询**——`age` 大于等于 18：

```js
get: function () {
  db.collection("ceshi").where({
    // age: 18        // age 等于 18
    age: _.gte(18)    // age 大于等于 18
  }).get()
  .then(res => {
    console.log(res, "查询成功")
  })
  .catch(err => {
    console.log(err, '查询失败')
  })
},
```

**多条件组合查询**——查询 `name` 等于阿白且 `age` 等于 18 的用户（`where` 中多个字段默认是与关系）：

```js
get: function () {
  db.collection("ceshi").where({
    name: "阿白",
    age: 18            // age 等于 18
    // age: _.gte(18)  // 大于等于 18
  }).get()
  .then(res => {
    console.log(res, "查询成功")
  })
  .catch(err => {
    console.log(err, '查询失败')
  })
},
```

#### 9.4.2.5 更新数据

更新有两种方式：

**1. 局部更新** `db.collection('集合名称').doc(记录id).update(json格式数据)`

- 只修改指定的字段；
- 其他字段不受影响；
- 更安全，不会意外覆盖数据；字段不存在时会新增该字段。

**2. 替换更新** `db.collection('集合名称').doc(记录id).set(json格式数据)`

- 用新数据完全替换原记录；
- 未指定的字段会被删除；
- 相当于先删除后新增。

记录 id（即 `_id`）可以在云开发控制台数据库的记录列表中查看：

```js
update: function () {
  db.collection('ceshi').doc('9b5f7bed68fa31df000dbf9842d9fd2f').update({
    data: {
      name: '测试修改'
    }
  })
  .then(res => {
    console.log(res, '数据更新')
  })
  .catch(err => {
    console.log(err, '数据更新')
  })
},
```

#### 9.4.2.6 删除数据

语法：`db.collection('集合名称').doc(记录id).remove()`

```js
delete: function () {
  db.collection('ceshi').doc('9b5f7bed68fa31df000dbf9842d9fd2f').remove()
  .then(res => {
    console.log(res, '数据删除')
  })
  .catch(err => {
    console.log(err, '数据删除')
  })
},
```

## 9.5 云存储

开发文档：<https://developers.weixin.qq.com/miniprogram/dev/wxcloud/guide/storage.html>

云开发提供了一块文件存储空间，提供了上传文件到云端、带权限管理的云端下载能力，开发者可以在小程序端和云函数端通过 API 使用云文件存储功能。在小程序端可以分别调用 `wx.cloud.uploadFile` 和 `wx.cloud.downloadFile` 完成上传和下载云文件操作。这就相当于腾讯直接提供了一个静态文件的 CDN，免费容量达到了 5G，一般项目前期是够用的。

### 9.5.1 文件上传

在小程序端可调用 `wx.cloud.uploadFile` 方法进行上传：

```js
wx.cloud.uploadFile({
  cloudPath: 'example.png', // 上传至云端的路径
  filePath: '', // 小程序临时文件路径
  success: res => {
    // 返回文件 ID
    console.log(res.fileID)
  },
  fail: console.error
})
```

**注意：** 上传成功后会获得文件唯一标识符，即文件 ID，后续操作都基于文件 ID 而不是 URL。

### 9.5.2 文件下载

可以根据文件 ID 下载文件，用户仅可下载其有访问权限的文件：

```js
wx.cloud.downloadFile({
  fileID: '', // 文件 ID
  success: res => {
    // 返回临时文件路径
    console.log(res.tempFilePath)
  },
  fail: console.error
})
```

### 9.5.3 删除文件

可以通过 `wx.cloud.deleteFile` 删除文件，`fileList` 传入要删除的文件 ID 数组（支持批量删除）：

```js
wx.cloud.deleteFile({
  fileList: ['a7xzcb'],
  success: res => {
    // handle success
    console.log(res.fileList)
  },
  fail: console.error
})
```

### 9.5.4 案例：上传媒体数据

下面通过一个 `cloudstore` 页面完整演示「选择图片 → 上传到云存储 → 下载 → 删除」的流程。

**1. 创建 cloudstore 页面**

在 `app.json` 的 `pages` 中注册 `pages/cloudstore/cloudstore`。

**2. 设计界面**

cloudstore.wxml：

```html
<view>
  <button bind:tap="upload" type="primary">上传图片</button>
  <button bind:tap="download" type="primary">下载图片</button>
  <button bind:tap="delfile" type="primary">删除图片</button>
</view>
```

cloudstore.wxss：

```css
button {
  margin-top: 30rpx;
}
```

**3. 上传图片**

> 注意：旧的 `wx.chooseImage` 接口从基础库 2.21.0 开始停止维护，请使用 `wx.chooseMedia` 代替。

```js
upload: function (options) {
  // 从本地相册选择图片或者使用相机拍照
  wx.chooseMedia({
    count: 1, // 图片数量
    sizeType: ['compressed'], // 图片的尺寸：原图 original 或压缩 compressed
    success: res => {
      // 本地临时文件路径（形如 http://tmp/xxxx.png）
      const filePath = res.tempFiles[0].tempFilePath
      // 用正则截取文件后缀，拼接出上传到云端的文件名，如 my-image.png
      const cloudPath = `my-image${filePath.match(/\.[^.]+?$/)[0]}`

      // 将图片上传到云存储空间
      wx.cloud.uploadFile({
        cloudPath: cloudPath, // 指定上传的云路径
        filePath: filePath,   // 指定临时文件路径
        success: res => {
          console.log('上传成功', res) // res.fileID 即文件 ID
        }
      })
    }
  })
},
```

上传成功后，可在云开发控制台的「存储」标签页中看到该文件及其文件 ID（形如 `cloud://环境ID.存储桶ID/my-image.png`）。

**4. 下载图片**

```js
download: function () {
  wx.cloud.downloadFile({
    fileID: 'cloud://环境ID.存储桶ID/my-image.png', // 文件 ID
    success: res => {
      console.log(res.tempFilePath) // 下载后的本地临时文件路径
    },
    fail: console.error
  })
},
```

**5. 删除图片**

```js
delfile: function () {
  // 要删除的文件 id
  const fileID = "cloud://环境ID.存储桶ID/my-image.png"
  wx.cloud.deleteFile({
    fileList: [fileID],
    success: res => {
      console.log(res.fileList)
    }
  })
},
```
