# 12 原型速建

从本章开始进入项目实战：开发一个带 Flask 后端管理系统的点餐（美食）小程序。本章完成项目原型的快速搭建——创建虚拟环境、导入项目原型骨架、配置多环境配置文件、跑通 HelloWorld，再导入现成的 web 资源（后台管理页面），让首页和登录页面可以在浏览器中正常打开。

## 12.1 项目环境搭建

本项目采用前后端分离架构：

- 常规前后端分离：前端（网页）——请求——后端（服务 + 数据库）
- 本项目：前端（小程序端）——请求——后端服务（后端管理页面（前端）+ 后端业务逻辑 + 数据库），即小程序端和后端管理页面共用同一套后端业务逻辑与数据库

搭建步骤：

**1. 创建虚拟环境**

```bash
mkvirtualenv food0228
```

**2. 安装项目依赖**

```bash
pip install flask flask-sqlalchemy mysqlclient -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 12.2 导入及分析项目原型

把课程资源中的「项目原型」导入工程（项目名为 `pro_food`），原型骨架的目录结构如下：

```
pro_food/
├── common/            # 公共模块（libs、tools 等）
├── config/            # 配置文件（base_setting、local_setting、production_setting）
├── docs/              # 文档
├── jobs/              # 定时/异步任务
├── web/
│   ├── models/        # 数据模型
│   ├── static/        # 静态资源
│   ├── templates/     # 模板
│   └── views/         # 视图（蓝图）
│       └── index.py
├── application.py     # 应用工厂：自定义 Application 类
├── manager.py         # 启动入口
├── requirements.txt   # 依赖清单
└── www.py             # 蓝图注册等路由装配
```

## 12.3 指定加载配置文件

在 `application.py` 中自定义 `Application` 类继承 `Flask`，在初始化时按运行环境加载不同的配置文件：

```python
import platform

class Application(Flask):
    def __init__(self, import_name, template_folder=None):
        super(Application, self).__init__(import_name, template_folder=template_folder)

        self.config.from_pyfile('config/base_setting.py')  # 不管本地还是线上都需要的配置
        if platform.system().lower() == "windows":
            self.config.from_pyfile('config/local_setting.py')
        elif platform.system().lower() == "linux":
            self.config.from_pyfile('config/production_setting.py')
        else:
            self.config.from_pyfile('config/local_setting.py')

        db.init_app(self)
```

要点：

- `base_setting.py`：本地和线上都需要的公共配置，始终加载。
- 通过 `platform.system()` 判断操作系统：Windows 加载 `local_setting.py`（本地开发），Linux 加载 `production_setting.py`（线上部署）。
- 也可以通过环境变量 `ops_config` 选择加载 `local` 或 `production` 配置（`self.config.from_pyfile('config/%s_setting.py' % os.environ['ops_config'])`），本项目简化为按操作系统判断。
- 最后调用 `db.init_app(self)` 把 SQLAlchemy 绑定到应用上。

## 12.5 导入 web 资源，测试首页和登录页面

把课程资源中的 web 资源（后台管理系统的前端页面）导入到项目的 `web` 目录下，包含：

- `static/`：静态资源（CSS、JS、图片等）
- `templates/`：模板文件
- `views/`：视图（蓝图），含 `account`、`food`、`member`、`user` 等子模块
- `UrlManager.py`：URL 构建工具类

导入后按以下步骤接线：

**1. 加载用户 user 视图：在 `www.py` 中导入 user 视图蓝图并注册路由**

```python
from web.views.user.User import route_user
app.register_blueprint(route_user, url_prefix="/user")
```

**2. 拷贝 `UrlManager.py` 文件到 `common/libs` 目录**

**3. 在 `www.py` 添加 static 静态资源路由**

```python
from web.views.static import route_static
app.register_blueprint(route_static, url_prefix="/static")
```

**4. 在 `application.py` 添加全局模板参数及根路径配置**

给 `Application.__init__` 增加 `root_path` 参数并关闭 Flask 默认的 static 目录（静态资源改用自定义接口加载），同时在模块底部创建 `db` 与 `app`：

```python
from flask import Flask
from flask_sqlalchemy import SQLAlchemy
import os, platform


class Application(Flask):
    # 增加 root_path
    def __init__(self, import_name, template_folder=None, root_path=None):
        super(Application, self).__init__(import_name,
                                          template_folder=template_folder,
                                          root_path=root_path,
                                          static_folder=None)

        self.config.from_pyfile('config/base_setting.py')  # 不管本地还是线上都需要的配置
        if platform.system().lower() == "windows":
            self.config.from_pyfile('config/local_setting.py')
        elif platform.system().lower() == "linux":
            self.config.from_pyfile('config/production_setting.py')
        else:
            self.config.from_pyfile('config/local_setting.py')

        db.init_app(self)


db = SQLAlchemy()

template_folder = os.getcwd() + "/web/templates/"
print('template_folder:', template_folder)

app = Application(__name__, template_folder=template_folder, root_path=os.getcwd())

"""
函数模板
"""
from common.libs.UrlManager import UrlManager

app.add_template_global(UrlManager.buildStaticUrl, "buildStaticUrl")
app.add_template_global(UrlManager.buildUrl, "buildUrl")
```

- `template_folder` 指向 `web/templates/`，`root_path` 取当前工作目录，保证模板和静态资源能被正确定位。
- 通过 `add_template_global` 把 `buildStaticUrl` 和 `buildUrl` 注册为模板全局函数，模板中统一用它们生成静态资源和页面链接。

**5. 自定义静态资源接口**

注意：静态资源不使用 Flask 默认的 static 路由，而是采用自定义接口进行资源加载。在 `web/views/static.py` 中：

```python
# -*- coding: utf-8 -*-
route_static = Blueprint('static', __name__)

@route_static.route("/<path:filename>")
def index(filename):
    return send_from_directory(app.root_path + "/web/static/", filename)
```

`www.py` 中完整的蓝图注册如下：

```python
from application import app
# 导入蓝图
from web.views.index import route_index
from web.views.user.User import route_user
from web.views.static import route_static

# 注册蓝图
app.register_blueprint(route_index, url_prefix="/")
app.register_blueprint(route_user, url_prefix="/user")
app.register_blueprint(route_static, url_prefix="/static")
```

**6. 测试首页和登录页面**

重新运行项目，访问首页可以看到后台管理仪表盘（左侧菜单含仪表盘、账号管理、美食管理、会员列表、财务管理、统计管理等，主区域展示营收概况、订单、会员、分享等统计卡片）；访问 `/user/login` 可以打开登录页面（用户名、密码输入框和登录按钮）。至此原型搭建完成。

## 12.6 扩展：自动生成 User 模型类

手写模型类费时且容易和表结构不一致，可以用 `flask-sqlacodegen` 根据已有数据表自动生成模型类。

**1. 安装包**

```bash
pip install flask-sqlacodegen
```

**2. 生成 user 表的模型类**

```bash
flask-sqlacodegen mysql://root:123456@127.0.0.1/food_db --tables user --outfile "web/models/user.py" --flask
```

参数说明：

| 参数 | 含义 |
| --- | --- |
| `mysql://root:123456@127.0.0.1/food_db` | 数据库连接串（用户名:密码@地址/库名） |
| `--tables user` | 只为 `user` 表生成模型 |
| `--outfile "web/models/user.py"` | 输出文件路径 |
| `--flask` | 生成 Flask-SQLAlchemy 风格的模型类 |

**3. 修改自动生成的 `user.py` 模块文件**

生成的文件默认自带 `db = SQLAlchemy()`，要改成从项目统一的 `application` 模块导入，保证所有模型共用同一个 `db` 实例：

```python
from application import db
```

生成的 `User` 模型与 `user` 表字段一一对应（包括 `uid`、`login_name`、`login_pwd`、`login_salt` 等），后续登录、账号管理等模块直接基于它做查询。
