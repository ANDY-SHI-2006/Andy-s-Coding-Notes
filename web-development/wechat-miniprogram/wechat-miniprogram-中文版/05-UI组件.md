# 5 UI 组件

组件是小程序视图层的基本组成单元，自带与微信风格一致的功能和样式。本章系统梳理常用内置组件：组件的通用属性规则、视图容器（view / swiper / scroll-view）、基础内容组件（icon / text / rich-text）、表单组件、导航组件 navigator、媒体组件（image / camera / video），最后通过一个「王者荣耀抽奖模拟器」综合案例串联所学。

官方文档：https://developers.weixin.qq.com/miniprogram/dev/framework/view/component.html

## 5.1 小程序 UI 组件概述

### 5.1.1 什么是组件

- 组件是视图层的基本组成单元。
- 组件自带一些功能与微信风格一致的样式。
- 一个组件通常包括**开始标签**和**结束标签**，**属性**用来修饰这个组件，**内容**在两个标签之内。

```html
<tagname property="value">
Content goes here ...
</tagname>
```

> 注意：所有组件与属性都是小写，以连字符 `-` 连接。

### 5.1.2 属性值类型

| 类型 | 描述 | 注解 |
| --- | --- | --- |
| Boolean | 布尔值 | 组件写上该属性，不管是什么值都被当作 `true`；只有组件上没有该属性时，属性值才为 `false`。如果属性值为变量，变量的值会被转换为 Boolean 类型 |
| Number | 数字 | `1`, `2.5` |
| String | 字符串 | `"string"` |
| Array | 数组 | `[ 1, "string" ]` |
| Object | 对象 | `{ key: value }` |
| EventHandler | 事件处理函数名 | `"handlerName"` 是 Page 中定义的事件处理函数名 |
| Any | 任意属性 | |

### 5.1.3 公共属性

所有组件都有以下属性：

| 属性名 | 类型 | 描述 | 注解 |
| --- | --- | --- | --- |
| id | String | 组件的唯一标示 | 保持整个页面唯一 |
| class | String | 组件的样式类 | 在对应的 WXSS 中定义的样式类 |
| style | String | 组件的内联样式 | 可以动态设置的内联样式 |
| hidden | Boolean | 组件是否显示 | 所有组件默认显示 |
| data-* | Any | 自定义属性 | 组件上触发的事件时，会发送给事件处理函数 |
| bind* / catch* | EventHandler | 组件的事件 | 详见事件章节 |

### 5.1.4 特殊属性

几乎所有组件都有各自定义的属性，可以对该组件的功能或样式进行修饰，请参考各个组件的定义。

### 5.2.2 swiper 与 swiper-item

滑块视图容器。其中只可放置 `swiper-item` 组件，否则会导致未定义的行为。

swiper 常用属性：

| 属性 | 类型 | 默认值 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| indicator-dots | boolean | false | 否 | 是否显示面板指示点 |
| indicator-color | color | rgba(0, 0, 0, .3) | 否 | 指示点颜色 |
| autoplay | boolean | false | 否 | 是否自动切换 |
| current | number | 0 | 否 | 当前所在滑块的 index |
| interval | number | 5000 | 否 | 自动切换时间间隔 |
| duration | number | 500 | 否 | 滑动动画时长 |
| vertical | boolean | false | 否 | 滑动方向是否为纵向 |

轮播图示例：

```html
<view class="index_swiper">
  <swiper autoplay indicator-dots circular>
    <swiper-item wx:for="{{swiperList}}">
      <image mode="widthFix" src="{{item}}"></image>
    </swiper-item>
  </swiper>
</view>
```

```css
.index_swiper swiper {
  width: 750rpx;
  height: 340rpx;
}
.index_swiper swiper image {
  width: 100%;
}
```

```js
data: {
  swiperList: ["/images/banner1.png", "/images/banner2.png", "/images/banner3.png"]
},
```

### 5.3.2 文本 text

文本。

### 5.3.3 富文本 rich-text

富文本。

官方文档：https://developers.weixin.qq.com/miniprogram/dev/component/rich-text.html

`rich-text` 通过 `nodes` 属性来接收需要渲染的内容，支持两种格式：

1. 字符串格式（HTML String）
2. 对象数组格式（Node Array）

| 属性 | 类型 | 默认值 | 必填 | 说明 | 最低版本 |
| --- | --- | --- | --- | --- | --- |
| nodes | array/string | [] | 否 | 节点列表 / HTML String | 1.4.0 |
| space | string | | 否 | 显示连续空格 | 2.4.1 |

space 的合法值：

| 合法值 | 说明 |
| --- | --- |
| ensp | 中文字符空格一半大小 |
| emsp | 中文字符空格大小 |
| nbsp | 根据字体设置的空格大小 |

示例：同一段 HTML 字符串，用 text 原样显示、用 rich-text 解析渲染。

```html
<Label>------------富文本rich-text--------</Label>
<view><text>{{htmlSnip}}</text></view>
<view>
  <rich-text nodes="{{htmlSnip}}"></rich-text>
</view>
```

```js
const htmlSnip = `<div class="div_class">
  <h1>Title</h1>
  <p style="color:red">
    Life is&nbsp;<i>like</i>&nbsp;a box of
    <b>&nbsp;chocolates</b>.
  </p>
</div>`

Page({
  /**
   * 页面的初始数据
   */
  data: {
    imgStyle: "img_middle",
    swiperList: ["/images/banner1.png", "/images/banner2.png", "/images/banner3.png"],
    htmlSnip
  },
})
```

渲染效果：`text` 中显示的是 HTML 源码字符串，而 `rich-text` 将其解析为带标题、红色文字、斜体和加粗样式的富文本内容。

## 5.4 表单组件

表单。当点击 form 表单中 form-type 为 submit 的 button 组件时，会将表单组件中的 value 值进行提交，需要在表单组件中加上 name 来作为 key。

常用表单组件及官方文档：

| 组件 | 说明 | 文档 |
| --- | --- | --- |
| form | 表单 | https://developers.weixin.qq.com/miniprogram/dev/component/form.html |
| button | 按钮 | https://developers.weixin.qq.com/miniprogram/dev/component/button.html |
| input | 输入框 | https://developers.weixin.qq.com/miniprogram/dev/component/input.html |
| checkbox | 复选框 | https://developers.weixin.qq.com/miniprogram/dev/component/checkbox.html |
| radio | 单选按钮 | https://developers.weixin.qq.com/miniprogram/dev/component/radio.html |
| slider | 滑动选择器 | https://developers.weixin.qq.com/miniprogram/dev/component/slider.html |
| switch | 开关选择器 | https://developers.weixin.qq.com/miniprogram/dev/component/switch.html |

综合示例：

```html
<view>
  <view>
    <form catchsubmit="formSubmit" catchreset="formReset">
      <view>
        <view>switch</view>
        <switch name="switch" />
      </view>

      <view>
        <view>radio</view>
        <radio-group name="radio">
          <label>
            <radio value="radio1" />选项一
          </label>
          <label>
            <radio value="radio2" />选项二
          </label>
        </radio-group>
      </view>

      <view>
        <view>checkbox</view>
        <checkbox-group name="checkbox">
          <label>
            <checkbox value="checkbox1" />选项一
          </label>
          <label>
            <checkbox value="checkbox2" />选项二
          </label>
        </checkbox-group>
      </view>

      <view>
        <view>slider</view>
        <slider value="50" name="slider" show-value></slider>
      </view>

      <view>
        <view>input</view>
        <view style="margin: 30rpx 0">
          <input name="input" placeholder="这是一个输入框" />
        </view>
      </view>

      <view>
        <button style="margin: 30rpx 0" type="primary" formType="submit">Submit</button>
        <button style="margin: 30rpx 0" formType="reset">Reset</button>
      </view>
    </form>
  </view>
</view>
```

```js
formSubmit(e) {
  console.log('form发生了submit事件，携带数据为：', e.detail.value)
},
```

点击 Submit 后控制台输出示例：`{switch: true, radio: "radio2", checkbox: Array(1), slider: 77, input: "1"}`——每个表单项以其 `name` 作为 key、`value` 作为值提交。

## 5.5 导航组件 navigator

页面链接，用于导航跳转。

官方文档：https://developers.weixin.qq.com/miniprogram/dev/component/navigator.html

说明：

1. navigator 在 Skyline 下视为文本节点，只能嵌套文本节点（如 text），不能嵌套 view、button 等普通节点。
2. 新增 span 组件用于内联文本和图片。

通用属性：

| 属性 | 类型 | 默认值 | 必填 | 说明 | 最低版本 |
| --- | --- | --- | --- | --- | --- |
| target | string | self | 否 | 在哪个目标上发生跳转，默认当前小程序 | 2.0.7 |
| url | string | | 否 | 当前小程序内的跳转链接 | 1.0.0 |
| open-type | string | navigate | 否 | 跳转方式 | |

target 的合法值：

| 值 | 说明 |
| --- | --- |
| self | 当前小程序 |
| miniProgram | 其它小程序 |

open-type 的合法值：

| 值 | 说明 | 最低版本 |
| --- | --- | --- |
| navigate | 对应 wx.navigateTo 或 wx.navigateToMiniProgram 的功能 | |
| switchTab | 对应 wx.switchTab 的功能 | |
| exit | 退出小程序，`target="miniProgram"` 时生效 | 2.1.0 |

提示：

- open-type 的值如果设置为 navigate 则可以拥有回退按钮；如果设置为 redirect 则没有回退按钮。
- navigate、redirect 这两个值和 switchTab 这个值的区别在于前面两个不能跳转到带 tabBar 的页面；而 switchTab 可以。

示例：

```html
<!-- 假如跳转到tabbar关联的页面，则需open-type="switchTab" -->
<navigator url="/pages/index/index" open-type="switchTab">跳转到首页</navigator>
<!-- open-type="navigate" 拥有回退按钮 -->
<navigator url="/pages/tap_test/tap_test" open-type="navigate">跳转到tap_test首页</navigator>
<navigator url="/pages/logs/logs" open-type="redirect">跳转到基本logs页</navigator>
<view bind:tap="tapEnterForm">通过事件代码进入视图容器页</view>
```

```js
tapEnterForm: function() {
  wx.navigateTo({
    url: '/pages/index/index',
  })
},
```

## 5.6 媒体组件

### 5.6.1 image

图片。支持 JPG、PNG、SVG、WEBP、GIF 等格式，2.3.0 起支持云文件 ID。

官方文档：https://developers.weixin.qq.com/miniprogram/dev/component/image.html

核心属性：

| 属性名 | 类型 | 默认值 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `src` | String | - | 是 | 图片资源地址，支持本地路径、网络路径、云存储路径等 |
| `mode` | String | `scaleToFill` | 否 | 图片裁剪、缩放的填充模式，合法值见下方详细说明 |

mode 属性合法值（图片填充方式）：

| 值 | 说明 |
| --- | --- |
| `scaleToFill` | 缩放模式，不保持图片原始纵横比，将图片宽高完全拉伸至填满 image 元素，可能导致图片变形 |
| `aspectFit` | 缩放模式，保持图片原始纵横比，确保图片的长边完全显示，可完整展示整张图片，不会出现裁剪 |
| `aspectFill` | 缩放模式，保持图片原始纵横比，确保图片的短边完全显示，图片仅在水平或垂直方向完整，另一方向会被裁剪 |
| `widthFix` | 缩放模式，固定图片宽度，高度自动按原始宽高比缩放，适配不同屏幕宽度 |
| `heightFix` | 缩放模式，固定图片高度，宽度自动按原始宽高比缩放，适配不同屏幕高度 |

提示：

1. image 组件默认宽度 320px、高度 240px。
2. image 组件中二维码/小程序码图片不支持长按识别，仅在 wx.previewImage 中支持长按识别。
3. 使用 svg 格式且 mode=scaleToFill 时，WebView 会居中（除非 svg 里加上 `preserveAspectRatio="none"`），Skyline 则会撑满；svg 格式不支持百分比单位。

### 5.6.2 camera

系统相机，可实现扫码二维码功能。

官方文档：https://developers.weixin.qq.com/miniprogram/dev/component/camera.html

核心属性：

| 属性名 | 类型 | 默认值 | 必填 | 说明 | 最低版本 |
| --- | --- | --- | --- | --- | --- |
| `mode` | String | `normal` | 否 | 相机组件的应用模式，仅在组件初始化时生效，不支持动态变更 | 2.1.0 |
| `resolution` | String | `medium` | 否 | 相机的分辨率等级，决定拍摄画面的清晰度，不支持动态修改 | 2.10.0 |

mode 属性合法值：

| 值 | 说明 | 最低版本 |
| --- | --- | --- |
| `normal` | 标准相机模式，支持拍照、录像基础功能 | 2.1.0 |
| `scanCode` | 扫码识别模式，可直接用于二维码 / 条形码扫描 | 2.1.0 |

resolution 属性合法值：

| 值 | 说明 | 最低版本 |
| --- | --- | --- |
| `low` | 低分辨率，适配性能较低的设备，画面清晰度较低、加载更快 | 2.10.0 |
| `medium` | 中分辨率，默认值，平衡画面清晰度与设备性能，适配绝大多数场景 | 2.10.0 |
| `high` | 高分辨率，拍摄画面更清晰，对设备性能与存储空间要求更高 | 2.10.0 |

> 提示：同一页面只能插入一个 camera 组件。

拍照示例：

```html
<!-- camera.wxml -->
<camera style=" height: 300px;width: 100%;" mode="normal"></camera>
<button type="primary" bindtap="takePhoto">拍照</button>
<view>预览</view>
<image mode="widthFix" src="{{src}}"></image>
```

```js

        const ctx = wx.createCameraContext()
        ctx.takePhoto({
            quality: 'high',

            }
```

### 5.7.2 抽奖页逻辑 draw.js

```javascript
// 英雄奖池配置
const heroPool = {
  legend: [
    { name: "李白-凤求凰", level: "legend", levelText: "传说" },
    { name: "孙悟空-全息碎影", level: "legend", levelText: "传说" },
    { name: "貂蝉-仲夏夜", level: "legend", levelText: "传说" }
  ],
  epic: [
    { name: "瑶-遇见神鹿", level: "epic", levelText: "史诗" },
    { name: "澜-逐浪", level: "epic", levelText: "史诗" },
    { name: "曜-云鹰飞将", level: "epic", levelText: "史诗" },
    { name: "孙尚香-时之恋人", level: "epic", levelText: "史诗" }
  ],
  rare: [
    { name: "安琪拉", level: "rare", levelText: "稀有" },
    { name: "亚瑟", level: "rare", levelText: "稀有" },
    { name: "妲己", level: "rare", levelText: "稀有" },
    { name: "后羿", level: "rare", levelText: "稀有" },
    { name: "铠", level: "rare", levelText: "稀有" },
    { name: "孙膑", level: "rare", levelText: "稀有" }
  ]
}

Page({
  data: {
    isDrawing: false, // 是否正在抽奖，防止重复点击
    isShake: false, // 抖动动画
    showResult: false, // 弹窗显示
    resultHeroList: [], // 本次抽到英雄数组
    totalDraw: 0, // 总抽奖次数
    bottomCount: 0, // 保底计数，90抽必出传说
    remainBottom: 90 // 剩余保底次数
  },

  onShow() {
    // 读取本地缓存数据
    let saveData = wx.getStorageSync("drawSave") || { total: 0, bottom: 0, ownHero: [] };
    let remain = 90 - saveData.bottom;
    this.setData({
      totalDraw: saveData.total,
      bottomCount: saveData.bottom,
      remainBottom: remain > 0 ? remain : 0
    })
  },

  // 单抽
  singleDraw() {
    this.startDraw(1);
  },

  // 十连抽
  tenDraw() {
    this.startDraw(10);
  },

  // 核心抽奖逻辑
  startDraw(num) {
    this.setData({ isDrawing: true, isShake: true });
    setTimeout(() => {
      let resList = [];
      let saveData = wx.getStorageSync("drawSave") || { total: 0, bottom: 0, ownHero: [] };
      let newBottom = saveData.bottom + num;
      let forceLegend = false;
      // 90抽保底，强制出传说
      if (newBottom >= 90) {
        forceLegend = true;
        newBottom = 0; // 重置保底计数
      }

      // 循环抽取对应次数
      for (let i = 0; i < num; i++) {
        let random = Math.random() * 100;
        let targetHero;
        // 触发保底直接拿传说
        if (forceLegend && i === num - 1) {
          let idx = Math.floor(Math.random() * heroPool.legend.length);
          targetHero = heroPool.legend[idx];
        } else if (random < 3) {
          // 3%概率传说
          let idx = Math.floor(Math.random() * heroPool.legend.length);
          targetHero = heroPool.legend[idx];
        } else if (random < 20) {
          // 17%概率史诗
          let idx = Math.floor(Math.random() * heroPool.epic.length);
          targetHero = heroPool.epic[idx];
        } else {
          // 80%稀有
          let idx = Math.floor(Math.random() * heroPool.rare.length);
          targetHero = heroPool.rare[idx];
        }
        resList.push(targetHero);
        // 存入已拥有英雄（去重）
        if (!saveData.ownHero.find(item => item.name === targetHero.name)) {
          saveData.ownHero.push(targetHero);
        }
      }
      // 更新存储数据
      saveData.total += num;
      saveData.bottom = newBottom;
      wx.setStorageSync("drawSave", saveData);
      // 更新页面数据，弹出结果
      this.setData({
        isDrawing: false,
        isShake: false,
        showResult: true,
        resultHeroList: resList,
        totalDraw: saveData.total,
        bottomCount: newBottom,
        remainBottom: 90 - newBottom
      })
    }, 500)
  },

  // 关闭弹窗
  closeMask() {
    this.setData({ showResult: false })
  },
  // 重置全部抽奖缓存
  resetAllData() {
    // 弹窗确认，防止误点
    wx.showModal({
      title: "重置存档",
      content: "确定清空所有抽奖记录、英雄图鉴、保底次数？数据无法恢复！",
      success: (res) => {
        if (res.confirm) {
          // 1. 删除抽奖缓存key
          wx.removeStorageSync("drawSave")
          // 2. 弹窗提示成功
          wx.showToast({ title: "重置成功" })
          // 3. 刷新页面数据，回到初始0抽状态
          this.onShow()
        }
      }
    })
  }
})
```

代码要点解析：

**（1）heroPool 英雄奖池（数据源）**

定义一个全局对象 `heroPool`，存放所有抽奖能产出的道具，分成 3 个品级池子。每个皮肤 / 英雄是一个对象，包含 3 个属性：

- `name`：展示名称（页面上显示的文字）
- `level`：品级标记（用来给卡片设置不同颜色样式）
- `levelText`：中文品级文字（传说 / 史诗 / 稀有，弹窗展示）

概率规则：传说最难出，稀有最容易。

**（2）Page 的 data 页面数据仓库**

| 变量名 | 作用 |
| --- | --- |
| isDrawing | 抽奖中锁按钮：抽奖时变成 true，按钮 disabled 禁用，防止玩家狂点重复抽奖 |
| isShake | 控制页面抖动动画，抽奖瞬间开启抖动效果 |
| showResult | 弹窗开关，抽完奖设为 true 弹出结果弹窗，点关闭变回 false |
| resultHeroList | 存放本次单抽 / 十连抽抽到的全部道具，弹窗循环渲染展示 |
| totalDraw | 统计一共抽了多少次，页面顶部展示 |
| bottomCount | 保底计数器，每抽一次 + 1，满 90 强制出传说，然后清零 |
| remainBottom | 90 - bottomCount，页面显示「距离保底剩余 XX 抽」 |

知识点：小程序所有页面渲染数据都存在 data，用 `this.setData({})` 更新页面视图。

**（3）onShow 生命周期函数**

- `onShow`：每次切换到这个抽奖页面都会自动执行（从图鉴页切回来、重新打开小程序都会触发）。
- `wx.getStorageSync("drawSave")`：读取微信本地缓存，永久保存抽奖数据，关闭小程序数据不丢失。
- `|| { total: 0, bottom: 0, ownHero: [] }` 容错判断：第一次打开小程序，缓存里没有 drawSave，会返回空；空的话就默认给一套初始数据：总次数 0、保底 0、拥有英雄空数组。
- 计算剩余保底次数 `remain = 90 - 当前保底计数`。
- `this.setData`：把缓存里的数据同步到页面，页面立刻更新显示总次数、剩余保底抽数。

缓存 saveData 里面存了 3 个东西：

- `total`：累计总抽奖次数
- `bottom`：当前保底累计次数
- `ownHero`：玩家抽到过的所有英雄（去重，给图鉴页面使用）

**（4）快捷点击函数：单抽、十连抽**

WXML 页面的按钮绑定 `bindtap="singleDraw"` / `bindtap="tenDraw"`；两个函数不写复杂逻辑，只调用核心抽奖函数 `startDraw()`；传参数字：1 = 抽 1 次，10 = 一次性抽 10 次，复用同一套抽奖逻辑，不用写两套重复代码。

**（5）核心抽奖函数 startDraw(num)**

- 抽奖动画前置：`this.setData({ isDrawing: true, isShake: true })` 按钮锁住，页面开始抖动动画；`setTimeout(..., 500)` 延时 500 毫秒，模拟抽奖转动等待效果。
- 初始化变量：`resList = []` 空数组存放本次抽到的所有道具；再次读取本地存档 saveData；`newBottom = saveData.bottom + num` 保底计数加上本次抽的次数；如果累计达到 / 超过 90 抽，开启强制传说标记 `forceLegend = true`，并把保底清零。
- 循环抽奖 + 概率逻辑：抽几次就循环几次；`Math.random() * 100` 生成 0 ~ 99.99 的随机小数判定品级：0 ~ 3（3%）传说、3 ~ 20（17%）史诗、20 ~ 100（80%）稀有；保底特殊规则：触发保底时十连的最后一发（`i === num - 1`）强制给传说；`Math.floor(Math.random() * 池子长度)` 随机从对应品级池里挑一个英雄。
- 保存抽到的英雄：`resList.push(targetHero)` 把抽到的英雄加入本次结果数组弹窗展示；`saveData.ownHero.find(...)` 去重判断，图鉴里没有这个英雄才放进拥有列表，重复抽到已有皮肤图鉴不会重复新增。
- 收尾：更新存档总次数、保底计数；`wx.setStorageSync` 把更新后的数据重新存入本地缓存；`this.setData` 恢复页面状态：解除按钮锁定、关闭抖动动画、打开结果弹窗传入本次抽奖列表、同步更新页面顶部总抽数和剩余保底次数。

**（6）关闭弹窗函数**

弹窗「收下英雄」按钮绑定 `closeMask`，把弹窗开关 `showResult` 设为 false，弹窗消失，回到抽奖主界面。

1. 打开抽奖页面 → onShow 读取本地存档，加载历史抽奖数据；
2. 点击单抽 / 十连按钮 → 调用 startDraw(1/10)；
3. 页面锁定按钮、开启抖动动画，等待 500ms 模拟抽奖；
4. 根据传入次数循环随机抽英雄，判定概率，90 抽保底强制传说；
5. 抽到的英雄去重存入图鉴列表；
6. 更新总抽奖次数、保底计数，存入本地缓存永久保存；
7. 关闭抖动、解锁按钮，弹出抽奖结果弹窗展示抽到的皮肤；
8. 点击收下英雄，弹窗关闭，可继续抽奖；
9. 切换到图鉴页面会读取缓存里的 ownHero，展示全部收集到的英雄。
