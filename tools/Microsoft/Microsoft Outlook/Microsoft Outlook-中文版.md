## 3.2 to（收件人） / cc（抄送） / bcc（密件抄送） 的区别

![[Pasted image 20260721134709.png]]

| 字段 | 全称 | 中文 | 是否互相可见 | 典型使用场景 |
|------|------|------|-------------|-------------|
| To | - | 收件人 | 所有人可见 | 邮件的主要对象，需要直接处理或回复 |
| CC | Carbon Copy | 抄送 | 所有人可见 | 需要知晓此事，但不需要主处理 |
| BCC | Blind Carbon Copy | 密件抄送 | 对 To/CC 不可见；BCC 之间互相不可见 | 悄悄通知某人，或群发时保护隐私 |

### 3.2.1 核心区别

**To（收件人）**：邮件的主要对象，必须处理这封邮件。
**CC（抄送）**：次要对象，只需要知道这件事，不强制要求处理。
**BCC（密件抄送）**：悄悄发给某个人，其他收件人完全不知道他被发了这封邮件。

### 3.2.2 谁能看见谁？

从某个收件人的视角看：

| 如果你是... | 你能看见 To 吗？ | 你能看见 CC 吗？ | 你能看见 BCC 吗？ |
|------------|---------------|---------------|------------------|
| To 中的人 | ✅ 能 | ✅ 能 | ❌ 不能 |
| CC 中的人 | ✅ 能 | ✅ 能 | ❌ 不能 |
| BCC 中的人 | ✅ 能 | ✅ 能 | ❌ 不能（看不到其他 BCC）|
| 发件人自己 | ✅ 能 | ✅ 能 | ✅ 能 |

也就是说：
- **To 和 CC 的人互相知道彼此**。
- **BCC 的人能看到 To 和 CC**，但 To 和 CC 看不到 BCC。
- **BCC 的人之间也互相不知道**。

### 3.2.3 什么时候用 BCC？

1. **群发邮件保护隐私**
   - 给全班同学、全公司同事发通知时，把所有人放在 BCC 里。
   - 这样每个人只能看到自己的邮箱，看不到其他人的邮箱。

2. **悄悄通知第三方**
   - 让领导、HR、审计知道某件事，但不想让主收件人知道。

3. **保护敏感关系**
   - 例如客户邮件中 BCC 给自己的经理，让客户不知道经理也在看。

### 3.2.4 注意事项

- **BCC 的人如果点“全部回复”**，他的回复只会发给发件人和 To/CC 的人，不会发给其他 BCC 的人。
- **BCC 的人不能通过邮件本身知道还有谁也被 BCC 了**。
- 如果误把应该保密的人放在 To 或 CC，所有人都会看见，无法撤回这个可见性。

## 3.3 如何标识重要邮件？

### 3.3.1 重要性

![[Pasted image 20260721140716.png]]

Outlook 提供两种重要性级别，用于告诉收件人邮件的紧急程度：

| 级别 | 图标 | 含义 | 使用建议 |
|------|------|------|----------|
| 高重要性 | 红色感叹号 | 邮件紧急，需要优先处理 | 只在真正紧急时使用，滥用会让别人麻木 |
| 低重要性 | 蓝色向下箭头 | 邮件不紧急，可稍后处理 | 适合群发通知、 FYI 类邮件 |
| 默认 | 无图标 | 普通邮件 | 大多数情况使用默认即可 |

**注意**：重要性标记是收件人能看见的，但它只是视觉提示，不会强制对方优先处理。

### 3.3.2 后续标志

![[Pasted image 20260721141247.png]]

后续标志主要用来**提醒发件人自己**跟进某封邮件，但收件人也能看到一个小旗帜图标。

| 使用场景 | 说明 |
|---------|------|
| 发件时设置 | 邮件发送后，发件人自己的“待办/跟进”列表里会出现这封邮件，到时间提醒 |
| 收件时设置 | 给自己收到的邮件设置后续，提醒稍后处理 |
| 收件人视角 | 能看到邮件上有旗帜，但不会在电脑上弹窗提醒 |

**注意**：后续标志**不是强制提醒**，更像是一个备忘 + 视觉提示。

### 3.3.3 分配策略

![[Pasted image 20260721141446.png]]

分配策略用来给邮件指定**保留、存档或删除规则**，主要在企业或学校邮箱（Exchange/Office 365）中使用。

| 要点 | 说明 |
|------|------|
| 作用对象 | 只影响发件人自己邮箱里的邮件副本（如“已发送邮件”） |
| 是否影响收件人 | 不影响，收件人收到的邮件由他自己的邮箱策略管理 |
| 常见策略 | 保留 1 年、保留 5 年、1 个月后存档、自动删除 |
| 个人用户 | 普通个人邮箱一般没有这个功能，或按钮灰色不可用 |

**注意**：如果邮箱管理员没有配置策略，这个按钮可能无法使用。

## 3.4 如何设置定时发送邮件？

### 3.4.1 为什么要定时发送？

定时发送不是让邮件“飞一会儿”，而是选择一个更合适的送达时间，常见原因：

- **提高被查看概率**：在对方上班后、收件箱最空的时候送达，邮件会排在较上方，更容易被看到。
- **避免打扰休息时间**：深夜或周末写完邮件，可以定时到工作时间再发送，显得更专业。
- **跨时区沟通**：给国外收件人定时到对方工作日上午发送，不用熬夜守点发。
- **提前安排**：节假日祝福、周报、会议提醒等可以提前写好，定时到合适时间发出。

**注意**：定时发送依赖 Outlook 处于运行状态。如果到点时电脑关机或 Outlook 未打开，邮件可能等到下次打开时才发送。

### 3.4.2 如何设置定时发送？

1. 写好邮件后，点击功能区 **“选项”** 选项卡。
2. 找到 **“延迟传递”** 按钮。
3. 在弹出窗口中勾选 **“传递不早于”**，设置具体日期和时间。
4. 点击 **“关闭”**。
5. 点击“发送”。邮件会先进入 **“发件箱”**，到时间自动发出。

![[Pasted image 20260721142137.png]]

### 3.4.3 取消或修改

- 发送前：如果还没点击“发送”，直接修改时间即可。
- 发送后但在定时时间前：到“发件箱”中找到邮件，双击打开后可删除或重新设置时间。

## 3.5 如何将邮件作为附件发送？

### 3.5.1 为什么要作为附件发送？

把邮件作为附件转发，而不是直接点击“转发”，主要有这些好处：

- **保留完整原始信息**：包括原始发件人、收件人、抄送、时间戳、邮件头信息等。
- **避免格式错乱**：直接转发有时会改变原邮件排版，附件形式更完整。
- **批量转发多封邮件**：可以一次性把几封邮件打包作为附件发出。
- **作为证据或存档**：需要提交邮件记录时，附件形式更正式。

### 3.5.2 方法一：复制 + 粘贴

1. 在邮件列表中，右键点击要作为附件的邮件。
2. 选择 **“复制”**（或按 `Ctrl` + `C`）。

![[Pasted image 20260721153715.png|415]]

3. 打开一封新邮件，在正文区域右键点击。
4. 选择 **“粘贴”**（或按 `Ctrl` + `V`）。
5. 原邮件就会以 `.msg` 附件的形式出现在新邮件中。

![[Pasted image 20260721153956.png]]

### 3.5.3 方法二：通过“附加项目”插入

1. 在新邮件中，点击功能区 **“邮件”** 选项卡。
2. 点击 **“附加文件”** 按钮旁的下拉箭头。
3. 选择 **“附加项目”**（Outlook Item）。

![[Pasted image 20260721153820.png]]

4. 在弹出的对话框中，选择要插入的邮件。
5. 可以选择插入为 **“附件”**（默认）或 **“文本”**。

![[Pasted image 20260721153849.png]]

6. 点击 **“确定”**，邮件就会作为附件添加。

**注意**：如果附件邮件本身也带有附件，这些附件会一并保留在原邮件中。

### 3.5.4 方法三：拖拽

1. 在邮件列表中，按住鼠标左键选中要作为附件的邮件。
2. 直接把它拖拽到新建邮件的正文区域。
3. 松开鼠标，原邮件就会以 `.msg` 附件的形式出现在新邮件中。

**注意**：如果同时选中多封邮件一起拖拽，可以一次性把多封邮件作为附件发出。

## 3.6 发错邮件后如何补救？

### 3.6.1 什么情况下能撤回？

Outlook 的“撤回邮件”功能**并不是万能的**，成功率取决于以下条件：

| 条件 | 能否撤回 |
|------|---------|
| 收件人和发件人在同一 Exchange/Office 365 组织内 | ✅ 通常可以 |
| 收件人使用 Outlook 客户端（不是网页版/手机端） | ✅ 成功率较高 |
| 收件人尚未阅读邮件 | ✅ 更有可能成功 |
| 收件人是外部邮箱（如 Gmail、QQ、163） | ❌ 几乎无法撤回 |
| 收件人已阅读或已转发 | ❌ 无法撤回 |
| 邮件已离开内部服务器 | ❌ 无法撤回 |

**总结**：撤回功能最适合在企业/学校内部 Exchange 邮箱之间使用，对外部邮箱基本无效。

### 3.6.2 如何撤回邮件？

1. 打开 Outlook 的 **“已发送邮件”** 文件夹。
2. 双击打开要撤回的邮件。
3. 点击功能区 **“邮件”** 选项卡。
4. 点击 **“操作”** → **“撤回该邮件”**。
5. 在弹出的对话框中选择：
   - **“删除未读副本”**：直接撤回，不留痕迹。
   - **“删除未读副本并用新邮件替换”**：撤回后自动打开新邮件编辑窗口。
6. 点击 **“确定”**。

![[Pasted image 20260721155113.png]]

![[Pasted image 20260721155148.png|395]]

### 3.6.3 撤回失败怎么办？

如果撤回失败或无法撤回，可以用以下方式补救：

1. **发送澄清邮件**
   - 主题写“补充说明 / 更正 / 关于上一封邮件”等。
   - 正文中明确说明上一封邮件哪里错了，正确内容是什么。

2. **重新发送正确版本**
   - 如果上一封邮件附件/内容有误，重新发送完整正确版本，并在主题中标注“以此为准”。

3. **主动联系收件人**
   - 对于重要邮件，直接打电话或发即时消息说明情况，请对方忽略上一封邮件。

### 3.6.4 注意事项

- **撤回不保证成功**：即使系统提示“撤回成功”，收件人仍可能在撤回前看到邮件。
- **已读未读判断的是对方 Outlook 里的邮件状态**：如果对方已经读过了邮件，但手动右键把它重新标记为“未读”，那么从 Outlook 撤回机制的角度看，它仍然是“未读”，理论上仍可能撤回成功。但这依赖对方的具体操作，不能作为可靠依据。
- **不要滥用撤回**：频繁撤回会显得不专业。
- **发送前检查**：养成发送前检查收件人、主题、附件、正文的习惯，减少出错概率。
