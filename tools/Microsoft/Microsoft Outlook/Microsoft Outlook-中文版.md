# 2 如何设置及使用邮件签名？

## 2.1 什么是邮件签名，如何自定义邮件签名？

### 2.1.1 什么是邮件签名

邮件签名是**自动附加在每封邮件末尾的信息块**，通常包含姓名、职务、公司、联系方式等。设置一次后，写邮件时 Outlook 会自动带上，不用每次手动输入。

### 2.1.2 如何创建

1. 打开一封**新邮件**窗口。
2. 点击功能区 **「插入」** 选项卡 → **「签名」** → **「签名」**（打开「签名和信纸」窗口；「邮件」选项卡下也有同样的「签名」入口）。

![[Pasted image 20260721133317.png|697]]

3. 点击 **「新建」**，输入签名名称（如「工作签名」）。
4. 在下方编辑区输入签名内容，可设置字体、字号、颜色，也可插入图片、公司 Logo 或电子名片。

![[Pasted image 20260721132856.png]]

5. 点击「确定」保存。

### 2.1.3 注意事项

- 签名内容建议包含：**姓名、职务、公司、电话、邮箱**，方便对方联系。
- 插入的图片不宜过大，否则每封邮件都会变大，且部分邮箱会把图片当附件处理。
- 可以创建**多个签名**（如中文版、英文版、简版），发送时按需选择（见 2.3）。

## 2.2 如何让新建邮件与回复和转发邮件使用不一样的邮件签名？

1. 打开「签名和信纸」窗口（新邮件 → 「邮件」选项卡 → 「签名」→「签名」）。
2. 在窗口**右上角的「选择默认签名」区域**：
   - **「新邮件」**：选择完整版签名（含 Logo、完整联系方式）。
   - **「答复/转发」**：选择简版签名（只有姓名和电话即可）。

![[Pasted image 20260721133543.png]]

3. 点击「确定」。

**注意**：回复和转发用简版签名，可以避免邮件来回多次后签名越堆越长，让邮件串更干净。

## 3.2 to（收件人） / cc（抄送） / bcc（密件抄送） 的区别

![[Pasted image 20260721134709.png]]

| 字段 | 全称 | 中文 | 是否互相可见 | 典型使用场景 |
|------|------|------|-------------|-------------|
| To | - | 收件人 | 所有人可见 | 邮件的主要对象，需要直接处理或回复 |
| CC | Carbon Copy | 抄送 | 所有人可见 | 需要知晓此事，但不需要主处理 |
| BCC | Blind Carbon Copy | 密件抄送 | 对 To/CC 不可见；BCC 之间互相不可见 | 悄悄通知某人，或群发时保护隐私 |

### 3.2.1 核心区别

**To（收件人）**：邮件的主要对象，必须处理这封邮件。
**CC（抄送）**：次要对象，只需要知道这件事，不强制要求处理。
**BCC（密件抄送）**：悄悄发给某个人，其他收件人完全不知道他被发了这封邮件。

### 3.2.2 谁能看见谁？

从某个收件人的视角看：

| 如果你是... | 你能看见 To 吗？ | 你能看见 CC 吗？ | 你能看见 BCC 吗？ |
|------------|---------------|---------------|------------------|
| To 中的人 | ✅ 能 | ✅ 能 | ❌ 不能 |
| CC 中的人 | ✅ 能 | ✅ 能 | ❌ 不能 |
| BCC 中的人 | ✅ 能 | ✅ 能 | ❌ 不能（看不到其他 BCC）|
| 发件人自己 | ✅ 能 | ✅ 能 | ✅ 能 |

也就是说：
- **To 和 CC 的人互相知道彼此**。
- **BCC 的人能看到 To 和 CC**，但 To 和 CC 看不到 BCC。
- **BCC 的人之间也互相不知道**。

### 3.2.3 什么时候用 BCC？

1. **群发邮件保护隐私**
   - 给全班同学、全公司同事发通知时，把所有人放在 BCC 里。
   - 这样每个人只能看到自己的邮箱，看不到其他人的邮箱。

2. **悄悄通知第三方**
   - 让领导、HR、审计知道某件事，但不想让主收件人知道。

3. **保护敏感关系**
   - 例如客户邮件中 BCC 给自己的经理，让客户不知道经理也在看。

### 3.2.4 注意事项

- **BCC 的人如果点“全部回复”**，他的回复只会发给发件人和 To/CC 的人，不会发给其他 BCC 的人。
- **BCC 的人不能通过邮件本身知道还有谁也被 BCC 了**。
- 如果误把应该保密的人放在 To 或 CC，所有人都会看见，无法撤回这个可见性。

## 3.3 如何标识重要邮件？

### 3.3.1 重要性

![[Pasted image 20260721140716.png]]

Outlook 提供两种重要性级别，用于告诉收件人邮件的紧急程度：

| 级别 | 图标 | 含义 | 使用建议 |
|------|------|------|----------|
| 高重要性 | 红色感叹号 | 邮件紧急，需要优先处理 | 只在真正紧急时使用，滥用会让别人麻木 |
| 低重要性 | 蓝色向下箭头 | 邮件不紧急，可稍后处理 | 适合群发通知、 FYI 类邮件 |
| 默认 | 无图标 | 普通邮件 | 大多数情况使用默认即可 |

**注意**：重要性标记是收件人能看见的，但它只是视觉提示，不会强制对方优先处理。

### 3.3.2 后续标志

![[Pasted image 20260721141247.png]]

后续标志主要用来**提醒发件人自己**跟进某封邮件，但收件人也能看到一个小旗帜图标。

| 使用场景 | 说明 |
|---------|------|
| 发件时设置 | 邮件发送后，发件人自己的“待办/跟进”列表里会出现这封邮件，到时间提醒 |
| 收件时设置 | 给自己收到的邮件设置后续，提醒稍后处理 |
| 收件人视角 | 能看到邮件上有旗帜，但不会在电脑上弹窗提醒 |

**注意**：后续标志**不是强制提醒**，更像是一个备忘 + 视觉提示。

### 3.3.3 分配策略

![[Pasted image 20260721141446.png]]

分配策略用来给邮件指定**保留、存档或删除规则**，主要在企业或学校邮箱（Exchange/Office 365）中使用。

| 要点 | 说明 |
|------|------|
| 作用对象 | 只影响发件人自己邮箱里的邮件副本（如“已发送邮件”） |
| 是否影响收件人 | 不影响，收件人收到的邮件由他自己的邮箱策略管理 |
| 常见策略 | 保留 1 年、保留 5 年、1 个月后存档、自动删除 |
| 个人用户 | 普通个人邮箱一般没有这个功能，或按钮灰色不可用 |

**注意**：如果邮箱管理员没有配置策略，这个按钮可能无法使用。

## 3.4 如何设置定时发送邮件？

### 3.4.1 为什么要定时发送？

定时发送不是让邮件“飞一会儿”，而是选择一个更合适的送达时间，常见原因：

- **提高被查看概率**：在对方上班后、收件箱最空的时候送达，邮件会排在较上方，更容易被看到。
- **避免打扰休息时间**：深夜或周末写完邮件，可以定时到工作时间再发送，显得更专业。
- **跨时区沟通**：给国外收件人定时到对方工作日上午发送，不用熬夜守点发。
- **提前安排**：节假日祝福、周报、会议提醒等可以提前写好，定时到合适时间发出。

**注意**：定时发送依赖 Outlook 处于运行状态。如果到点时电脑关机或 Outlook 未打开，邮件可能等到下次打开时才发送。

### 3.4.2 如何设置定时发送？

1. 写好邮件后，点击功能区 **“选项”** 选项卡。
2. 找到 **“延迟传递”** 按钮。
3. 在弹出窗口中勾选 **“传递不早于”**，设置具体日期和时间。
4. 点击 **“关闭”**。
5. 点击“发送”。邮件会先进入 **“发件箱”**，到时间自动发出。

![[Pasted image 20260721142137.png]]

### 3.4.3 取消或修改

- 发送前：如果还没点击“发送”，直接修改时间即可。
- 发送后但在定时时间前：到“发件箱”中找到邮件，双击打开后可删除或重新设置时间。

## 3.5 如何将邮件作为附件发送？

### 3.5.1 为什么要作为附件发送？

把邮件作为附件转发，而不是直接点击“转发”，主要有这些好处：

- **保留完整原始信息**：包括原始发件人、收件人、抄送、时间戳、邮件头信息等。
- **避免格式错乱**：直接转发有时会改变原邮件排版，附件形式更完整。
- **批量转发多封邮件**：可以一次性把几封邮件打包作为附件发出。
- **作为证据或存档**：需要提交邮件记录时，附件形式更正式。

### 3.5.2 方法一：复制 + 粘贴

1. 在邮件列表中，右键点击要作为附件的邮件。
2. 选择 **“复制”**（或按 `Ctrl` + `C`）。

![[Pasted image 20260721153715.png|415]]

3. 打开一封新邮件，在正文区域右键点击。
4. 选择 **“粘贴”**（或按 `Ctrl` + `V`）。
5. 原邮件就会以 `.msg` 附件的形式出现在新邮件中。

![[Pasted image 20260721153956.png]]

### 3.5.3 方法二：通过“附加项目”插入

1. 在新邮件中，点击功能区 **“邮件”** 选项卡。
2. 点击 **“附加文件”** 按钮旁的下拉箭头。
3. 选择 **“附加项目”**（Outlook Item）。

![[Pasted image 20260721153820.png]]

4. 在弹出的对话框中，选择要插入的邮件。
5. 可以选择插入为 **“附件”**（默认）或 **“文本”**。

![[Pasted image 20260721153849.png]]

6. 点击 **“确定”**，邮件就会作为附件添加。

**注意**：如果附件邮件本身也带有附件，这些附件会一并保留在原邮件中。

### 3.5.4 方法三：拖拽

1. 在邮件列表中，按住鼠标左键选中要作为附件的邮件。
2. 直接把它拖拽到新建邮件的正文区域。
3. 松开鼠标，原邮件就会以 `.msg` 附件的形式出现在新邮件中。

**注意**：如果同时选中多封邮件一起拖拽，可以一次性把多封邮件作为附件发出。

## 3.6 发错邮件后如何补救？

### 3.6.1 什么情况下能撤回？

Outlook 的“撤回邮件”功能**并不是万能的**，成功率取决于以下条件：

| 条件 | 能否撤回 |
|------|---------|
| 收件人和发件人在同一 Exchange/Office 365 组织内 | ✅ 通常可以 |
| 收件人使用 Outlook 客户端（不是网页版/手机端） | ✅ 成功率较高 |
| 收件人尚未阅读邮件 | ✅ 更有可能成功 |
| 收件人是外部邮箱（如 Gmail、QQ、163） | ❌ 几乎无法撤回 |
| 收件人已阅读或已转发 | ❌ 无法撤回 |
| 邮件已离开内部服务器 | ❌ 无法撤回 |

**总结**：撤回功能最适合在企业/学校内部 Exchange 邮箱之间使用，对外部邮箱基本无效。

### 3.6.2 如何撤回邮件？

1. 打开 Outlook 的 **“已发送邮件”** 文件夹。
2. 双击打开要撤回的邮件。
3. 点击功能区 **“邮件”** 选项卡。
4. 点击 **“操作”** → **“撤回该邮件”**。
5. 在弹出的对话框中选择：
   - **“删除未读副本”**：直接撤回，不留痕迹。
   - **“删除未读副本并用新邮件替换”**：撤回后自动打开新邮件编辑窗口。
6. 点击 **“确定”**。

![[Pasted image 20260721155113.png]]

![[Pasted image 20260721155148.png|395]]

### 3.6.3 撤回失败怎么办？

如果撤回失败或无法撤回，可以用以下方式补救：

1. **发送澄清邮件**
   - 主题写“补充说明 / 更正 / 关于上一封邮件”等。
   - 正文中明确说明上一封邮件哪里错了，正确内容是什么。

2. **重新发送正确版本**
   - 如果上一封邮件附件/内容有误，重新发送完整正确版本，并在主题中标注“以此为准”。

3. **主动联系收件人**
   - 对于重要邮件，直接打电话或发即时消息说明情况，请对方忽略上一封邮件。

### 3.6.4 注意事项

- **撤回不保证成功**：即使系统提示“撤回成功”，收件人仍可能在撤回前看到邮件。
- **已读未读判断的是对方 Outlook 里的邮件状态**：如果对方已经读过了邮件，但手动右键把它重新标记为“未读”，那么从 Outlook 撤回机制的角度看，它仍然是“未读”，理论上仍可能撤回成功。但这依赖对方的具体操作，不能作为可靠依据。
- **不要滥用撤回**：频繁撤回会显得不专业。
- **发送前检查**：养成发送前检查收件人、主题、附件、正文的习惯，减少出错概率。

# 4 如何回复邮件？

## 4.1 如何回复邮件？

### 4.1.1 回复与回复全部的区别

| 操作 | 回复对象 | 适用场景 |
|------|---------|---------|
| 答复 | 只回复给发件人 | 只想和发件人单独沟通 |
| 全部答复 | 回复给发件人 + 所有 To 和 CC 中的人 | 需要让邮件串里的所有人都看到你的回复 |

![[Pasted image 20260815145638.png]]

### 4.1.2 举例说明

假设张经理发了一封邮件：
- **发件人**：张经理
- **To**：你、小李
- **CC**：王总监

你点 **“答复”** → 你发出的邮件中：
- **To**：张经理
- **CC**：（空）

你点 **“全部答复”** → 你发出的邮件中：
- **To**：张经理、小李（原发件人 + 原 To 中的其他人）
- **CC**：王总监（原 CC 中的人）

### 4.1.3 注意事项

- “全部答复”不会发给 BCC（密件抄送）中的人——因为你根本看不到他们。
- “全部答复”时，你自己不会出现在 To/CC 中，Outlook 会自动把你去掉。
- 群邮中点“答复”前先想清楚：是否需要所有人看到，避免误用“全部答复”造成打扰。比如在 50 人的群发邮件里点“全部答复”，所有人都会收到你的回复。

## 4.2 如何转发邮件？

### 4.2.1 转发

把收到的邮件原样发给其他人，收件人可以看到原邮件的内容和附件。

![[Pasted image 20260815150718.png|577]]

| 要点 | 说明 |
|------|------|
| 原邮件内容 | 自动带入新邮件正文（含原发件人、时间等信息） |
| 原邮件附件 | 默认一并带上 |
| 你可以做的修改 | 可以补充自己的说明、删减内容、增删附件后再发 |

**适用场景**：
- 把收到的通知、资料转给需要的人。
- 把问题邮件转给能处理的人，并附上自己的说明。

**注意**：转发前检查原邮件内容，确认没有不适合给对方看的信息（如内部讨论、隐私内容）。

### 4.2.2 作为附件转发

把整封邮件作为 `.msg` 附件发送，而不是直接把内容带进正文。

| 对比项 | 普通转发 | 作为附件转发 |
|--------|---------|-------------|
| 原邮件呈现方式 | 内容显示在正文里 | 作为一个 `.msg` 附件 |
| 原始信息完整度 | 可能被改动或格式错乱 | 完整保留（发件人、时间、邮件头等） |
| 一次转发多封 | 不方便 | 可以一次附加多封邮件 |
| 对方打开方式 | 直接阅读 | 双击附件打开（需要 Outlook） |

**操作方法**（详见 [[#3.5 如何将邮件作为附件发送？]]）：
1. 复制粘贴：邮件列表中右键复制，到新邮件正文中粘贴。
2. 附加项目：新邮件中「附加文件」→「附加项目」。
3. 拖拽：直接把邮件拖进新邮件正文。

**适用场景**：
- 需要提交邮件记录作为证据或存档。
- 需要完整保留原始邮件信息时。

## 4.3 如何在邮件来回沟通中自动使用批注功能？

### 4.3.1 什么是批注功能？

在邮件来回沟通中，如果你想在**引用原邮件的正文里**插入自己的话（而不是写在最上面），可以开启批注功能：你插入的每段话前面会自动加上 `[你的名字]` 标记，别人一眼就能分清哪些是你说的、哪些是原文。

### 4.3.2 如何开启？

1. 点击「文件」→「选项」→「邮件」。
2. 找到「答复和转发」区域。

![[Pasted image 20260815151257.png|433]]

3. 勾选 **「在批注前面加上」**，并在输入框中填写你的名字（如：张三）。

![[Pasted image 20260815151417.png|449]]

4. 点击「确定」。

### 4.3.3 使用效果

- **回复和转发都能触发此效果**：无论点「答复」「全部答复」还是「转发」，只要你在引用原邮件的正文中输入内容，前面都会自动带上 `[你的名字]`。
- 多人来回讨论时，每个人的批注带各自的名字，邮件串里谁说了什么一目了然。

![[Pasted image 20260815151459.png|623]]

**举例：**

原邮件中有一段：

> 会议时间定在周三下午，请大家确认。

你在该行下方输入意见后显示为：

> 会议时间定在周三下午，请大家确认。
> [张三] 周三下午我有课，能否改到周四？

**注意**：名字填写的格式建议中英文都写上（如 `张三 San Zhang`），方便与国外同事沟通。

## 4.4 休假了如何设置自动回复？

### 4.4.1 如何设置？

1. 点击 **「文件」** →「帐户信息」页面。

![[Pasted image 20260815151959.png]]

2. 点击 **「自动答复(外出)」**。

![[Pasted image 20260815152021.png|401]]

3. 选择 **「发送自动答复」**。
4. （可选）勾选 **「只在以下时间范围内答复」**，设置开始和结束时间——到点自动开启和关闭，不用手动操作。
5. 在文本框中写好自动答复的内容。

![[Pasted image 20260815152054.png|445]]

6. 点击「确定」。

### 4.4.2 组织内与组织外分开设置

自动答复有两个选项卡，可以分别写不同的内容：

| 选项卡 | 作用 | 内容建议 |
|--------|------|---------|
| 在我的组织内 | 回复给本单位（同一 Exchange 组织）的同事 | 可以写得详细些，如休假时间、紧急联系人 |
| 在我的组织外 | 回复给外部邮箱的人 | 建议写得简略，避免泄露过多内部信息 |

### 4.4.3 注意事项

- **每个发件人只自动答复一次**：同一个人反复发邮件，只会在第一次收到自动答复，不会每次都回。
- 自动答复由 Exchange 服务器执行，**即使电脑关机、Outlook 没打开也能生效**（与定时发送不同）。
- 休假回来后记得检查并关闭自动答复（如果没设时间范围）。
- 自动答复内容建议包含：休假起止时间、紧急事务联系人及方式。
# 5 邮箱高效管理

## 5.1 如何设置邮件以会话形式显示？

### 5.1.1 什么是会话（对话）视图？

把同一主题来回沟通的邮件**折叠成一组**显示，而不是按时间一封封散开。点开会话可以展开看到整串邮件的往来记录，适合跟踪多人讨论的邮件串。

![[Pasted image 20260817111712.png]]

![[Pasted image 20260817111729.png]]

### 5.1.2 如何开启？

1. 点击功能区 **「视图」** 选项卡。

![[Pasted image 20260817111233.png]]

2. 在「邮件」区域勾选 **「显示为对话」**。

![[Pasted image 20260817111317.png]]

3. 在弹出的对话框中选择应用范围：
   - **此文件夹**：只当前文件夹（如收件箱）生效。
   - **所有邮箱**：所有文件夹都生效。

![[Pasted image 20260817111407.png]]

4. 勾选后可通过下方的 **「对话设置」** 微调显示方式（如是否显示其他文件夹中的邮件、是否始终展开等）。

### 5.1.3 注意事项

- 同一「对话」是按**邮件主题和邮件头中的引用关系**归组的，主题改了可能会被拆成不同对话。

## 5.2 如何设置需要跟进的邮件为 Follow-up 并设置提醒？

### 5.2.1 什么是 Follow-up（后续标志）？

给需要跟进的邮件打上一个**小旗帜标记**，提醒自己稍后处理。标记后的邮件会进入「待办事项」列表，还可以设置到点弹窗提醒。

### 5.2.2 如何设置？

1. 在邮件列表中，**右键点击**要标记的邮件（或直接点击邮件右侧的旗帜图标，默认为「今天」）。

![[Pasted image 20260817114315.png|309]]

2. 在菜单中选择跟进时间：
   - **今天 / 明天 / 本周 / 下周 / 无日期**：快速设置。
   - **自定义**：自由设置标志名称、开始日期、截止日期。

![[Pasted image 20260817114337.png|379]]

3. 如需到点提醒，点击 **「添加提醒」**，在弹出的「自定义」窗口中：
   - 设置 **开始日期 / 截止日期**。
   - 勾选 **「提醒」**，选择具体日期和时间（到点会弹窗提醒）。

![[Pasted image 20260817114407.png|377]]

![[Pasted image 20260817114431.png|390]]

4. 点击「确定」。

### 5.2.3 标记后的管理

| 操作 | 说明 |
|------|------|
| 标记完成 | 事情办完后点「标记完成」，旗帜变成对勾，邮件不再出现在待办中 |
| 清除标记 | 点「清除标记」直接去掉旗帜 |
| 设置快速单击 | 可自定义单击旗帜图标时的默认行为（默认是「今天」） |

### 5.2.4 注意事项

- 带提醒的邮件，到点时 **Outlook 必须处于打开状态**才会弹窗提醒。
- 提醒弹窗可以选「消除」（不再提醒）或「暂缓」（稍后再次提醒）。
- 所有带旗帜的邮件可以在「待办事项」中统一查看，也可以建搜索文件夹集中管理（见 5.3）。

## 5.3 如何创建 Follow-up 搜索文件夹？

### 5.3.1 什么是搜索文件夹

搜索文件夹是一种**虚拟文件夹**：它按设定的条件把所有符合条件的邮件聚合在一起显示，但邮件本体仍留在原来的文件夹里，不会被移动或复制。

![[Pasted image 20260817115634.png|201]]

### 5.3.2 如何创建

![[Pasted image 20260817115903.png|224]]

![[Pasted image 20260817115936.png|276]]

1. 点击功能区 **「文件夹」** 选项卡 → **「新建搜索文件夹」**。
2. 在列表中选择 **「已标记待跟进的邮件」**（Mail flagged for follow up）。
3. 点击「确定」。创建后它会出现在左侧导航窗格的 **「搜索文件夹」** 下，所有带 Follow-up 旗帜的邮件都会集中显示在这里。

### 5.3.3 注意事项

- 删除搜索文件夹**不会删除邮件本体**，只是取消这个聚合视图。

## 5.4 如何保存某封邮件？

### 5.4.1 另存为文件

![[Pasted image 20260817121428.png|700]]

1. 双击打开要保存的邮件。
2. 点击 **「文件」** → **「另存为」**（快捷键：`F12`）。
3. 选择保存位置和格式：

## 5.5 如何设置邮件存档？

### 5.5.1 什么是存档？

存档是把**旧邮件从邮箱中移入本地的 `.pst` 数据文件**里，从而释放服务器邮箱空间。存档后的邮件仍可在 Outlook 左侧的存档数据文件中查看和搜索。

### 5.5.2 第一步：新建 .pst 数据文件

1. 点击 **「文件」**。

![[Pasted image 20260817122106.png]]

2. 在「信息」页面点击 **「帐户设置」** → **「帐户设置(A)...」**。

![[Pasted image 20260817122141.png]]

3. 在弹出的窗口中切换到 **「数据文件」** 选项卡，点击 **「添加(A)...」**。

![[Pasted image 20260817122213.png]]

4. 选择保存位置并命名（如"我的 Outlook 数据文件.pst"），点击确定。新建的 .pst 会出现在数据文件列表中。

![[Pasted image 20260817122333.png]]

**说明**：这个 `.pst` 就是存放存档邮件的"容器"，建议保存在**非系统盘**。

### 5.5.3 第二步：执行存档

1. 点击 **「文件」** → **「信息」** → **「工具」** → **「清理旧项目(C)...」**。

![[Pasted image 20260817122736.png|431]]

2. 在「存档」对话框中：
   - 选择 **「将该文件夹及其子文件夹存档」**，在列表中选中要存档的文件夹（如"收件箱"）。
   - 设置 **「将早于该时间的项目存档」** 的日期（早于该日期的邮件才会被存档）。
   - 在「存档文件」处点 **「浏览(B)...」**，选择上一步新建的 .pst 文件。

![[Pasted image 20260817122853.png|355]]

![[Pasted image 20260817122919.png|581]]

3. 点击 **「确定」** 开始存档。存档期间状态栏会显示进度（如"正在存档收件箱"）。

![[Pasted image 20260817123209.png]]

**注意**：存档是**移动**不是复制——存档后，邮箱里的原邮件会被移走，只能在 .pst 中查看。

### 5.5.4 第三步：关闭与重新打开存档文件

- **关闭**：在左侧文件夹列表中右键 .pst 数据文件 → **「关闭"我的 Outlook 数据文件"」**。这只是让它不在 Outlook 中显示，文件仍保存在硬盘上。

![[Pasted image 20260817123548.png]]

- **重新打开**：点击 **「文件」** → **「打开和导出」** → **「打开 Outlook 数据文件」**，选择 .pst 文件即可重新查看存档邮件。

![[Pasted image 20260817123708.png]]

### 5.5.5 补充：自动存档

除了手动存档，还可以让 Outlook 定期自动存档：

1. 点击 **「文件」** → **「选项」** → **「高级」** → **「自动存档设置」**。
2. 勾选「每隔 N 天运行自动存档」，设置存档周期、旧邮件标准和 `.pst` 保存位置。

**注意**：自动存档同样把邮件移入本地 `.pst`，`.pst` 的备份要求与手动存档相同（见 5.5.6）。

### 5.5.6 注意事项

- **新建的 .pst 只保存在本地硬盘**：以后重装电脑时，必须提前把 .pst 文件复制一份到非系统盘/U盘/网盘，否则存档邮件会全部丢失（详见 [[#10.1 备份邮件存档]]）。
- 存档是移动操作，存档前确认目标文件夹选对了。
- 企业 Exchange 邮箱的存档可能被管理员策略接管（如服务器端存档），此时本地存档方式可能不可用。

## 5.6 如何搜索需要的邮件？

### 5.6.1 即时搜索框

![[Pasted image 20260817125346.png]]

1. 点击邮件列表上方的搜索框（或按 `Ctrl` + `E`）。
2. 输入关键词，结果即时筛选显示。
3. 在搜索框右侧可切换搜索范围：**当前文件夹 / 当前邮箱 / 所有邮箱**。

### 5.6.2 搜索工具选项卡

![[Pasted image 20260817125404.png]]

点击搜索框后，功能区会出现 **「搜索」** 选项卡，可按以下条件组合筛选：发件人、主题、有无附件、时间范围、是否未读、是否带标志等。

### 5.6.3 常用搜索语法

直接在搜索框输入语法，比逐项点击更快：

| 语法 | 作用 |
|------|------|
| `from:张三` | 搜索发件人为张三的邮件 |
| `subject:报告` | 搜索主题含「报告」的邮件 |
| `hasattachments:yes` | 只搜索带附件的邮件 |
| `received:>=2026/8/1` | 搜索 8 月 1 日之后收到的邮件 |
| `hasflag:yes` | 搜索带 Follow-up 标志的邮件 |

**注意**：日期格式随系统区域设置（如中文系统是 `2026/8/1`），多个条件可用空格组合，如 `from:张三 hasattachments:yes`。

# 6 如何自定义日历？

## 6.1 如何添加双时区？

1. 点击 **「文件」** → **「选项」** → **「日历」**。
2. 在 **「时区」** 区域，为主时区输入标签（如「北京」）。
3. 勾选 **「显示第二个时区」**，选择对方所在时区并输入标签（如「纽约」）。
4. 点击「确定」。

**注意**：适合跨时区协作（如与国外同事约会议）。约会时间仍按主时区理解，日历左侧的时区栏会并排显示两个时区，方便对照。

## 6.2 如何显示农历及法定节假日？

1. 点击 **「文件」** → **「选项」** → **「日历」**。
2. 勾选 **「启用备用日历」**，选择 **「农历（中文）」**，日历日期旁会显示农历。
3. 点击 **「添加节假日」**，勾选 **「中国」**，导入法定节假日。

**注意**：节假日会以**全天事件**的形式出现在日历上；重复添加会导致节假日重复显示，不要多次导入。

## 6.3 如何修改日常工作时间？

1. 点击 **「文件」** → **「选项」** → **「日历」**。
2. 在 **「工作时间」** 区域设置：
   - **开始时间 / 结束时间**：如 9:00 - 18:00。
   - **工作周**：勾选周一到周五。
   - **每周第一天 / 每年第一周**：按习惯选择。

**注意**：工作时间会影响日历中工作时段的底色显示；组织内同事用调度助手查看你的忙闲时，也以此为参考。

## 6.4 如何在日历上显示周数？

1. 点击 **「文件」** → **「选项」** → **「日历」**。
2. 在 **「显示选项」** 区域勾选 **「在月视图和日期导航中显示周数」**。
3. 点击「确定」，月视图每行左侧会出现「第 N 周」编号。

**用途**：适合按「第几周」安排工作的人，如学校教学周、项目迭代周。

# 7 如何新建及管理会议邀请？

## 7.1 如何新建会议邀请？

1. 点击 **「开始」** → **「新建项目」** → **「会议」**（或在日历中按 `Ctrl` + `Shift` + `Q`）。
2. 填写与会人（To）、主题、地点、起止时间和正文。
3. 点击 **「发送」**，与会人会收到会议邀请邮件。

### 7.1.1 如何查看与会人可用时间？

1. 在会议窗口中点击 **「调度助手」**。
2. 网格中会显示每位与会人的忙闲时段（蓝色为忙碌）。
3. 拖动选择大家都有空的时间段，或点击 **「自动选取下一个」** 让 Outlook 自动找最近的全员空闲时间。

**注意**：调度助手查忙闲依赖对方用 Outlook 日历记录日程；对方日历为空不代表真的有空。

### 7.1.2 如何预定会议室？

1. 在会议窗口的「地点」处点击 **「会议室」** 按钮。
2. Exchange 环境下会列出可用的会议室资源邮箱，选择容量和位置合适的会议室。
3. 会议室会作为**资源与会人**加入，根据冲突情况自动接受或拒绝邀请。

**注意**：会议室功能需要管理员事先配置资源邮箱；同时记得在调度助手中确认会议室本身没被占用。

## 7.2 收到会议邀请如何响应？

收到邀请邮件后，阅读窗格顶部有三个响应按钮：

| 响应 | 含义 |
|------|------|
| 接受 | 确定参加，会议进入自己的日历 |
| 暂定 | 可能参加，日历中标记为待定 |
| 拒绝 | 不参加，会议不进入日历 |

每种响应都可选三种发送方式：**立即发送响应**、**不发送响应**、**编辑响应后发送**（可附上一句话说明）。

**注意**：

- 接受后会议自动进入自己的日历，无需手动添加。
- 时间冲突无法参加时，建议点 **「建议新时间」** 或在答复中说明原因，比直接拒绝更礼貌。

## 7.3 如何查看与会者响应情况？

1. 组织者在自己日历中**双击打开该会议**。
2. 点击 **「跟踪」**（或「会议」选项卡中的「跟踪」）。
3. 列表中会显示每位与会人的状态：**接受 / 暂定 / 拒绝 / 未响应**。

**注意**：

- **只有组织者**能看到跟踪页，普通与会人看不到。
- 如果与会人响应时选了「不发送响应」，组织者这里会一直显示「无响应」，不代表对方没看。

## 7.4 如何修改会议邀请？

1. 组织者双击日历中的会议，修改时间、地点或内容。
2. 点击 **「发送更新」**，所有与会人会收到更新通知，各自日历自动同步。

**注意**：

- **只有组织者**能修改会议，与会人只能改自己日历里的备注/提醒。
- 与会人添加个人备注后保存时，可选择**不发送更新**（避免打扰其他人）。
- 取消会议用 **「取消会议」** 按钮并发送取消通知，会议会从所有人日历中移除。

# 8 如何管理联系人？

## 8.1 Outlook 通讯录及区别？

| 类型 | 存储位置 | 特点 |
|------|---------|------|
| 联系人 | 本地个人通讯录 | 自己创建和维护，可增删改，重装电脑会丢失（需导出备份） |
| 全球通讯簿（GAL） | Exchange 服务器 | 组织内全员名单，由管理员维护，**只读**，不能自己添加 |
| 自动完成列表 | 本地缓存 | 输入收件人时弹出的历史建议，随使用自动积累 |

**注意**：外部联系人（客户、供应商等）不在 GAL 中，需要手动添加到「联系人」（见 8.2）。

## 8.2 如何添加外部联系人到本地通讯录？

**方法一：手动新建**

1. 切换到 **「人员」** 视图（左侧导航窗格）。
2. 点击 **「新建联系人」**，填写姓名、邮箱、电话、公司等信息。
3. 点击「保存并关闭」。

**方法二：从收到的邮件添加（推荐）**

1. 打开对方发来的邮件。
2. **右键点击发件人地址** → 选择 **「添加到 Outlook 联系人」**。
3. 邮箱地址会自动带入，补充其他信息后保存。

**注意**：方法二最快捷，邮箱地址不会抄错；建议及时补充姓名和公司，方便以后搜索。

## 8.3 如何添加本地联系人组？

1. 在 **「人员」** 视图中点击 **「新建联系人组」**。
2. 输入组名（如「项目组」）。
3. 点击 **「添加成员」**，可从通讯录选择或新建联系人加入。
4. 点击「保存并关闭」。

**用途**：给一组人群发邮件时，收件人栏直接输入组名即可；组成员变动时只需改组，不用改每封邮件。

**注意**：

- 联系人组**仅自己可见**，保存在本地联系人中。
- 收件人展开组名后能看到组内所有成员地址，介意隐私时请改用 BCC（见 [[#3.2 to（收件人） / cc（抄送） / bcc（密件抄送） 的区别]]）。

## 8.4 如何导出和导入本地通讯录？

**导出：**

1. 点击 **「文件」** → **「打开和导出」** → **「导入/导出」**。
2. 选择 **「导出到文件」** → **「逗号分隔值」（CSV）**。
3. 选择 **「联系人」** 文件夹，指定保存位置完成导出。

**导入：**

1. 同一向导中选择 **「从另一程序或文件导入」** → **「逗号分隔值」**。
2. 选择 CSV 文件，按需**映射字段**后完成导入。

**注意**：重装电脑前必做此项备份（见 [[#10.2 重装前导出重装后导入本地通讯录]]）；CSV 文件可用 Excel 打开编辑，适合批量整理后再导入。

# 9 做好助理必会技能

## 9.1 如何创建来自老板的邮件以绿色显示？

1. 在收件箱中点击 **「视图」** → **「视图设置」** → **「条件格式」**。
2. 点击 **「添加」**，给规则命名（如「老板」）。
3. 点击 **「字体」**，把颜色设为绿色。
4. 点击 **「条件」**，在「发件人」处填老板的姓名或邮箱。
5. 一路「确定」完成，来自老板的邮件即会以绿色显示，一眼可辨。

**注意**：条件格式规则**按视图保存**，只影响当前视图；可同法为重要客户设置其他颜色。

## 9.2 如何设置老板的 Outlook 授权？

以下操作在**老板自己的电脑**上进行：

1. 点击 **「文件」** → **「信息」** → **「帐户设置」** → **「代理人访问」**。
2. 点击 **「添加」**，选择助理的姓名。
3. 分别为日历、任务、收件箱等设置权限级别：

| 权限级别 | 能做什么 |
|---------|---------|
| 审阅者 | 只能查看，不能改动 |
| 作者 | 可以查看并新建项目（如代建约会） |
| 编辑者 | 可以查看、新建、修改、删除 |

**注意**：授权的是**老板自己的邮箱**，不是助理的；此功能仅 Exchange 环境支持。

## 9.3 如何查看老板日历行程？

以下操作在**助理的电脑**上进行：

1. 切换到 **「日历」** 视图。
2. 点击 **「打开日历」** → **「打开共享日历」**。
3. 输入老板的姓名或邮箱，点击「确定」。

**注意**：

- 前提是老板已按 9.2 授权（日历权限至少为「审阅者」）。
- 打开后老板的日历会出现在「共享日历」组，可与自己的日历**并排显示或重叠显示**，方便对照安排。

## 9.4 如何以老板名义发送邮件？

1. 打开一封**新邮件**。
2. 点击 **「选项」** 选项卡，勾选显示 **「发件人」（From）** 字段。
3. 在 From 处选择老板的邮箱。
4. 正常撰写内容并发送。

**注意**：

- 前提是老板已授予 **「代表发送」（Send on Behalf）** 权限。
- 收件人看到的发件人会显示 **「助理 代表 老板」**。
- 如需完全以老板身份发出（不显示"代表"字样），需要 **「发送身份」（Send As）** 权限，由 Exchange 管理员配置。

# 10 重装电脑要注意事项

## 10.1 备份邮件存档

**方法一：导出为 .pst**

1. 点击 **「文件」** → **「打开和导出」** → **「导入/导出」**。
2. 选择 **「导出到文件」** → **「Outlook 数据文件(.pst)」**。
3. 勾选要备份的文件夹（可含子文件夹），指定保存位置完成导出。

**方法二：直接复制 .pst 文件**

1. 点击 **「文件」** → **「信息」** → **「帐户设置」** → **「数据文件」**，查看 .pst 文件的实际路径。
2. **关闭 Outlook** 后，到该路径复制 .pst 文件到备份位置。

**注意**：Exchange 邮箱的邮件保存在服务器上，重装后重新配置帐户即可同步；但**本地存档 .pst、规则、签名**只存在本地，必须手动备份。

## 10.2 重装前导出重装后导入本地通讯录

方法见 [[#8.4 如何导出和导入本地通讯录？]]：重装前把「联系人」导出为 CSV 备份，重装后用同一向导导入即可。

**注意**：导出的 CSV 文件请放在**非系统盘、U 盘或网盘**，重装系统会清空系统盘数据。

## 10.3 重装后重设邮件签名

签名保存在本地（`%APPDATA%\Microsoft\Signatures`），重装后会丢失，需按 [[#2.1 什么是邮件签名，如何自定义邮件签名？]] 的方法重新创建。

**建议**：重装前可把 Signatures 文件夹**整体备份**，装回系统后直接拷回原路径，签名即可恢复，无需重建。
