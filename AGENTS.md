# Project Conventions

## Bilingual content sync

Most course content exists in paired Chinese and English versions (e.g. `python/python-中文版/` ↔ `python/python-english-version/`, `devops/network-basics/网络基础-中文版/` ↔ `devops/network-basics/network-basics-english-version/`).

**Any content modification requested by the user must be applied identically to both language versions** — same structural change in both, with prose translated accordingly. Code blocks, commands, and code comments stay in English in both versions.

## Conventions within each language pair

- File names: numbered chapters, Chinese names in the Chinese folder, English names in the English folder (e.g. `01-网络基础.md` ↔ `01-networking-fundamentals.md`).
- Each folder has a `README.md` with a table of contents in that folder's language.
- Chapter files carry navigation links at top/bottom, in the folder's language, pointing to that folder's file names.
- Section numbering (e.g. `1.1.2`) is identical across languages.
