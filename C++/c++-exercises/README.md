# C++ Exercises

This folder contains practice exercises designed to reinforce the concepts covered in the `c++-english-version` notes.

## How to Use These Exercises

1. **Read the chapter first** — Complete the reading for the relevant phase before attempting exercises.
2. **Write code by hand** — Do not copy-paste. Type every line yourself.
3. **Compile and run** — Every code exercise must compile without errors and produce the expected output.
4. **Use a debugger** — If something goes wrong, use `gdb` or your IDE debugger to investigate.
5. **Compare with solutions** — After completing an exercise, review your solution critically. Is it clean? Efficient? Safe?
