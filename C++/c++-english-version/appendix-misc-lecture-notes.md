### Course Coverage

The course is designed to teach C++ fundamentals, commonly used data structures, and practical problem solving. Planned technical topics include:

- C++ grammar: variables, data types, expressions, flow control, functions
- Abstraction and encapsulation via classes
- Basic algorithmic analysis
- Classic data structures: lists, stacks, queues
- Sorting algorithms
- Trees and binary search trees (BST)
- Hash tables
- Graphs
