# Computer Architecture & Parallel Computing — English Version

Study notes on computer architecture and parallel computing, covering instruction sets, pipelining, memory hierarchy, cache coherence, parallel programming models, and GPU computing.

## Table of Contents

> Notes are updated as learning progresses; the chapter structure below is the planned outline.

### Part 1: Computer Architecture Fundamentals
1. Computer System Overview — *Hardware components, von Neumann architecture, performance metrics*
2. Data Representation & Instruction Sets — *Number systems & encoding, ISA, RISC vs CISC*
3. Processors & Pipelining — *Datapath, pipeline, hazards & branch prediction*

### Part 2: Memory Hierarchy
4. Cache & Memory Hierarchy — *Locality, cache organization, mapping & replacement policies*
5. Virtual Memory — *Paging, TLB, address translation*

### Part 3: Parallel Computing
6. Parallel Computing Fundamentals — *Levels of parallelism, Amdahl's law, Flynn's taxonomy*
7. Shared-Memory Parallelism — *Threads, locks, OpenMP*
8. Message-Passing Parallelism — *MPI, distributed-memory model*
9. GPU & Heterogeneous Computing — *CUDA basics, SIMT, memory model*
10. Cache Coherence & Memory Models — *MESI, memory ordering, synchronization primitives*
