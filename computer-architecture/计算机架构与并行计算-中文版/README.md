# 计算机架构与并行计算 中文版

计算机架构与并行计算学习笔记，涵盖指令集、流水线、存储层次、缓存一致性、并行编程模型与 GPU 计算等主题。

## 目录

> 笔记随学习进度持续补充，以下为规划中的章节结构。

### 第一部分：计算机架构基础
1. 计算机系统概述 — *硬件组成、冯·诺依曼结构、性能指标*
2. 数据表示与指令集 — *数制与编码、ISA、RISC 与 CISC*
3. 处理器与流水线 — *数据通路、流水线、冒险与分支预测*

### 第二部分：存储层次
4. 缓存与存储层次 — *局部性、Cache 组织、映射与替换策略*
5. 虚拟内存 — *分页、TLB、地址翻译*

### 第三部分：并行计算
6. 并行计算基础 — *并行性层次、Amdahl 定律、Flynn 分类*
7. 共享内存并行 — *线程、锁、OpenMP*
8. 消息传递并行 — *MPI、分布式内存模型*
9. GPU 与异构计算 — *CUDA 基础、SIMT、内存模型*
10. 缓存一致性与内存模型 — *MESI、内存序、同步原语*
